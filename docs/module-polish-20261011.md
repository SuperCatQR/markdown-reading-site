# 各模块细节打磨

本轮依据 `docs/product-philosophy.md` 的阅读、查找、复习与核验定位，服务复习者、连续学习者、文字读者、引用者及校对贡献者。继续使用紧凑资料库入口，冻结正文、来源、版本及审核和正式发布事实遵守 README 当前内容契约。

## 已交付

| 模块 | 具体改善 |
| --- | --- |
| 资料库与搜索 | 浏览展开不误称命中；查找方式默认可见，解释当前语义；综合查询提供正文证据或标题相关排序；清除查询保留其他条件；加载状态可感知。 |
| 阅读与目录 | 返回链接描述原搜索上下文；键盘跳到正文不改变路由；连续阅读更新活动目录的辅助语义和标题；右栏开关在布局稳定后恢复规范段落及偏移。 |
| 视频内查找 | 当前 P / 全视频范围；上一处与下一处的边界；跨未加载 P 保留查询；切换工具后后台查找仍可完成；快速连续跳转以最后目标为准；跨失败导航不复用过期会话。 |
| 最近阅读 | 同时展示近期相对时间及实际时间，保留准确 ISO datetime；版本失效与内容撤回原因继续可管理。 |
| 工具与排版 | 工具标题及关闭按钮保持可见；恢复默认字号、行宽、行距、字体并保留主题和段落；输入焦点、折叠指示和小屏布局细化。 |
| 复制与下载 | 准确版本的段落分享；当前正文或参照的完整原始 Markdown 复制及下载；连续阅读按可见 P 取源；失败显示完整手动文本；UTF-8 BOM、CRLF 保留，非法 UTF-8 拒绝且可重试。 |
| 修改建议 | 反馈对象、准确版本和段落前置；字段用途、实时计数和有效状态；选中原句可带入上下文并关联选区段落；超限输入供修正，不截断；修改后旧 Issue 链接失效，迟到复制结果不宣称已复制新草稿。 |

## 验证

- 单元测试 `pnpm test`：178 项。
- `scripts/accept-site-browser.py`：37 项实际阅读任务，包括 320–2048px，正文、参照、连续阅读、故障恢复、侧栏空间及规范段落恢复。
- `scripts/accept-discovery-browser.py`：查找、范围与排序、清除、最近阅读、跨 P、快速点击、延迟与故障重试。
- `scripts/accept-feedback-browser.py`：选区、实时校验、过期预填链接、复制失败、长文本、明暗主题及固定关闭。
- `scripts/accept-document-actions-browser.py`：真实网络原文件与复制及下载字节一致，正文与参照分别验证；当前 P 身份、排版复位与键盘入口。
- `scripts/check-refactor-search.mjs`：实际查询仍与共享核心结果一致。
- 构建及 `scripts/check-refactor-assets.mjs`：4476 个稿件资源，2984 个 Markdown 文件共 168257720 字节，均与冻结快照一致。

上述浏览器脚本以部署子路径的生产构建运行，并接入 GitHub Actions。具体运行结果由流水线 artifact 中各 `report.json` 保存；本文件描述本轮交付范围，不替代未来部署的验收结果。

## 边界

复制与下载按当前准确版本的原始文件交付，不改写 Markdown。建议仍由读者在 GitHub 确认提交。阅读记录和设置属于本机浏览器，建议草稿属于当前会话；跨设备同步、人工定义的跨视频系列及在线协作未在本轮实现。宽泛查询仍可能读取较多正文分片；构建保留现有主包体积警告。
