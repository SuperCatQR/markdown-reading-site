# 访客体验修复说明

日期：2026-10-10。依据在线站点的真实桌面、手机访问检查，改善进入内容、找回概念与持续阅读的任务。保留安静资料室的方向，遵循产品原则中的内容优先、中文阅读优先、辅助信息按需展开、手机和键盘可用及准确版本关联。

## 实现与边界

| 原问题 | 修复后的行为 | 服务的任务 |
| --- | --- | --- |
| 深色模式当前导航不明显 | 当前项使用各主题的强调文字、浅底与底线 | 辨认所在入口 |
| `q` 只有不换行空格，看起来空却显示清空按钮 | 路由、状态和分享 URL 把纯空白处理为空；保留有效输入中的空格和 IME 合成 | 正确开始查找 |
| 手机首页、正文前辅助控制过多 | 单行站点页头；来源、稿件详情和核验按需展开；减少重复导航 | 首屏开始阅读 |
| 全量源标签难以浏览 | 默认 12 个常用标签；数量按不同 BV 视频去重；搜索全部标签，分批增加 48 个 | 找到相关主题 |
| 标题排序藏在高级查找 | 有查询时直接显示结果排序；保留正文优先默认与原句、关键词的准入规则 | 判断与调整相关性 |
| 多段命中证据过长 | 默认一段较短证据，其他段落可展开；所有链接仍绑定真实正文命中 | 快速筛选后查证上下文 |
| 无小标题长文难以定位且没有排版设置 | 原文目录或明确标注的段落导览；字号、行距、宽度、字体设置保存于当前浏览器 | 自主阅读与再次定位 |
| 跳到命中后难以辨认篇目和查询 | 固定栏显示篇目入口；手机可展开完整标题；命中栏保留查询；连续阅读更新可见 P | 理解阅读位置 |
| 分 P 跳跃容易误认为顺序断裂 | 标注本站尚未收录的前置和中间范围；“下一个已收录部分”；顶部可进入连续阅读 | 正确理解收录范围并继续 |
| 主题弹层 Escape 无效 | Escape 关闭并恢复入口焦点，点击外部关闭，主要弹层互斥 | 键盘与触摸操作 |

主导航围绕全部内容、主题、最近阅读组织；发布状态仍通过明确筛选及逐篇真实状态区分。最近阅读没有记录时，仅在访问该入口后说明当前浏览器尚无记录。

段落导览用现有解析器生成的正文块 ID、原文顺序与开头摘录，每组最多十个定位入口。它不是编辑章节、概念摘要或学习顺序。冻结 Markdown、来源标签、整理说明、审核状态、版本及内容哈希未修改。真实章节、摘要、系列说明和缺失稿件仍需上游编辑、审核及快照导出。排版设置不提供跨设备同步，存储失败不会宣称已保存。

使用系统字体回退，移除阻塞或失败的外部字体请求。正常正文保留中文长文的阅读节奏；排版设置同时作用于单篇正文、参照视图与连续阅读，但不改变内容或锚点。

## 验证

- `pnpm test`：101 项单元及契约回归，覆盖源标签去重、纯空白查询、准确锚点、编号间隔、设置清洗与存储失败、短证据保留全部链接，以及既有来源、搜索、版本和贡献者契约。
- `pnpm build`：两类快照校验与生产构建；内容目录未修改。
- 按 GitHub Pages 的 `VITE_BASE_PATH=/markdown-reading-site/` 构建并预览该子路径，复测手机搜索、主题、320px 分 P 弹层、排版与导览、校验参照查找、准确版本反馈和空发布目录；没有运行时异常或 HTTP 失败。
- `scripts/verify-visitor-experience.browser.js`：在本地 Vite 服务上用 Playwright CLI 执行；390×844 触摸上下文、320×700 窄屏及 1440×900 桌面尺寸。覆盖真实内容查找、标题排序、目录往返、主题 Escape/外部关闭、深色导航、排版保存与失败、导览与设置组合、正文定位、稀疏 P 与连续阅读、行宽及无运行时异常。
- 390×844 新访客测试：首页第一条内容位置从在线约 503px 提前到本地约 377px；同篇正文第一段从约 514px 提前到 319px。数值受内容标题、字体回退、视口和最近阅读状态影响，不是所有页面的固定保证。
- 排版测试将正文第四块定位于固定栏下，切换字号、行距、字体并关闭后，段落顶部由 76.14px 保持到 76.03px；导览 → 排版 → 返回阅读处及连续模式也通过。
- 独立代码评审发现并修复了顶部连续阅读入口被收起的问题。将新增设置清洗条件取反后，回归测试正确失败；已恢复原实现。

