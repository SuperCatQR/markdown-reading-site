## 加载成本与边界

初始 JS 从 4,406.24 kB 降至 1,389.90 kB（gzip 452.75 kB），独立目录摘要从 2,577.85 kB 降至 98.18 kB（gzip 31.72 kB）。目前初始化轻目录身份 JSON 为 1,076,625 字节；Vite 大于 500kB chunk 警告仍如实保留，不通过调高阈值隐藏。

CPU 查询解码 JSON 从全库 47,697,829 字节降为候选+分片 5,612,954 字节，减少约 88.2%；CPU/cpu 结果等价。广泛关键词“存在 自由”仍读取 30,806,462 字节和 533 个请求；这次取消了强制全库加载与无界缓存，但不声称任何查询都低成本。缓存只对完成成功数据生效，超预算资源不缓存。实际网络时间依托管和连接而变化。

覆盖 Chromium 149.0.7827.55、桌面和模拟 320/390/900/901/1440/2048px 布局，未声称真实手机、Firefox、WebKit、完整 WCAG 或安全审计通过。npmjs 依赖审计重试仍 ECONNRESET/timeout，保留 `.tmp/site-fixed-audit.log`，不能据此宣称无漏洞。

旧未接线 UI 的物理清理仍属于重构计划 G；当前生产仅加载新入口，没有双路由兼容层。未改动维护者独立的 `docs/automatic-topics-design.md`。
