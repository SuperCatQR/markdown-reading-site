# 贡献者体验修复：#70–#73

本轮服务校对贡献者和查证读者，改善“找到正文原句 → 核对参照 → 整理建议 → 返回阅读”的任务。依据 [项目哲学](product-philosophy.md) 的版本准确性、渐进展开、独立前端及连续阅读原则。当前实现继续遵守 README 的 v2 快照契约；没有改变稿件文件、catalog、manifest、审核或发布事实。universal-v3 的独立升级计划不构成本轮完成状态。

## 实现与边界

| Issue | 当前行为 | 边界 |
| --- | --- | --- |
| [#70](https://github.com/SuperCatQR/markdown-reading-site/issues/70) | 页头“核对”及正文/参照切换按实际段落捕获位置；在参照的整理稿中进行唯一文本匹配；返回原查询、锚点与连续阅读状态。后退与刷新保留历史中的版本绑定。 | 只统一空白，不猜测语义或复用段落序号。重复文本列出候选；无法匹配时保留原句并提供参照内查找。完整稿件/两份文件/发布身份变化后不复用证据。 |
| [#71](https://github.com/SuperCatQR/markdown-reading-site/issues/71) | 页头“纠错”和“反馈这一段”打开原生模态面板，带入选中文本或段落；填写上下文、建议与理由，复制完整文本或前往 GitHub。 | 无需登录可整理与复制，GitHub 提交仍需登录。当前会话保存最多 10 份、每字段 4000 字符；正文与参照分开，存储失败明确提示。编码后 URL 超过 7000 字符时改为复制粘贴，不截断证据；复制失败展开并选中完整文本。 |
| [#72](https://github.com/SuperCatQR/markdown-reading-site/issues/72) | 已识别模板的技术信息默认折叠；原文、整理稿和疑点分层，来源回看链接避免断字。保留原锚点、未知附录和完整原文入口。 | 只做安全 Markdown 展示，复制保留完整原文件。未知或缺少必要段落字段的模板回退到完整普通展示；没有猜测来源时间。 |
| [#73](https://github.com/SuperCatQR/markdown-reading-site/issues/73) | 参照页顶部“查找”只检索已加载参照，提供段落命中数、前后切换、突出显示和隐藏内容展开；结束后恢复阅读位置及原折叠状态。 | 字面文本匹配，计数单位是命中段落。独立于目录/视频正文索引，不额外请求搜索文件，不将核验工具位置写入正文阅读进度。 |

反馈没有自动提交或改写文章。参照中的 AI 基线说明与关联稿件当前审核状态继续分别表达。

## 验证

纯函数测试覆盖全部 583 份当前参照的块保留，以及未知模板、未知附录、危险 Markdown、唯一/重复/编辑后无法匹配、版本维度、反馈长链接和损坏/禁止存储。冻结内容通过原有构建校验；没有添加内容兼容回退。

浏览器回归脚本：

- `scripts/check-contributor-browser.js`：真实稿件的正文 `passage-2` → 参照 `passage-14` → 原正文位置，后退/刷新、参照独有词“公共实践性体验”、疑点、收起的生成信息、选中文本、暂存及复制失败；1440、390、320px 的两种主题和触控尺寸。
- `scripts/check-contributor-edge-browser.js`：仅在测试浏览器中拦截参照响应，验证重复候选、零匹配、旧版本、未知模板、原文复制及注入防护、禁止存储、长 URL、连续阅读往返及窄屏分 P 菜单。没有修改真实快照。
- 原有 `scripts/check-reader-browser.js` 与 `scripts/check-tool-progress-browser.js`：普通目录/正文流程和 390px 手机工具往返、阅读进度保护。

固定测量样例为 `edition-18e76d4ae0464b0fa478507531463970`，截图在 `artifacts/contributor-review-{width}-{theme}.png`。字体加载完成后从页顶测量首个对照组标题；旧值来自线上审计，本轮值来自本地开发环境，属于该样例的布局验证，不是全站性能或所有标题高度的保证。

本轮 `pnpm test` 为 95/95，`pnpm validate` 与子路径 `pnpm build` 通过。上述四个浏览器回归脚本通过。五维代码检查覆盖行为正确性、模块边界、安全 Markdown/文本插入、工具与阅读进度生命周期、按需加载；将唯一匹配条件临时反转后，测试确实失败，再恢复文件并重新跑通 95 项，确认测试能够发现误匹配。
