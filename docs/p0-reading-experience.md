# P0 阅读体验交付说明

本次改动依据 [项目哲学](product-philosophy.md)，服务内容查找者、连续学习者、文字读者与查证者。目标是让读者发现可读内容、区分同视频的分 P、定位搜索上下文、连续阅读，并在返回目录时继续探索。

## 六项 P0 的实现

| 产品要求 | 当前行为 | 主要实现 |
| --- | --- | --- |
| 清楚的首页介绍与内容入口 | 首页默认全部内容，说明用途与数量；发布为空时明确引导到公开预览 | `src/directory-view.js`、`src/ui.js` |
| 视频聚合、分 P 标识、顺序导航 | 按 BVID 聚合，分 P 数字排序；发布版与草稿分别标注；阅读页首尾提供同类别前后部分 | `src/manuscripts.js`、`src/reader-view.js` |
| 搜索命中片段与高亮 | 标题、摘要、标签、正文搜索；结果显示命中上下文；正文命中链接定位并高亮对应段落 | `src/search.js`、`src/document.js`、`src/browser-document.js` |
| 返回目录保留状态 | 恢复搜索词、标签、展开列表、已显示数量与滚动位置，支持浏览器后退和同标签页刷新 | `src/directory-state.js`、`src/main.js` |
| 来源、整理方式与稿件状态 | 展示冻结 attribution、editorNote、来源、版本及审核和发布状态；校验参照单独说明其基线属性 | `src/reader-view.js`、`src/ui.js` |
| 按需加载与搜索索引 | 构建时验证快照后派生索引和摘录；首页不请求正文或完整索引，搜索时加载索引，阅读时只请求当前文档 | `scripts/reader-content.js`、`vite.config.js`、`src/main.js` |

## 数据与交互边界

- 两份输入快照及其 schema、文件集合、内容哈希与 manifest 契约保持不变。派生索引和摘录只进入构建产物，不写回快照。
- 搜索索引只包含编辑正文的可读文本，不包含 AI 校验参照。索引与渲染使用相同的段落标识。
- 缺少摘要时，前端展示明确标注的正文摘录。源视频标签保持原名称，不推断主题或跨视频系列。
- 聚合目录可以同时显示同分 P 的发布版和草稿；文章内部的分 P 导航始终保持当前稿件类别，不把草稿当作正式下一篇。
- 分 P 导航只列已收录部分；前后部分可能有编号间隔，界面显示实际编号，不声称完整收录。
- 目录状态保存于 history、当前标签页 sessionStorage 与内存；不承诺跨设备或会话结束后的个人阅读进度。存储被禁用时，当前页面往返仍可使用。
- 搜索链接的 fragment 保留命中段落和词语，直接打开时也可定位。复制 Markdown 仍使用原始完整文件，页面高亮不改写原文。
- 网络加载失败显示可重试状态；导航期间过期的异步结果不会覆盖新页面。

## 验证与复测

运行 `pnpm test`、`pnpm validate` 与 `pnpm build`。单元测试覆盖视频与版本聚合、搜索命中及段落定位、安全高亮、状态恢复、来源说明和快照校验。

浏览器检查脚本使用已经安装的 Playwright CLI，无需添加运行时依赖：

```powershell
pnpm dev
playwright-cli -s=p0 open http://127.0.0.1:5173/
playwright-cli -s=p0 run-code --filename=scripts/check-reader-browser.js
playwright-cli -s=p0 run-code --filename=scripts/check-reader-errors.js
```

第一份脚本检查首页按需请求、搜索命中、返回状态、刷新、展开分 P、前后篇与历史导航、校验参照、手机深浅主题、空发布目录和未找到页面。截图输出至被忽略的 `artifacts/`。

第二份脚本检查索引与正文的加载失败及重试、导航期间的延迟搜索，以及禁用浏览器存储后的阅读与返回。脚本使用当前实际内容中的“哲学”标签与“克尔凯郭尔”正文作为任务样例；内容变更后应更新样例，单元测试保持独立合成数据。

子路径复测应使用 `VITE_BASE_PATH=/markdown-reading-site/` 构建，再从同子路径打开生产预览运行两份脚本。检查脚本明确排除开发期 `?url` 模块请求；它们只提供文档地址，不是文档正文。

## 后续范围

关闭会话后继续阅读的个人进度、收藏、阅读设置、批注和离线保存仍属于 P1/P2。搜索索引目前按发布类别拆分，首次全文搜索会加载该类别的可读正文索引；内容进一步增长时可根据测量结果考虑分片或 Worker。
