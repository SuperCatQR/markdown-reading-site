# 迁移稿的分 P 标题补充

本改动服务按分 P 连续学习、复习定位的读者，落实产品原则中的“同视频多个分 P
可辨认”和“来源事实准确表达”。前端继续使用导出快照，运行时不补抓或猜测标题。

生产者 issue #313 引入 `legacy-part-title-supplement-v1`。它沿用
universal-origin-v1/catalog v3/content v2/origins v1/manifest v2，但对该政策严格要求
`metadataSupplement`，保留 legacy-frozen-facts-v1 的原验证规则。没有新证据的旧稿
仍显示“分段标题未提供”。未知时间继续为未知；证据登记时间不冒充采集时间。

消费者核对补充证据 ID、平台、视频、零起始分 P、本地 part ID、字段值及逐字段哈希。
CID 必须是安全正整数且由证据哈希绑定；上游生产者负责核对真实归档 CID，前端
不访问生产数据库。证据类型准确表明这是当前归档分 P 投影，不声称有上游签名。
正文保留声明和历史 AI 参照的校验保持原规则。重新生成 manifest 也不能绕过
来源身份、字段值、政策和证据一致性检查。

先部署支持新政策的消费者，再成对替换生产者导出的公开/未发布快照。旧消费者
会明确拒绝新政策；不得将补过标题的稿件伪装成旧冻结政策。

验证：`test/source-supplement.test.js` 消费生产者直接导出的测试快照，验证真实标题
出现在目录、来源面板仍保留未知时间、历史 AI 模板准确，并拒绝语义篡改。
`test/fixtures/source-supplement-v1` 来自隔离的合成测试归档，不是生产快照。
本实现不修改现有 content/draft-content，不表示网站已经部署或生产标题已补齐。
