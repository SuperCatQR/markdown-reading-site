# 下一阶段功能计划：内容反查与多分 P 阅读

依据 [项目哲学](product-philosophy.md)，本阶段围绕两个用户任务展开：凭记得的内容找回文章，以及把同一个视频的多分 P 组织为完整的阅读入口。

用户已提出这两个方向。截至 2026-10-09，视频总览、内容反查增强与视频内搜索已实现，交付范围与验证见 [内容发现交付说明](discovery-experience.md)；连续阅读模式也已完成，见 [连续阅读交付说明](continuous-reading.md)。下文保留设计依据。此前基线见 [P0 阅读体验说明](p0-reading-experience.md)。

## 1. 当前基线与新增范围

| 方向 | 当前已有能力 | 下一阶段新增能力 |
| --- | --- | --- |
| 内容反查 | 搜索标题、摘要、源视频标签与正文；连续关键词匹配；每篇返回一个命中，可定位段落 | 原句查找、多关键词查找、正文优先匹配、多个命中与相关性排序、按视频展示命中分 P |
| 多分 P 整理 | 目录按 BVID 聚合并按分 P 排序；文章内同类别前后导航 | 独立视频总览页、分 P 级目录与状态、视频内搜索、显式开启的连续阅读模式 |

## 2. 内容反查文章

### 服务场景

用户看过视频或读过文章，记得一句话、几个术语或一段表述，想找回对应稿件和原始视频。例如输入“克尔凯郭尔 痛苦 审美”，查看同时涉及这些词的正文，再判断具体是哪一部分。

### 建议交互

保留一个全站搜索入口，并逐步提供清楚的匹配方式与范围：

- 原句查找：输入或粘贴原句，忽略首尾空格与连续空白，查找连续匹配的正文。标点不同仍可能无法命中；不能将未命中表述为网站一定没有该内容。
- 多关键词查找：以空白分隔关键词，默认要求各关键词都出现在同一篇正文中；允许位于不同段落，结果分别展示证据。匹配部分关键词的结果如提供，应单独标明并由用户主动展开。
- 搜索范围：普通搜索保持现有标题、摘要、标签与正文能力；内容反查明确优先或限定正文，不让标题命中遮蔽正文证据。
- 多个命中：显示每篇命中段落数，默认展示少量上下文，展开查看更多；每个片段都有准确的正文定位链接。
- 结果组织：按视频组织命中文章，显示具体 P 编号及稿件状态。排序先考虑匹配方式与关键词覆盖，再考虑同段共现等证据，保留确定的排序规则。
- 查询状态：允许分享或恢复查询方式、范围与关键词，返回结果时保留展开项与位置。URL 扩展需要显式验证参数，不放宽现有稿件路由的冲突检查。

结果说明应使用“原句匹配”“全部关键词命中”“部分关键词命中”等可验证语言。未经过校准的相似度不得展示为“准确率”或文章事实判断。

### 验收条件

1. 原句能找到对应正文，点击上下文直接进入正确段落并高亮。
2. 空白分隔的多个词可在同一篇的不同段落中命中，用户能看到每个词的证据。
3. 同一篇的多个段落命中不会被第一个匹配吞掉；标题匹配不会隐藏正文命中。
4. 无结果、仅部分匹配、来源标签限制与已发布/未发布限制都有明确结果。
5. 分享链接、浏览器后退、返回目录和中文输入组合期间的状态稳定。

## 3. 同视频多分 P 整理

### 视频总览页

为每个 BVID 提供可直接分享的总览页。目录的视频标题进入总览页，分 P 的阅读链接继续直达单篇正文。

总览展示冻结标题、视频来源、已收录分 P 数量与阅读时间估计，按实际 P 编号列出文章，并提供按已发布/未发布查看的明确入口。已有原视频标签保持原名称；缺少编辑摘要时展示标注为正文摘录的内容。

目录只列实际收录部分。发现 P 编号间隔时可以提示间隔，不推断视频总 P 数，也不声称完整收录。同一分 P 同时存在发布版与草稿时并列标注，用户明确选择版本。

### 视频内搜索

在总览页提供“在此视频中查找”，复用全站内容反查规则，只搜索当前 BVID 的已收录正文。结果展示命中 P、段落和版本状态，并保留返回视频总览的上下文。

### 连续阅读模式

总览页提供“连续阅读”入口，读者选择已发布或公开预览类别后，按实际 P 编号进入同一阅读流。

- 各部分保留完整正文，不改写或物理合并输入 Markdown。
- 每个 P 有明确边界、来源、审核与发布状态、版本信息和单篇链接。
- 先加载当前部分，后续部分通过明确操作逐步加载；避免打开长视频就请求全部正文与参照稿。
- 分 P 目录可跳转，未加载的部分显示加载反馈与重试；跳转与浏览器历史保持一致。
- 连续阅读保持所选稿件类别；缺少正式发布部分时明确提示，不用草稿自动补齐。
- AI 校验参照继续单独打开，并关联对应编辑版本。

“整理到一起”首先是聚合与阅读结构。合并导出 Markdown 可在后续单独讨论，不能让派生合辑看起来像新的正式 release。

### 验收条件

1. 同一视频只需一个稳定入口即可查看全部已收录分 P。
2. P2 在 P10 之前，编号间隔与同分 P 多版本都能清楚辨认。
3. 从总览到正文、下一部分、校验参照再返回总览，导航上下文正确。
4. 连续阅读逐篇保留来源与状态，当前稿件类别不混用，加载失败不会阻断回到目录。
5. 超长标题、十余个分 P、单分 P、空类别、手机、深浅主题与键盘操作均可使用。

## 4. 建议实现顺序

1. **视频总览页**：补上稳定视频入口、完整分 P 清单与版本选择，先把已有目录聚合变成明确的内容结构。
2. **内容反查增强**：实现多关键词、正文证据、多个命中、可解释排序与查询状态恢复。
3. **视频内搜索**：复用增强搜索，限制当前视频范围，并连接命中段落与视频总览。
4. **连续阅读模式**：在稳定的视频路由与分 P 数据上增加逐段加载的阅读流。

每步独立验证并更新交付文档。测试优先使用独立合成快照，覆盖多版本、缺失分 P 与跨段落匹配；真实内容用于检查阅读任务和视觉体验。

## 5. 技术与内容边界

- 延续独立静态前端、快照校验和按需加载，不为这两个任务引入运行时后端。
- 内容反查首轮使用可解释的文本匹配。凭同义改写或问题自动找内容的语义检索是额外范围，需要另行评估模型、索引体积、性能与维护成本。
- 同视频关系只以可靠 BVID 和 pageIndex 元数据确定；不把标题相似的视频自动合并为系列。
- 派生索引、视频总览与连续阅读不改写冻结正文、源标签、审核状态或 release。
- 查询命中、文章定位和版本关联沿用准确身份；稿件撤回、更新或未找到时保留明确提示。
- 大索引下的搜索响应时间需要实测；根据结果考虑 Worker、预计算索引或分片，避免多关键词搜索阻塞手机输入。

## 6. 相邻功能建议

本地阅读进度、收藏与最近阅读能补足持续学习体验；段落引用与笔记导出能补足复习和分享体验。它们继续属于项目哲学中的 P1/P2，不自动并入本阶段两个方向的实施范围。
