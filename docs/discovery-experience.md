# 内容发现交付说明

依据 [项目哲学](product-philosophy.md)，本次改善复习者凭原句或术语找回上下文，以及学习者查看同视频已收录分 P 的任务。对应 [下一阶段计划](next-reading-features.md) 的前三步；第四步后续已完成，见 [连续阅读交付说明](continuous-reading.md)。

## 已实现

- 直接阅读：目录标题直达当前目录类别中该视频首个已收录 P；查询结果中的标题直达首个命中 P。移除独立视频总览页，阅读页保留按实际编号排列的同类别分 P 切换，多 P 可从当前 P 开启连续阅读，单 P 不显示重复导航。
- 收录说明：阅读页保留原视频、源视频标签、当前篇阅读时间和稿件状态；视频内查找展开后提供收录数量、前部未收录与内部编号间隔说明。不推断末尾是否缺失，不声称完整收录。
- 综合搜索：匹配标题、摘要、来源标签与正文，正文证据优先；标题命中不会遮蔽同篇正文命中。
- 正文原句：在可读正文段落内连续匹配，忽略首尾及连续空白，大小写不敏感；保留标点区别，不跨段落拼接原句。
- 正文关键词：用空白分隔，去重后所有词必须在同篇正文出现，允许跨段落。标题和标签不能代替正文满足条件；不自动混入只命中部分词的文章。
- 多个命中：显示命中段落数量，先展示两个片段，可展开其余命中；每个片段都有具体稿件和段落链接，并在正文高亮该段命中的词。长段落分散的关键词分别提供上下文。
- 可解释排序：正文结果优先；多关键词中同段覆盖越完整越靠前，同分保持原目录顺序。按视频聚合时以最高相关分 P 决定视频位置，组内仍按 P 编号及稿件类别排序。
- 视频内搜索：正文及校验参照阅读页提供默认折叠的“在此视频中查找”，复用三种方式，仅搜索当前 BVID 和选择的稿件类别。结果直接定位具体稿件正文与段落，切换 P 或正文/参照时保留查询；参照材料不进入索引。空类别不以草稿补齐，也不会移除正在阅读的文章。
- 查询恢复：全站搜索 URL 使用 `view`、`q`、`mode`、`tag`，阅读页内查找使用 `vq`、`vm`、`vview` 并绑定稿件 selector，严格限制长度、类别和查找方式，拒绝重复或混用参数。旧 `?video=<BVID>&view=...&q=...` 链接在原历史位置转换到对应类别首篇正文，保留查询；旧空类别链接进入该视频的可用正文，但查找仍明确保持原空类别。共享链接恢复条件，页内历史额外保留查找结果展开状态与阅读滚动位置；全站目录会话恢复保持原行为。
- 来源标签筛选：将“全部”固定在首位，其余标签按当前稿件类别中的出现次数降序排列，同次数保留首次出现顺序。每篇稿件贡献一次出现，多分 P 分别计数；保留所有来源标签及原名，标签搜索与筛选规则不变。
- 列表简化：目录与视频内查询结果不展示自动首段摘录，保留有来源的编辑摘要和主动查询后的命中上下文。目录 BV 号使用稿件来源链接，在新标签页打开原视频，方便扫描与核验。
- 目录密度：收紧 BV 信息到阅读入口、记录底部的留白，保持 44px 点击区域。阅读页内查找默认折叠，携带查询或非默认查找方式时自动展开。服务扫读目录、持续学习与复习的读者，对应项目哲学的内容优先、渐进披露和来源状态准确表达原则。

## 内容与技术边界

保持独立静态前端，未增加依赖或运行时后端。目录不加载 Markdown 或全文索引；进入正文只请求当前稿件，分 P 导航基于已有元数据。输入查询后才加载按发布类别拆分的索引，展开空查询不请求索引。AI 校验参照不进入正文搜索索引。

未改写 `content/`、`draft-content/` 的正文或 catalog。视频标题来自收录稿件的冻结标题；源标签保留原值。首段不作为自动摘要，查询命中不代表文章事实正确。

这是可解释的字面文本检索，不支持同义改写或语义问答。首次搜索仍需加载所选类别的完整正文索引；索引分片和 Worker 可依据更大规模的测量结果评估。共享链接恢复查询条件，结果会随部署快照变化；片段仍绑定具体稿件版本。

## 验证与复测

运行 `pnpm test` 与 `pnpm build`。合成数据覆盖跨段落关键词、元数据与正文冲突、原句空白与标点、高亮安全、同分 P 多版本、数字排序、缺失范围、URL 往返及非法参数。

浏览器脚本使用已安装的 Playwright CLI：

```powershell
pnpm dev
playwright-cli -s=p0 open http://127.0.0.1:5173/
playwright-cli -s=p0 run-code --filename=scripts/check-discovery-browser.js
playwright-cli -s=p0 run-code --filename=scripts/check-overview-browser.js
playwright-cli -s=p0 run-code --filename=scripts/check-reader-browser.js
playwright-cli -s=p0 run-code --filename=scripts/check-reader-errors.js
playwright-cli -s=p0 run-code --filename=scripts/check-reader-video-errors.js
```

脚本验证目录直达正文、单 P 简化、旧链接转换、真实 13 分 P 阅读页导航、按需请求、跨段落证据、命中定位、正文/参照查询恢复、共享查询、空发布类别、历史导航、无结果、原句、375/768/1024/1440 宽度、手机深浅主题、全站反查和中文输入。`check-overview-browser.js` 保留原脚本路径，当前验证的是替代总览的直接阅读流程。截图存入忽略的 `artifacts/`。

子路径生产复测：以 `pnpm build --base=/markdown-reading-site/` 构建并在相同子路径的 Vite preview 页面运行以上脚本。浏览器示例依赖当前真实内容，内容变化后需调整示例；单元测试使用独立合成内容。

首次内容发现交付验证：42 项 Node 测试通过，快照校验与 Pages 子路径构建通过；新增任务脚本、原阅读流程及加载失败/重试脚本均通过。反转“全部关键词须命中”条件后测试失败，恢复代码后通过。同步已合并的内容导入后，再次对 320 篇快照完成上述验证。开发机检索计算约 37–39 毫秒，结果标记生成约 3–7 毫秒；这不包含网络、DOM 布局或真实手机耗时，不作为性能保证。该快照的正文索引约 7.8 MB（构建 gzip 估算约 2.7 MB），目录与摘要 chunk 约 503 kB，构建有体积提醒；索引分片仍待后续优化。

目录密度与总览层级调整验证：47 项 Node 测试、快照校验和 Pages 子路径生产构建通过。新总览脚本、内容发现、连续阅读、原阅读流程及加载失败/重试浏览器脚本均通过；覆盖单 P 主操作、辅助控件展开、空类别恢复、键盘查找、懒加载、375/768/1024/1440 宽度与深浅主题。目录首条记录 BV 信息到阅读按钮间隔约 4px，按钮底部到分隔线约 21px。反转“多 P 才显示连续阅读入口”的条件后测试失败，恢复后通过。本次构建目录 chunk 约 406 kB，全文索引仍约 7.8 MB，未改变首次搜索加载完整类别索引的边界。
