# 【哲学与现实】平准均输的哲学道理与现实意义

今天要讲一个制度，实际上是汉武帝时期的制度，由桑弘羊提出。

在之前我们还讲过资本主义，资本主义产生的一个危机就是两极分化。所以它是财富的繁荣，马克思说多少年、几十年来生产的财富相当于人类几千年的总和，财富总量大幅上升，是极度上升的；但它的分配非常不均，因为它的目的就是要人为制造贫困，然后豢养贫困——养着你，但让你穷，于是你不得不去劳动力市场出卖自己的劳力。不是贱价，而是按照它那个价格，这就是资本主义的玩法。

所以中国有句古话叫“不患寡而患不均”。人类甚至在资本主义出现之前就知道，如果单纯按照市场逻辑、商业逻辑进行物资分配，永远会有不均衡。总量非常大时，这种不均衡不明显；不是危机之前就没有不均衡，同样有不均衡，只不过再不均衡，获得最少的人也能勉强维持劳动力再生产，所以不凸显。但当资本主义危机来临、两极分化导致的危机凸显时，那个比较少的就太少了，就明显显现出来了。这个电影叫什么？《饥饿站台》，你自己看看。

不是说平时就没有这个矛盾、没有这个危机，平时也有，平时也有这种不均衡，不患寡而患不均。人类是动物，动物其实都是这样：它没有办法自己生产能量，没法像植物一样光合作用，得靠摄取外部的食物来获得活动、生存的能量。

一旦抵达那个底线，人就会丧失人性，丧失社会性；人会逐步丧失，先是丧失社会性。人丧失社会性就变成动物，动物再进一步丧失其动物性、趋利避害的本性，就变成植物，变成麻木的。人在丧失了社会性之后还有动物性，动物性起码还有它的方向性。

商君或者说荀子就说，你再怎么动物性，好歹我有赏罚二柄、利害二柄，我还可以控制你，对不对？赏罚这两个手段、途径，我还可以控制你，因为你有趋利避害的本性。但再进一步，你连趋利避害的本性都没有了，那你这个有机体、这个人的神经系统就麻痹了，麻木了，纯粹麻木了，然后就是一种应激范式、机械性的重复。比如在饥饿状态下饿到麻木，就没有趋利避害的本性了；那个动物可以不停动态维持其稳定的反馈机制失效了，比如吃东西吃到肚皮撑爆、肠子撑爆，它还继续吃，因为它是一种神经机制。我不知道，反正就是那种套路，它一直在重复、重复、重复，最后肚皮吃得……我不知道你有没有看过、小时候读过一篇文章，叫《柳叶儿》对不对？柳叶儿包的包子、柳叶儿包的饺子，吃得太多了，它那个肚皮薄薄的，像燕饺一样，一戳就破了，麻木了。

再不就是变成植物性了，麻木了；再往下就变成无机性了。变植物、有机物都不算了，变成无机性、无机状态。但它说不定还活着。植物好歹有它的稳态调节机制，但这不是动态调节，而是比较僵死、静态的调节，是它内在的稳态。或者说在植物那边还有内在性，它再怎么样最后还有一种内在性；到最后没有内在性了，变成无机状态了，那这个人就面如死灰。就算变成无机状态，它的内在性崩解瓦解了；就算这个人被救回来，他的心也可以说死了，心也死了。

所以这个不均，我们就能看到，它实际上是一直有的、一直存在的。不是说在危机很明显的状况下才会有不均，平时就有。这个不均平时就有，就体现为人会变成动物性的人，或者甚至变成植物性的人，或者这个社会人身上部分体现出动物性。不是全部都是社会性的，他在处理事务时不是全部都会考虑到公共的、和他人的关系，不从这些视角出发，他部分地具有动物性，或者甚至部分地体现出一种植物性。因为你局部会有这种匮乏、缺失；哪怕日常很充裕，财富总量很充分，没有明显危机的时候，但是还是有，你懂吧？

有匮乏，你才能用赏罚二柄。动物性，比如简单重复劳作的那些人，就是植物性；植物性甚至可以理解为不停进行简单重复劳作的劳动者。动物性体现在人的目光狭隘，就是趋利避害，只能看到眼前，看不到长远，懂吧？这是在底层劳苦大众身上都能看到的植物性和动物性，甚至有的时候我们还能看到它具有某种无机状态、无机性，没有内在性。一些现象、一些体验，别人能够升起一种恻隐之心，或者升起一种所谓羞耻感。然后他的审美、价值观这方面，连植物状态都维持不了了，连麻木都不麻木了，变成一种无机状态。

那么日常我们就会看到，在很多人身上——但不是说整个人都是这样，而是部分的。比如部分人的审美上是一种动物性，有些钢铁直男，他的审美上，女性审美的那个符号就是那种白瘦幼的，或者那种丰乳肥臀的。或者说在价值观上，他具有某种植物性，是一种重复的、麻木的、植物性的价值观，紧紧抓住一个符号或者一个价值度量去思考问题。这体现为要爬道德制高点、占道德制高点，或者作为受害方，永远把自己归罪为一个受害方，于是道德制高点就站上去了，就可以指责所有人，不反思，他没有运动性。在日常生活当中我们都能看到。

那么这扯远了。我要讲的是，今天要讲的不是这个问题，你大致要理解一下：这种不均衡状态造成人的生存状态的一个降阶次，越来越从社会性的人降到动物、降到植物、降到无机物；再往下降，连无机物都不是了，连化学性都不是，先是化学性的，然后降到物理性的，再往下降，降到机械性的，再往下降，连机械性的都不是，降到效应性的，再往下降，变成规范性的，再往下降，效应性的就变成光电效应，到规范性就纯粹只是一个什么希格斯场了。我靠，什么……完全都降到最后就降没了。但是说不定这个人还活着，那个人说不定还活着，但他的行动就非常重复、单一、简单，简单到如同一颗原子，或者简单到像一个量子，像一个光量子被射出来。不均衡会不断制造这种符号系统的降级，一个人的精神状态、活动状态、内在精神和外在活动方式就会降级。所以怎么样？所以要平抑这种不均衡。

那么在汉代汉武帝时期，就有桑弘羊提出要通过均输法。均输法就是用来平抑物价的。本来在武帝时期，或者在武帝之前，在均输法实践之前，各地要把物资输送到都城。桑弘羊就说，我们干脆在各地设均输官。“均”就是要通过输送，你不输送怎么来均呢？依次分配已经是不平衡了，你要通过输送、通过物流体系。所以他在各地设立均输官，本来要送到都城的东西，就不要送到都城来了，浪费运力。怎么样？那就近的，或者远的，按照情况输送到各地去；本来要输送到都城的，现在拐个弯，不送到都城，送到各地去，然后由官方来加以售卖，就打破所谓的价格秘密、商业秘密嘛。

比如这里产麦子，麦子本来剩余的像征税一样被国家征收了，要送到都城，那不需要了，因为都城用不到。那就把这些麦子输送到另外一个地区，甲地输送到乙地。乙地本来不产麦，但它比如是个卖盐的地方，或者卖铁的地方，不产麦，麦特别贵。那把这里的麦输送到这里，不需要绕一圈，直接由均输官协调输送到乙地，然后麦子直接卖出去，由官方来卖。那么获得货币，只要都城储存货币就可以了，以充国用，就可以去打仗；乙地的卖价就相对降下来，就平抑下来了。这个均输官本身有两个好处：一方面，把不易流通、不易储存、有时效性的经济产品转化成货币，通过这样一来可以长期储存，可以变成一个攒在那边的东西，成为社会动员力。国家就是武帝说，我攒了这么多钱，我相当于把这些劳动产生的力量攒起来了。另一方面，他把各地商人所制造出来的局部不均衡、潜在危机消灭在萌芽阶段。我卖也是卖，商人当然也可以卖，同样也卖麦子，但没赚那么多了呀。

它使得每个地方都需要物资种类 A、B、C 三种。如果说人类社会活动只要三种物资的话，这个地方产 A，那 B 和 C 都要靠其他地方运过来；如果它们比例失调，这里就会有危机。把这种危机消灭在萌芽阶段，那么整个国家就可以抽出更多力量。有这么一个均输官派在一地，他说不定本地的一些治安性力量、军事力量或者其他力量就可以节省，非常节省行政成本，降低了这个地方的行政成本；通过对经济活动的竞争性管理，它降低了行政成本，提高了行政力量的集中度。行政力量就可以——不仅仅经济、货币集中在这个都城，行政力量以及治安性的力量也可以集中，它这个矛盾就少了嘛。这对于汉武帝能够集结起那么大力量去打仗是非常重要的。那么还有一个就是平准法。平准法就是在大城市，包括都城，还有一些集中性的城市，比如洛阳、邺都、陈留等；这些地方，之前六国都城，他们同样设立平准官。这些平准官，它可能没有价格优势。你这个麦从甲地调过来，甲地均输官说我本来是要上供给朝廷的，那现在运到乙地，乙地过去一看，哎，这个商人他卖得贵，价格不贵？对不对？我这个官方卖的麦子没有价格优势。

啊，我就那就不卖成钱了。或者把一些易储存的、比较容易储存的麦子，把粮食集中到大城市里面，就近集中到大城市里面去集中起来，由平准官来统一调配。大城市是一个商贸中心，所有大城市基本上都具有商贸功能。那么它就可以在大城市里面平抑主要的经济中心、主要的商业中心里面的物价：这个贵了我就卖，贵了我就卖掉它；便宜的话，东西比较便宜的话，那我就收购它，我甚至可以收购它。那么它就相当于有它的小金库了。我不是学历史的，我不知道它是怎么运行的。它有它的物资，物资就是靠均输官在各地攒的，攒在那边，一时半会卖不掉，那么就全都送到大城市来，由这个平准官按照各地本地的价格情况，来进行对于市场价格的平抑。在过程当中，古代行政效率——你说完全没有贪污腐败，那不可能；武帝时期我不知道，我不太确定，会有一点点吧。

但是说对于经济活动，其实我们中华民族向来并不是仅仅依靠市场这个规则来……在汉代，两千年前就已经有这个非常成熟、相当成熟的方法了。那么在这里面最重要的其实是一个“输”，是一个运输、转运。因为你这个均输官要通过地区差异；没有地区差异，就不会有价格差异。通过地区差异来获得价格差异，这个价格差异对你有利。不仅仅是他能挣钱，这个价格差异他还能怎么样？他还能获得很多，比如政治点数，或者把行政力量集中起来，不需要分派到各地去；或者获得货币，或者维持各地秩序，让各地秩序稳定，各地民生得到发展，各地造血能力更强，能够攒起来的力量就更强。所以它要通过运输来获得、实现一个地区的差异。光是这个麦子，你这个均输官的核心词在于这个“输”，它要输送到其他地方去。所以运输活动有其内在价格、有其内在价值。

它不是纯粹损耗性的，这种资源的合理分配有它的内在价值。我们都说，《孙子兵法》学多了就会觉得，这个粮送来送去，千里运粮，百担只能得一担——那个字应该念“十”，“担”是一个错误的发音。还有一个就是说，这个平准官同样依赖于运输。它实际上依赖的运输，是一个大城市所具有的集中和发散的功能。

大城市就是人类的生活方式会集中起来，就是要更好地利用运输。因为你所谓大城市就是道路的交叉点；通过运输——实际上只有人类发明了运输。我实事求是，动物哪有什么运输可言？运输可以说是人类性的一个表现。就这么说吧。

动物是不懂得运输的，动物只会迁徙，这个迁徙就是它自己，是吧？比如骆驼，骆驼把东西都吃到肚子里面变成脂肪，变成驼峰；它迁徙的时候是带着自己在走，它一定要把这个东西内在化，变成它身体的一部分，才能把它迁徙走。又比如松鼠，它会藏松子，但它藏起来，会埋好多好多地方，可它不是运输，它是把它藏起来、集中起来。唯有人会进行运输，只有人会进行运输。因为在运输的时候，很明显，人和物的关系是既分离又结合的。人与物的关系既分离又结合，这种又分离又结合就定义了什么叫做物。一个东西——当然我们现在说财产有动产和不动产之分，但所有权里面的动产、可动的东西，它是更为原初的，对于财产的性质是更为原初的。因为不动产其实它的产权也是可动的，对不对？所以我们要知道，更重要的对于物的理解、对于所有权和所有物的理解，就是要把握到它的运输、运输性。而运输首先是一个人与物的关系：这个物可以跟你分离，它本来不在你身上，现在可以加载在你身上，我弄到那边去，又可以把它卸载下来；在可以分离又结合的过程中，你是和它结合的，是既分离又结合的状态。

那么在这个过程当中，人就变成一个载体，变成一个运载体；人本身是载体，人本身带着这个物可以运动，它带有一种人类性，动物是不具有的。那么运输里面的人与物的关系，实际上代表人与人的关系，因为光是人和他自己的物，他不需要运；人和他本身的物不需要运多远。运输如果本身是一个独立的行为，那它实际上必须包含人与人的关系。比如原始人打猎，打了一头鹿下来，然后因为有老虎要吃，我就把这个鹿搬回去，那不叫运输，那叫收藏。你的目的并不是说要把它搬回来，并不是说要让它通过这个路途；你的目的是什么？你的目的是不让它被老虎吃掉，要由你来吃掉。如果人可以一下子把它全吃掉，那人就立刻把它全吃掉了；他没有能力一下子全吃掉，对不对？我们甚至说这里面已经隐含、包含了人和人的关系，因为搬回来不仅仅是我自己吃，还要让其他不能够到那边的人来吃。

所以，当运输本身进一步成为独立的活动的时候，就不仅仅是食物的收集、不让其他动物夺走、把它藏起来或者占有起来，而是说这个物我要把它运输起来。那么什么叫运输？运输意味着它具有一个目的。它的目的是要使得人与物的关系转化成人与人的关系。我把这个物运到那边去，我的目的并不是这个物本身来到这里，我的目的是这个物到了这里，其他人可以对这个物加以进一步的操作，或者可以吃它，或者可以加工它，或者可以怎么样，或者其他人可以用他的物来还给我，可以交换这个物。因为物本身价值的实现，对于人类来说，对于人来说，如果不通过他人，不通过分工，不通过分工和交换，那么这个物本身价值的实现，对于原始人来说就只有两个。

一个是生存，还有这个物干嘛？一个是它可以当食物，有助于我的生存；还有一个，这个物可以当武器，变成一种武器，变成一种工具，就是原始工具，没有那种比较详细的分工性。这个工具可以当武器，或者可以当避难所，怎么样；要么就制造，要么就消费。当物开始和人结成一种不仅仅制造、不仅是消费，而是用来和别人去交换的价值的时候，那么人与物的关系就实际上已经是代表人与人的关系，那就必须要有运输，必须要有独立的运输活动来支撑。这种独立的运输活动，对于人类来说，对于人类之为人类来说，是非常非常重要的，极为重要的。

它不是通过反思形成的。甚至说，人在脱离动物的时候，人在从动物当中脱离其动物性、超越其动物性的时候——因为人还保留其动物性——人就是通过可以携带着一些致命性的武器，携带这些致命性的武器，不停地驱赶一些原始的兽类，把这些兽类弄得筋疲力尽，最后再上去收割、杀了，然后吃掉。那么他驱赶那么远，他作为猎手驱赶那么远的话，他自己的部落里面那些老弱病残、老弱妇孺还在千里之外，他要把这些肉运回去，他就必须要有一个去和回来的长途耐力。人在获得这种耐力的过程当中，他的神经系统、他的抑制性能力就不断进步。越能够克制自己那种生理本能的人，他就活下来了。这就是人性显露出来一种否定性的力量，一种平抑、压抑动物性冲突、动物性节律的力量。动物吓得要死、喘得要死，人可以深呼吸，人可以做。人的神经就形成了一种新的调节模式。
