# 【哲学与现实】 历史的逻辑是同一个阶级矛盾跨越不同层面的运动方式

我们现在要讲的是，历史的逻辑在运动。它的运动是从一个层面跑到另一个层面。历史逻辑这种跨层面的运动，体现为 class struggle。跨层面、层面这个词，就是 class struggle。

我们都知道，2027 年要发生一件重大的事情，因为 1997 年开始的第二轮家庭联产承包要到期了，三十年嘛。

那么，农村土地还是按户分。但大家，城市无产阶级会对农村土地抱有一个前现代的幻想，觉得可以回去。文件里就说了：维持承包关系不变，2027 年维持承包关系不变。

这个承包关系是一个高度受监管的资本主义关系，实际上就是资本主义关系。农村土地现状其实是两极分化的，但它效率特高。目前农村土地承包关系的状况是：在农村本身就是要消灭小农，消灭小农的目的是把小农转换成城市无产阶级，然后通过两头在外的代加工，就可以赚取国际外汇。

劳动力直接转换成商品，劳动力本身直接商品化。这种商品化实际上是核心中介：两头在外，原料和产品都在外面。城市无产阶级作为劳动力，实际上是把自身商品化，这就是所谓的外贸导向型经济。因为我们是一个很多大宗资源比较匮乏的国家，所以这个循环一定要维持，一定要维持，这样可以赚得外汇。以外汇做锚，才有铸币税，才有我们所说的货币税、铸币税。

实际上，大型民族国家怎么可能依靠房产这种东西养活自己的财政呢？它实际上是靠铸币。但它一定要有锚来铸币，那叫外汇，或者说用全世界财富的增长份额来铸币。所以为了实现这个循环，它要在农村不停地消灭小农，然后生产城市无产阶级，并维持这种两头在外的经济。因此它一定维持承包关系不变。

很多还有小农幻想的城市无产阶级太痛苦了，他们还在幻想 2027 年可以按人头分地。当年我们的 M 如果按劳动力分，更不要说按户来分；当然当年按劳动力分基本上就是按户分，也就是说一个劳动力可以撑起一户，一个壮劳力，或者两个，比如父亲和大儿子，一点几吧。如果当时按劳动力分，对中农、稍富一点的富农和中农有利；按人头分则对贫农有利。

现在的城市无产阶级在幻想，这其实是我们 M 主义的一个回潮，就是想回农村，把农村的土地、生产资料按人头分，直接和土地结合，免于商品经济的冲击，不会每年有 6% 的劳动财富被稀释。不过这个 6% 对他们来说本来也没什么意义。我们要讲的是，这是个幻想，这是个幻想。

这个幻想一定会使布尔什维克，或者说我们的 M 主义，和民族主义结合到一块去。按人头分地的逻辑曾经是解放性的，但它只适用于农业时代，或者说只适用于一个为资本主义城市生产剩余劳动力的农业空间。我们曾经就是这个逻辑。但这个逻辑现在运动到不同的层面，运动到一个新的层面，这个新的层面就变成民族主义。

最近的一个情况，比如允许在比东北更东北的地方开放耕地，这是最近或者不远的将来要去讨论的。因为那个“客工君臣”似乎玩脱了，能力有限；他搞那么多长安之星、五菱宏光，也救不了他狗命。这种游戏说穿了就是林子里被老虎追，跑赢不需要跑赢老虎。现在是九月份，但局势到底如何还要再看，不能说他真的完全玩脱了，只是玩脱了一部分，因为要看谁更能熬。各方面消息层出不穷，比如德国汽车厂商到底是要来建厂，还是要断，还是要脱钩？我最近比较忙，没时间一一核实这些新消息，也不是非常感兴趣，因为这玩意儿我捞不到一分钱好处，我只跟你们聊聊。

我要讲的是，这个逻辑已经从城乡冲突的逻辑，或者说乡村内部冲突的平等主义幻想——它曾经不是幻想，这种平等主义就是平均地权，说穿了——转向了。现在它开始在地缘层面，或者说在 international 的层面运行，也就是 far east，当然也包括欧洲。

我作为一个国际主义者，如果说遥远的未来，全人类实现了国际主义理想 internationalism，赤旗插遍全球，那么依然要考虑一个问题，就是土地和人口的关系问题。因为你不能说一下子全世界所有人都进入发达工业体系，农业彻底消失；在国际主义胜利、国家已经不存在的时候，也不能说全世界所有地区都已进入非常发达的工业化农产品产业，所以势必还要面临土地和人口问题，还要面临局部前共产主义的技术条件和经济现实。在这种情况下，依然有解放生产力的大前提。那时我们的 M 曾经做过的事情要在全世界重新做一次，就是按人口分配土地、平均地权——这当然是我们的 S 的口号。

在这个意义上，非常明显，一些民族、一些种群人口很少，却占据地力产出非常大的广袤土地，这当然不利于生产力发展——这是在届时国际主义已经在政治、军事、全球治理层面实现的前提之下。必须着手进行经济上的平等主义解放行动。按照土地的富饶程度，也就是按人口分配土地；具体以产出、日照、土地上其他要素、矿藏、淡水、交通便利程度等，乘上一个系数，得出土地的可发展度、可开发度以及已开发度，再乘上土地系数，乘出来的就是所有的地利。

这些要按人口来分配。对于一些后发达、落后、能力更弱小的民族，当然不需要刻意去说：穷的爱斯基摩人就多分点地，多分点土地上的好处；已经很发达、非常聪明的日耳曼人就少分点，你不需要。为什么呢？因为发达民族和社群的人口比例中，绝大部分都在工业体系里，都在我们那时所说的后共产主义工业体系中。所以，按照人口分配土地利益这个逻辑，现在不再运行在具体的城乡矛盾或乡村生产生活现实中。至少在可见的几年、未来可见的三十五年里，它不会再运行在那个层面。但这不意味着这个逻辑失守了；它会继续运行，只是到另一个层面去运行，会展现为某种地缘规则。

实际上这也是战争潜力，我指的是常规战争潜力。人口在土地上，人口一定要和土地紧密结合，才能支撑起军事行动。光有五菱宏光、长安之星，一堆内燃机套铁皮没用，还是得由人操作。人是高级机器。在地缘政治家眼中，人是高级机器；高级无人驾驶机器就是人。人本身是高级驾驶，具有驾驶能力，能自动智能识别各种障碍信息、路况，还能维修轮胎、链条、内燃机，是非常通用的。

有足够的人口量，而且足够训练、精壮、有序，这样一个辅助性单位，才能支撑起交通线、运输线。这个逻辑在地缘层面非常强大、铁一般地运行着，并主导着历史某些重大进程。它是一个战争规律。这个逻辑现在体现为战争规律，而战争会引发很多地缘结果、结论和地缘大变动，也会带来非常巨大的政治经济学波动。

所以今天我们用一个例子来说明，我更在意的是不可偏废：domestic 和 abroad 两者都不可偏废。实际上这是同一个 class struggle，只不过展现在不同层面：要跑到外东北去安排那么多人，或者 Middle East 那边也是地广人稀。这个矛盾不仅表现为 international，甚至表现为 inter\-religion、inter\-regional。你们都明白这个道理，所以要思考清楚，这是同一个乌托邦模型，我甚至说它会折射为意识形态。

这个历史逻辑在现实中会展现为政治、军事、经济、技术、物质层面的东西；按人头分的逻辑会变成这些物质性层面非常强大的交往规则和运动规律。一方面是在客体侧；另一方面在主体侧，它也会生产出意识形态、自我认知和幻想——幻想一个乌托邦，可以把它从痛苦中救赎出来。就像现在很多产线上的城市无产阶级，会幻想回到农村，按人头分三分地就行了，对不对？这些幻想会支撑意识形态，意识形态会支撑派系意识，支撑在野的派系意识。

但实事求是讲，这里有个历史铁律：两头在外是最高效的集税模式。目前看来，它好像比你那一套还要硬，实事求是讲，硬多了。这就是算账，你可以去试点试一试，just try，好好算一算。

人心向背——有时我们说物质现实是一码事，但人心向背，如果这个过程极端痛苦，那么你不可避免会面对无数社会能动者或行动单元，也就是那些微小的、区域性的、小的既得利益派系。比如苏州光福镇上那一群世家小族，这些人有人心向背，他们的子弟、他们的货币流向本身也是铸币集税环节的一员。好好想一想，好好想一想。

今天讲清楚一个道理：一个逻辑在不同层面运转，这些跨层面、跨层级的运动展现为 class struggle，也就是阶级矛盾。那就讲到这里。

当然，这个阶级矛盾有很多层面：国家之间、民族之间、宗教之间、个体之间、城乡之间的 class struggle。不要简单化，它会展现为好多矛盾。This class struggle is class struggle, but it will represent itself as 各种其他形态的矛盾。但我们又要知道，它最终就是阶级矛盾。它是同一个历史逻辑，这个历史逻辑支配各种幻想，同时也生产出各层面非常铁硬的规律。那就讲到这里，好吧？
