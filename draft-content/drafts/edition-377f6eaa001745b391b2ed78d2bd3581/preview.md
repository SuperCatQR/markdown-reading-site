# 【现代哲学】3\-莱布尼兹：用比特币克服无限月读（这也行？）

我们在这里进展到了莱布尼兹。莱布尼兹要克服斯宾诺莎式的那种无限月读。为什么要克服无限月读？因为看过《火影忍者》结局的人都知道，无限月读会让人变成白绝；白绝就变成僵尸了，也就失去了自我意识。

莱布尼兹认为，不仅仅是无限月读施展下去，人变成白绝、僵尸，最后连大筒木辉夜这个神也会变成白绝，也会变成傻逼，也会失去自由，因为他变成电影放映员了。这个神其他事不干了，天天帮你放电影，从程序员变成一个电影放映员，变成电影小站站长、电影放映员。这样收入就不需要那么高了吧？本来 996 可以拿 30K，现在电影放映员一个月给你 3K 就可以了，神本身就变得廉价了嘛。

所以莱布尼兹认为不行，绝对不能这样搞。这个世界不可能是斯宾诺莎那种无限月读：大家排排坐，看老师给你放电影，然后陷入幻梦里面，那种不行的。莱布尼兹想了一种办法来克服这种无限月读。

不过，漫画我记不得了，火影最后是怎么结束的？好像是靠两个什么因陀罗、阿修罗最后把她拍死了。但《火影忍者》没有给出政治解决方案，而莱布尼兹可以给出解决方案，这就是单子论。

单子论在无限月读里面是怎么说的？在莱布尼兹那里有一个上帝，上帝的精神就像一个全世界的写轮眼。这个写轮眼向所有人投射幻觉，所有人都中了它的月读，所以叫无限月读。然后人最后慢慢变成白绝。那么单子论怎么突破无限月读呢？

他反过来有一个办法：让这个结构变成每个人都有自己的一只写轮眼，这只写轮眼反过来给自己投射一个月读。也就是说，每一个人都有一只自己的写轮眼，给自己投射月读。

而且这个东西不只是每个人，甚至每条小猫小狗，甚至每块石头，都可以自己搞一个无限月读。所以这些东西叫单子。在这个意义上，我们把它叫作无限月读，一种无限的无限月读：每一个实体都可以给自己设立一个幻术。

这叫单子论。所以在这个意义上，单子的本质叫作思。所谓的思，其实就是一种二阶的认同，是 reflective 的。每个个体的自我认同，都是通过一个视角、一个视点去实现的。

也就是说，之前我们可以用电脑来理解：斯宾诺莎式的电脑只有一台主服务器，在上面跑一个程序，把一切东西都模拟出来。这是斯宾诺莎式的。但在莱布尼兹那里，他认为每一个个体都是一台电脑。这是一个互联网，有无限台电脑、无限个运算中心，每一个运算中心就是一个单子，叫作 monad。大家共同算的那一份东西是一个实在，共同算的是同一个东西。这就形成一个网络，这个网络就是世界。

这个硬盘是大家共享的，就是实在的这个世界。康德会说：对不起，这个硬盘是物自体，你不能描述它。莱布尼兹则说，这个硬盘就是一台计算机，一个 CPU 在计算、读取硬盘里面的东西；但在莱布尼兹那里，它是一个互联网。这个公共网络里面的世界硬盘，每一个终端都可以去调用里面的信息内容。然后每个硬盘都从它的角度去把握整个世界。所以它就叫一个单子。这个单子从它的角度可以折射出这一切；从我的角度出发，我可以把握其他整个世界，而且还有其他个体，我都能把握出来。

他认为，通过这种方式就可以获得自由。他以自由作为前提，以思作为前提：每个个体都是自由的，每个个体都能够反思性地去把握这一切。

那么下面要讲的东西，有可能要超出一些人的理解了。我要说的是，这种单子论是错的——不，不能叫错的，我们一般不说一个哲学是错的，如果那样所有哲学都是错的。单子论是有代价的。因为这个玩意儿特别像什么？特别像挖矿。

挖矿，特别像挖矿。也就是说有一个东西，一个矿池，然后无数台电脑在里面挖。这里的问题在于：上帝也不过就是一个单子。上帝可能是个总服务器，是一个大一点的服务器，算力强一点的。这个就是 God。上帝算力强一点，所以算得快，可以定义这个矿池。旁边这个是人，这个是猫，这个是石头，这个是一个数字，每一个东西都是个单子。上帝算得快，所以它定义了这个矿池里面绝大部分的实在；绝大部分的实在都是上帝创立出来的，了解吗？

你要把它理解成挖比特币。挖矿，上帝算力多牛了：整个物理学的宇宙都是他的矿机，他算得多快啊。他有多少个量子比特？现在八个量子比特的量子计算机就已经算力上天了，上帝有多少个？你可以把整个宇宙里面的所有原子数统计一下，再换算成量子数，就知道上帝的算力有多强了。所以它可以定义绝大部分的物理学实在。

好像挺有道理的，但是单子论有个问题：它预设所有个体都具有思，也就是说预设所有个体都有权利去挖矿。这实际上是有问题的。这里有个前提：这些个体得能忍受痛苦。

我后面全是比喻性质的。就是能够感受到命运，才能反思。因为我们之前讲过清醒和梦的一种辩证关系，其实梦就是命运了。所以我们之前讲过，清醒是二阶的，是一种二阶的认同，梦是一种一阶的认同。

所以一个个体、一个单子要获得反思能力，前提就是必须和这个一阶的、或者说和这个命运拉开距离。如果拉开距离，我们用挖矿作比喻的话，就是它必须承受一种痛苦；在矿机里面承受痛苦，就是你的整个意识系统必须忍受一种痛苦，必须承受一种命运，叫作无聊，也就是 boring。

你作为一个单子，和上帝这个大大的单子相比，他很厉害，他把整个矿池都算出来了。分布式记账嘛，他都先要把那个旧账单算出来，才能在新账单上记录。你作为人去算，你也去挖矿，你算出绝大部分都是重复的、无意义的，因为他都已经提前算好了。你要很努力很努力，才能在这个矿池里面挖出新的比特币，才能拥有自由。

所以莱布尼兹单子论的设定——所有单子都是自由的——实际上是一种意识形态。不对，不是所有单子都是自由的。这个单子必须能够忍受痛苦，能够感受到命运，感受到这种重复的、无意义的海量无聊、海量无意义。实际上这种海量的无意义就是恶，就是无限，就是恶。也就是 meaningless，就是罪恶，让你承受无止境的那种罪恶。

所以在单子论的基础上，莱布尼兹要为这种模式辩护。特别是他为了设定这个上帝具有反思性，还要进一步设定上帝本身具有反思性、上帝本身是全知的、是有反思性的自由的。那他一定会面临一个问题，叫作神正论的问题。就是说：既然上帝是个单子，而且是最厉害的单子，那他为什么创造出来这个世界是缺乏某些反思性的？这个世界是有罪恶存在的，为什么它是有罪恶存在的？

关于神正论，我专门写过一篇文章介绍过，它的编号是 1212，还是 1211，我记不太清了。文章在我的知乎专栏里面有，你们可以去看。

莱布尼兹既然设立一个单子论，用类似比特币挖矿的模式去定义整个世界，那么他必然需要神正论来进行辩护。就是说：你既然说这些东西都是自由的，那么自由从何而来呢？特别是你上帝创造出这整个世界，你为什么没有经历过反思呢？你为什么看上去如此鲁莽，设立了很多有缺陷的、有问题的、罪恶的东西在里面？那他必然要加上一个神正论的模块。

总的来说，莱布尼兹的哲学图景就是一个单子论的图景。或者这么看来，就是有好多台电脑终端在读取同一块硬盘里面的数据，然后各自建构它自己的世界。每一个小单子都能建构一个完整的世界，都能建构一个属于它自己的完整世界。这和海德格尔的看法就不一样了。

海德格尔明显就说过——具体在哪本书里，我不说了——石头是没有它的世界的，石头是无世界的，包括猫、狗，也是无世界的。世界要世界化，这个 Welt 要世界化；这个词的德语我就不说了，德语比较差，不好意思。world 要 become a world，或者叫 worldify；世界要 worldify，世界要世界化。它必须具有时间性的结构，或者必须具有我刚刚所说的那种辩证法式的结构，必须能够拉开距离，它才能够世界化，才能够敞开一个世界的图景。

所以他把单子论、把思这个属性……单子论的本质是思，单子的本质是思。它太过于廉价了：把写轮眼给阿猫阿狗都配一只，凭什么你不配？阿猫阿狗不配有写轮眼。而且，单子论其实比这还野。单子论不是这个意思；无限月读才说只有写轮眼存在，只有写轮眼存在。

哲学上的无限月读其实比这个还野：只有那个大筒木辉夜的写轮眼存在，一切都是大筒木辉夜的写轮眼幻化出来的。单子论告诉你：除了大筒木辉夜那个高级的大写轮眼之外，还有小写轮眼，每个小的写轮眼都可以投射出它自己的一个小宇宙、一个小怪兽。这就是莱布尼兹的哲学。

那么再说，爱情上的对应物是啥呢？这不是显而易见的吗？爱情上的对应物，就是精致的爱情，也就是精致利己主义的爱情。

这种爱情有点像挖比特币、挖矿一样：两个人互相竞争，谁爱谁更多一点，谁爱谁更多就是谁挖矿挖得更快。我算力比你强，挖矿挖得比你更快，我就越能够在这种爱情当中感受到一种超越性、一种灿烂璀璨的意志性、一种浪漫的感觉。

所以这种精致利己主义之间的爱情，他们通常会说“我们的爱”，歌都唱出来了，“我们的爱，我们的爱”。他们认为我们之间会存在一个独立的东西，就是那几台矿机——两台矿机一起挖的一个矿池。它就是这个爱，love，美其名曰 love。所以精致利己主义者其实就是把爱情本身实体化、对象化。

我们之前说单相思那个东西，它好歹单相思爱的还是那个个体、那个人；母子共同体那种恋爱、恋母，他恋的是他母亲，他不会说恋一个纯粹的爱情。爱情是啥玩意儿？它不存在这个东西，它是一种相互关系。

那么精致利己主义者，或者在莱布尼兹那里，就会存在一个“A 和 B 之间的爱情”。为什么会出现这么一个 A 和 B 之间？因为 A 和 B 是平等的，他们都是单子。精致利己主义就是一种双方平等关系之下、其实是竞争关系之下的两个个体之间的又有一个爱情的东西出现，就是两个矿机之间的一个矿池出现，要去挖这个矿池；谁挖得多一点，就是谁爱谁多一点。

你不能叫谁爱谁多一点，而是谁获得、感受到的爱更多一点，所以感受到的自己那个崇高的浪漫形象更多一点。所以这种精致利己主义的爱情、莱布尼兹式的爱情，也是一种现代特有的爱情。

这样你就能理解，没谈过这种恋爱的人都能懂：就是互相各种表演、做作，然后我爱你更多一点，我给你买了个啥，我又给你买了个啥，我让你用什么给我怎么样。这种互相比来比去的爱情是前观念论的，因为莱布尼兹的哲学不是一个观念论哲学，在我看来是一个比较庸俗的哲学。好吧，我们很快速地把这个环节也给你讲完了，先这样，拜拜。
