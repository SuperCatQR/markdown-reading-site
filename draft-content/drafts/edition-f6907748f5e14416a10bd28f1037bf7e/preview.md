# 【主义主义】现世的现象学（3\-1\-4）——泰斗之背书：晚年狄尔泰重要的现象学“遗产”

我今天要来讲主义主义的三杠一杠四。它的发轫，或者说领头人物、代表人物，最能代表其精神的是晚年的狄尔泰。一定要是晚年的狄尔泰。他要做的那个决断，具体是在一九多少年呢？他一定要在胡塞尔《逻辑研究》出版之后，读到《逻辑研究》。那时他已经年纪很大了，七十岁了，必须是七十岁的狄尔泰做出那个决断。他自己开了……我看一下，他应该是在自己最亲近的徒子徒孙里面开了一学期的课，一学期还是两学期？一学期，一学期的《逻辑研究》课。在他晚年最后倒数第二年，七十岁的狄尔泰成了一个现象学家。这个殊荣要给他。

这个年轻人从年轻的时候就开始抵抗科学化、实证主义化的方式，抵抗那种很僵死的、学科固化的思维方式对哲学的入侵，首先是对于历史学的入侵。狄尔泰是一个历史哲学家。他本人的学问是二字头，我就不说了；但他晚年作为一个觉醒了的现象学家，我会给他个面子，让他在三杠一杠四上面。因为他具有启发性，他的思想对于海德格尔具有启发性，海德格尔又连续激发了加达莫尔、梅洛庞蒂这些人，所以我给他放在三杠一杠四这个位置，算作一个领头的。他在年轻的时候就拒绝……

他年轻的时候就拒绝当时的历史学、当时的科学。十九世纪，特别是十九世纪中叶，从一八四几年开始，英国那种思维方式，英法哲学当中的实证主义化思维方式，就是我之前说的穆勒、马赫——马赫那个时候还没出生呢——还有孔德，Count 是这样拼的吧？

穆勒和孔德这些鸟人坏了大事。他们的思维就是主导着以一种科学化的方式去科学化哲学，要把哲学给科学化，要把狄尔泰所搞的人文科学、人文学科——也就是 Wissenschaft——科学化。Wissenschaft 在德语里是科学的意思，相当于中文的道术、道书，或者道之书、道之术。Wissenschaft 就是德国的科学，是一个很屌、很厉害的东西；德国人追求的科学是一整个至高知识、终极知识体系。这样拼的吧？我不知道有没有拼错，我大概率会拼错，因为我不会德文，有个 s c 吧？我大概率会拼错。哦，我觉得我肯定拼错了，s c h a f t 啊。哦，我写的有 c，对，没错，那我没拼错。它的意思比科学广得多。

它的意思比科学广得多。如果直译，差不多可以翻译成“学问的架子、枢纽框架，学问之枢纽之框架”。所以当时英法的那种科学，特别是实证主义哲学家——我靠，有点背叛 positive、posit——他们想要用科学方法去解决所有哲学问题，这就像作弊：游戏不玩了，直接作弊，开搞心理学。但那个时代的心理学和现代心理学不同。现代心理学从良了，有点改过自新，因为受到布伦塔诺、詹姆斯心理学以及精神分析屡次的反击。心理学某种意义上可以看成这种实证化的科学，实证化的科学，与德国那种哲学性的科学形成两个拉锯对垒；还有一种叫批判性的科学，甚至诊断性、批判性的科学。

批判性的科学，这三种科学形成对垒。现在心理学、认知主义、精神分析、实验心理学、以神经生理学为基础的研究，还有现象学的心理学，都有；心理学有好几种，并不是心理学就属于 science，英文意义上的 science。英法知识分子普遍学术异化比较严重，法国稍微好一点，英国就很严重。它的分科系非常割裂，一个 mind of science，what kind of science，哪一种 science？到处割裂，只知道它那个 doctrine、教条，它那个学派下面的一系列规矩规则、一系列术语表，用烂了几十年，继承下来修修补补，里面的方法论也用烂了、修修补补。了解吗？它就是这么讲规矩、内卷。

心理学我扯远了。当时想要有一种方式，不仅心理学，乃至于历史学——可能就是生活学、生活史、人类的生活、人类学、生活史这些东西——通通都要被一种科学范式，也就是实证主义的科学范式统一。实证主义科学范式说得简单一点，就是要有时间空间框架，还有一维是概念表，还有一维是它的范畴表。范畴表里面定义正负轴，哪些是现实存在的、实际存在客观的，哪些是主观的；符合这个框架的东西，可预测、可量化，可以量化、定性、分类，非常细致地在范畴表里面定位，这才是它的研究课题。然后它的方法只不过是把这里面不同点连接起来写成函数罢了。这种实证主义科学是很垃圾、很蠢、很笨的东西，stupid；在这么一个僵死的框架之下进行研究。

这种方法就嵌入、想要侵略到德意志的心理学，才会有心理学这么个东西；它还侵入德意志传统的精神科学、历史学。当时历史学本身也很郁闷，因为它不知道这个历史到底是文化史——就是文化艺术文学这方面的文化史——还是政治史。竞争之后说，哎，干脆把整个叫做精神史。这就是那个马堡学派，妈的，文德尔班、李凯尔特，我靠，这名字都挺好玩的。狄尔泰都是什么尔？稍微加一个喉音就是一个什么尔。好了，不扯了。

狄尔泰实际上从年轻的时候开始——他后来是学界宗师——由他来编整个人文科学导论，关于人类的科学，整个人文科学都由他编，他是执牛耳者。但这个人到了中年，五六十岁、六七十岁的时候，他的哲学体系里不可避免地会有我刚才说的这种科学化、实证主义化的倾向和思维方式，这没办法。

狄尔泰没办法，因为他的追求是：在本体论上，他追求生活，生活对他而言就是原原本本的生活本身的一种本质性结构。他要探寻本质性的生活，把生活作为一个实实在在、原原本本被给出来的东西，探寻它的基本结构；这种基本结构要通过人文科学的方式得到揭示，进而实现他的历史哲学。所以这种热忱其实跟现象学相似，就是面向事情本身，不预设术语表，不预设框架，不预设一个范畴表或术语表、分类表，不预设这种蛇皮东西。所以在认识论上，他的概念体系是实事求是的，是朝向事情本身的，这是现象学的基本精神。他不预设概念表、概念体系、术语体系，他有一种探索精神，一种认识论上的探索精神。

晚年狄尔泰依然保留着这种精神，依然年轻。也就是说，用海德格尔的话说，他要进行一种生产性的概念生成，productive。海德格尔说，我们的学术探索一个专题领域，一个 sematic domain，它要生成，它要通过生产性的概念生成来进行探索。但这件事后来会被一些人……

如果这个姿态是面向事实本身、面向实事本身，那么它显现出来是一就是一，显现出来是二就是二，我不很牵强，这是值得称赞的。但这种方式在狄尔泰那里也产生了一些错误影响：后面的人喜欢搞体系，比如新黑格尔主义那些人，还有一些模仿费希特搞唯我论的人，模仿费希特的人也会搞一个体系，在体系里自创一个术语表，然后用这个术语表包罗万象，什么东西都可以套进去。德勒兹嘛，我都可以说是这种人。那就不是一种生产性的概念构成了，而是一种掠夺性、侵吞性的 exploitative、剥削性的概念生成，是 appropriative、占便宜性的，把什么都消解掉、消化掉。这是不对的。

狄尔泰年纪很大、七十岁的时候，胡塞尔的《逻辑研究》出版了。《逻辑研究》到底是干什么？《逻辑研究》不是研究逻辑学，而是研究逻辑本身。你们很多人都不知道《逻辑研究》是在干嘛；它是消解掉逻辑本身，把形式逻辑去形式化。我不承认你他妈有某种什么……当然，后面我可以建构你可能具有先天性，或者具有一种我自己会建构的先验性；但前面我要用意向性的方法、现象学的方法去看穿、看透你逻辑到底是什么，逻辑到底是个什么东西。胡塞尔用了很多，比如类、语法学、句法学，逻辑里面的诸个环节都被他拆分了，然后一个一个去探讨。在《逻辑研究》里，很多环节都很痛苦，非常痛苦；你要讲清楚逻辑是什么，就是不停地用现象学直观道明逻辑这件事情到底意味着什么：What is logic? What is logic proper? 它自己到底是什么？不要用下面这些屌东西去说逻辑是什么，而是让逻辑本身内在的规定性向我们显现，然后我们恰当地给它命名，并且使我们命名它的那个体系与逻辑本身具有同构性；不仅具有同构性，能够俘获、捕获逻辑，而且可以揭露逻辑内在的机制。不是说我把它解释成脑电波、神经冲动，或者把逻辑解释成语言习惯、心理习惯，不是解释成什么东西，而是描述逻辑本身在各个环节、意识环节里面怎么来充实它自己，怎么来把自己建基，把自己变得有效，把自己变得澄明，把自己变成一种可以操作的规则，然后也可以把自己变成专题、变成对象去把握。《逻辑研究》就是研究逻辑本身。

《逻辑研究》恰恰不是一种逻辑学的研究。在《逻辑研究》之前，胡塞尔也写过另外一本书，是他教职论文中论述的概念，当时叫心理学分析。那时他还在布伦塔诺的大弟子 Stump 的指导下。后来是心理学分析；这种心理学分析当时其实已经很接近现象学了。这个心理学不是现代心理学，当时是布伦塔诺的心理学，其实就是意向性结构，就是意向性分析，已经很接近在告诉你：数到底是通过什么样的意识活动、意识结构把它结构起来、构造出来的。数学的基本概念、基本规则、基本体系化、基本操作、它的活动，也就是说，数到底是什么？论数学。你看当时了不起的哲学家的论文都很有创造力，别人不敢去想这些东西。它看上去好像是一种心理主义，其实不是心理主义，已经脱离心理主义了；因为心理主义的基本范式还是很矬的，还是一种实证主义、科学实证主义，或者说还是想要有一个材料，然后用一些既定的框框去套这些材料、加工这些材料，然后得到一些既定的结论，而不是让数的本质性结构本身向我们显现。这个本质性结构也是被缘结出来、被结构出来的，但也是会不停地显现出来的；这里面的动态机制或者一些静态的沉淀，你必须讲清楚，用现象学的方法去讲清楚。

当然，你不可能去看一个小博士生的博士论文或者教职论文，那还是毕业没几年。他后来花了好像十几年时间搞出了《逻辑研究》，非常痛苦，这个过程非常痛苦，花了十二年时间从这走到这。因为这更具有普泛性，逻辑结构好像在所有知识结构里面都有，所有学科化的、当时盛行的科学化思维、逻辑化、形式逻辑化的思维都盛行。好歹他活了这么多年，好歹狄尔泰活了这十几年；否则，一个学数学出身、然后歪门八门去搞的人……你要知道，如果没有狄尔泰去接纳胡塞尔的这个现象学，没有狄尔泰接纳胡塞尔的《逻辑研究》，文德尔班、李凯尔特这些马堡学派的人——其实已经成为学阀的那些人——他们是要把整个布伦塔诺心理学，就是意向性和现象学，以及胡塞尔的现象学，通通都要枪毙掉的，会压迫、压制他们。幸亏狄尔泰多活了两年；他如果没活这两年，如果没活这几年，现象学就不会这么轻松、不会这么早。这是历史的巧合。

而且幸亏狄尔泰不忘初心，不忘他年轻时候的那种姿态：回到事实，看到真理本身，看到事实本身的哲学姿态。而李凯尔特这种人，他不像哲学家，这种叫做学术学法；你知道，他不是追求知识，而是通过概念体系、学术活动来维护自己的名位和权力，专门搞占便宜。他做学问不是为了追求真理，是为了占便宜。他可能忠诚于康德的某些教条。海德格尔在《时间概念史导论》这本书里面清楚地告诉你，这个李凯尔特有多蛇。这本书挺好的，还不错，因为它比较清晰地梳理了现象学如何经由狄尔泰在海德格尔那里酝酿出一种全新的……

我把它叫做 temporal，所以我把三杠一杠四这整个体系叫做 temporal phenomenology。或者我把它叫做……不能叫做这个，因为如果把它叫做 modern，它会和我这个英语发音不标准……不管它，它会和生活世界混淆起来。它一定要叫做 temporal，就是它是时间的、可朽的、历史的；这个词里面有可朽、历史，都蕴含在里面。这种现象学的问题线索就是时间性。

为了探寻时间性，我们在认识论上必须敞开，要实事求是，不能瞎搞；不能像胡塞尔那样用本质、用范畴直观，或者用一种他早年喜欢说的描述心理学，不能太早地用范畴表把这个东西固定下来。他甚至还要引入辩证法。胡塞尔的问题就在于他的现象学还原太快了，不停地用范畴表把东西固定下来，这就不行。虽然要有一种概念性的、生产性的概念生成，但胡塞尔做得太快了，而且他完全是在一种现象学的迟滞、滞留当中，完全是悬在那边的，所以他错失了时间性的一些很重要的结构。所以在胡塞尔那边，内时间意识、时间性被看成是被构造物，它没有被看成具有构造性的力量，没有被看成具有那种生成过程。时间性有生成过程，但它本身是被构造的。

becoming，它有 becoming，但它的 genesis 没有太高的本体论地位。所以这个现象学我把它叫做一种尘世的现象学。但这个现象学是最具有丰产性的，它最具有丰产性，它是最 productive 的，它产生出来的那些智慧是最了不起的。也就是说，在现象学上，它对应着海德格尔、萨特、梅洛庞蒂、列维纳斯。我不知道，我不确定，这里不是每一个人都放进去，要看我到时候具体的思考。我不预先有答案，这种东西本身也需要我来思考。I have to think about it\. I have to think through it\. 海德格尔放在哪一格？萨特放哪一个？梅洛庞蒂放哪一个？列维纳斯放哪一个？列维纳斯可能不在这里面，不一定要放在这里面。这都不确定。

也就是说，三杠一杠四具有解放性。它不是观念论，不是德国观念论。德国观念论运动已经结束了；在三杠一杠四，在这种 temporal phenomenology，或者时间性的现象学、时间的现象学、时间中的现象学产生之前，德国观念论也是很伟大的一次智性活动，但它已经结束了。三杠二，这一整个德国观念论已经结束了。后面是由关于历史时间、生命、真正生活过程性的这种现象学，启发了后面的存在主义、身体现象学、哲学人类学，乃至一些结构主义的思路。所以它是非常具有丰产性和启发性的一个思维节点。

狄尔泰的影响是很深重的。如果没有狄尔泰跳出来阻止马堡学派对于现象学的污蔑，如果没有他这么斩钉截铁地去称赞现象学的地位，那你光靠一个布伦塔诺——一个心理学家，他之前还不是哲学家，之前是搞经院哲学、搞亚里士多德和托马斯·阿奎纳的，他喜欢搞分类学，但他的分类学是实事求是的，来一个我分一个，来一个我分一个，了解吗？——如果没有狄尔泰的话，现象学甚至都不会作为一个轰轰烈烈的运动。它会变得有点蛇。你就想，如果没有狄尔泰，胡塞尔在他的学术生涯当中的影响力不会那么强，他就很容易被其他东西给压迫掉、压制掉。

德意志民族还是幸运的，有狄尔泰，慧眼识珠也好，或者说，用他的话来说，其实是解了他终身的难题。因为他说这像一座山：狄尔泰从一个方向去钻，胡塞尔从另外一个方向去钻。胡塞尔钻把什么东西给钻掉了？把数学、把数、逻辑这些很硬的东西——在哲学、在科学化的哲学被科学所轻视，被实证科学所荼毒、所污染的哲学当中，数学和逻辑学这些真理都被看成是很硬的东西，它不是被构造的，逻辑真理本身就是一直和心理主义、逻辑主义在不停搏斗的。狄尔泰在另外一方面，从人文科学、从人文关怀、历史性，还有生命体系，也在这边挖。他最后通达了，两边挖通了，挖通了一整个现象学。
