# 【主义主义】纯思（$\-1\-1）——“存在”本身，理念等级制派下来的先锋小弟，试着自居这一角色，你就把握了这个环节

我们今天讲这个主义主义的存有论，没有缺省，然后一杠一。这就是黑格尔所说的存有论。存有论的第一个环节，我们把它叫纯思。

啊，pure thinking，pure thought。我要把它写成 pure thinking，写成动名词形式；我不写成 thought，而是写成 pure thinking。

它是个动词，但在目的论上也是没有的；从目的论上也可以看成是缺陷，但没必要写缺省。省下来的纯思其实就是存有，但它还不存有，还不是存有。

因为在黑格尔那边，它代表的是巴门尼德、埃利亚学派。当然，我对埃利亚学派的解读和黑格尔对埃利亚学派的解读不一样，所以我这里的代表人物是黑格尔所认为的 Eleatic 埃利亚学派，即黑格尔哲学史版本里面的埃利亚学派。那么这个是纯思，其实就是有；但这个纯思还没有意识到它一定会走向无。所以一杠一杠一就是：目的论上有了这个一之后，才是走向无的那个存有。所以这里，在本体论上这个一还是逻辑，在认识论上这个一就是系词。这个纯思实际上就是存有，它代表系词，一种系词意识，你也可以把它叫做系词意识。

就是准备描述，ready to describe, ready to describe, but don't know nothing，你不知道 describe anything。就是说它出去之后，describe 什么都 describe 不了，回来就回到它自身。

这很简单：所谓的纯思就什么都不思，但它这个时候还没有把握到自己是什么都不思；它是一个尚未把握到自己“我打算思考了，but I don't know”的状态。所以这种纯思，由于它还是尚未把握到自己的状态，黑格尔在这里其实赖皮——他直接把纯思或者埃利亚学派那边的纯思说成有，就是有，或者就是 being，就是存在，就是存在。

我不把它写成纯有，因为所谓的纯有就是纯粹的纯思，pure thinking。纯粹的纯思的话，黑格尔走向后面实际上是加倍的。

纯思是有所谓的，就是开口说话，打算开始描述，准备开始描述，就是开始想要说 there is……，想要开始描述。描述什么？描述你的意识场域，描述这个场。什么样的场他不在乎，场论上是没有的；他不预设你这是一个什么样的场，所以谁都可以用。他就打算说 there is……，后面是啥不知道，不知道。但是黑格尔说他这种纯思可以这样说：他就是 there is……

这是一种敞开的状态。但是黑格尔直接说纯有论这个环节属于质 quality，quality 的下面第一个是 pure being，纯粹的、纯粹的有。那么这种纯粹的有在他看来，其实在我这里就是一种纯粹的纯思 pure thinking。或者把这个 pure 改成 only，only pure thinking，这个 pure thinking 就变成 there is nothing, only there is，只有这个 there is。这个意识还不是问题意识，只有这个描述意识、意向性，只有这个意向性本身。

只有一个想要把自己充实的意向性本身。但是它想要把自己的意向性充实，却怎么样？没东西充实，它只能用自己充实它自己。所以它归根结底是匮乏，里面没有任何东西，就像我要吃没东西吃。黑格尔说把这个纯思等于有，那么纯有就变成只有纯思；所谓的纯有，在黑格尔逻辑学那里……

后面一个一杠一杠一了，我们今天就讲一杠一。一杠一在这里是有两个运动的。它是有运动的，只不过它没有被写到这个图里；或者说它是有四种运动都有可能的：前面是不可能，后面这个是还没有，对不对？那么这个一杠一会有，黑格尔哲学一开始就会说它会有：这个要到这里来，这个要回到这里去，要给出来，再回去，会有这么个运动。就是这么一个本体，本体想要给出自己，给到认识论上，给到这个现象、体验的维度；本体想要给出体验，体验要回过来成为这个本体本身。所以黑格尔说这个东西如果普遍来说就是 self 等于 self。

这个所谓的纯思，就是 self 等于 self。如果是真正纯粹的纯思，就是谢林的，就是上帝的那个纯粹纯思。完成一整个过程的话，要展开一整个过程，就是理智直观。但对于人来说，这么一个纯思就是纯直观，only 直观，只有直观本身。我只有想着是直观某个东西，但发现没东西直观，就是它直观它自己，只有这个直观本身；你只能看这个看活动，没其他东西可看。

所以黑格尔在这里已经把握到这个运动：一方面它是绝对匮乏，但另一方面它又使得后面这些运动环节开始了。这运动环节到后面就会一个个增补到这个上面去，甚至增补到这个上面去；就是后面这个累计上去之后，它会让认识论上开始有更复杂的，然后开始变复杂之后，它会让本体论上变得更复杂。这是一个发端、开端，是一个发端的开端。它跃跃欲试，蓄势待发，要到后面去，但不知道到后面哪里去。黑格尔认为你把握这个张力，就知道他怎么把后面这开显出来。他一开始开显出来是认识论上这个一是一样的，认识论上一是一样的。

这里的“一”可以解说、描述、阐述，是对它的一个刻画、一个规定。他就是说想要给出规定性，想要让规定性显现出来，打算让规定性把这个视域敞开出来。所以认识论上它就是个系词，认识论上就是个系词。就是 being，这个 being 作为系词本身被名词化，而且它是个动作过程，这里其实可以看成是个动名词，系动名词。

它就这么一个东西，而且它是 pure being，就是除了这个 being 之外什么都没有。这个 being 其实就是打开门，等着看有什么东西从这门进来。那门里什么都没有，那这个门有什么？门只有这个开门这个过程自己，或者只有这个门自己。你连门都没有，门也是规定性。

我们举个例子，它这就只有这个敞开活动本身，只有这个敞开活动本身；它敞开了后面这个东西，使得后面这个有后。但是后面这个目的论的运动是在它们的差异之间的，就是这个一杠一。只有这两个东西，左边这个是逻辑。左边这个东西就是完满的上帝，但它是作为逻辑的上帝，或者作为一切本质，一切完满的本质。

这个逻辑里面包含了整个世界的所有发生学的东西。这其实就是语言，神圣的语言，一种神圣的语言；就是神的形而上学。在本体论上，这里就可以叫做神的形而上学。里面包含了神的形而上学，但是他要把它讲出来，讲出来首先要有系词，要用系词把它讲出来。那么第一首先讲出来就是系词本身，就是这个有，或者叫做存在，there is 那个 is，就这个 is 本身。

先把这个系词讲出来。但在这样讲的时候，实际上已经是一种分裂了，在这里隐隐地包含分裂。这个东西是蛇皮的匮乏，这个东西厉害得不得了、完满的；它都是一，但它们又都是一，又是等同的，非常有意思。所以他立刻——下面后面立刻一个运动——就是：这个东西要奔向无，要说我是小弟，我是被您讲出来的。我这个系词是被您这个神圣逻辑给倒说出来的，我是您讲出来的，我是小弟，立刻当小弟。先臣服，所以这个一杠一杠一，这个一就是臣服，先跪下来，跪下，禀圣上：咱家已经到达现实存在的第一线了。

我学个太监腔，说明我没有性别歧视，我连太监腔都能模仿。我是无，等着您来给我施加定在，规定性降临下来，这么个意思。所以你可以看成，黑格尔所想的就是神派了个小弟，这个小弟就是他的一个系词。这个系词就是让太监下去开戏台，开戏台募捐，挣钱挣回来。其实他自己是匮乏的。说实话，这个就像嘉靖皇帝一样：你看上去好像这个神非常富有，其实他自己是匮乏的。他就靠小弟下去开一个戏台子，这个戏台子就是这么一个系词，being 存在；它是一个整体，整全。

那么实际上，他们之间相互之间是有张力的。这个东西并不是直接和它相等同，但是他会下去就直接说我什么都不是；他必须说自己是匮乏的，才能让这个大哥放心：你这个小弟很会当小弟。他必须把自己说成什么都不是，所以才能反过来说自己是他，自己秉承着他的旨意。我是一个空的规定性，这规定性展开要靠一个外面的意志性神圣力量来降临。所以他首先展开的是这么一个认识论上这个一。两个看上去都是一，但他们不是同一个一：这个是站在背后的大哥，这个是站在前面的小弟。你要知道，他就是个小弟；大概你要明白这里面的关系。

但是呢，这个大哥要本体上这个一，本体上这个一，他会发现他问题很复杂：他没有完全直接就是一到底，他最后要变成二。没有办法，自己要分裂，本体上自己要分裂，他最后要变到二。就是这个小弟不停地回来禀报：我下去这样搞，一二三四，不同的方式搞了，大哥都不行；那我变成二，大哥本人变成二。

那么明天我们再来讲辩证法第二讲，这个纯有。所谓纯有，今天讲的就是有，它等于纯思，pure thinking。所谓纯思，就是自居为是大哥的太监降下来摆戏台子；我的纯思是摆戏台子，就是展开戏台子的。我的大哥要登场了，或者说你们赶紧募捐，赶紧把好东西交过来。这个纯思就是敞开一个主体性的视域。这个敞开敞开了之后，在后面就会立刻说：我什么都不是，什么都没有，我什么都没有；里面就是我，我就是场，我就是负责下来开这个视域的。你不要以为我是什么，他一定会走向无，一定会立刻走向无。好，那就讲到这边。
