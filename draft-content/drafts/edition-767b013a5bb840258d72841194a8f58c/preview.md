# 【实事求是】我不是媒体人，我在现实里做现实的有利于大家长远利益的事，以及为什么单单是评价某些小资产阶级媒体人，就是在侮辱我自己

我来评价一下我眼中的马前卒。我觉得他年轻的时候是一个纯粹走激进知识分子路线的人，搞所谓的“体外合成一个不可复制病毒”。这里说清楚，病毒是体内合成的，体外是有一个壳，DNA壳或RNA壳在那边。

我们说，他这个东西是体外合成的一个不可复制的病毒，就是他所谓的 YCA。YCA 后来因为丑闻以及核心成员的背叛，没有什么代表性。YCA 当年就是一个激进小知识分子，没有大众性，也没有代表性。也不是说他那边的左派代表人物去打工了，打工打得蛮开心。我去广东想见他，在微信上说“我到你厂门口了”，两三次他都不出来。这个人已经做日子人了，绝对的日子人，身上也没什么料，我不确定。他们 YCA 所谓的左的那一部分人，打工打得很开心、很舒服。之前他和尖椒部落闹矛盾，法律援助都找到我们这里来了——找到我们这里来，五四的前身，搞劳动仲裁。就这个人情，他见都不愿意见一面。他以为我是什么地下激进活动家？不是的，我只是一个什么都不懂的小年轻，想去了解了解、认识认识。当时我不知道他曾经是 YCA 叱咤风云的所谓的左派代表人物。现在回想，那群人就是一群失心疯的小年轻疯子。马前卒在里面是一个最识趣的疯子，早早离开了疯子团队。这群疯子在网上他们那个网站 2014 年最后的文章说，马前卒带着这群人是伪 YCA。后来马前卒投靠了所谓的官网，拿了名字开头和我三个字三个字母一样的那个人，好像拿了多少风头嘛，一千万吗？我不确定。你不要说我诽谤他，不要说我乱造谣。

说他拿到这笔钱之后，还资助了一些残部，YCA 的残部，或者流散出去的这些东西。你安全机构或者一些机关，我没有递过材料，也不掌握线索。你们想了解，直接去问他好了，老婆孩子都在苏州呢，你去问他，他啥都不交代嘛。据我所知，他没有收过境外的钱。如果你把 YouTube 上他几万、几十万、上百万的浏览观看也算成境外的钱，那他收过；但除此之外，据我所知，他应当没有收过。如果收过，他早就没了，早就进去了。

在那之后，他就是个媒体人，基本上就是个媒体人，没什么用的媒体人。作为一个媒体人，在我眼里就是没有用的。他对于上海和江苏这一片的激进学生没什么影响力，老实说，没什么影响力。你说他将来有没有可能加入那群有所谓影响力的人？那他得流亡出去啊。他有老婆孩子，得流亡出去才能说对这些激进学生有煽动洗脑的能力。目前来讲，他不太有；我的判断是他基本上没有。那你说我判断他是个所谓的社会主义者吗？我认为他不是，很显然不是。

他赚的钱能够在苏州买房了嘛？他能接受那个资产阶级投机客的那么多钱，完全丧失独立性。这东西实事求是讲，没什么好说的。我最低要求是：你自媒体赚的钱——他不是像我一样。我在自媒体里面，账号是我自己运营的，完全是自己拍的，而且我从来不剪辑。我的机构号，甚至我的网店，机构号是我自己公司的注册号，网店收益我是不拿的，我不从中获利。这个话我公开说，如果传到我团队成员那里，如果我说假话，那我就没有信用、没有威望了，我对他们说话他们就不服我了。但是马前卒呢？不是的，他是一个机构号，不是个人号，是他所谓《睡前消息》的机构号，是共同劳动的一个东西。你里面的钱是怎么分的？我不认为他是社会主义者，他不践行社会主义。

你里面的钱是怎么分的？我不认为他是社会主义者，他不践行社会主义。他哪怕做自媒体，做一个自媒体的老板，他是个资本家——那不能算资产阶级，算个小资产阶级，是一个账号运营人、老板。我的团队成员称呼我为老板，那是保护我，出于保护。那么我们要讲的就是，对于马前卒，他做一个媒体人，就是资产阶级做派、小资产阶级做派，这就是利益分配。你现实的利益怎么分？你自己拿大头去苏州买房了。你们薪资保密，但是实事求是讲，我认识的朋友如果在马前卒团队里面，没有向我透露过他们的薪资状态。你不要说我这个朋友违反了你的什么薪资保密协定就把他开除了，那我们要帮他劳动仲裁的，都闹得不好看了。

我们说马前卒他的团队，包括整个《睡前消息》，在社会主义者、共产主义者里面是混不进来的，没有位置。你说他们反什么，那都是自我标榜的。我的判断是，他最近这一系列操作，我明确和你们所有人说，就是人事卡位。最终目的指向的是人事卡位，可能是后面的金主——不一定是金主——或者说对他本人做这些具有政治风险的投机、具有影响力的那些人给他派的任务，就是四个字：人事卡位。我再明确告诉你，就这四个字。人事卡位，因为他能够影响到的受众……

实事求是讲，你不要以为他几百万、上千万粉丝好像很多。他现实能够激起的，老实说，只有一些敏感地区、比较容易成为景观的——成为海内外某种风景、某种丑闻性景观的——一些年轻人。这些年轻人可能因为他所遭受的东西，更加悲伤绝望一些，或者说更具有幻想、更具有妄想一点。这可能是一个要素、一个因素。那么就算有这些丑闻性景观，它最后实质的作用就是人事卡位。金木水火土之木也，木在东方，木色为青。

我对他的评价，我觉得有的时候挺可笑的。我不是指他人可笑，我是说我对他的评价本身挺可笑的。因为按照道理，我这样的人根本不屑于去评价他。实事求是讲，我这种人应该根本不屑于去评价他才对。因为在实践上、在线下活动上，他是搞了一地鸡毛。YCA 还出丑闻，非常滑稽，以为可以在体外合成好，然后搞激进知识分子。你说他成网络化吗？

他也不登大雅之堂，没有高级知识分子加入，都是些小苗苗头。这又不是说他保持平民性，但 YCA 里面的右翼很早就在想和这个大人物合作、和权贵合作。这些人其实也都是实用主义者。但是马前卒始终没有探索出一条，他根本没有探索出一条，也根本没有探索过任何一条怎么做。他所有的说辞都只是在表演、在放屁。说来说去，我的评价就是一个娇嗔的硬仆。

哀婉的娇嗔。乾隆评价纪晓岚，哪怕是纪晓岚这样的，本倡优畜之，倡优之徒也，倡优之辈。这也是整个小资产阶级的可悲性：对于时局、对于现实不能有实质性的影响、实质性的改变，停留在虚幻无力的舆论层。

那你说我有什么不同？仅从做自媒体这一点来讲，我从来不追求我的东西广泛传播，因为我知道在小资产阶级圈层里面广泛传播不是件好事。所以我的视频从来不剪辑，很少剪辑，基本上不剪。我就算要剪辑，也是为了过审，我不剪辑的。而且我就是做得长。小资产阶级里面得有有耐心的人，因为看我视频的受众主要是小资产阶级。在互联网上看我视频的主要是小资产阶级，但这些小资产阶级当中的青年是要无产阶级化的。我们不用“先锋化”这两个字，不说他变成先锋战斗分子、先锋分子，我说他无产阶级化——他变穷，穷了去打工。现实会告诉他的，很多话不需要我来说。

包括线下他一起打工的同学朋友会告诉他的，他自己自然就会懂，轮不到我来说。我不追求互联网上广泛传播，根本不追求这个东西。我的差别就是：我不认为我的本质是个自媒体人。从根本上来讲，我不是个自媒体人，不是个媒体人。我的视频主要内容很明确：一是哲学入门，然后意识形态可以进阶；把哲学学好之后，可以搞意识形态分析进阶，具有意识形态批判力。那就是训练理论家，不是传播。我的视频是从零从无到有训练理论家。哪种理论家？无产阶级化的小小知识分子、无产阶级化的知识分子。你要具有我点出来的这些理论能力：意识形态分析能力。

另外一方面就是现实观察、生活建议、行动建议。这些观察和建议就是给我的支持者看的，我不要给很多人看。你认同我、支持我，你就看、就采取；你不认同、不支持我，你滚蛋。我不要你，我要你干嘛？不是说你不认同我怎么样，或者不采取我的建议怎么样，我压根就不要你。相看两厌，对不对？所以我做自媒体，什么路人缘啊？你觉得我的道理有道理？你觉得我的建议是建议？你觉得这个生活方式是你比较好的优化方向？你就这样活。目前来讲，按照这种方式重拾生活希望的人不少。

按照这种方式，在无产阶级化的生活当中克服小资产阶级种种劣根性，甚至精神病理化倾向的年轻人不少。我线下见过不少，本来魔怔着，正儿八经过日子之后越来越不魔怔了。像这棵树本来长歪的，慢慢又长直了。我抛头露面在互联网上讲这些东西，那是因为没有别人。我怎么拦着别人不准讲啊？讲我这个东西，要让无产阶级青年、无产青年知道怎样的生活好过，怎样的日子能够正儿八经、坦坦荡荡、舒舒服服地过，至少心里舒服，只要不被歧视，至少有一个不歧视你的、平等的生活情境和氛围。

我们看小资产阶级媒体人里面最勇敢的，真的要说是马前卒了。抛头露面，还被人挖前面的料、后面的料，家里老小。除此之外，这些人都不敢为自己说的话承担现实代价。我承担现实代价，我还被告了，还被凌控。我要说清楚：我觉得我评价他都是在侮辱我自己。首先，我评价他，我不侮辱他，我都实事求是——他做过什么、没做过什么，起到什么社会作用，就那个限度，不超过那个限度。他没有额外的政治作用，没有什么社会号召影响力。有几个人会按照他说的办法去生活？在小资产阶级观众眼里，他就是个电子榨菜，看着玩的电子宠物。看他什么时候乱，看他什么流亡，看着玩的。有几个人是践行他那种生活方式？没有，很少。

但是我不一样，我们还走群众路线。你小资产阶级有时间发那么多东西，在我评论区或者知乎上发有的没的，我的主要受众没有时间发这些东西。我的主要自媒体受众，是我的理念的支持者、践行者，他们很多人把知乎都删掉了、卸载了。而且我不需要多少人。我们这些都是小资产阶级青年当中无产阶级化的那一部分。他家里本来可能还给他一个重新稳固、继承小资产阶级社会地位的苗头，一个火苗，火苗慢慢熄掉了。后来他慢慢从我这里重新把准生活方向，但他已经是个无产青年了。他在城市里面，如果问家里要几万块钱，去混个什么东西，可能又变成小资产阶级青年了。

但是这些青年，只要不向家里一下子要那么多钱——一要几万块的那种——他在城市里靠自己的劳动所得、劳动状况，就是个无产青年。这些人很老实，很听我的话。不是因为他们听话，而是因为他们懂得什么样的话该听。我叫他们不要政治激进化，不要和小资产阶级这些其实就是目的为“人事卡位”的喉舌一块玩，没有任何意义。对于他自己的现实、实质的人生发展、生活形态、生活方向，听那东西，听来听去，听个响、听个玩，没有任何意义、没有任何价值。你这个时薪能涨一块钱，或者房租可以少交一点，但是听我的这个，某种意义上，他能找到志同道合的人一块合作、一块去打工、一块去谈价格，能够影响他的切实利益。你不要说少，六七个七八个总有，六七十个七八十个总有，六七百个七八百个总有，对不对？

各地调查人员去调查这些人有没有激进化，有没有要上街、要搞事、要什么乱七八糟的。你说他们农民工，本来就是工人，没什么融不融的。而且我说了，不要激进，不要搞事。六七百个七八百个，我没有统计过，我毛估估。你说我在吹牛，但我有六十万粉丝了，我不相信这六十万粉丝里面没有打工的、没有做工人的年轻人，肯定有。按照我的说法去找志同道合的年轻人，干干净净、正大光明地一起生活、一起劳动，让自己的利益最大化，谋求自己和自己所属劳动群体的长远利益。这样的年轻人肯定有。如果没有，六十万里面连六百个都没有，那这个国家没救了。肯定有，我觉得远远不止这个数。

所以这是我和马前卒的绝对不同。马前卒讲的那些东西，有几个小资产阶级按照那种方式转变他的生活方式、生活习惯、利益取向、人生重大利益抉择？有吗？没有，在搞笑。实事求是，这就是我对他的评价，以及我和他的不同，巨大的不同。咱们不一样。

他是媒体人，而且是小资产阶级媒体人。他在现实世界当中的主要身份就是这个。我不是，我不是媒体人。我创造的媒体、我创造的这些视频内容，不是要让它广泛公众传播的。有些视频传播得多了，干啥？我不让它传播那么多。你能过上我所说的这种生活方式，你认同，那你就要过这样的生活。阿正说了，对社会主义者、共产主义者来说，崇拜单一的生活方式，也是一种对哲学的盲目崇拜。

哲学到生活方式，生活方式到生存的意义，这是哲学的一元论、独断论。真正的社会主义者、共产主义者应该有什么样的生活方式？应当随着历史运动的大潮流、大趋势变化，是要发展的。最终追求的不只是个人的解放、民族的解放，而是全人类的解放。过程当中生活方式是要调整的，是富于变化的，是勇于变化、敢于变化的。没有说让你往非法的、激进的方向去变，但不是一成不变的。不是说有某个理想的、好的、不变的生活方式过上了，我人生就完满了。人生完满什么？

真正的共产主义，哪是追求个人人生完满？要追求的是全人类的解放，对不对？但这不是要求所有人觉悟都那么高。所以我们说，你就做一个现实的社会主义者的话，那你做一个无产青年，过一个相对舒坦的、至少精神上、心理上舒坦的生活。然后在自己的团体当中还是平等的一种生活，是能过得上的。在我们的努力之下，很多人也过上了这种生活，只不过相对穷一点、相对磕碜一点。但无论如何，它是个现实的变化。

再强调一遍，马前卒虚头巴脑，他是虚拟的键盘棋盘上面的一个虚幻人物。甚至我要说，我们的态度是：我们不仅对自媒体、媒体舆论上的东西感到它是过眼云烟，甚至对什么人事卡位这种东西，我都觉得是过眼云烟。它不是历史的大事，都是细枝末节、等而下之的东西。无非是茶壶里的风暴，或者风暴里的茶壶，蜗角之争。蜗牛两个角上有两个国家，两个国家要互相攻打，蜗角之争而已。它不是社会劳动群众运动的大潮流。

但在这一个小喉舌媒体，你不要看他那个样子。按照他实质的影响力，他只能影响一些幼稚、无知的激进青年小孩，往往是无产阶级青年。我相信无产阶级青年，我是能劝得下来的。我们精准能找到高校或者互联网上的无产阶级青年，我是能劝得下来的。他只能搞一些这种景观，然后最后搞丑闻，丑闻然后就是派系斗争、人事卡位，除此之外没有意义。他是派系斗争、人事卡位的工具。这类喉舌只有这个意义、只有这个作用。喉舌之为喉舌。

他只能说这个食物好吃不好吃，口感如何、味道如何。那对于这个东西有没有营养、有没有毒，即使很多他尝不出来，没那个本事，要靠肠胃，要靠跑肚拉稀，要靠身体不适、肌肉酸痛、头晕目眩这些东西，才能判断这个东西到底有没有问题。

所以我最后再说一遍，马前卒是憋腿的卒子，让这个马跳不出来。马克思主义真正的现实的活动、现实的实践，被这个卒子憋了腿，跳不出来。他这个小资产阶级喉舌没有任何意义。money，钱，money 只是个钱而已，钞票而已。
