# 【主义主义】原来“形而上学”才是真正的辩证法：论辩证法的片面、静止、只有量变和二元对立——正统辩证唯物主义（2\-4\-4\-2）

今天要讲的是主义主义的二杠四杠四杠二。这个代表人物是 S，这个东西叫做 orthodox；后面那个 orthodox，也就是正统的 DM，即正统的 DM 主义——正统辩证唯物主义，dialectical materialism。

那么代表人物是 S 同志、Stalin。这个哲学其实很简单：在场域论上，它本质上是形而上学，但它用两个东西对立起来。一个是形而上的秩序，即一个静态僵死的观念体系投射到这个世界里面、主宰这个世界；另一个是它所谓的辩证的、生命的、鲜活的东西，但不是否定性的。问题在于，它把否定性捐弃掉了，把主体性的否定性变成一种辩证法。这个 orthodox dialectical materialism 的问题就在于把否定性变成一种形而上学秩序，认为世界本身具有否定性，却没有意识到这种否定性永远要 subjectivize，永远要主体化。它的主体性被称为主观能动性，但这个主观能动性根本一点都不能动，就是个屁，因为它没有把主体性的维度架设到它的形而上学秩序里面去。主体性的维度就是：世界本身、实体本身是主体化的，实体本身是断裂的，实体本身并没有被一种既定的正反合辩证运动所操纵。

它之所以能够体现出这个世界，是因为它的中介化不可避免；因为第一人称，它阉割了这个 dialectical materialism 里面的 matter。它里面的物质不是真正的物质，而是科学实在论那种物质，即世界具有物质性。

这个“正统”（orthodox，加引号）教科书里面的物质，其实就是科学实在论那种很庸俗的物质。但它又说这个东西不能直接认识，只能间接地反映，我们对它采取一种反应论。这种反应论是一种能动的反应论：它既是可知论，又是能动的反应论，可以对它加以批判，是能动的。这个体系就是我们在必修四政治书《生活与哲学》里都会学到的。

但这个东西其实是一种形而上学，归根结底是形而上学。按照它自己的标准，它也不符合。它里面所说的一整套辩证法——矛盾是普遍的，也有特殊性，矛盾是特殊的，一切对立统一——这个“对立统一”概念本身就是虚假的概念，连 unification 都出来了。它是总体主义，实际上是一种整体主义，最好说成整体主义：无所不包，什么都被它说了。

然后我们用 Stalinism 里面对形而上学和辩证法的二分来看。这个二分很有意思。前面讲高尔吉亚时也讲过，高尔吉亚 versus 德谟克里特 versus Stalin，里面就讲过。斯大林认为，一个理论、形而上学是片面的，而辩证法是整体的。判断形而上学的一个标准，其实他妈的辩证法才是整体的。他第一句就说：辩证法永远是片面的，dialectical, it's always partial，它总是 partial。因为你不能预设一个背景性的秩序，辩证法不能预设一个背景性的整全秩序。你假设有一个背景性的整全秩序，那就是形而上学。所以这是 S 对形而上学和辩证法二分提出的几条评判标准。

第二条：就算一个形而上学是整体的，就算存在一种整体的形而上学，但它是将死的，形而上学是将死的；而辩证法是活动的、运动的。这是第二条。你看他不停后撤。他妈的满足你第一条规则了，是整体的，那你有没有可能用一种整体的形而上学冒充辩证法？当然有可能。

然后又来第三条：就算这个形而上学是运动的，但形而上学是什么？形而上学的运动只有量变，没有质变，只有量变；而辩证法有质变，有断裂，有跳跃性。这是第三条。

还有第四条：就算这个形而上学有质变，它还是什么？它还是一个循环往复的质变。它的运动是循环往复的。辩证法则是正反合的螺旋上升。我跟你讲，这四个判断标准……

真正的辩证法通通站在形而上学那一边，the real dialectic stands……你如果要真正理解辩证法的话，真正的辩证法通通站在这里面对形而上学的指控那一边。斯大林在判断形而上学和辩证法二分时，提出了这么一二三四的标准。但他就是层层后退：你形而上学是片面的，我辩证法是整体的；就算你是整体的，你还是僵死的；就算你不僵死、是运动的，你还是只有量变；就算你不仅有量变、有质变，你还是二元对立的，还是在换汤不换药的循环往复的运动，而不是螺旋上升。这个二元对立的循环往复的运动不是螺旋上升。你看，一个形而上学就算做得再像辩证法，也还不是辩证法。这样结果就使得：辩证法到底是啥？其实这里隐藏着，它所追求的那个辩证法就是他妈的一种形而上学，就是一个僵死的。因为它只不过用一种所谓的螺旋上升、正反合、总体主义、整体主义的合体，来掩盖它的片面性、僵死性、只有量变、只有言辞的变化，掩盖它归根结底的二元对立——主体性、主客体的二元对立。归根结底是二元对立的，蛇皮的，很蛇的。

这里要插开来讲一句：你要理解辩证法的思维，恰恰和这种 orthodox dialectical materialism 完全不一样。我们应当站在 the real 或者 the true dialectical materialism 这一边。那我们要怎么做呢？我们要告诉你：辩证法是片面的、僵死的、静态的，是只有量变的，还是二元对立的。辩证法本身是片面的、僵死的、只有量变的、二元对立的。和解呢？辩证法就是否认有一个 impartial，即有一个公正体国、不偏不倚的视角；不存在不偏不倚的视角。这个不偏不倚的视角、这个大他者视角、这个绝对真理的大他者视角，一旦你去想有这个视角，你就是形而上学，或者就是实在论，就已经不是辩证法思维，而是一种反动的思维。你假设存在一个不偏不倚的大他者视角，那岂不是拱手把所有的斗争必要性全都让给掌控这个视角、对这个视角具有发言权的人？所以辩证法永远代表主体只能以一种行动的、干涉的、牵连的、受到牵连的方式存在：你的思维、你的精神、你对世界的把握和你的行动是一体的，不能分开。了解吗？

它不能分开，不意味着它们形成一个整体，而意味着你所有的行动、所有的思想都是从特定角度出发的。这叫做视角主义，perspectivism。你不理解视角主义的话——perspectivism 都是从特定角度出发的，从你特定的那个 partial 出发；这个 impartial 是不可能的，不偏不倚是不可能的，这是幻想，是形而上学幻想。你越这样，你越不敢去。举个例子，就是考茨基和当时的十月革命。当时你要获得一个不偏不倚的视角，然后说“这个时机到了，我们可以做事情了”，这永远抵达不了，你了解吗？因为你那个不偏不倚的视角是那些胜利者灌输给你的，是那些站在上面的人给你洗了脑的。你如果按照这个不偏不倚的大他者视角去看待现实时机什么时候到来，你永远是错的，永远是来不及的。因为你的行动最终就是要突破这个不偏不倚的、现行的、公认的不偏不倚的视角，突破现行话语统治中在话语和思维体系里占统治地位的视角。辩证法就是这样的：真正的辩证法永远是片面的，永远是 for partial，这个 standpoint、partial standpoint。你总是已经牵扯身在局中，不能打马虎眼，不能说公中体国那种好货的样子。这不是辩证法。辩证的行动永远是 subjective 的，是一种主观的；主观意味着深陷其中。不是说只有 subjective 才可以 objective，而是你只有主观了才具有客观性。辩证法当中主客观统一，你要不要理解成我们可以获得一个主观客观的整体？不是的。它不是获得谢林意义上的主客观结合的那个点，不是那个超验的点。辩证法意义上的主客观不是统一，而是你只有以一种主观的、片面的、有限的姿态去实践，去向意志性敞开，才有可能对这个体系造成客观影响。这个客观不代表在一个不偏不倚的视角之下可以产生确定因果性的把握，而是新的因果性会生成，新的符号学秩序会生成，这种秩序本身能够被你领会到。因为符号学背景背后到底怎么样，你不能由一个不偏不倚的视角说“背后怎么样”，你一定要介入其中，介入干涉，刺穿、打破均衡。因为这个均衡本身脱离实际，是虚假的，这个悬浮在空中的普遍视角本身是欺骗性的。它不普遍；如果它普遍，根本不会有你存在，根本不会有辩证法家出现，根本不会有这些混乱动荡。这说明它本身屁股是歪的。无论你是一种学术性的姿态，还是意识形态上高高在上的姿态，说“我把握了社情民心”，这都是他妈忽悠人的，你知道吗？

所以辩证法的姿态，你看卢卡奇《历史与阶级意识》里面，其实比较清楚地描述了列宁当时如何进行这样一种冒险，一种跨越性、跳跃性的冒险。这意味着你如果是辩证法家，你的实践、你的行动不会依据一个整全的视角——哪有嘛？你要能够敏锐地把握到一些核心矛盾、核心断裂、一种张力，快不行了。像列宁就非常天才，进一步发展了 Marxism 的观点，把它演变为帝国主义的论断。他得到一个天才洞见：可以在一些民族国家里提前爆发革命，因为帝国主义的矛盾在当时是主要矛盾，当时 class struggle 的形态变成了 nation states 之间的形态。但只在那个时代，只在一百多年前那个时代，好吧。

这是一个片面性。还有一个是僵死性。辩证法是僵死的，因为辩证法可以把握到所谓历史的流畅运行、流畅进步、平稳运行，但这是个幻觉。辩证法代表的是历史卡住、卡壳、卡住的地方，卡住的那个点。历史按照它这个时候，一些意识形态里的观念本该流畅运行——“多少年，多少年，怎么怎么样”——但它在那个点上卡住了。这种卡住意味着背后有某种物质性力量、意志性力量，超出你的符号系统，能够对你的符号系统具有 subvertive 的作用。这种力量、这种卡住、这种僵住，是辩证法特有的思维。辩证法就能够知道什么是关窍。所以辩证法要善于把握僵死；在一个地方就要坚持住那个僵死的点，坚持住那个僵死的点。

辩证法是有力量的。辩证法不是好好先生，不是那种调和主义、整体主义：正题反题，哎呀你们别争了，我用一个合题把你两个都包含在内。不是，这不是辩证法。辩证法是要能够让大家知道这是个僵局：你们的二元对立是个僵局；你们的对立不是你们的对立，而是这个符号系统自身的对立。不是说我有一个正反合的体系，能够牵引着这个二元对立消解掉。不，是这个体系本身他妈的已经不行了。正反合，如果它不停正反合，你根本不可能把握到矛盾；正反合不能运动，不能顺利抵达它的合题，这才是辩证法。正反合能够顺利抵达合题的时候，辩证法尚未运行。辩证法什么时候运行？辩证法真正运行的时候，是概念体系已经没有办法俘获这个意志性了，这里的意志性已经大到一定程度，已经超出你的把握了，超出你概念的把握。你没有办法再去忽悠别人说“他妈的这是正常的”“这是你看正反合”，你没有办法再去调和了。你没有办法再说“这是新时期新现象”，不行。掌握这种调和话语的人这时就会惊慌失措，不知道说啥了，沉默了。这个时候只能有真正意义上颠覆这种所谓新时期新话语的一种力量，一种新的命名出现。辩证法、辩证性思维什么时候出现？是在僵住啊。正题和反题的矛盾，不是这两者之间的矛盾，也不是说它就是一个背景性的、更大的、集体的东西的矛盾，不是的。正题和反题的矛盾，就是我们应该按照这个矛盾得出一个正题加反题的大合题，但是这个大合题本身没有办法顺利诞生，历史卡住了，没有办法了。

举个例子，辩证法怎么运行。比如性需求和心理社会化。青年男女青年人的性需求就是肉体关系；心理社会化就是恋爱关系。这两个东西之间有矛盾：你到底爱我，还是爱我的身体？最后用什么来调和？用婚姻来调和，对不对？或者先用爱情来调和。爱情来调和，按道理说这是一种什么？所谓的合题。因为爱情既包含性关系，也包含他们的心理依赖；这种激情也被看成性关系的一个组成部分，好像爱情就把这个东西调和了。

但是黑格尔会告诉你，这种调和永远是临时的，因为它僵住了、卡住了。你把它叫做爱情，其实……爱情这个东西的存在，它很快就会在下一步抵达婚姻。婚姻会把爱情摧毁掉，因为婚姻是一种财产关系，等于说同时把性关系和心理关系这两个都扬弃掉了。婚姻归根结底是一种财产契约关系，财产性的契约关系，共同体的契约关系；它跟你两个具体的人没关系，而是他们的社会属性之间发生关联。它的生物学、心理学这两种急切的主观自我规定性没卵用了。婚姻更多的是：我不管你自我规定性怎么样，它必然使得性需求变得异化，变成一种“不得出轨”、彼此对生殖器使用权的垄断。心理社会化也是如此，婚姻不意味着你们相互之间的情感关系怎么样，而意味着你们共同忠诚于一个新的共同体，就是你们的家庭。这就使得这两个维度的私人性变成公共性。而爱情只是一个僵局，爱情只是这两个东西变成婚姻当中的一个僵局；爱情本身可以说什么都不是，you know，你们了解吗？理解吗？爱情代表一种僵局：到底是性需求还是心理社会化，不知道这两个到底是哪一个。它之所以会成为一个过渡性的合体，就是因为它代表了这个僵局，代表了这种僵住——这两个矛盾对立面僵在那边，僵持在那边。

为什么会僵在那边呢？进一步延伸，因为性活动和心理需求是分不开的，它们是同一种性化机制。这个性化机制本身有内在矛盾，所以才会二元化、二级化成这个东西。这种张力、这种二分性是不可避免的。那么这个僵局会被爱情把握在那边，爱情就会有一种极端的排他性。这个排他性最后会变成结果：极端的去自我中心化，不排他了，完全不排他了。爱情极端的排他性最后让位于子女、父母，就是爱情极端的社会化，极端地形成一个家庭共同体，然后极端地必须具有社会性存在；婚姻必须是一种社会承认的。这个时候，它就不是以一种排他性的姿态来廓清周围人际关系，然后使得这个共同体的最小单元、市民社会最小单元共同体能够建构起来。在这个过程中，辩证法就是你要能够领会这个运动的辩证。你直接从性需求和心理状态通向婚姻是不行的，你一定要站在性需求和心理社会化之间，站在这个二元对立上面，停留在二元对立那个冲突性张力上面，然后把握到这个二元对立本身就是爱情。我们只不过用一种比较粗暴的方式把它命名了，了解吗？

我们看上去爱情并没有扬弃这两个，它没有真正扬弃这两个。如果有个庸俗的合体，那么性需求和你的恋情、你的心理——你和他搭建一个主体间关系——这两个的合体不是爱情，这两个的合体是婚姻。婚姻才是它们真正的合体，因为婚姻使你从激烈的私人关系中解放出来，能够重新获得一个新的自我认同。而爱情只是一个代表这两者张力一直僵在那边、卡在那边的一个符号，一个临时的命名。爱情甚至可以说 is not something notional，爱情不是一个 notional 的东西，不是一个概念性的东西，了解吗？它代表这种不可能性，代表这种 impossibility。所以在这个意义上，爱情可以被说成 some kinds of truth，它是某种真相，truth event，它卡在这边，代表这两者之间的张力。那么婚姻，所以我们说婚姻是爱情的坟墓，婚姻是这两个东西当中冲突的、两者张力的一个坟墓。你结婚之后，这两个东西的关系就被很好地调和了，因为这两个东西都只是有一个更大的共同体的法律在那边调节它们，对不对？这样你理解吧？

什么叫做辩证法？一定是要站在这个僵死的、卡住的那一边，才有辩证运动。因为你光是这个，没什么可说它们是辩证的。你要把握它们之间的辩证关系，心里一定要预设这么一个环节：这个环节是他们僵住的环节，这个僵局没有办法被调和。这个僵局最后如果发展到极致，那只有一种非常创伤性、悲剧性的……它相当于在这个创伤性、悲剧性的矛盾当中，迫使周围共同体必须承认他们两个必须结成一个新的、超越于个人那种极为紧张亲密的私人关系，就要把他们这个关系公开化，以一种合法方式公开化，大家要为他们腾出位置来，那么才有婚姻。自然而然，他们这种张力就消解掉了，爱欲不会过度被投射在两者的差异当中。
