# 【主义主义】目的行为主义（1\-1\-4\-2）——“现实太复杂，生活很简单”婚恋平台的运作机制，吃瓜群众的意识形态

今天来讲主义主义的1\-1\-4\-2。它的代表人物是爱德华·托尔曼（Edward Thorndyke）。他是美国心理学家，但受的是德国训练，也就是格式塔心理学训练。因此，他比较侧重整体主义。这个体系是在德国格式塔心理学、整体主义、完形主义影响下形成的一种行为主义，叫做目的行为主义（purposive behaviorism）。目的行为主义也可以看作整体行为主义的代表，整体主义行为主义（holism）的一个代表。整体主义行为主义又叫做摩尔行为主义。

摩尔行为主义。他们把这套新的行为主义称为摩尔行为主义，而把传统行为主义叫做分子行为主义（molecular behaviorism）。当时很多学科，包括社会学、经济学，都有分子主义和摩尔主义之分，也就是 molar 和 molecular 的对立。我们之前讲过很多次，包括在一些经验主义里面也讲到过。

为什么分子行为主义代表传统行为主义？因为传统行为主义的那个概率论网络，比如用贝叶斯网，里面每一个行为都要算进去，每一个行为都当作一个节点。操作主义更夸张，它把每个可操作项都算一个节点，然后做一个概率论网络，再用贝叶斯原理计算每个节点的概率，计算强化的效率、内在性知识的确信度等等。这种实验做起来数据量太大了。另一方面，它忽视了心理过程：它没办法先算外面再算里面，只能局部地算。局部地算，外部影响以及模型中没有涉及的东西就漏掉了。在可操作主义、可测量原则之下，有些要素不可操作，但它确实是要素，比如潜在学习（latent learning）。

托尔曼举了潜在学习的例子。小鼠被强化成：从 A 点知道可以走到 B 点。强化之后，再通过特定刺激强化它，让小鼠从 A 点走到 B 点。比如地图上这是 A 点，这是 B 点，有这么一条通路。然后把小鼠引到 C 点，给它同样的刺激，按道理它应该走到 D 点，对不对？这个过程小鼠肯定要知道：从 C 点走到 D 点，因为给的是同一种强化，它应该给出同一种行为（behavior）。但结果呢？小老鼠加了同样的刺激之后，它知道这个刺激是要去 B 点。也就是说，它不仅仅知道要走 A 到 B 这个过程，不仅仅知道要进行 A 到 B 这个行为，它还知道有目的性。它把这个强化当成有目的性的，把 B 当成一个目的来把握。这个过程里，它潜在学习到了 B 这个点本身和它的环境，甚至潜在学习到 A 点本身、周围环境怎样，A 到 C 这个过程、这条通路、环境怎样变化，它知道 C 可以重新走回 A，再重新走回 B。这些东西都是潜在学习到的。这些都是你的行为主义理论、操作主义理论没有办法预料到的。这些要素都没法预料到，你根本不知道小老鼠内在的学习有没有学习到把 B 本身当成一个目的去把握，有没有把它目的化。所以潜在学习表明：并不是一种强化、一种刺激就得到一种行为，而是得到了一种意向性，甚至得到某种心理格式塔、某个层面的拓扑学结构。

小鼠明显把它所处的 A、B 整个迷宫环境拓扑化了。它一开始会在 A 点乱窜，然后你引导它到 B，其他地方它都把空间格局拓扑化了，这些东西都被当成一个整体的背景、语境、环境来把握。所以托尔曼告诉你：如果你用分子性的模型——分子就是单个的、一个个的、一个个都拎得很清楚的要素、节点、环节、影响参量——操作主义认为可以把它们一个个都拎清楚，然后再编织一个网络，人工编一个网络出来。但在小鼠这个例子里，网络编出来就失效了，没用了，这种预测没有用。所以托尔曼认为不能这样编网络，不能先把单个的全拎出来再编网络，而要反过来，先认为肯定先有这么一个整体网络在里边。先有摩尔。摩尔就是 6\.02×10^23 个，也就是一摩尔；你学过高中化学就知道，摩尔是分子量单位。很多个、表面上很多很多，它是集群的，变成一个整体，然后简单要素之间形成非常复杂的系统，之后有一个整体的趋向性、整体的一种目的性。比如放到 C 点，它还是会跑回 B 点。它有好多要素，比如这里一个转角、这里光线的暗度，这些要素无数多。名义上，如果把这个链条拉得很长，这个转角处的光亮、这边留下过的气味，这些东西都是可操作的，都有可操作性，你单独拎出来都可以。但是太多了，有无数个，太绵密了。

所以，这个时候就从分子行为过渡到：我们要描述一种摩尔行为。摩尔行为某种意义上可以讨论意向性，还有对环境的认知。认知也包括潜在学习、背景性、背景语境、潜在的学习目的，目的就是意向性的。摩尔行为是和环境发生整体互动的，在环境当中，由环境默认预设了许多要素，形成一些特定的行为。比如这时我们可以说小鼠想要走回避，它有目的；给它的就不仅仅是走本身，而是小鼠能够领会到 B，这时就有对象性，有某种内在的对象意识、对象化的意识，比如定位，以及内在的整个框架轮廓。它能把环境的框架轮廓识别出来：走到这个点发现这里有个转角，走到这里还是同一个转角，框架轮廓有同一性，还有参照系。这时你可以把这些看成基本的意识活动、基本的心理结构，都可以用摩尔行为主义、目的行为主义来描述。所以这是行为主义当中比较优秀的一个模型。

但是它在场域论上还是一，世界秩序还是从底层由物理主义秩序或强力秩序维持的；归根结底还是物理秩序，或者行为主义、操作主义那种秩序铺满的一个场。本体论上也是一，归根结底都是客观现实。但这个客观现实，我们没有办法像操作主义那样一个一个拎出来都描述清楚，这个行为、变量、变动，每一个都拎出来太难了，太多了。只是我们在认识论上没办法描述它。所以认识论上的这个四可以理解成：它不仅仅是黑箱，还是一个过于混乱、太复杂的黑箱。由于它太复杂，里面参量太多，所以我们就放弃认识论，还是用概率学模型去解释它。当然，这个太复杂的黑箱，一方面指客观现实里面参量太多。

目的行为主义融合了格式塔心理学，但它没有办法坚持格式塔心理学的一些立场，没有办法堂而皇之、正大光明地把拓扑性的结构或现象学的一些假设拿出来。所以它顶多把人的心灵想象成一个很复杂的黑箱，只不过它过于复杂，太复杂了，所以我们把它简化成一些行为。但这些行为只是宏观行为，永远只是宏观的。你没有办法，也没有必要，更不应该像操作主义那样搞出孤立的行为，搞出一个个别的、原子化的、分子性的事件。You don't have to, you can't even, you can't，因为它背后有很多参量，有过多的参量，比如认知倾向性、欲望、心理习惯等等。这些可操作的参量太多了。在这种情况下，我干脆就讨论一个宏观行为。这个宏观行为具有内在性，具有某些内在性。但这内在性归根结底还是由底层的分子现实集群过多之后，像混沌系统一样生成、涌现出来。在微观层面还是物理决定论，还是就是没有心灵，不能说有心灵。所以它还是四。它不承认有一个额外的心灵位面、认识论位面，或者有独立的、可供描述的心理位面。它不承认。它还是行为主义，归根结底还是行为主义。

只不过它相信，比如目的性、对象性这些东西可以解释为、最终可以被消解为一系列的分子事实、一系列分子行为，最终可以消解成这种东西。我们要描述目的性、对象性、同一性、认知框架这些虚的内在东西，我们没办法，只是没办法。所以目的论上还是二：有两个维度，一个是分子的，我们要把它写成离散的，甚至可以说离散的、不相干的；另一个是摩尔的，它是整体的，整体成为一个因果网络，一个复杂的因果网络。这个复杂因果网络底层本身是超认识的，是无法认识的，没法说清，you can't articulate，没有办法描述清楚。因为包括人类的精神、人类的思想本身也是一个摩尔，人类的心理学研究活动本身也是一个摩尔行为主义式的整体性行为。

所以在这里面，由于它没有办法再从底层搭建概率学网络的模型——从下往上——它这个时候就要用一些主观指标了。这些主观指标，比如强化等级，哪些要素更怎么样，或者哪一类摩尔行为，就靠你评判了，靠心理学家、行为主义心理学家来评判。心理学家看这个小鼠，不再需要看小老鼠从比如强化成什么，不再需要用概率学的、纯粹数理化的方式去。举个例子，你可以给它打等第、优、良，不再需要给它算分数，大概这个感觉。就是心理学家自己毛估估，它强化等级，你用数学指标的话，那太慢了，这些环节里面太慢了，你可以大概。因为这个时候他也把心理学家自己的评判指标、自己的话语也看成一个摩尔，一个整体的行为。所以在这种情况下，它可以介入，以主观指标、主观评价方式来评价，因为按照格式塔心理学，这都是一个整体，对不对？我这个心理学家的研究精神、研究的意向性、我的目的性在里面，也是尽量还原，尽量保证它不失真。我按照一种客观中立的心理学家的探索欲。比如这个小老鼠一直往那边钻，一直往这里钻，但好像它一直往右下角钻，或者最后统计下来 30% 往右下角钻；但它每一次往左下角钻的时候，都会往右下角看一看，怎么样。这些要素太复杂太多了，我不可能都建模。它的小爪子挠了几下，这都算进去吗？不可能的。它眼睛往那边瞟几下，就毛估估这个心理学：哎，你看到，这个强化有用了，它对右下角感兴趣了。虽然它没有跑到左下角，没有直接跑到右下角，或者 90% 都跑过去，但它每一次到左边都会瞄一眼，往那瞄一眼。这个时候你就可以用一些比较软、比较弱的指标，比如强化等级这样的指标，去描述这个过程，大概概括一下这里面的。因为这个时候摩尔整体主义已经放宽了它的统计学底层报告的标准，通通放宽了。

我们要说的是，它在目的论上的这种形态表明：分子的离散化会导致太多、太混乱，再搞一个概率学模型出来算不过来，计算总量太大。甚至在现象层面，或者说在宏观现象层面，你会发现可操作的要素是无限可分的，甚至有一种无限可分。然后它不得不聚合，不得不聚合。特别是所有心理现象，心理学本身、心理现象本身就是一种不得不聚合。所以我要说，在目的论上，我们可以说左边是离散，右边是聚合。左边离散意味着，按照操作主义、操作行为主义的原则，我可以把每一个都算清楚，每一个单独的都可以测、可控制，每一个要素、每一个环节单独可测、可控制。那么小老鼠从 A 点到 B 点，或者从 C 点绕回 A 点、绕回 B 点，中间有一些要素你操作它没有意义，或者是不能操作，它一瞬间，你怎么操作它呢？小老鼠跑到这个 C 点转角，它跑到这个转角的时候，一瞬间看到这里一个角似曾相识，才跑过来的。那这个要素可以操作，但没有任何意义，你在实验上没有可实现性。理论上当然可以操作，理论上用个什么很精妙的装置，或者这边搞一堆装置，是可操作的，让那个角突然拐了或者突然变软了，但是没有意义。你要用很复杂的装置才能实现这种操作主义理想，理想的操作主义。操作主义背后预设的是：我每一个要素，这边的光线、那边的气味、这边的什么，我都可以操作它。但操作主义是个理想模型，根本做不了。所以它这个一就意味着：按照操作主义行为主义，我可以认定这个世界是无限可分的——不叫无限可分，是可以精准地分成单个要素、单数的那些要素，或者单数要素组合起来的单个的小的基本结构、分子。分子不是原子，分子由原子构成基本结构，我可以一个个给它弄出来。

它就是独立的基本结构、独立的基本环节，我可以把它搞出来，但是它表面不对。目的行为主义表明，理论上在本体论层面，确实是这些东西一个个都有，我承认它都有。但是在一个心理最后变成行动的那种行动因果链网络、行动本身的活动或者内在体验、心理的那些倾向、那些事件本身的宏观因果网络的时候，这个东西搞不掉，它没有办法说明，没办法说明。也就是说，在这个意义上，在目的论上，这个意识形态会告诉你：是有界限的。下面那个东西它是有因果性，互相之间有因果性，但是这种因果性不可被认识。这个东西互相之间有因果性，但这个因果性已经是聚合起来的，它怎么聚合起来是不能被认识的。但是这个东西有用，这个东西可以有用，有解释力。

我们再往远一点看，整体主义的、摩尔层面的这种因果链、因果网络，根据这个维度，它其实代表着一种——虽然不是直接的实在，归根结底它不是，但有用。就是在这个里面你会感受到，在认识论上、知识论上，这宏观的评价报告或这个里面，它是一种有点悲观主义。我觉得这里面就是一种有点悲观主义。操作主义反而是乐观的，而这个则是一种悲观主义，或者说它是一种开放的姿态。操作主义过于封闭了，而这种人是一种开放姿态：它就是说总会犯错。行为主义心理学就算用最严格的数理统计学模型，它底层就是做不到，参量太多了。但是它能做到的地方意味着：这个系统、这个预测模型本身是主观的，或者不确定的，或者整体语境化的，受不知道什么的、一种无知的东西影响。你保持无知，不去知道它，不去把这一团浆糊、混乱当中弄一两个要素，然后以偏概全。不要去以偏概全。
