# 【三刻钟哲学】《存在与时间》为什么没有写完？因为海德格尔怂了

今天我们来谈海德格尔的《存在与时间》这本书为什么没写完。

这个问题齐泽克在《敏感的主体》第一章讨论过。我最近看了他这本书；我小时候也是读海德格尔长大的。

虽然《存在与时间》没写完，但海德格尔的一些问题其实都得到了回答。也就是说，海德格尔自己认为他完成了。但齐泽克在《敏感的主体》里告诉大家，《存在与时间》所爆绽出的那种激进革命性，其实被海德格尔自己的语言学转向遮盖了。这个 turn 在德语里叫作开合，我不知道念得对不对。海德格尔语言学转向之后，实际上背叛了自己在《存在与时间》里获得的那种最极端的革命性，那种主体性革命性被他背叛了。这是齐泽克的观点。

我们来看《存在与时间》。这本书没完成，原来的写作计划分两部分。第一部分又要分三部分：第一，从日常生活中如何获得此在的存在，把此在的存在暴露出来，实际上就是奠定一种存在主义的分析方式，一种描述日常生活的存在主义分析方式。

所以他搞了一些上手、在手、烦之类乱七八糟的结构。熊伟在翻译这本书时觉得海德格尔这个人太跳了，用了好多黑格尔或康德那里没出现过的概念。这其实不能算范式转换，有点文化学研究，用了一些新概念，其实是使用了一个新的符号学矩阵。

比如有……我不举例子了，你们自己感兴趣去看。我还是把这个矩阵画一下吧：本真方面、非本真方面。本真的有一种是上手状态，上手状态是本真的；非本真则是这种在手状态，现成在手、现成性。

还有一种向死而生是本真的；沉浸就是随波逐流，我可以简单说，随波逐流是非本真的。这就变成所谓的 das Man，即常人。要不要多写一个常人状态？陈嘉映的版本把这个术语 das Man 翻译成常人。

上手状态和……我应该把这个写到右边去。这两个是融为一体、与物融合的状态，是一种入世的状态。另外两个是出世的状态，与对象分离开来。所以海德格尔基本上给出了这么一个矩阵。这是他的第一部分。

其实对本真性的两种批判，实际上是在 part two 里才写的，不是……应该是卷一、卷二、卷三。其实卷三是多余的，不在原来的写作计划里，是他后来为了凑字数写的。卷二写的是……

我想想，这书是我好多年前、十几年前读的。卷二应该是讲……卷一是准备工作，卷二想要在所谓存在论的基础上分析此在的存在。卷一是从日常生活中获得此在存在，也就是获得存在论的基本术语规范或套路。卷二是用这个套路进一步分析主体性的存在。

所以卷二是一个登峰造极的 subjectivism，广受争议，说它是主体主义的，因为卷二有点把整个世界的存在都放在此在的存在上面。

卷三是从个体的向死而生走向群体的，也就是所谓的 people，民族 people 的天命，领受了所谓的天命。卷三一开始不在写作计划里。这是第一部分。

海德格尔这本书最后在他原来设置的两个写作计划里，只完成了第一部分的卷一和卷二，然后觉得篇幅不够，又把卷三添进去。卷三基本上写的是一个个体的本真存在、向死而生的本真存在，如何变成一种群体的本真存在，也就是克服上面卷一和卷二里出现的那种庸俗、庸庸碌碌的常人的生存状态。

那么海德格尔第二部分想写什么？第二部分他实际上也写了，但不是在《存在与时间》这本书里，而是在两本书里：一本叫康德书，即《康德与形而上学问题》，实际上是把康德的哲学范式用他的存在论和时间样态的分析描述一下，就是德国观念论，主要是。

还有一本书是《现象学的基本问题》，里面也描述、讨论了其他几种，比如亚里士多德、笛卡尔他们的时间样态。所以第二部分实际上是什么？第二部分是海德格尔想要探讨一个时间，它作为存在问题的存在论问题的先验视域，transcendental horizon。

他想讨论的就是在时间这么一个先验视域里，存在论有哪几种。你可以简单讲，就是我们之前一直说的操作系统版本更新史，就是存在论的不同种类。他主要讲三个，其实是四个，海德格尔认为是四个。

第一个是亚里士多德式的时间性，第二个是笛卡尔式的，第三个是康德式的，第四个是海德格尔本人的。

在这里面，谢林和黑格尔没有被算进来。莱布尼兹、斯宾诺莎他另外有书讨论，但他没有把其他人看成是时间的先验视域有重大变化。他把这三个，包括他自己，看成是时间问题、时间性、时间样态的一个重大更新。

比如你可以把它理解成：亚里士多德是 Windows 95，笛卡尔是 Windows 98，康德是 Windows 2000，到海德格尔这里是 Windows XP。ontological 是存在论，存在论的 problematicity，存在论的问题性，它在不同版本里发生变化，追溯性的原因就是时间在其中有不同的样态，时间样态。

海德格尔本人的时间是一种绽出、绽出的时间性；其他亚里士多德、笛卡尔、康德那边都有不同的时间性。康德那边可能把时间性空间化了，我都记不得了。康德书你们感兴趣自己去读。就是《存在与时间》原本第二部分计划讨论一个时间性、时间样态，时间的样态。

就是不同意义上的时间性，它在不同操作系统，或我们所说不同的存在论问题的先验视域，也就是不同操作系统里面，你这个电脑里面的时间函数是怎么……它这个时间你不能看成线性时间，它不是线性时间。

线性时间可能是亚里士多德和笛卡尔那边生成出来的。亚里士多德那边一开始有一种工具性的目的论时间，笛卡尔那边是数学化的一种线性时间，登峰造极。到康德那边，时间更有一种空间化的，特别在牛顿那边空间化的一种时间。到海德格尔这边，他说我返璞归真了，我回到时间本身去，把时间作为存在的一个视域、先验视域来加以分析。

那么在《存在与时间》这本书里，实际上这本书的书名应该叫《存在与天命》，不包括时间；就是时间被换成了天命。所以这本书是一本名不副实的书。它名叫《存在与时间》，但它只分析了存在问题的一部分，而且是一部分 Dasein 的问题，然后时间性的讨论很有限，非常有限。

它里面讨论了一部分什么到时、什么谋划，还有一些乱七八糟的东西，那个东西不是很精细，在我看来不具有哲学上的精细性，只有文学创作的意义。所以我觉得《存在与时间》这本书可以叫《存在与天命》《存在与命运》。然后我们的什么 Destiny，德语不知道怎么念了。Being and Destiny，你可以把它重新翻。

这本书齐泽克有一个批评：他把重要的、困难的问题略掉了。第一部分里面重要的困难的问题被略掉了。就是说，最原始的要去阐释存在的事业，这个活他没干。他很快就从一种……走向二元对立，海德格尔很快走向一种本真 versus 非本真的二元对立。

然后海德格尔认为，克服本真/非本真二元对立的方法就是从个人走向群体，实际上就是走向民族。这个民族中，个人要勇敢地向死而生。如果这个民族有这么一个英雄出现，他是向死而生的英雄，那么其他个体要向他学习，要重复他的向死而生，重复这个英雄个体的向死而生，然后去领受一种天命，存在之天命。

所以这时齐泽克认为，他这种做法遮蔽了一个先验主体性、先验主体主义的视域，transcendental subjectivity。他把这个视域遮蔽掉了。他本来应该走到本真个体之后，本真性本来应该变成一种创造力、历史性的创造力。它对应在传统观念论里，对应在康德哲学里，或观念论哲学里，这种创造力其实就叫先验想象力。我们可以去看《纯粹理性批判》，先验想象力，transcendental imagination。

先验想象力是种什么东西呢？比如你脑子里想三角形，三角形这个概念一定会导致你头脑里浮现出一个三角形 image，哪怕你眼前并没有真正的三角形，也一定会浮出一个三角形 image。这就叫先验想象力。

就是你头脑里的那些预制的函数、概念或函数，它可以自己调用出来，而不仅仅调用可以起作用；它不仅仅是一个函数，也可以变成一个 image、一个图像。也就是说，你的 CPU 不仅仅是 CPU——不应该打叉——你的 CPU 不仅仅是 CPU，你的 CPU 是个 APU。

简单理解，你的 CPU、APU 是带核显的，你不需要一个显卡。显卡意味着你还需要某个东西帮你来算，不是的。你头脑里的语词、符号、概念体系，它自己能够图像化。想象力这个词 imagine、imagination，实际上就是图像化的意思，先验图像化能力。

比如想一个马，它不仅仅在你脑子里是一个声音、一个符号、一个集合、一个抽象集合，把所有具体的马都放进去；它同时会隐约感受到那种马的形状，就在你眼前浮现出来。它不能算内视觉，你没有看到具体的图片，但它是先验的一种图像化能力。

其实在你快入睡的时候，你的内视觉的抑制功能、自我抑制的抑制神经，或者说审查机制，比较弱、不起作用、变弱的时候，你嘴巴里说马，眼前是会浮现出具体的马的图像的。

这个时候就不是先验想象力了，这个时候想象力变成经验性的 empirical，变成经验图像了。但我要说，先验想象力是能起作用的，特别是在审查机制、感官自我抑制功能缺失或松懈的时候，你调用符号系统、语词、符号，先验想象力立刻喷涌而出，使经验图像显现出来。

你可以试一试，快入睡的时候，半睡不醒的状态，有人说这是做梦，其实不是做梦，你还是清醒的。你的符号学认同还是清醒的状态，还是自由的自我意识、清醒的自我意识。但这个临界状态我跟你们说一下。

齐泽克认为，缺失的讨论就是本真个体和先验想象力之间的关系。他说，本真个体就是做出抉择。

做出抉择，并不是说在 A、B、C、D、E 不同选项里做出一个抉择，这些都不是本真的。真正本真的是创造选项、创造新选项，这才是本真。就突破环境，然后叫回溯性的，通过回溯性把原本不存在的选项变为一个必然的选项，不仅仅变成和它并列的选项，而且变为一个必然的选项。

这种能力就是先验想象力。我举个例子，为什么我说这种能力就是先验想象力？因为你把一个外部事物给你视神经带来的神经冲动、外部事物的神经刺激图像化的能力。比如红色光波到你视网膜里，最后要显现出一种红色，对不对？这个红色有任何东西规定它长什么样吗？没有，只有先验想象力自己在规定它什么是红色。你了解吧？这样你就理解了，先验想象力就是红色光波，它按道理可能会让你感到烫、痛、亮，或怎么样怎么样，但唯有先验想象力这种无中生有的能力，能变出一个本来没有的东西。

然后通过先验想象力把它注册进来，把它注册进这个符号系统。我用一个成语告诉你，但这个成语我一说出来就暴露了我老司机，叫作“食髓知味”。你懂了吧？

就是说一个东西它是全新的，它到底是什么样子？就是神经通路被打通，你可以理解成神经通路被打通。但这种神经通路被打通，它到底是一种什么感受、什么样一种现实化？它要经验化成一种什么样的体验、一种什么样的客观状态？这是由先验想象力来创造性地实现的。

所以先验想象力是这么一种创造性的能力，它就是海德格尔意义上的本真性，个体的本真性，本真地做出抉择。这个抉择并不是从既定选项中选。海德格尔后来在一些文章里批判了从既定选项里选的这种自由，这是一种病态的自由，是一种美式自由、消费主义的病态自由、消费主义的美式自由，被海德格尔狠批。从已经既定的选项里选一个，那个东西不叫自由。

海德格尔认为真正的自由是把桌子掀了，既定选项全给你掀翻。就是能够自己通过一种主体性的姿态和立场、一种抉择、一种向死而生，把自己内在的那种创造性的全新力量让它绽放出来，这叫绽放。这个东西并不是从内在中绽放，可以说是从此在的，也就是主体的内在，它既从此在的内在绽放出来，同时其实就是从时间的未来、时间的未来中绽放。

然后这两个东西在海德格尔那里是主体的内在性，极度的内在性；极度的内在性和时间上的一个未来希望是同一的。它绽放出来，结果就好像本来就是这样、本来就有，也就是括号，它是回溯性地篡改了历史。通过这种力量——一种本体论的力量，这种力量就是神的力量，你可以理解成这是一种创造性的本体性力量，创造之力——然后它是一种本体性的、本体论意义上的 ontological 事件。他后来把这个事件叫作本有，回溯性地篡改了历史。

但是这个东西，海德格尔是不敢直接面对它的。齐泽克认为海德格尔是个怂逼，他不敢直接面对它。他的《存在与时间》讨论到这边，没有细，没有具体研究下去。

然后这个东西，先验想象力，是康德在《纯粹理性批判》里就讨论过的：先验想象力、感性形式、先验辩证法、先验逻辑等等。康德你可以理解成老程序员，研究 Windows 2000 系统非常缜密的老程序员，或者面向对象的 Java 程序员。他研究先验想象力犯了最多的错误，但有一个研究范式在那边，这应该是康德的一个主题。

但问题是，海德格尔在研究康德的时候，海氏完全视而不见，后来自己完全遮蔽了。

他认为这种主观主义、太把本体性的力量说成是主体内在的，把主体的内在性等同于时间的未来、时间的绽出的未来，他认为这太主观主义，或叫主体主义、太主体主义了。所以海德格尔后来批判康德时，基本上不再从这个维度思考了。

那么这个维度在齐泽克看来，这个先验想象力的维度，在齐泽克看来，它的缺失导致什么？导致海德格尔、导致海氏变成了纳粹。为什么？
