# 【自学课堂】集合论（2）

我们继续讲集合论。昨天讲完了第二节，今天讲第三节——公理，axioms。现在开始搭建公理体系，并努力让每一条公理的直观含义都变得清晰。我们不仅要用集合论把公理体系搭建出来，也要差不多能感觉到它是什么意思，对它有一个直观化的把握。

这里我们假设第一条公理：我们的论域不是空的（universe of discourse is not void），也就是说总有某种集合存在。具体地说，我们假设存在一个特定的集合，这个集合就是空集。第一条就是存在公理：there exists a set which has no elements，存在一个没有元素的集合。

A set with no elements can be variously described。直观上，它可以以各种方式描述。例如，所有 1789 年之前的美国总统组成的集合——其实 1789 年之前没有总统，美国还没有独立。又比如所有满足 x²=\-1 的实数组成的集合，但没有任何实数的平方等于 \-1，那是虚数。所有这类例子都描述同一个集合，也就是空集，vacuous。直观上只有一个空集，但我们现在还不能证明这个断言。我们还需要另一条公理来表达“每个集合由它的元素决定”这一事实。

我们还要证明：一个集合是哪一个集合，是由它的元素决定的，所以还得证明这一条。直观上确实有空集，但要证明空集只有一个。怎么证明？只要两个集合里面的东西一样，它们就是同一个集合；里面都没有东西，那它们就是同一个空集，所以空集只有一个。为此还需要证明外延定律，extensionality。我们接着看。

另一个例子：x 是一个恰好由数 2、3、5 组成的集合；y 是大于 1 且小于 7 的所有素数组成的集合，也就是 2、3、5；z 是方程 x³\-10x²\+31x\-30=0 的解组成的集合，解出来也是 2、3、5。于是 x=y，y=z，x=z。我们对同一个集合有了三种不同的描述。这就引出了外延公理（axiom of extensionality）。

所以我们就有了外延公理，extensionality。extend 就是展开，展开性。如果 x 的每一个元素都是 y 的元素，并且 y 的每一个元素都是 x 的元素，那么 x 就等于 y；也就是说，两个集合的元素一模一样。

外延公理简述为：如果两个集合有相同的元素，那么它们就是同一的。我们现在可以证明引理 3\.1：There exists only one set with no elements。这个引理是说，有了存在公理和外延公理这两条符合直观、作为集合论预设而不加证明的公理，就可以推出：空集只有一个，它是唯一的。证明：Assume that A and B are sets with no elements。假设 A 和 B 都是没有元素的集合，要证明 A 和 B 是同一个集合。Then every element of A is an element of B。既然 A 没有元素，怎么能说 A 的元素都是 B 的元素？因为没有元素。Since A has no elements, the statement A belongs to A implies A belongs to B。按形式逻辑，前提为假时，结论无论如何都成立；也就是说，蕴含命题只要前件为假，整个命题就恒真。比如“如果他早上吃了大便，那么我今天下午就零车漂移”，只要前件是假的，这个假设句就永远是真的。A 导出 B 也是如此：只要 A 是错的，A 导出 B 作为整体就恒真。所以他就证明了……这个表述叫 A。

这个逻辑表述是：小 a 属于大 A，蕴含小 a 属于大 B；它是一个蕴含，implication，也就是“如果 A 那么 B”的命题，一般翻译成蕴含命题或暗含命题。这个蕴含命题有一个假的前件，所以它自动为真。反过来同理。因此 A=B。为什么？因为有外延公理：只要两个方向都成立，引理就成立，两个集合就是同一个集合。

定义 3\.2：the unique set with no elements is called the empty set and is denoted ∅。也就是说，把这个独一无二、没有元素的集合叫做空集，记作一个圈加一横。注意，空集是一个常量或常元，是固定的东西；它的定义由存在公理和引理 3\.1 保证，justified 即正当化。通过这一条公理和一条引理，我们可以这样对待它。

直观上，集合是一些共有某种共同属性的对象组成的汇集，所以我们期望有公理来表达这一事实。但正如第一节的悖论所展示的，并非每一个属性都能描述一个集合。

正如第一节的悖论所展示的，demonstrated 这里可以理解为“展示出”，并非所有属性都能描述一个集合，有些属性会导致矛盾，不能刻画集合。例如 x 不属于 x，或者 x=x，都是典型例子。x=x 也没有办法刻画集合，它说的是废话，并没有办法刻画集合。

在这两种例子中，问题似乎在于：要把拥有某种属性的所有对象收集起来放进一个集合，我们首先就得能够感知所有集合。也就是说，你本来就已经能够设想所有集合，知道哪些共同点可以构造集合、哪些不能构造，头脑中已经有一套对万事万物的全部分类学；你知道哪些分类标准可以分、哪些不能分，知道天底下所有可能的类，才能去设想，才能把那些非法属性先排除掉。

这种困难可以避免：我们假设拥有某个给定属性的所有对象组成的集合存在，但仅当已经存在某个集合，它们都属于它。也就是说，先要有集合。当我们讨论一些对象拥有同一个属性时，我们先假设这个集合已经存在。这样可以避免一种情况：把一堆东西找出一个共同点，却没法说这堆东西能构成一个集合，因为这个共同点会使集合在被把握时自相矛盾。第一节讲过自指涉问题，自己指涉自己会导致共同点自相矛盾，而 x 不属于 x 这类都包含自指涉关系。所以必须先假设存在一个集合，先假定按这个属性给出的那堆东西的集合是合法的，然后才能说它们可以有一个集合。这样，x 不属于 x 这种情况就被避免了，它不符合这个假设。

如果采用这个假设，x 不属于 x 这种情况就不行；它作为属性传出来的集合不合法，因此不能说一些东西符合这个属性就能得到一个集合，因为它们传不出集合，或者传出来的集合不合法。所以这叫可理解性，或者概括性，是 comprehension 的公理图示；也有逻辑学家翻译成概括图示公理。概括可以理解为：先要把具有同一属性的那堆东西概括成一个合法集合，然后才能说这个属性可以传出一个集合。预先给出这个集合的概括，其实就是一个预先的理解、一个理解的图示；先对它作某种图示化理解，这种理解在逻辑上站得住，才能说这个属性的一堆东西可以传出一个集合。Let P\(x\) be a property of x\.

引理 3\.4 说：for every A，there is only one set B such that x belongs to B if and only if x belongs to A and P\(x\)。也就是说，对于每一个 A，存在且仅存在一个集合 B，使得 x 属于 B 当且仅当 x 属于 A 且 P\(x\)。这个引理就是说只有一个。怎么证明？证明假设有另外一个 B'。

假设有另一个 B'，使得 x 属于 B' 当且仅当 x 属于 A 且 P\(x\)。那么 x 属于 B，就可以直接用概括定理；但这里实际上用的是外延定理。外延公理说，只要两个集合的元素相同，它们就是同一个集合。因为 B 和 B' 的元素相同，所以 B=B'。也就是说，对于任意集合 A，只有一个集合 B 满足 x 属于 B 当且仅当 x 属于 A 且 P\(x\)。如果还有另一个 B'，它满足后面的概括公理要求，那么 x 也属于 B'，于是 B 中的 x 和 B' 中的 x 是一样的，所以 B 和 B' 是同一个。这样就证明了唯一性。We are now justified to introduce a name for the uniquely determined set\.\.\.

D：if A∈S, then A⊆∪S。如果 A 属于 S，那么 A 是 ∪S 的子集。这个也好理解。A 是一个集合，S 是一个集合系统。比如 S=\{A,B,C,D\}，A=\{x1,x2\}，B=\{x2,x3\}，C=\{x4,x8\}，D=\{x3,x8\}。很明显，A 肯定是 ∪S 的子集。因为 ∪S 是 A,B,C,D 并起来，结果是 \{x1,x2,x3,x4,x8\}。A 中的 x1,x2 通通在并集里面。所以 A 的要素肯定是并集的要素，但并集的要素不一定是 A 的要素。比如 B 里面的 x3 是 B 的要素，但不是 A 的要素。并集可能比 A 多。特殊情况，如果 S 就等于 A，那么 S 是 A 的集合的集合，S 的并集就是 A。如果 S 里面有个 B，而 B 中某个 X 不属于 A 但属于 B，那么并集就等于 X 和 X'，A 就是这个并集的子集。

The next axiom postulates that all\.\.\. 下面一个公理假定，给定集合的所有子集都可以在一个集合里面被收集起来。也就是说，给定一个 S，S 可以写成 \{A,B,C,D,\.\.\.\}。那么存在一个集合 P，使得 X∈P 当且仅当 X 是 S 的子集。这个 P 就是 S 的子集的合集。S 的子集有哪些呢？比如 X 可以等于 A，可以等于 B，可以等于 C，可以等于 D，也可以等于 \{A,B\}、\{A,C\} 等等，所有排列组合的情况。P 就会变成形如 power set，也就是幂集。

Power set，你理解这个“幂集”。“幂”不是草字头，是秃宝盖，下面是个金。这个叫幂运算，相当于 power。不管了，反正这个东西就是把所有排列组合的可能性都搂进去了。只要它是子集，比如有 A、B、C，有 \{A,B\}、\{A,C\}、\{B,C\}、\{A,B,C\} 等等，这个 P 就是幂集。这个 P 是独一无二的。We call the set of all subsets of S\.\.\. 我们把 S 的全部子集——各式各样的小弟，以及它自己——形成的集合叫做 power set of S。这个 power 翻译成“幂”，乘方，或者说相当于给它加平方的感觉。就是“密集”，它自己对自己的小弟全部囊括进来，进行一个密集。

下面举个例子，讲完就歇。比如空集本身的幂集：空集的唯一子集就是它自己。如果 S=∅，那么它只有空集是它的子集，所以幂集里面只有空集本身，即 P\(∅\)=\{∅\}。如果 S 有一个要素，那么除了空集是子集，还有它自己，所以幂集至少包含空集和 S。如果 S 有两个要素 A,B，那就是排列组合：P\(S\)=\{∅,\{A\},\{B\},\{A,B\}\}。这个很好理解。

We conclude this section with another notational convention\. Let P\(x\) be a property of x。我们用另一个记号约定来结束这一节。假设 P\(x\) 是 x 的一个属性。If there is a set A such that for all x, P\(x\) implies x∈A，如果存在一个集合 A，使得对于所有 x，P\(x\) 都能推出 x∈A，那么 x∈A 且 P\(x\) 就存在一个 B，并且这个 B 不再取决于 A。原来的概括定理是 if and only if x∈A 且 P\(x\)。现在的情况是：如果 P\(x\) 本身就可以推出 x∈A，而且对每一个 x 都成立，那么 B 就是独立的，不再依赖于 A。这个 B 就相当于把原来的 A 这个范围去掉了。它自己本身可以让它成立。也就是说，B 突破了范围，可以写成 \{x \| P\(x\)\} 这种东西。我们一般教的就是这个。

但是这个东西不是原初的，而是后面推出来的。最后一个记号约定：如果 P\(x\) 本身能够让 x 有定义域，也就是说，只要你给它设了一个 P\(x\)，它天然就能确保自己有解。

我用日常生活中的例子：比如 P\(x\) 表示“他吃饭”，或者说 X 是活人，或者 X 是时间，X 是时间的流淌。它自己能够给出自己的范围。用数学例子，P\(x\) 写成 x&lt;10，那么 x&lt;10 一定能够推出 x 是一个数，至少是一个数，甚至是一个实数。因为你已经写了 x&lt;10，所以 x 一定是一个数，x is a number，或者说 x 是一个实数，x is a real number。我们就可以写 x 属于实数域。所以你就不要再写“x 是实数，并且 x&lt;10”，只写 x 就行了。That means that if A' is another such set that for all x，P\(x\) implies x∈A'。比如取 P\(x\) 为 x&lt;0，那么你可以说 A 是 x 是实数；而 x&lt;0 本来就蕴含它是实数，或者说 A' 是 x 是负实数，因为小于 0，它是负实数，不是正实数。它本身 P\(x\) 里面就包含了这个东西，x&lt;0 本身就包含了这个 A 或 A'。所以在这种情况下，x∈R 且 x&lt;0 这个集合就等同于 x 是负实数，这两个集合是一样的。

换句话说，我们本来筛出集合是怎么筛的？x∈A 且 P\(x\)，把这个东西筛出来，B 等于这个集合。它是在 A 的范围里面按照 P 筛出来。现在变成：在一堆 A 的范围里，按照一个标准，比如方框，在这个范围里筛。现在会变成：我只要有这个方框的标准，或者这是一个 A 的范围，那是一个 A' 的范围，我发现这个范围不要了。整幅图上就这两个方框，我不需要用 A 这个范围来约束它了。我只要有 P\(x\) 就够了。对于这个范围，我筛出来的是这两个方框；对于那个范围，筛出来也是这两个方框；对于 A'、A'' 等不同范围，筛出来都同样是这两个方框。那我就不需要再描述我是从哪个范围里筛出来的，只要说我是按照这个标准筛出来的就行了。

We can define，这样我们就可以定义：在这种情况下，\{x \| P\(x\)\} 就等于 \{x∈A \| P\(x\)\}。因为这个 A 是一个可以被 P\(x\) 导出来的集合。换句话说，A 是这种东西，A 属于 S，它们符合 P\(x\) 这样一个关系。A 是所有可以从 P\(x\) 这个关系当中推出来的各式各样的集合、范围。所以这个 A 就像小弟了。Where A is any set for which P\(x\) implies x∈A。A 就是任意一个集合。

A 是任意一个集合，只要 P\(X\) 蕴含 X 属于 A。像 A、A'、A''、A''' 这些集合，都可以从 P\(X\) 推出来，也就是说 P\(X\) 蕴含 X 属于 A，也蕴含 X 属于 A'、A'' 等。要点是：我到底用 A、A'、A'' 还是 A''' 来筛，并不重要；最后筛出来的要素都是这两个要素，用哪一个都不重要。重要的是我用 P\(X\) 来筛，用这个标准、这个属性来筛；从哪里开始筛、怎么筛都不重要，我都可以筛出来。因此在这种情况下，我们可以写成 “is a set of all X with the property \.\.\.”，意思就是所有具有属性 P\(X\) 的 X 的集合。

我们要再次强调，这个记号只有在已经证明某个 A 包含所有具有性质 B 的 X 之后才能使用。也就是说，至少存在一个集合 A，它包含所有满足 P\(X\) 的 X。用自然语言说就是：A 包含了所有具有属性 P 的 X，所有满足 P\(X\) 的 X 都包含在这个 A 里面。至少存在这样一个集合。

如果不是这样的话，它就会有遗漏；如果不是这样，你就不能这样写。如果不能证明存在一个集合 A，它囊括所有具有性质 P 的 x，你就不能这样写，因为会有遗漏，会漏掉一些点。比如刚才说的，你不能写 x 属于负实数 R 且 x&lt;10；这样一来，非负实数中小于 10 的那一部分不就漏掉了吗？零到十的那一部分就漏掉了。所以你不能这样写。

但现在可以这样写了，为什么？因为我现在证明存在一个 A，它能够囊括所有这样的 x。比如取 A 等于实数集 R，那么 x&lt;10 就能推出 x 属于 R，也就是 x 属于 A。因此就不必再多写一步 x 属于 R，只要写 x&lt;10 就行了。既然后面的条件已经蕴含了 x 属于 R，前面那个 x 属于 R 就可以不写。能这样写的前提是：有一个 A 能够囊括所有满足 x&lt;10 的要素。如果你不能确定存在这样的 A，就不能这样写。这相当于一种自限性：这个 P 自己限定了自己的范围；由 P 导出来的推论可以自己限定自己的范围，自己给定一个可以摆上台面操作、从中摘取要素的范围。然后你从这个范围里面取要素。在这种情况下，后面这个描述本身就具有范围限定性，所以前面就不需要写了。

然后看例子。例子 A 是 \{x \| x 属于 P 且 x 属于 Q\}，它存在。这个东西相当于说交集存在，也就是 P∩Q 存在。两个集合 P 和 Q 只要存在，它们的交集就存在。这里要注意，P 是斜体的 P，代表集合。假设有一个这样的集合，老师当时把黑体画两圈来表示，我就直接抄一下这个记号。令用来包含它的集合 A 等于 P，那么性质 “x 属于 P 且 x 属于 Q” 会蕴含 x 属于 A，因为 x 属于 P 就是 x 属于 A。这是废话，但正因如此，你就不用再那样写了。或者你可以把它扩展出来写：本来这边只有一个 x，你可以把 x 属于 P 补充出来，写成 x 属于 P 且 x 属于 Q。后面这个限定条件和前面那个限定条件一样，所以它就等于 x 属于 P 且 x 属于 Q，这正是之前定义的交集。你要证的，就是这个所谓的 x 的属性是后面这两个；后面这两个是它的属性，也就是黑体的 x∈P、x∈Q。你只要证明它蕴含了 x 属于 P，然后把蕴含的这个东西——相当于 x 属于 A——放回前面，再写成 x 属于 A 且 x 属于 P 且 x 属于 Q。这个过程我就不写了；其中 x 属于 A 和 x 属于 P 约掉，变成废话，也不需要有了，因为它前面已经有了。于是剩下的就是之前定义的那个交集。

第二个例子 B 是 \{x \| x=a 或 x=b\}，要证明这个集合存在。证明很容易：令 A=\{a,b\}，那么很明显，x 属于 A 当且仅当 x=a 或 x=b。这个 x=a 或 x=b 就是配对的定义，也就是配对公理（axiom of pairing）。你只要直接运用配对公理，做一个配对就可以了，所以它存在。这个东西不就是 \{a,b\} 吗？这个不需要再证，它就是配对公理所预设的、天然存在的集合形式。C 也是类似的，考虑 \{x \| x 不属于 x\}，它不存在。

因为罗素悖论，要证明它不能存在也很容易。这个记号是不可承认的（notation is inadmissible），因此在这种情况下，这个记号不能用。也就是说，\{x \| x 不属于 x\} 不能写成这样的集合。这个证明不用单独做，直接用前面第一节里的罗素悖论就可以了。如果 x 不属于 x，它就会导致 x 属于 x；于是推出 x 属于 x，这就矛盾了。因为你搞出这样一个集合，就要问 x 是否属于它。举个例子，令这个集合为 A，那么 A 本身是否属于 A 呢？

如果 A 属于 A，那么 A 就符合这个描述，P\(A\) 成立；于是 A 不属于 A。所以罗素悖论表明，在这种情况下记号不可承认，你不能这样写。还有一个原因：你写不出这样一个 A，你没有办法找到这样的 A。尽管我们的公理表并不完备，因为它无法穷尽集合论中所有真命题，我们仍推迟引入其余假设：除非有必要，现在不再引入其他假设。现在已有的公理已经足够引入不少概念，并证明一些引理和定理。读者可能已经意识到，我们并不保证任何无限集合的存在。所有集合都要通过空集和这些运算方式逐步构造出来，一步一步、一环套一环。因此在这个意义上，每一个集合都是有限的。不过现在好像又可以构造无限集合了。

这个限制在第三章会被突破，这个缺陷在第三章中会被解决。其他公理会在第六章和第八章中引入。完整的公理表可以在第十五章第一节找到。

这个公理体系是恩斯特·策梅洛（Ernst Zermelo）在一九零八年提出的，通常称为 ZF 系统。另一个名字我一时记不得了。这个集合论的标准公理系统是 ZFC；这个 C 就是要加上选择公理，所以通常简写为 ZFC。策梅洛–弗兰克尔（Zermelo–Fraenkel）系统是最基础的，反正记得这两个名字就行。弗兰克尔名字里的 ä 是德语里的一个字母，在英语里写成两个字母 ae，其实就是一个字母。Fraenkel 的公理系统，就是 ZFC 系统。习题你们有兴趣就做吧；我当年上这门课时做习题还蛮开心的。不管了，就讲到这里。
