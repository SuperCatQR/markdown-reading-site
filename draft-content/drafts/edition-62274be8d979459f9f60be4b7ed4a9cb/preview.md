# 【主义主义】隐喻的象征主义（3\-4\-1\-2）——早期拉康的符号学精神分析：想象性的误认从一开始就预示着隐喻和象征

先讲主义主义的三杠四杠一杠二，代表人物是早期拉康。这个格是一个哲学格，三四一二，它的名字叫 metaphoric symbolism，即隐喻性的象征主义。

这里就涉及拉康有名的三界论、三界说。不过在早期拉康那里，实在界还不是一个非常强的问题域，他主要研究的是镜像、想象界的问题，也就是镜像阶段、镜像认同，以及如何从镜像认同走向符号化秩序、走向象征秩序。镜像认同是一个两极震荡的、零一震荡的状态。

如果一个人只有镜像认同，或者自恋的自我镜像过于固着，他就会要么陷入全能幻想，要么把攻击欲转向他者，转向一个理想中的他者，对他特别有攻击欲。他会设想一个理想的他者，ideal other，然后对他极度具有攻击欲。镜像认同也可能是一种 narcissistic、suicidal 的攻击性认同，identification、identity。这种认同如果没能比较好地整合到象征秩序里去，如果符号运行出现问题，就会有拉康研究的一个案例：一个女文青去刺杀一个演员，那个演员或文艺界明星就是她自己无法成为的那个人。镜像认同有可能就会两极震荡，就这么简单。如果不进一步被整合到父性的象征秩序里，他就会两极震荡。

所以某种意义上，我挺难理解我那些黑粉做的事情：对我的形象无止境地抹黑，做那些事情，实际上是一种攻击性的镜像认同。他们自己人生没有办法实现的东西，看到我可能实现了，就以为我实现了他没办法实现的东西，以为我成就了、我成为了那个他自己，我整合了他；但他自己事实上又处在分裂、混乱、爆裂的痛苦之中，于是把所有这些攻击欲转向我这个镜像。有这种人很正常。那么直接看他的格吧，我不想多废话了。

在场域论上是这两个东西对峙：一个是想象界，另一个是无意识。右边是语言结构，是 language 语言的结构，也就是无意识——在拉康那里，语言的结构就是无意识。左边是想象界，也就是镜像认同、镜像关系。这些东西由什么来维持、由什么来协调呢？一般的观点认为是由他者来协调，更确切地说，是由他者的目光；但实际上是由他者的欲望来协调。我再强调一遍，实际上是由他者的欲望来协调的。

一般来说，人们认为是 A，也就是拉康自己比较早期认为的由大他者来协调。但实际上，我们再进一步说，真正协调这个的是实在界。不过这里还不是象征界，他还没进入象征秩序；早期拉康也没有比较好地梳理象征秩序，他前面几个讲座主要关心的是镜像、镜像关系。

镜像关系的目的是用否定性的辩证法去消解掉主体性，特别是消解掉萨特存在主义的那种生存论主体性。萨特那种生存论式的主体性，最后落脚在萨特描绘的主体性上；虽然虚无占了很大篇幅，但它的机制还是存在，《存在与虚无》的机制还是存在，是自在自为的存在，自为代表虚无的那一方面，它只是它的用。而它的体是存在，它的身体现象学、爱欲现象学——我说的萨特——最后会告诉你一个最原初的主体性，其机制是一个广袤的、深层的整体主义存在。所以拉康不喜欢这个东西。

拉康从镜像阶段、镜像关系中认为，主体对于自我的把握永远是一种误认，而且这种误认实际上是无意识的一个时间性机制；主体的主体化依赖于无意识的时间性机制，它就叫将来过去完成时，will have been，I will have been myself。也就是说，无意识由于是一个能指链或符号系统，所以其中所有的更改、调配都是回溯性的，都是整体主义的、整体性的、回溯性的。对于符号系统里的一个更改，它坚持共识性原则。所以无意识归根结底在拉康那里和弗洛伊德一样，是无时间的。它的无时间性体现在共识性原则和差异性原则：共识性原则是第一优先的；但它里面会发生变动，无意识也会发生变动，只不过变动方式是将来过去时——变化了之后会发现它没有变化，它本就如此，但其实它变化了。也就是说，无意识不停地在取消它的历史性，永恒地取消它的历史性，不停回溯性地取消它变化了的痕迹。这是无意识的一个特点。

这种永恒地取消历史性，在人类的心理学体验里就是：我们总是活在当下。人为什么会体验到自己总是活在当下？因为无意识就是符号学，符号学是一个共识性的、差异性的系统，里面所有东西的自我同一性都是由它和其他东西的总体差异构成的。这样的符号系统，其时间性只会有一种，就叫将来过去时；这种将来过去时就是永恒地取消它的历史性，永恒地取消它曾经和现在不一样。它发生了变动之后，会说“我本就是这样的，我本来就已经是现在这个状况，只不过我之前搞错了、弄错了”。这叫做它的时态性。无意识具有这样一个时间性机制；而在想象界、镜像关系里面则没有这个时间性机制，而是一个直接同意、直接同意关系。

在镜像关系、想象界里面，反而会有一个连贯的、循环的时间性。婴儿在镜像阶段、镜像关系中觉得自己可以不断地控制自己，随时随地可以控制自己，那种自由状态让他痴迷、感到开心。但这种想象界的认同是一种误认，是一个致命的误认：婴儿会把自己认作那个镜像，那个镜像就是 L 图里的 a'，小写的他者；而他自己设想的自己的理想形象是 A。更确切地说，用法语写就是想象性的自我 moi。

想象性自我，moi，imaginary self 或 imaginary self\-image。这两个东西短路：镜子里的形象和他设想的自己的形象相对应，直接是同一的镜像同一关系。这两种关系之间是有冲突的，很明显有冲突。

因为无意识在这种情况下……这两个场是冲突的。镜像关系为你提供了一种虚假的直接自我统一，而在无意识里，按照差异性原则，事物永远不能够直接自我统一，世界不允许这样。因为镜像关系其实就是乱伦禁忌，它触碰了符号系统的乱伦禁忌：一个所指直接对应一个能指、直接统一了，这不行，不允许这样。如果这样的话，就会有精神病理化，就会有偏执狂、狂躁症这类东西。不允许这样。

那么协调这两者，在拉康那里一开始是这个大写的 A，由它来做担保。这个 A 和主体相当于是一个并列关系。当然这个 A 也是一个镜像误认，它是一个大写的他者；和镜像里那个可以被婴儿控制的形象、那个他者相比，那个他者在那个时候被叫做小他者。小他者不是客体小a，不一样的。镜子里面那个小他者就是镜像当中的小他者，这是镜像认同阶段的。后面拉康的术语表会发生变化，因为他这里还没有系统性地研究欲望和镜像的关系。

而在这里，大他者其实就是：婴儿在识别镜子里的形象、把它想象性地认同为同一个自己的时候，会转头去看别人，去看其他东西；这些其他东西做了担保，这个并列的他者做了担保。甚至我们可以说，你可以理解成镜像当中不动的那些东西。再简单一点，婴儿面对镜子里的自己，他头摇了摇，镜子里这个头也摇了；他这个时候的欣喜其实更多来自……他头摇，只是这个头在动，其他比如这边放了个柜子，柜子没动，那边放了个柜子，柜子也没动。这个柜子的镜像关系：他看这边有柜子，那里也有一个柜子，它们是同一个柜子，这样也实现了某种镜像认同。作为某种自身性的他者，和这个镜像是并列的；而和这个小他者——镜子里那个和他实现镜像认同的他者——相对，其他那些他者叫做大他者。

早期拉康那里，大他者作为一个担保，向主体担保他的镜像认同是得到承认的：对的，没问题，你没搞错，你认同得对。也就是说，在这种意义上，他者的担保、他者的承认，尤其是他会转过头去看母亲的目光，或者父亲的赞叹的目光等等；他会因为这个目光的结构格式塔，在镜子里也看到自己有这个目光的结构格式塔。他会看到父亲眼神里的目光结构格式塔和这个镜像是一样的。无论如何，这些镜像是并列关系；无论如何，大他者一开始也是个镜像。你要明白，大他者一开始也是被当作镜像的。

然后这里就是说，镜像关系这个东西在发生，不一定需要一面真正的镜子；镜子只是一个模型，不是说必须有一面真正的镜子才行。而是说，只要在这个孩童体验到的外部事物当中出现这么一种关系——他动一动，那个东西也动一动——他就实现了镜像关系。这样就会有镜像认同。比如他哭一声，妈妈就跑过来，妈妈跑过来这个形象和他哭的声音、声响，就会形成一个镜像关联。我们用镜子只是作为一个最能让大家理解的镜像关系实现，只是用镜子做一个比喻；实际上是能指，镜像关系是一种特殊的能指关系，可以看成是能指之间的联动关系。这种联动关系是真实的。所以拉康在 L 表、L 图里面会用实线来表示，它不是符号学拟制的，它是真实的：这些能指、这些符号之间确实有这么一个关系——我一哭，那边母亲就跑过来了，或者怎么样。

我们把这张表画出来吧。这边是大他者，大写的他者。这个大写的他者还不是那个意义上的大他者，不是 big other；它只是说，作为一个可以做担保的、可以为主体的自我和他的 image 之间的同一关系做担保的他者，和那个小的他者相对。然后这个他者会指向一个自我，在符号学上为他做保。然后是无意识。这里指向想象关系，这一条线是一个想象关系，imaginary。然后这里是他者，是小写的 a'。然后这里是一个真正自我、主体，subject。主体是拟制的，这个关系也是符号学拟制关系。早期拉康会用这个符号，要去找这个主体，但这个主体永远是符号学拟制的，他是找不着的。所以其实他就是这个：没有的，一个符号化的主体，一个象征化的主体，象征主体，象征化的主体。镜像关系就是这么一种误认。这个是 moi。这个自我是虚假的，是想像出来的，但你会直接觉得那个图画就是“我”，那个镜像和自己直接是同一的，所以它们是一条实线。想象性的自我会直接朝向这个镜像：你脑子里会有一个虚影的“我”的形象。比如我现在盯着屏幕上我自己的脸看，就觉得“这就是我，这不就是我吗”，这种直接性，这种能指的直接性。但它最低限度上是换的，最低限度上是这个能指换到那个能指。然后这个他者是通过无意识来做保的。

他者是借由无意识来做保的。无意识本身也是一套符号学机制、一套符号结构。无意识就是一套符号结构，这符号结构有它自我运作的机制，就是我刚刚讲的共识性和差异性：取消自己的变动，抹去自己的痕迹，抹去自己发生学、历史性的那些痕迹，让别人不感觉它是历史性的，让别人觉得它永远是这样、一直是这样的。无意识一定要通过无意识做保，才能使得直接认同的这种想象关系能够拉开距离；这两个东西能够拉开距离，就已经要靠这条线了。也就是说，这条线你可以看成是一个最低限度的象征活动、隐喻活动，最低限度的隐喻活动，你可以把它叫作原初隐喻。这个原初隐喻隔开镜像和这个自我形象，隔开镜像和想象性的自我。一定要由它隔开；不隔开这两个东西，如果这两个东西短路，那就又回到原质状态，又回到实在，又回到 real，前符号的那种痛苦的、惨烈的、很痛苦的状态。

可以说是靠这条线。但这条线这边这个是拟制的，因为这个东西永远是这个主体，永远是无头的主体性。这个主体是无头主体性、无意识主体，它是个无意识主体。拉康那里的主体是无意识，是一种关系、一个运动、一个机制。拉康那里主体的机制就是代表无意识的自我取消这么一个特点：无意识不会落到实处，不会变成一个符号。无意识的主体就是无意识本身会主体化，但它主体化的方式就是使他不变成任何一个能指；他不在能指链条里面，他自己不会把自己固结成任何一个能指。这个主体是一个机制，是这个符号系统的机制，它总会把自己排除在外。但这种排除在外的特性又使得这个……

在这里我们就是说，早期拉康认为这边是 A 在协调，协调符号和这个……我说错了，协调这个无意识和这个，就是由他来做保，你知道吗？由他来做保，或者协调符号性的秩序和主体化的机制；符号学秩序和主体化的机制是由那个他者、大写的他者来协调的。也就是说，由他人的承认、他人的目光，或者主体在进行镜像认同的时候，其他东西保持中立，其他东西按部就班，其他东西默认，其他东西不变，其他东西维持不变，就这么简单。

这个他者你可以理解成：婴儿在镜子面前操控自己的镜像的时候，其他东西不变。这个大写的他者就是其他东西，其他东西不变。它就是符号系统的那个不变性，是符号系统的共识性和差异原则所维持的那种虚假的不变性。共识性原则和差异性原则维持了符号系统的不变性。符号系统是不变的——这里要加引号，因为它会回溯性地取消自己的变动。

那么主体会感觉到自己在控制它，会有一种全能幻想，或者怎么样。恰恰是因为他觉得他没有变任何东西，没有改变任何东西；他就是这个镜像，他没有设立镜像，而他就是镜像。它会短路，原因也是因为这个符号学机制。这个符号学机制使得主体和镜像的认同，在最底层、或者说会有这种认同，就已经代表分裂了，不得已地已经代表分裂了。而这个共识性、差异性原则，会使得所有的镜像认同都注定失败。因为你要去兑现这一镜像认同的时候，主体就会陷入某种……除非他被整合到一个能指链里面去；你要去兑现这一镜像认同，都是注定失败的。

但至少在镜像阶段，婴儿会处在一个稍微稳定的状态，他会两极震荡。如果处在镜像阶段，婴儿会两极震荡：要么处于全能幻想、怡然自得，要么就是拼命地哭；要么又处在全能幻想，然后又拼命地哭。如果仅仅停留在镜像阶段，就会两极震荡，就是零一的两极震荡，也就是我们前面、上一次讲的那个会两极震荡。除非把你编入符号学秩序里面去。

那么本体论上，本体论上也是四。四意味着在拉康那里，事物的存在只有否定性，否定性原则，也就是差异性、否定性。否定性就是 negativity，就这么简单。本体论上最重要的就是否定性，最重要的否定性，或者我们叫差异性、差异。如果可以的话，我甚至禁不住想要写德勒兹的那个 nonsense。它就是否定性。差异本身是一个符号学效果，符号学效果是每一个能指其实都具有的一个特点：它都是 floating 的，因为它是个结构主义者，就这么简单。floating signifier 意味着，一切事物你对它的把握都不能直接把握到所指，这是乱伦禁忌、非法的；那你只能靠一个缝合性的能指，一个主人能指。第一个能指其实冒出来，第一个能指就是那个镜像。如果我们把符号学的标准放普泛一点，那个想象性的镜像它也是个能指，只不过它没编到符号系统里面去。它就是一个 image，mirror image，它的符号学机制等同于 mana，基本上是类似的，就是全有全无、一零、全有全无。

floating signifier 的机制如前所述，一切事物不能直接把握到所指，只能靠缝合性的主人能指；第一个能指就是镜像，想象性的镜像也是能指，只是未编入符号系统，其机制类似 mana，全有全无。婴儿发现能肆意控制一个东西，就觉得能控制一切，或者能控制某个，于是处在镜像阶段的那种状态；他觉得控制这个东西就是控制了一切。另一方面，他又觉得自己什么都不能控制。婴儿在身体肌肉各方面运动还没协调的情况下，在一个镜子里面看到，比如他的意向性活动导致一个圆圆的东西上面的另外两个圆圆的东西，他闭了闭，他就觉得他获得了超能力，你知道吗？
