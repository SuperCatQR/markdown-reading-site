# 【现实与哲学】一个重要的节点：可复制性；资本vs团结

我觉得我们要思考一个重大议题：可复制性。英文大概是 copyability、duplicability 或 replicability，也可以译作 reproductivity，也就是再生产性。这个词很关键。

我们看帝国主义，主要是以美欧为代表，当然澳大利亚、以色列、日本也可以算在内。它们的特点是拥有垄断性技术：技术不可复制，存在很强的技术壁垒，或者说知识产权壁垒。这种技术的不可复制性使其资本具有某种垄断性，也使其武器、地缘实力和生活方式保持优势。比如最近非常有革新性的 ChatGPT，写代码只要跟它打个字就行了，它会帮你把代码写出来。

这些都维持了它们的优势，而且可以说是一种很大的、压倒性的优势。技术不可复制，反而使帝国主义的金融、金融工具和资本具有增值性，反而变得可以复制了。它的帝国货币可以像无止境地印，反而维持了一种可复制性，维持了资本的可复制性，也就是它的增值性。

或者说，它的存在模式，也就是新自由主义存在模式、新自由主义霸权的可复制性。各式各样的颜色革命，它以不可复制的技术垄断，当然还有它的符号性秩序；而帝国主义很多东西都是不可复制的，每一个帝国主义、每一个主权国家、每一个地缘实体，其本身的内在政治经济秩序看上去好像可以复制，但实际上都不可复制。它们各在某一个产业、某一个垄断行业中居于不可复制的技术优势地位，以及资本优势地位，所以它们是垄断资本。

那么，帝国主义之外的非帝国主义国家，或者说南方国家（South），其他就算有资本，这些资本的内核也是可复制的。你再怎么标榜自己独一无二，实际上资本内核运行的技术生产方式并没有压倒性优势或垄断性壁垒。

但资本这个符号性内核——我说的是它的符号性或知识性内核，也就是知识产权、知识性内核——是可复制的；而资本所调用的其他条件则具有一定不可复制性。比如大规模的廉价劳动力，大量的廉价原材料、廉价劳动力、廉价能源；廉价能源对应俄国之类，廉价劳动力对应印度之类。这些东西不可复制。这种不可复制性使非帝国主义资本还具有一定的竞争力。它的内核是可复制的。它能够作为一个国际性资本依然存活，是因为在外部实现资本增值的很多现实条件、客观条件是不可复制的。

所以我们会看到，资本的增值性要通过内部和外部，或者说通过资本的符号性、知识性内核和资本现实的产业化、金融化再生产过程。两者之间存在可复制性与不可复制性的差异，它才能成为资本。但这也注定了这两种资本具有实质性差异。都有这两层，当然这两层是不一样的。我们看到这两层在转化：随着技术壁垒被突破，或者随着专利期结束——当然这都是有序的秩序，不是突变性的——本来具有垄断性、不可复制性的技术跌落了，可能变得具有可复制性。我觉得最简单的是万用宝。万用宝这个东西其实没什么技术含量，就是一天到晚不停地震动嘛。

那公司叫什么名字？泛英公司，Fiam。好像是在二零一几年的时候，它的专利二零一九年才到期，还是一几年才到期；在那之前大家都不能用，所有其他公司都不能用。但是现在万用宝性价比最高的是东成的，两百多块钱，我说你可以在闲鱼上淘更便宜的。专利期到了，我们会看到，可复制性与不可复制性的核心差异体现为专利或者知识产权、智慧财产。

知识的私有制，知识性的私有制，智慧性的私有制。我们也很能够看到，帝国主义与非帝国主义与否，可以看到它这种垄断性的知识、不可复制性的技术，以及那些技术人口、知识人口，附庸于谁、从属于谁。谁可能就是一个完全的帝国主义，谁有点帝国主义苗头，谁还不是帝国主义。

我们要看到，我们刚刚讲的都是资产阶级建制内部的可复制性与不可复制性；但对我们来讲，可复制性也非常重要。也就是说，我们追求一种团结形式的可复制性。我们要拒绝资本化，这意味着我们的行动、团结形式要追求可复制性，而且是它的知识性内核——也就是它的知识、原理、技术原理——符号性内核以及内在的符号性组织关系等等，都是可复制的；同时，它外在的现实发生机制，各种现实要素结合起来生产、转化出真正意义上的团结，也是可复制的。它要内部和外部都是可复制的。你嘴巴上念的东西得是可复制的，你现实去做的东西也得是可复制的，这样才有希望。

这样才有希望，团结才能战胜资本——平等而自由的团结，平等而自由的、开放的、紧密的团结，solidarity，它才能够战胜资本。所以我认为，团结的内核是可复制性。在我看来。

我们目前看到很多话语讲究一种一次性：大敌是一次性，怂恿人去送死，那你的团结不也是一次性吗？一群围着挨刀，那是一次性的团结，它不叫团结。或者他根本认为不能团结，只有孤狼式的自杀式冲锋；或者悲剧性的、注定被背叛的，要么被背叛，要么背叛别人。这些话语让人们对团结嗤之以鼻。这里的团结指的是现实团结，不是嘴巴上的团结。这种现实团结的最低限度叫作互保。

有的人认为团结没有必要，或者认为这样的团结再怎么做得出来也不可复制，它只是你的小圈子，或者没有办法形成一种派系性、潮流性。所以这些人宁愿做一次性的孤狼，为自己的人生铭刻一个不可复制的、不可磨灭的、悲剧性的冒险勋章。这种悲剧性的、不可复制性的、失败的冒险勋章，实际上是这些人——这些自称自居革命者的人——要这么个勋章来干什么？用来向自己证明一次这个东西注定失败，然后他就背叛了。这种人随时随地准备着背叛，所以他绝对要一个不可复制的、专属于他的借口，一个失败的挫折，一个专属于他的冒险勋章。有句话不是这么说的吗？

三十岁之前这个人不是共产主义者，说明他没良心；三十岁之后这个人还是共产主义者，说明他没脑子。那么这种一次性的孤狼呢？他在十几岁、二十几岁的时候追求一种一次性的、不可复制的，或者说肯定失败的、悲剧性的冒险，就是要给自己攒一个勋章。‘我已经爽过一次了’，他把这个东西当成成人礼：‘我戳穿了这些理想背后的谎言，我用最彻底的失败，我这一生已经对得起你们大家了，我败了！’但是他完全没想到，他在这个过程中根本不讲究团结，或者说他那个团结根本是不可复制的团结，是虚假团结。败了一次之后，他说那我三十岁之后就可以完全投靠资本主义，完全投靠新自由主义了。

这种活动就是以背叛为目的的。在这个意义上讲，这种东西追求不可复制性，其实恰恰是小资产阶级、小资产阶级子弟——这里不搞性别歧视，不是像骂男人一样——这些人的子女。他们专门复制这种模式：所谓的信仰危机，或者说理想主义危机，失败之后就彻底堕落成犬儒，或者堕落成功利主义者、马基雅维利主义者。这些东西其实恰恰就是这些人的可复制性，意味着他们就是可复制的。我们看这是一个辩证法：内在，这些人以为追求的是一个唯独属于他的、不可复制的失败；外在来看，它就是一个小资产阶级阶级意识再生产。小资产阶级的阶级意识再生产就是背叛，做资产阶级帮凶、附庸，背叛无产阶级。它实际上是一种意识形态资本。

我讲了，这种虚假的团结、一次性的冒险、孤狼式的自毁，是一种资本。它的运行逻辑和刚刚讲的资本——无论是帝国主义国家还是非帝国主义国家的资本——的逻辑是一样的。而且它可能追求的是里面不可复制、外面可复制。它可能靠近帝国主义，所以我们当然可以知道，这种人为什么会坚持所谓的中地论。他宁愿相信他自己里面那套是不可复制的，外面在批量复制。里面是不可复制性，里面这个东西是神圣的、高贵的、失败惨痛的，一种苦难悲剧；外面是可复制的，外面一看，所有人都这样，都他妈是叛徒、都被叛了。我说这是一个小资产阶级子弟的阶级意识再生产，那实际上是一种资本，是原教旨资本。

或者说，悲剧主义、牺牲性的原教旨资本，是一种意识形态的资本。就好像《雷雨》里面那个爸爸——名字我记不得——《雷雨》里面那个爸爸教训他的儿子说：‘你读过几本社会学的书？看过几本马克思的书？我当年也跟你一样热血过，但我遭受了沉重的折磨，我也有这么一个勋章。’他就是个意识形态资本，成为这种人的意识形态资本。那么这种人有了这么一个资本之后，就可以不择手段，就可以完全向资本逻辑妥协，完全靠近帝国主义的垄断性，背叛解放性的力量。他有最不可为人倾诉的、轻易说不出来的那种内在理想性的挫折、失败，一个悲剧性的、壮烈的粉身碎骨，然后他又复活了。复活之后他想：我再也不要这样了。

所以我们说，这类人物——比如激流网的拥趸、做一二三这种人——我认为他们都是在撺掇这样一次次的孤狼式、自杀式行动。他们的拥趸还在知乎上撺掇我去做一个一次性的、孤狼式的自杀。我们始终追求的是可复制性，而且是内在和外在如一的可复制性。这种可复制性只要能够贯彻、内外如一，就能够扬弃、超越资本逻辑。我并不是说我本人的成长过程、我的互联网形象或者我的视频制作形式可复制，我讲的是团结的形式可复制。而且我正在探索，我目前正在探索一种内外都可复制的团结，一种劳动群众的无产阶级团结，一种以互保作为最低限度的团结。如果这种团结能够被批量地现实生产，并维持其自身再生产，那我们就有机会去战胜整个资本主义世界，战胜资本的逻辑。

所以我认为，这是一个关键性的概念。当然我们可以说这是阿尔都塞论再生产，但这是我目前思想的一个节点，也是某种转向。那先讲到这里。
