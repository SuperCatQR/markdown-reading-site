# 【随便聊聊】历史与运动中的苍白与细腻

年纪很大的人掌握权力，最典型的是美国。两个总统候选人，现任总统和前任总统，一个七十八岁，一个八十多岁。这其实有两个原因：一是世界人民求稳，需要有更有社会经验的成年个体来裁决问题，因为大家觉得世界在动荡，可能出问题。但像美国这样求稳求过头，最后变成糟老头子掌权，很明显说明底层或中层利益集团已经开始要求变、求乱，目的就是希望在任上总统去世，让副总统接任。所以我觉得 Trump 和拜登选举，最关键的是副总统人选，因为两人都有概率在任上失去执政能力，一旦如此就会大换血，利益格局发生大转变。比如法国马克龙，政治就非常不成熟：欧洲议会右翼居多，他竟然解散国内议会重选，结果大败极右翼。年轻政客会带来巨大不确定性；他做这种姿态，虽然败了，某种意义上也是在给自己攒政治资本。于是我们看到一种超政治——meta politics：他明知这种政治活动会带来政治失败，但因为年轻、政治生命还很长，就要用失败表明鲜明立场，赌的是等他五六十岁、六七十岁时，政治资本还能翻起来。这就像买股票一样。

他不是白左入脑；那些白左价值在巨大危机前都是错误的，而且引发危机。但危机发生后，比如幻想中的三战或局部地缘冲突变成多个大国介入——不一定是三战，可能是某种事变——各国联盟之间出现不可挽回的损失，人们就会回忆起他战前所提倡的中间温和派角色。这有点像以退为进：年轻人输得起。这种超政治（meta politics）在政治之后，可能涉及他本人的权力、地位策略，因为他已做到最高。比如马克龙已经在本国做到总统，要追求政治定位、让政治遗产发光发热，就必须把自己的名位当成筹码、道具，与时代、政坛以及人类交往博弈方式发生冲突。所以我不觉得解散议会重选纯粹是政治操作；他毕竟学哲学出身，是在用政治方式进行哲学探索。这种东西叫形而上学，是高级政治学或元政治学，whatever。政治本身被这样的哲学人物当成探索工具，宁可失败也要表明立场。这就像一个钥匙拧大石盘，或一把小螺丝刀拧超大螺丝，看能不能拧动；它必然折断，但他把折断后留一个外面的把手给后人。法国佬能整出这种活。

现在美国也基本上在整这么一活。美国的立国精神实际上是法国精神，独立战争其实是法国人帮美国打赢的，非常类似。明明是两个老头争总统位置，但实际上非常类似。总统总会出混乱、出非常不确定的情况。川普代表偏右，拜登代表民主党反建制派，非常有意思；拜登自己的派系，这两个人随时随地可能死。关键就在于此：公众能接受认可这两个特别老的人再选总统，而且无论谁选上都是老调重弹，Any of them，都是一种重复。川普已经干了四年，再选上也不过再来四年；拜登也是。这就是历史刻意反其道而行之。而且我相信，无论拜登还是特朗普，哪一个上台，另一个绝对会成为地下派系领袖、在野党领袖，不会退出政坛，会依然成为旗帜。两派都在等一个老人死亡，然后冒新人出来。有人说什么贺锦丽，或者 Newsom 之类。

whatever，建制派都在等一个，这是刻意创造新人，也是一种群体性的客气；他们无法确定那个人是新的。假如川普和拜登都不选，两个矬货不选，让年轻人来，大家就会觉得全都一眼看穿，蛇皮，是不是一眼看穿？两边建制派都是什么货色，直接接受不了。但如果两个老鬼哪一个在任上突然去世，紧张之间他的派系和本党建制派激烈冲突，然后有一个年轻人出来，公众就有想象空间了。政治就会被设想成：这样才有某种不可能性，本来不可能的东西在这里才可能发生，才可能有所突破。所以我觉得目前两个老头选的选情，其实就是民众的精神、民众的心理。这种情况是美国。就像严嵩或徐阶不会让高拱上来；年轻力壮，但老派人物虽然怎样呢？夏言这种也他妈什么屌人，太一板正经。

非得是严嵩、徐阶这种老逼，忽然斗倒一个，另一个也与之偕亡，这时才可能有张居正这种人出来，实现某种非常强力的国家控制。现在无论 Trump 还是拜登，都不能说是很强力、非常娴熟、连贯，有压倒性影响力地控制美国。这是我的观点。大选还有一段时间，但看这个样子，拜登好像选不上了；退选也不太可能，因为我刚说的结构：这其实是两党策略，表面推老人，实际是看老登嗝屁之后一下子冒出来的人，超越民粹和建制的二分，或在矛盾混乱中仓促上阵，大姑娘上轿头一遭，一下子担当大任，擦出不可能的火花，这样才维持公众对政治的期待。所谓物极必反：过于老、过于求稳，然后一下子嗝屁、崩断，物极必反。通过这种选举政治策略，实际维持了民众对两个派系、四个派系或好多派系、对地下政府/deep state 深层政府的某种期望和展望。我国情况不讨论。我的观点是，人类目前已跨入这样一个时代：不能看表面那些人，而要看预期，这就叫政治金融化；一方面政治哲学化、形而上学化，有一个超政治。马克龙的操作把失败本身当表态，对政治成果、政治得失就当玩票，但玩的这张票将来又变成政治成本兑现，重新玩，是一个高阶东西：现在我买进是亏了，将来升值就血赚。所以我们又叫政治金融化，是政治本身金融化，不是金融政治化。政治本身也像金融一样，要炒、要囤、要拉高买低。人类进入这样一个年岁，已经没有那种茁壮……换言之，反而代表社区的自治性挺大；现代社区生活模式都类似水电煤气供给，街区一划分，治安、卫生等各种公共服务一生产……

各种公共服务一生产，然后排排坐就进去了。所以在很大程度上，这个世界还有特定的人、具体的人在主导某种决定性的发展，很多国家这已经是维持统治的核心。技术治国论论调的错误在于：并不是某些人推崇用技术治国，好像这些人凌驾于技术之上，是专家治国论，有高级人拿专家治国，或拿技术官僚治国；其实更进一步，有没有可能人类本身现在受限于技术本身、统治技术，或人类存在的基本范式？所以技术治国论应该叫技术在治国，技术本身是去人称化、匿名化的，同时也是人称化、匿名化的。不是草台班子、马前卒的肤浅就在于此：他还觉得是草台班子里唱戏的人在决定万事万物，其实是草台、戏台子本身在生产唱戏的人。戏台子本身非常不一致，内在矛盾、自相悖谬，但又是大家所能设想、遵从、在生活中习以为常的唯一秩序。所以很多情况下不是人的问题，不是人类的问题，而是人类被某些问题纠缠，不得不打肿脸充胖子说这是人类的问题。人类唯一可能解决问题的第一步，在于承认人类并不能主宰自己创造出的问题，也不能主宰自己设立出来的——甚至不是人设立的，而是经由人才出现在世界上的——种种框架、制度、技术、思想；这些玩意儿反过来严重束缚人类，或者说经由人类的自我束缚才显现、展开。所以我们需要在多大程度上关心或期待某些人物？简单讲，人事问题并不等于政治问题，人事问题只是政治问题的小要素。

人事问题只是政治问题的要素，或其中可待参考的环节。但人事斗争本身在历史中非常尖锐，你死我活。因为一点点人事力量对比还没达成，先被揭牌，就要弃卒保车、弃车保帅；哪怕它是个车，不是卒子、不是炮、不是马，保完之后还要被说可耻，弃了之后还可耻。我不知道你们怎么看待这些历史现实、人类生存的现实，它类似一种无可奈何的常态。人类现在还在穿纺织品，还没有纳米外衣，也没有靠高级生物科技改造自己的皮肤；人类现在仅仅是长在地球表面上一个比较诡异的疤，是一种疤痕性的存在。这个疤说明人类活动空间仅限地表，只不过是长一些疤、丝状分裂、复制彼此搭建。想一想，这种进步相比于农业时代或初步工业时代，并没有实际显著的提高。我们只不过更多掌握了比较小的电力、电化学过程，有一些物理效应，用信息世界把自己包裹起来。现代人类和以前完全不同的地方是，现代人在很大程度上活在信息世界当中。就像我，我的形象、我生命的某些意义和价值，都在信息维度、虚拟理智空间里才存在。但这种进步在技术层面上仅仅是应用性的、大规模应用性的。人类做个键盘都得依赖有机化学分子之间简单的、可控或不可控的过程，很多情况下不是完全可控的。

高温高压或复杂化学变化，因为有机物成分复杂。人类做塑料，单纯某种东西功能无法满意，必须组合添加，像炼金术一样形成新质量，满足需求。总体讲，我并不觉得……你看灯亮的全是小 LED 灯，一个关键性效应被广泛应用；超出这个效应本身、超出物理世界定律束缚的东西，不存在，那叫魔法，必须服从它。人类的力量在于服从，服从大量简单而粗糙、粗陋的秩序。只要人类更彻底地服从，通过服从来编制自己的任务线索、任务表，人类就逐步缓慢获得各式力量。人类并不是地球的主体，实事求是讲，人类并非地球主体。人类所遭受的政治制度、经济制度压制和束缚，这些压制和束缚才是地球的主体，或我们所处宇宙自然环境的主体。这个主体以某种不容分说——我们权且假设它是主体化的——无限冷酷的规律，铁的规律支配宰制人类，这才是主体，人是这个主体的仆人，或者说是试验品。但人类主体性本身反过来可以把握、觉知、反思，然后通过行动和努力寻找实践路径。在这些实践路径中，又需要百倍千倍利用手段、技巧、途径，才能整合力量、争夺资源，让自己在历史中站稳脚跟，然后诞生出更大规模、更大范围的理念和意志延伸。我们把这样的活动称为运动。但实际上，真正的主体在压制运动、妨害运动，同时以让运动失控、偏离的方式激起运动。运动的失控、偏离和被妨害状态，反而是运动可以扩大、在历史中被践行、被讨论、被怀念、被悔恨的基本力量。

运动到后来基本上全部走样，只有少部分哲学运动或科学运动——指改变人类存在和交往方式的运动本身——也基本走样变形。或者说，它一开始就是阻止、妨害人们以某种方式激发自身，或不满于自身被妨害状态，去寻求某种内在的、收缩到内在的人类主体性。黑格尔说明收缩到最内在、不管不顾一切，这是人类的主体性。这种主体性并不是世界的主体性；它是世界之夜，主体性是世界之夜，但世界之夜不是主体性，夜晚不是主体性。夜晚意味着死亡吗？夜晚又是世界本身对于这个主体不再重要，但世界主体性不会被夜晚取消，世界主体性就像夜晚的鬼魅。所以我们大致可以得出结论：比如科层制注定腐化堕落，人在里面注定异化；引来异化、腐化、堕落的东西，可以叫鬼魂。这种铁的定律具有某种活的灵魂，但这种活的灵魂其实是死的，是死的灵魂，你不会觉得它活。活的灵魂在人的活生生状态：意识、思维、情感、沟通交流方式、记忆、联想、感知、反应、情怀，机心巧智、宽怀大量、慷慨等等气质秉性，是人的灵魂、活的灵魂。死的灵魂比较鬼：偏狭、一意孤行、固执、执着、彷徨，随时准备以非常惊悚的方式降临，一下子让你觉得这个人不认识了，一下子觉得这个游戏不是自己想要的。

彻底后悔了，想要逃避。人像怕鬼一样怕着这些现实人类特定活动种类中一定会产生的人的自我背叛、自我奴役、自我压迫、自我毁灭，这些力量才是鬼，才是鬼魅。所谓旧社会把人变成鬼，其实不是，旧社会就是鬼；旧社会种种政治利益关系、意识形态征召机制、享乐病理化机制，都可以说成鬼，而且直接附身在你这个个体活的灵魂中，直接起作用，让你变得狂、疯癫、无可救药。如何对抗这种鬼？首先人要团结起来，要知道有鬼的存在。我们讲最大的鬼是资本主义，the biggest ghost。但德里达把共产主义当成幽灵、鬼魂，这不一样：幽灵不进入人的精神；这里讲的是鬼魂，中国意义上的鬼魂，总要附身，obsess，获取附身，obsession，附体。西方意义上的幽灵 ghost。东方意义上一直会有一种上升哲学。但我们讲的关键点，这东西不是什么主体化，不是什么意识。它只能说是一种——我们刚刚已经比较清晰地界定了——是世界本身，甚至不是一种意志，是非常消极的，然后是非常固定僵死的一种漩涡，就像一个漩涡，或者一个……

大的、非常垂直、坡度特别大的瀑布。没有人可以战胜这些东西，但有人可以反过来获取它们。我讲没有人可以战胜，Nobody could。如果我沦为政客，或有幸成为政治家，那么这些东西该有的都有，该涨的都会涨，该发生都会发生，不会因为这个人尚未掌握权力、尚未进入这种活动方式之前是怎样的人，就免于所有规则和机制。它实际上是客观的，客观性就停留在暴力斗争初期。暴力斗争初期基本上以地下秘密情报体系为开首，地下秘密情报体系要有大量现金、大量钱，以及少部分知识精英和中等规模执行人员。这个时候已经起作用了：拉帮结派、势力均衡、制约、资源分配、冲突竞争，以及精英知识分子团体和少部分死士卖命者之间话语、理想、情欲、爱欲上的交易，一定会让精英知识分子一下子手都脏了。你们不要轻易过这种生活，也不要有幻觉和联想。它只不过把游戏里必须遵从的套路搬到现实；不遵从，就会被判定挂机、作弊之类，受到各式处罚惩处。所以我们讲的就是这样一种层面、概率、几率。为什么讲概率和几率？

因为这些逻辑随时随地会让你在人际斗争、矛盾冲突中占得头筹和先机。这些矛盾冲突比如和父母冲突，或和单位、企业同事领导，或学校同学老师冲突。简单讲，会玩这种东西的人叫会来事、人精。他们会利用巧妙机制、利益结合点、均衡平衡、发展动向动态，来缓解自己的痛苦。哪个团体没有基本痛苦、基本压抑、压迫？缓解痛苦是一方面，另一方面也激起欲望，往新方向发展，或至少维持。这种游戏没人能拒绝，但我们不能简单叫权力游戏，也不能温和说成交往，不能把交往说成实践；我们把它说成一种一过性但终身携带的病理化基因。病理化体现像带状疱疹一样，在集体中，在特定情况下，某些要素或健康度重大折损时，某些利益关切极其重大的核心底线性利益被迫发生、显现时，都会成为巨大偏斜。这些是一过性、自限性的，但会产生巨大偏斜，人会在决策中戏剧性偏离。比如你小时候是地主家孩子，在父母介绍下跟佃农家孩子打交道，人家更活泼；你凭身份地位压迫压倒别人，或借自己懂，偷偷拉帮结派。
