# 【主义主义】宇宙平等主义（2\-3\-4）——哥白尼革命/公转的伟大的科学史、思想史意义

接下来讲主义主义的二杠三杠四。二杠三杠三已经讲完了。二杠三杠四其实也是从二杠三里产生出来的一种我思形而上学，我把它叫做 cosmica，这个词怎么拼？

这个词有点难拼。egalitarianism 就是宇宙论的；我感觉不应该用 cosmica，应该用 cosmology，即 cosmological。在宇宙论上，它的形而上学是一种平等主义，代表人物就是哥白尼。哥白尼原则其实就是哥白尼原理，或者叫平庸原理：所有观察者都是平等的，不存在一个静止的、作为中心的观察者，没有中心。哥白尼那本《天体运行论》里，所谓“运行”其实是 revolution，也就是天体公转论。我把它叫做宇宙论上的平等主义，或者宇宙平等主义，也叫观察者平等主义。它不是指不同的宇宙论之间平等，而是指在宇宙论上所有观察者平等。

哥白尼原理其实预言了：整个宇宙在空间上是均质的，并且在每个位置上都是各向同性的。你把它摆向不同方向，它的物理性质不会变。它既是均质的，也是各向同性的。现代物理学，我刚查过，在六十亿光年这个尺度上，可以说它是均质的，是符合哥白尼原理的：能量密度看上去差不多，空间的褶皱在这样一个尺度上看是舒缓的、平的，平均密度也是一样的。

那么，为什么我把它看成认识论上的“四”呢？因为这意味着没有一个观察者具有特殊的视角。哥白尼原理预设了不存在一个具有特定、特殊视角的观察者。有人会说，太阳上也没有观察者；哥白尼原理实际上是否定性的：人类的视角并不是特殊视角，人类并不具有认识论上的优越性。但是这种否定性的姿态只能由谁来提出？只能又由人类本身来提出。所以在这里，它看上去就有点认识论被击穿了。

所以这种宇宙平等主义，我也可以把它看成一种实在论，一种形而上学的实在论，或者说一种自然主义。但它是二字头的，是一个标准二字头。因为这个“二”就是——我们来看它的场域：两种背景性的场域，一个是 cosmos，即形而下的宇宙；另一个是上帝的安排，也就是几何关系。那种简单而美妙的上帝安排是形而上的。所以它在场域论上还是一种对立关系。

然后说哥白尼的“革命”，哥白尼革命——其实翻译成哥白尼革命是一个误会。不要翻译成哥白尼革命，它就是哥白尼公转；只有在哥白尼那里才存在公转，也就是绕太阳转、绕恒星转。哥白尼革命就是哥白尼公转。公转和革命是同一个词，the same word。哥白尼革命就是哥白尼式的公转，他的公转体系和托勒密体系是不一样的。

托勒密体系是地球在中间，有一个固定不动的均轮，每个行星都有自己的本轮。托勒密体系为了解释——其实只有太阳，地球绕着太阳转——这个现象，就把太阳本身的转动也看成一个比较稳固的转动，其他东西实际上都绕着太阳转，于是好像在转动之上又加了转动，有的要套好几个本轮。在哥白尼体系这里，你必须克服一种直觉才能进入哥白尼原理：不要认为你是世界的中心，也不要相信经验，反而不要相信经验。

所以我把它说成时代论是不太恰当的，因为他不相信直觉性的经验，他知道背后几何关系更真实；但这个几何关系很简单、很简明，不足以建构出一个形而上世界，却可以作为一个背景性秩序，和形而下的秩序产生冲突。所以它是二字头的。

而且哥白尼在世的时候，《天体运行论》并没有堂而皇之地说这就是事实。他有一个前言，说这本书是让大家在把握托勒密体系时，在数学上有一个便利性，更简单、更方便地理解托勒密体系；我们可以假装把它看成这样，那么这些就变得更容易了。他骗过了好多人，但没骗过谁呢？没骗过路德，没骗过聪明人路德。路德知道他玩的把戏，因为他们都是二杠三的，路德也是二杠三的；而当时的罗马没有看出来。

然后在本体论上，同样有一个对立：一边是经验性的世界，即表象世界，或者体验性的凡俗世界，也就是万物；另一边是主宰，主宰万物。

这种竞争关系是被调和的。被什么调和呢？被一种几何学关系调和。你可以把这种几何关系、几何架构或简明性关系看成是这种调和关系。从之前是一个中心，其他所有东西都和这个中心发生关系，现在已经变成每一个东西之间都有关系存在，每个东西之间都有关系存在。这就是力，类似引力这种东西。

在托勒密宇宙里，事物和一个中心发生一种关系，那个关系都是附带品，可以并到这里面去；只有到了哥白尼式的宇宙里，这种关系本身才会被思考，才开启了后面伽利略、牛顿这些人的思想。所以在这里，我们可以说，力在本体论上就是一种关系。

就是物与物之间的一种关系，其实是一种数学关系——不要写成几何关系，数学其实更是一种数学关系。数学关系是能够显现出来的，它显现出公转的那个轮、公转的圆；哥白尼把这个数学关系画成正圆形，完满的正圆形，其实就是赋予它本体论地位。这很像托勒密体系或亚里士多德体系里的 sphere，但它不是 sphere，而是轨道。这里其实该把握的不是轨道，而是两个东西之间的关系，它和太阳之间的那种关系。

为什么它和太阳之间的运动一定会甩成这么一个正圆形呢？那后面的人就要去思考了。从日常现象看，拿根绳子甩起来，它就是一个正圆形。所以在本体论上讲，这种力、力学关系，而且是超距关系，就具有一定的本体论地位了。然后在认识论上，它是完全敞开的。

它短路了，认识论上就闭合了。这意味着，按照哥白尼原理，主体性的维度没有优先性了——不叫主体性，就是第一人称；不叫第一人称，就是我们所处的那个位置、观察者的位置，也就是我们在神学当中的那个位置，不具有第一人称优先性。但我们在什么当中具有优先性呢？

就是在一种简明性当中。数学关系直接导向目的论：这种关系要够简洁、够明了、够清晰，它就直接代表世界运行的真实运动模式，直接就是。所以不需要认识论来中介它。认识论的维度这时会觉得：我就是直接在认识这个本质，并没有任何棱镜在束缚我，我认识的就是真理。我直接认识到的这些就是真理，它不是什么神学里的偶像、幻象，也不是表象世界里一些不可靠的东西。我认识到的就是这个。把它叫做形而下其实也不是非常恰当，因为 cosmos 在这里本身具有一种神圣性，宇宙本身具有一种神性。我直接把握到的这个宇宙里的天文学结构或物理学关系，直接就是事实。所以它认识论上的“四”就是一种自然主义态度，或者说一种实在论的态度。

他就认为，自己体验到的东西里面包含了秩序；本体论上的万物和主宰，目的论上的运动模式，直接就被力学关系，或者说宇宙运行的那个数学或几何学原理吸收掉了，那就是他的目的论。

那么在哥白尼这边，我没有写他的目的论，直接把它算作二杠三杠四，原因是我后面要给伽利略、牛顿这些人腾位子，他们需要有位置。

这个“四”其实也代表哥白尼原理：哥白尼原理就是不存在中心化。你看，二杠三杠三里调节的都是逻辑体系具有优先性，或者是一种叔本华式的直观，用它来缓和哲学和生存论冲动，或者哲学和伦理学、哲学和神学之间的对抗，都要有逻辑学来调和，或者都要有一种分析性的、充足理由律式的东西来调和。现在不需要调和了，或者它直接崩掉了，因为它直接就是：我看到的东西，我认识它就是真的，就是真实的东西；这个世界运行的模式直接就在真实东西当中，我通过数学就可以感受到、就可以把握到。数学关系就可以。

然后数学本身具有本体论地位了。在这个宇宙平等主义里面，数学本身就具有本体论地位了。或者我可以把它叫做几何学主义，因为它其实就是后面引发了经典力学体系。这里要讲的其实就是经典力学体系它的背景性的形而上学。

它在本体论上还是这么一个三元结构：经验性的事物、第一推动力，然后数学关系，或者说力、物、神。这三个在本体论上都有一席之地。

然后认识论上那个就没了，认识论就没了，不具有中心了。我们本来说认识论代表主体性的维度，但你的主体性没办法中心化了。我不欠你什么，你不需要主体性给我什么逻辑结构、充足理由律，帮我去推、去演绎、去使它必然化；不需要了，不需要你的主体认识论来中介它了。你直接去认识它背后那个数学关系就行了。

而这种数学关系被看成是独立于人的认识而存在的，跟人的认识没有关系。数学关系不是一种逻辑关系。以前二杠三杠三的时候，这里的“三”可以由逻辑学来中介，因为逻辑学明显是一个心智构造——比如排中律，明显是一种语用学的人类精神构造品。但在二杠三杠四里面，它不需要也不能中介了，而是一种本体论里的数学关系。数学关系本身被看成这个世界本身的数学关系，就是 practical 的，或者说现实的数学关系；现实的数学关系本身被看成一种真实的空间关系，或者说时间，或者说就是现实的力学关系。我在这里可以说，现实的力学关系或者物理关系、物理学关系。

这种关系就具有本体论地位了，它就是世界的真相，是世界当中真实存在的。你不需要一个认识论去把握它、调节它，你直接感受到它就行了。从这个角度讲，二杠三杠四离康德越来越远，它里面没有意识到主体性还在里面中介，认识论的维度还是存在的。

它是离康德越来越远，会变成一种朴素的东西，最后会变一字头。它里面的探索全探索完了，最后 cosmos 和 mathematics、数学性规律之间的冲突，会随着你从微观粒子去把握，各种现象被消解，最后全部消解掉。那这个最后二字头就变成一字头了。

那么至少在当时的传统背景下，自然哲学的、或者说经院哲学的背景下，哥白尼是一个很虔诚的人，相当虔诚。他还是二字头的：他背后仍然认为这个神圣的自然秩序来自于主宰。而万事万物是比较混乱、复杂的，比较矬的。那个神圣的自然秩序都是同心圆，都是绝对的圆，它由上面来保证，代表一种完美性。他死前摸了摸书的封面，然后就安然死去了。

所以这是二杠三杠四。这个形而上学体系就是西方科学真正意义上的开始，就是西方物理学的开始。西方科学前面也已经讲过它是怎么开始的。

所以这个二杠三的整个体系，就是一个完整的体系：如何从经院哲学晚期延宕出怀疑论，最后导向先验哲学，怎么延宕出莱布尼兹的这种实在论，还有斯宾诺莎的这种也是 realism，也是一元论的实在论。这些实在论其实一直保留到现在。比如有些唯物主义者，他的本体论其实是斯宾诺莎式的；还有一些分析哲学家，他的本体论其实是莱布尼兹式的，没有什么大的变化。他们只不过嘴巴上说“我不是了，我不是”，换套说辞，但他们那个想象性的格式、想象性的模式还是一样的，没有什么差别。他想象的那个世界、那个形而上学图画没有太大差别，他想象的模式、他预设的那个世界的样子还是那个样子，因为他没有真正走向康德。

然后还有科学共同体，好多科学共同体想象世界也是想象成二杠三杠四：我直接体验到的就是这个世界，只不过背后有一个神秘的数学关系，这个神秘的数学关系代表有一个神秘的、超越性的创造者，或者一个布局设定者，一个第一推动力在那边。所以它是二杠三杠四，它认识论是被击穿的，认识论上直接被击穿。那我们就讲到这边。
