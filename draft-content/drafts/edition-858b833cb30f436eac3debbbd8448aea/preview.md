# 【社会观察】帮助别人前，先要确定对方是否需要，是否愿意接受，尤其是近乎无用的帮助

如果你要帮一个人，先确定他需不需要。这里我加个限定：成年人。如果你要帮一个成年人，先确定他需不需要。我再明确一点：这里的“需要”是一个情态动词，He need it or not。为什么我要强调这一点？你要理解这个命题，要把它当情态动词来理解。

因为发生了一件事：我在直播间里说，我要给我的视频盒子刷固件，把它修好后带给我妈看。这个视频盒子类似电视机顶盒，但它是另一个东西，生产厂商是华为。可以把它刷到出厂版本，就能自由安装通用版本的软件，不需要再买额外会员，因为很多会员不通用，比如电信版本的会员就不通用。我专门在优酷上充了会员，但如果是电信版本附带的优酷APP，打开后又要我充会员，很烦。我在刷固件的时候，有人跑过来说：“你刷固件要注意版本。”我说我已经说了我要刷固件，而且我说今晚刷好，明天要给我妈带过去，我心里有把握能做成这件事。这意味着什么？

这意味着我知道什么叫刷固件。刷固件就是找到这个机顶盒、视频盒子或电视盒子的版本，然后到网上对应找它的方法、步骤和补丁包。我会，I can do it myself。我不仅会，我还知道：光看表面那个版本不行，还要看芯片版本、电路板上的版本；电路板上的版本在网上找不到对应固件时，还要用其他方法，比如把网上已有固件的文件内容稍微改一下。我知道的东西比他提的这个建议深刻得多，我可以拒绝这种建议。我不仅拒绝，而且还要教训他，告诉他不是所有人都需要你提这种建议。这就相当于一个人说“我明天要开车去上海”，旁边一个陌生人跑过来说“你开车时记得踩油门，要先系安全带”。当然，开车有准入门槛，一定要学驾照；那好，我骑自行车，自行车没有专门考试，陌生人又跑来说“骑自行车要知道用脚踩踏板、要按刹车”。这种陌生人提的建议，回到成年人身上：如果你要帮一个人，尤其是帮一个陌生人，而且这个陌生人不是说你对他完全一无所知——他在做一件事情的时候，你知道他已经会做这件事，他默认自己会做——你说你要帮他、给他提建议，你要确定他需不需要，首先要确定他需不需要。我为什么强调这里的“需要”是个情态动词？因为很多人以为，比如刷机顶盒、电视盒子固件这件事，绝大部分人不会，绝大部分人不会刷固件，所以他提这种建议是对的。但这里你在偷换概念！我表现出来的明显不是那绝大部分不会刷固件的人，我是在直播间里明确说我刷好了，明天要给我妈带过去。你这个命题在偷换，把它偷换成：绝大部分在直播间里明确说自己会刷固件、并且第二天答应母亲要把电视盒子刷好带过去的人，不会刷固件。这很荒谬吗？

你不能因为中国人口的绝大部分人不熟悉这个、不会弄这个，就说他提这个建议是对的。但我在直播间里当时表现得兴致冲冲，至少信誓旦旦地表现出我很会做这件事，而且我把前因后果讲清楚了：我之前有个电视盒子，拿了好久一直放在家里没用，现在把它拿过来，要重新启用；而且我的直播内容历来也有这些。当然，他可以说从没看过我的直播，但那些片段的直播他可能也看过，就是我说刷固件的时候。哪怕我没有表现出我很会刷固件，请问一个宣称要刷固件的人，在多大概率上不知道刷固件时要注意固件版本？刷固件就是找到对应版本，这是个ABC，就相当于下面条就要买面条。固件本身就是以版本为首要属性，就相当于我去找个人，先要知道他是谁、他的名字。听懂了吗？

这种建议实际上代表一种很恶劣的成年人陌生人交往习惯。就相当于我已经骑上自行车，说我要骑到下面去，你却说：“你走的时候记得踩刹车，骑车时要记得用脚踩踏板，不要用脚趟着地把车往前骑，要用脚踩踏板骑车。”你要确定他需不需要，对不对？

我再绕回来：为什么你现在还不明白，我强调这里的“需要”是个情态动词？它不是需要一个助动词或be动词，后面加do need，或者is needing，或者is in need of，它不是这么一个状态。为什么？因为不用系词、be动词或助动词的原因在于：你不能因为绝大部分人需不需要、想不想，就按照这种态势来推断。你不能说“他是需要帮助的，他是需要这种帮助”，You can't say that。你只能直接说“他需要这种帮助”。你看出这里面的语义差别了吗？这个“需要”是他主动发出来的，是由他本人主动发出，而不是由你来描述、由你来判断的。这就是“需要”作为情态动词的时候：I need, I need, I'm not in need of, I need。我需要，这是我内在的一种意愿，是我自己表露出来、主动发动起来的意愿。我需要帮助，我会直接说I need help。

如果我真的需要帮助，我会表现出我需要帮助、我想要帮助，就像问：“今天要刷这个机顶盒的固件，怎么弄啊？”但我没有表现出来，我没有表现出一种意愿，我表现出来的是得意洋洋：今晚马上要下播了，我要刷固件，明天要把机顶盒带给我妈。我没有表现出这种意愿，我需要你给我提这种意见干什么？这种意见根本不能算意见，就相当于说“你要包饺子，记得买面粉”。我记性差到什么程度？一个人要包饺子，你跑来说“包饺子要买面粉”，这是侮辱性的，而且是成年人。

一个母亲对她儿子都不会说这种话。我再强调一遍，你们不明白这种交往规则背后意味着什么？它意味着没有把一个人对意见、对建议的需求，看成这个人的自主决定事项。我如果需要建议，我会主动要求；如果我真的无知、真的不知道，我也会说我一无所知。一个现代人在某方面缺乏专业帮助，而他又需要这些专业帮助来逐渐熟悉这个专业，他会表现出来，不需要你直接给他。你知道灌输论是什么时代的事情？灌输论是前现代向现代运行、自由主义现代化进展过程中需要的。但这不是灌输论不灌输论的问题，而是这个家伙在做这件事的时候，哪怕你是个灌输论者，也要反思：你要不要对这个对象进行灌输？你有没有资格对他进行灌输？所以我们现在知道为什么我一再强调：你要确定他需要不需要，他有没有做出需要的表示、做出需要的明确姿态。弄明白吗？

如果这一点弄不明白，你就急于用一些基本ABC去帮别人，那你这人生也太有意味了。你看到陌生人穿皮鞋，就说“穿皮鞋要穿袜子，否则会臭”；看到另一个人，就说“衬衫纽扣要系紧，否则会感冒”。谁不知道？谁不知道？那你就可在直播间里这样大呼小叫，一天到晚说这些事。我觉得你们要意识到，这个东西在我的体验里不是善意。人有差别，他可能觉得这是所谓的善意。那请问，如果你的善意传达到我这里，我体验到的不是善意，我又不告诉你，那我这个不告诉你、瞒着，是善是恶？而且我明确知道你这里面出了什么问题：在我这里就不是善意，这是伪善，标准的伪善，是在投射一个虚假的共同体、虚假的人际关系。

我跟这种人没有这种人际关系，我跟我现实中的朋友、家人不会有这种人际关系。我觉得这种小孩是多欠缺真实的现实人际关系，才会犯这种错误。在我看来，这明显是一种错误：因为这个人已经很明确地表明“他好像很会”，那我要不要去再说一句基本ABC？不是有问题吗？这明显有问题。就相当于你看一个美食博主——当然我不是美食博主——你看一个成年人在做一件他自己发起的、对其他人有挑战性的事，然后你告诉他：“你这件有挑战性的事里面最基本的一二三点，你会吗？”这是挑衅性的，你懂吗？

就相当于一个人摆地摊卖艺、卖武艺，电影里扮演这种角色的一般都是泼皮。有几个人跑过来问：“你会翻跟斗吗？”大部分人都不会，你会翻跟斗吗？他说：“我是林冲，我是杨志，我不仅会翻跟斗，其他我也会。”杨志、林冲落魄的时候可能没办法好声好气，但我要告诉你，不应当如此，你不应当像个泼皮一样说这种话。我不知道你们的体验怎么样，在我眼里，我很明确知道，因为我传达过哪些信息：我摆了摊，告诉大家我会翻跟斗、我会武艺，比如我会刷固件。我本来可能在给人家算命测字，然后另摆一个摊，摩拳擦掌要举东西，要胸口碎大石，我会武艺。这时候有几个人说：“你胸口碎大石的时候，要用锤子抡石板，不要用锤子抡脑袋，要用锤子抡石板。”你们大致能感觉，胸口碎大石当然……

我觉得你要刷一个软件，肯定要知道版本。这是民众平均智商都能理解的事情，根本不可能说绝大部分人不知道。现在哪个手机上没有软件天天在更新？大家都知道软件是有版本的，版本是要对应的。我觉得这个东西也太小看人了，太小看群众的智慧了。我不相信绝大部分人不知道手机操作系统是有版本的，我不相信绝大部分人不知道；最起码很大比例的人知道。像我们这种年轻人，基本上一半吧，我感觉，我不确定，大概有个感觉。再精细一些人，就知道怎么刷固件，怎么进手机安卓系统的开发者选项。但我再强调一遍，我当时表现出来的不是一个普通人请别人帮我刷固件，我明确表明是我自己要刷固件。我觉得这些小朋友在直播间里，把他头脑中理解的世界、把他虚幻以为的一种善意，当成所谓的善意建议、所谓的建议，说废话、说没有意义的话、说空话，实际上是具有基本冒犯性的话，在这里啰嗦。那我有必要给他点出来，告诉他这种废话、屁话少说，因为不是所有人都懂这个道理。

我发了条动态，里面那么多人说：“这是个什么圣人啊？”“这是个不食人间烟火的。”“这是个智商怎么怎么、情商不可兼得的怪物出现在世界上了？”各种话都来了：“这个人不会做人，这个人没朋友。”我不认为所谓的朋友就是互相宣泄这种廉价的善意，这种确实没有任何帮助的东西。不按照实际情况出发，不按照这个人明确给你呈现的状况出发，凭空觉得“我只要说了这话，就是对你好，你就得承我的情”，哪怕你口头上不表现，心里也要知道“我是把你当自己人看的”。不好意思，不是说这个世界你把他当自己人，说几句不关痛痒的屁话、所谓的建议、所谓的善意，流露那么一点点，别人就要反过来把你当自己人，别人就要承你的情，别人就要意愿你这种莫名其妙的意愿。了解吗？

我再强调一遍，还有个很诡异的家伙说什么：“未明子不是这种人，但是你做的是对的，你就要在不确定别人需不需要的时候去给他提供，不确定别人要不要的时候就要给他。”那打着这种幌子去干涉别人私人空间的事太多了。你以这种借口去干涉别人，岂不是太简单了？不确定他要不要，你就可以给他，那你这是什么？性骚扰，对吧？不就是这种逻辑吗？“不确定他要不要，但是我这对他有好处，向他证明了他是一个有魅力的人。”不就是这种逻辑吗？你不觉得这是很夸张的事？这是个很夸张的事。

我在这里要强调一点：虽然我没有扯到什么社会主义、资本主义，但我讲的是，你不要去幻想有一种普遍性的善意、普遍性的什么叫人、普遍性的什么叫情商，都要具体问题具体分析。什么“绝大部分人不会，所以他在直播间里对你说这话，或者对别人说这话，就是对的、好的”。我举个例子：绝大部分人家里没有一百天的战备储存粮，对不对？那怎么样？那你是不是就要拼命买粮食，然后挨家挨户按门牌号，几幢几零几，一零一、一零二、二零一、二零二，挨家挨户批量发到他们家去，匿名发邮件，发这种战略储备粮？你是不是也这样去做？总归是对的？人家不需要呀，你了解吗？他不需要，他要不要是由他自己的意愿决定的。你就天女散花，九天玄女下凡，普降甘霖，所有人都得承你的情？这世界不是这样的，游戏不这样玩，人生不这样过，所有事情不是这样搞的。

我觉得成年人交往规则里面，你得有这么一个起码的眼力劲。如果不会，那我今天教会你。如果你不乐意承受这样一种世道规则，那你自可以回到那种有所谓的普遍善意、普遍好意、普遍的做人情、普遍的情商的世界里面，去看看那些打着普遍性幌子、无条件加以干涉的行动是什么样子的：回老家被催婚，生活被各种干涉。你大概能知道，你回到那个世界里面去生活，咱们不是一个世界的人。好吧，那就讲到这里，我没什么多说的。

这里的很简单：我不需要，我不需要。你如果很厉害很屌，知道我当时把固件全称都已经发出来了，而且我知道那个版本，把那个版本的固件全称都发出来了。它对应其实就两个版本：4\.4\.4和4\.4\.2，没有什么多个版本要注意，他稍微去了解一下就知道了。他没有了解就普降甘霖，就是他们所谓的善意、所谓的好意，然后他就赚了，或者让我承他的情了。不是这样玩的。他就在公共互联网空间里扮演“我是个好人，我是个热心肠的人”，“我在某某主播、人文区主播的直播间里，你看我如此助人为乐”。人家不一定要你帮助。这不仅叫己所不欲勿施于人——对，其实这也是己所不欲勿施于人——你要意识到，己所欲者也勿施于人。为什么？

因为如果你所欲的东西，或者确实是你想要的东西，一百个人都过来给你，比如电影里那个美女在抽烟，一百个男的拿着打火机过来给你点火，你会乐意吗？你会乐意吗？我不希望这个世界是这种世界。因为它会打着这种幌子，很容易打着帮助你的幌子来干涉你、影响你。一个两个占便宜，破窗效应啊！等到四个、五个、六个、七个、八个、九个、二十个、三十个的时候，你再体验一下是什么感觉？

我们需要帮助的时候，希望他能够有及时反馈，这是个好社会。什么不是好社会呢？你不需要帮助，但很多人需要道德完人的自我迷恋的感觉，他会卖廉价的帮助，就是普降甘霖，到公共空间里去散发这种廉价的帮助、廉价的关怀。这不代表这个社会更有道德，或者更有人情味，反而代表这个社会有点问题。

为什么这些人的生存需要这种东西作为一个基本调味品，作为他在公共空间里扮演某种角色的基本模式？是什么引起了这样一种对别人是否意愿你帮助的意愿的忽视？我觉得，就相当于你这个人得了癌症，跑到药店里，里面全是感冒药：“你生病了来吃感冒药，你生病了来吃抗生素，对你有好处，你生病了来吃蛋白粉。”不，他得的是癌症，或者他得的是另一种没那么严重的病，他不需要这些帮助。他意不意愿这些帮助？要不要这些帮助？等他需要了，明确告诉大家他要哪一种帮助的时候，你再去尝试。如果他不知道，你就尝试问：“你要这个吗？还是那个？”你尝试去试错。了解吗？

不要默认所有人都有求于你。他都明确表明他不是有求于你，你还故意表明“我有恩于他，我对他有德”，这也太奇怪了！哎，我把这直播间环境弄得像一个互相帮助、其乐融融的环境，这也太奇怪了！我不需要，因为这东西在掩盖——掩盖这个现实好像不是这个样子的。你在我直播间里玩普降甘霖，耍那么一点小恩小惠，这算什么？我觉得这是有问题的。

这是刻意把一个直播间乌托邦化，刻意把粉丝、把观看者和被观看者的关系庸俗地、廉价地人情化。这些东西都是赵高给秦始皇上奏书、报喜不报忧的那种东西，你懂吗？现实不是这样的，而且现实当中绝大部分人不会是这样的。我举个例子：一个老年人不会用智能手机，他过来问路，问路之后……

请问，你难道要教他？比如他问你医院怎么走，你直接告诉他怎么走就行了，他要的就是这个。但你又要额外一劳永逸地帮他解决这个问题：“你安装一个叫百度地图或高德地图的软件，以后要看就点开这个。”然后发现他用的不是智能机，是老年机。“老人机没事，我把老人机带回去给你刷个机，给你装一个固件版本，里面自带百度地图。”他不是这种人吗？

你为什么要给别人他不需要的帮助？我可能是因为能力强，不需要这种帮助；也有一些人是因为能力弱、现实条件不允许，不需要这种帮助。所以这种事情在我看来就是“何不食肉糜”的反面，那叫什么？“何不喝粥糠？何不咽粥糠？”吃糠咽菜嘛，对不对？他说：“何不喝米粥？你肚子饿了，吃点饭，吃点米饭就行了。”不，人家是准备做一顿饺子，吃饱了美滋滋的。你说：“肚子饿了就吃饭，吃大馒头啊？”那我一顿吃二十个大馒头？我刷固件，版本弄对了我就装好了。你看，弄明白版本刷固件多好。

我再强调，不要老是这样。为什么老是有这种人？老是喜欢在虚幻空间里弄点这玩意儿，满足他自我理想化的形象。多看现实吧，虚幻空间里也有现实的规则。什么是现实的规则？我明确告诉过你，我又不是没说。他那话一说，我立刻就在直播间里说了：“我明确会的东西，你还教我，这算什么事儿呢？”这事儿是很失败的一件事。这不仅说明你很失败，说这话的人很失败，我这么一个经营直播间的人也很失败。我这个直播间里的氛围、弹幕氛围，我没带好，我很失败。实事求是的精神，我没有传达下去；我没有让我的粉丝、观众意识到，我天天在讲实事求是的东西，这家伙还是这种状态，那我有什么办法呢？
