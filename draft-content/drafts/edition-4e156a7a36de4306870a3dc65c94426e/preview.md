# 【主义主义】Financial Capitalism（3\-3\-3\-4）——不学就会的无意识哲学，永不终止的生存论危机，现代原子化主体的永恒偏斜

我今天要讲主义主义的三杠三杠三杠四，它的代表人物是人类历史上的金融资本家，也就是 financial capitalism。financial capitalism 的精神结构是一种崩坏的精神结构。它可以被看作一种哲学信仰，也可以被看作布尔乔亚的人生信条，是他们的超人形态，即他们所领会的尼采主义超人形态。据他们说，这个东西可以治疗他们的生存论危机；更准确地说，不是治疗，而是解决他们的生存论危机。解决生存论危机，就是成为金融资本家，成为 T 同志所说的“食利”，或者叫寄生。实际上他们是寄生性的 proletariat，是寄生性的 proletarians。这些人已经脱离生产，脱产专司金融投机，也就是 financial speculation。这个东西可以理解成思辨哲学。就像尼采晚年喜欢思辨哲学一样，这些人追求的人生终极样态也是陷入金融思辨。金融思辨是一个词，投机和思辨是一个词。

投机和思辨，也就是说，金融投机在本质上与后本体论思辨是同一种活动。看金融投机，就是赌一赌，看一看本体论到底是个什么结构、到底怎样，用什么来看？用钱投进去，用他的金融筹码投进去，投石问路，投进去看，旁敲侧击，猜一猜，投一投，赌一赌。这和思辨哲学的精神是一样的，特别是转向存在论、转向生存论的思辨哲学。这个视角切一下，投入一点我的生命张力进去；那个视角切一下，投入我的生命张力进去看看，它的本体论结构是怎么样的。

所以在这个意义上讲，financial capitalism 是一种哲学，而且是一种观念论哲学，是一种大的观念论哲学下面的生存论哲学，而且是一种尼采主义的同一生存论哲学。它最终预示的是绝对者和主体的同一。也就是要成为蚯蚓，或者说成为超人。我们来看它的格就行了。

但是你要意识到，辩证法起作用的地方在于：所有 capitalist 词里面有一种 capitalist 词，它成为一种我们叫做骑士、侠士的东西。它不是生产，脱离所有生产，脱离工业、服务业等，脱离生产，仅进行一种游戏。他们的生存就是打游戏，玩金融投机游戏就是打游戏，是击鼓传花类的游戏。所以它是一个寄生性的 proletariat。所以它是一个谢林点，是 capitalist 词里面的谢林点，也就是同一点：在这一点上主客体同一。这是一方面；另一方面，它又是它的构成性例外。或者说，这个东西和外面的那个流氓 proletariat 在本质上是相等的，本质上它们是一种东西，they are the same thing。他没赌赢，他赌赢了；从概率学上看，他没赌赢，他赌赢了。他们是一种东西，他们的本质都叫做寄生性的 proletarians，他们的异形态色彩是 extreme right，极度依赖于一个符号系统。

我们来看它的场域论。左边是产业资本、产业经济，这里面是有秩序的，就是传统布尔乔亚。右边是金融资本，以及布尔乔亚的 domination。也就是说，这边是有秩序的、有先验秩序的，有体系化、分类学、等级制的秩序，有那种比较庞杂的有机秩序；而另外一边是金融资本。这种金融资本会不断给自己多阶化、高阶化，不断给自己升阶、升阶次，进行一种看上去越来越复杂、其实是不停纯化的过程，本质上就是使自己变成一个投机游戏：赌大小，越简单越好，赌大小，越简单越好。它会不停给自己升阶、升阶次，但这个升阶次实际上是给它降阶次，把它降到一个纯化成赌大小的投机游戏：赌快慢、赌大小，就是博弈论，基础博弈论。那么这两者之间调和的场域，在 financial capitalists 那边，调和的场域是什么？

生存论危机。也就是说，他们永远陷入在生存论危机中；这种生存论危机使得它觉得自己是一个可以不受一切制约的蚯蚓。但是这种超人的、不受一切制约的状态，一定要找一个定在，它一定会陷在这个场域里面。同时，它在精神上完全是认同这个场域，在身体上完全是放纵在这个场域里面，各种享乐，这是它的身体享乐；而它真正的精神享乐、它的冒险精神，是享乐几千万、几个亿，不停地去玩这个游戏。调和这种身体享乐和精神享乐的，就是它的生存论危机。它始终是灵肉二分点，永远是灵肉二分的。你们可以去看看丁蟹，代表人物都可以说丁蟹、华尔街之狼。

我再强调，这种哲学，我甚至可以说它是唯一一种无意识的哲学，人类史上唯一一种无意识哲学。它在目的论上是四，所以可以看成是人类主体性的倒转，是人类主体性的倒转，是绝对的无头主体性倒转。无头主体应该是四三三三，人类主体，它是绝对的倒转，是主体性的一种绝对畸态、绝对变态的状态。financial capitalists 在本体论上，由于它完全陷入金融资本，精神上完全陷入金融资本的投机活动，所以它的本体论上只有符号。它的本体论是完全本体论化的，没有本体性的剩余，完全本体论化、彻底本体论化，也就只有符号性的东西。

本体论左边是钱。这个钱可以用来操纵产业资本。这个钱就是通用的交换符号，通用资源交换配置符，就这么简单，是资源配置的一个符号。这个钱实际上是由金融资本的投机活动、增值活动、冒险活动，来促使布尔乔亚政权进行铸币活动。右边则是罪。罪就是普遍的金融资本投机：它要玩赢，不可能只使用金融资本交易市场的内在规则，一定会用盘外招。所以在这个意义上讲，一方面可以说金融资本有原罪，它不停地自己生自己，掠夺整个社会财富；另一方面，它一定会用盘外招，比如内幕消息、非法交易等等。它可能今天是控制十几个行业的大鳄，明天因为一瞬间交易错误或别的什么，就变成阶下囚，或者像丁蟹一样跳下去。那么调和这两者的是什么？是他们对于权力的欲求，更确切地说，是对于布尔乔亚 regime 的权力、political rights 的欲求，是由这个来调和的。

所以在这个意义上讲，他们都是极端的支配型人格。这些家伙都想使他的游戏、他的金融符号游戏可以主宰一切。这就是他的目的，但他又不可能得到真正的权力，为什么呢？因为他受不了任何符号化。他的本体论虽然已经完全本体论化、符号化了，但由于他处在生存论危机中，这个生存论危机导致他的头脑在目的论上不可能符号化、无法符号化。所以他天生就是骑士阶层，天生是一个寄生性的 proletariat，因此他没有办法驾驭资本主义的国家机器，他驾驭不了。

认识论上，左边是享乐，右边是理性，绝对的理性。这两侧，这个世界由于他拉满了，这些都是充钱玩家——不叫充钱玩家，就是运气好，欧皇。就是在这个体系里面，产业资本那边为他提供享乐，或者说他从产业资本拿到钱，再通过这些钱得到充盈享乐、过剩享乐。另一方面，他是金融资本，金融资本要投机赢，他要用盘外招；或者他不用盘外招，他本身带原罪，这个原罪就意味着他一定会陷入这种冰冷的理性、冰冷的秩序性理性当中。但是这种冰冷的秩序性理性由于是一元化的，所以他没有办法有序符号化。我刚刚没有说完整：他没办法驾驭权力的原因，不是因为他不够符号化，而是因为他太符号化、过剩符号化。也就是说，他没有办法形成一个井然有序的等级制，而是一个超频了的、冒烟儿的高速循环的加引号理性。实际上不是理性，实际上是疯狂，是高速循环的疯狂。

那么由什么来调和呢？痛苦。这家伙基本上都是自虐性的痛苦，是压抑的、很压抑的。这种痛苦会使他始终处在生存危机里面。为什么他能够调和这两者？因为这种痛苦就是他的享乐，这就是金融布尔乔亚独一份的享乐。产业资本为他们提供美女、好吃的东西、漂亮房子、车，这些东西都不能让他享乐；他家里面什么都有，儿子结婚送一套别墅，这些东西都不够了。在这个意义上讲，他实现了尼采所设想的那种超人。尼采晚年也有这种把痛苦当成快乐去享受、去压抑的做法，也会有痛苦让他爽，也就是自虐和受虐机制。这个就实现了所谓的完成了的完全中介性。但是这个结构不仅仅在金融布尔乔亚身上会有，在行动者身上也会有：痛苦会是一种享乐。但是我们要看到目的论，有没有目的论？

这个 log 是没有目的论的，四没有目的论。这个四的目的论这边，是辩证统一，是抗争，辩证统一。然后这里是一种厌恶，就是否定虚无、鄙夷虚无；在尼采那边则是一个多重化。你知道这里面其实是什么机制呢？这个四，你们知道最后是什么吗？是偏斜，四是偏斜。也就是说，这个同一生存论的目的论机制，实际上就是原子论机制。

它的四个环节的发生学过程，在目的论上的四个环节，实际上就是一个原子论机制：辩证统一。每一个原子和它的位置、和它的运动自我统一；这个原子既是又不是它自己，它是运动的，否定虚无，能够占据空间；多重化原子是复数个，最后偏斜。最后这个偏斜是伊壁鸠鲁主义。马克思在青年时代的博士论文里面也写着原子的偏斜。领会到这一点很重要，这是现代性的基本，我们把它叫做原子主体性，不是没有原因的。原子化的主体性，最后一个四字头的基本运动就是偏斜，它会不停地偏斜。通过偏斜，使得它不能够形成概率论上的闭合，不会有一个稳固的概率论。也就是说，这个体系、这个自循环体系，这个金融资本投机的自循环体系，会不停地偏斜。这个偏斜实际上就是主体的任意性。你可以理解成最近放的《扫黑风暴》里面的孙兴，那家伙就体现出一种偏斜。那个犯罪团伙总是要求他怎么做，他偏不那样做，他就要偏斜，因为他处在生存危机里面，他就要偏斜。这种偏斜是他享乐的特定方式。他需要这种偏斜为他提供痛苦，支撑他的享乐，让他感受到那种完成了的完全中介性。不偏斜，他不能够拥有一个他自己的本体论根据；不偏斜，他没有意志性根据了。他必须不停地偏斜，才有意志性的根据。

这个偏斜运动这种形式特征、形式特点，很虚的一个形式特点，这个偏斜运动反而成为了它的根据性的、实质性的一个支撑。它可以把自己伪装成是不一样的，伪装成是自己，伪装成是意志性的，伪装成是超越的，伪装成是超人，尼采意义上的超人。尼采意义上的超人只有一种方式可以成为，这种方式就是 financial capitalism / capitalist。阴阳怪气地说一下，因为我很戏谑这个东西，他们看不起这个东西，但这是绝大部分小布尔乔亚意识形态最高点的那种哲学状态：“我什么时候可以学哲学了？当我成为一个 financial capitalist 时，我可以光玩游戏，一天到晚在手机上拨弄数字，我就可以捞到钱生存。”我这时候就可以学哲学，因为我那个时候的冒险状态、直面必然性、直面虚无的状态，就一样了。我的哲学不也是陷入这种状态吗？特别是尼采哲学：超人、超人的强力意志让我重估一切价值。重估一切价值，不就是在一个价值定价体系的最高层、最高层级，也就是在这个金融交易系统里面，去操弄整个市场的价值体系。

但是归根结底，它是同质化的，归根结底只有一种均质符号在里面运行。它里面的什么罪、权利，都是这个均质符号甩出来的假东西，甩出来的自我内在矛盾。它真正的自我内在矛盾、真正的内在对抗性，其实被它压抑了。这个东西就是它对人的压抑。真正的对抗性被压抑了，但压抑之后它会偏斜，它会不停地偏斜。真正被压抑的是无产者，但无产者会偏斜，它会被压抑在这个符号系统之外。这个东西是人，可以看成是一个蛮大的 boss，它是一个大 boss，蛮大的 boss。

但是这个东西还没有获得 global 属性。在这个意义上讲，它的矛盾还是仅限于一个 nation state 的 regime 体系里面，也就是政治权力体系里面，还在里面玩。它的一二三都是中心化的，依凭一个产业资本，或者说一个民族国家——一个井然有序的资本主义民族国家——的井然有序的生产再生产机制，为它提供这些享乐。它这些享乐不是真的吃这些东西，而是要通过吃这些东西来获得否定性，否定这些东西，获得一种“理性不过如此”。多少万、几百万的别墅，不过如此，不过如此。它要不停地获得这种否定性，然后偏斜，从大众价值观偏斜。它也要不停地引导所有大众都羡慕这个、喜欢这个，然后它才有偏斜；要让大众的价值观受它所鄙夷的价值观的主宰，然后它再去偏斜，再去鄙视这些庸俗。

这个东西骨子里是一种无意识的哲学。这种无意识的哲学不是人在思考，而是物质世界在思考；这个东西不是由人思考的，归根结底是由世界在思考，而且是世界当中的那种非人化的意志性力量、非人化的异化力量、非人性的异化力量的哲学。这个非人化的异化力量就是三杠三杠三，它把自己结构起来，就是世界的自结构；这个世界不需要人的自我结构。这个哲学出现，意味着世界具有自中介性，货币体系具有自中介性，人只不过完全是它的傀儡。你不能做它的掌舵手，而是它来掌你的舵。它的自中介性就是可以完全超掉、扬弃掉你这个主体性的抉择和决策，扬弃掉你生存论里面的抉择和决策，因为在认识论上也闭合了，就是这个三。这个闭合会导致很糟糕的结果，是认识论上的这种闭合。但它们都是危险的闭合。三字头的闭合和一字头的闭合不一样，三字头的闭合都是危险的闭合，它不稳固，不会稳固，因为它都要有主体性来中介，都要由主体来感受到它的威能、它的全能。这种威能和全能必须在生活当中，它可以支配别人——比如支配一个信邮差给它，在古代是这样，或者在现代，他偏要这个邮差跑几十公里——他一定要在别人的支配当中感受到这个，才能维持这个回环；他一定要感受到某种自虐性的痛苦，才能维持这个回环。这种自虐性痛苦还代表他神圣，这基本上都会表现为“信道错”，在认识论上会注定如此。这种哲学是一个具有哲学形态的意识形态，这是三字头意识形态唯一的一个，也不能算唯一的一个吧。反正太野了，我只能说就讲到这里。可以说是唯一的一个三字头意识形态了，那就讲到这里。
