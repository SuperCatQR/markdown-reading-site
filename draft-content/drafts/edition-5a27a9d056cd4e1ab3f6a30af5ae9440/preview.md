# 【主义主义】主体间普遍主义（3\-1\-3\-1）——哈贝马斯的去先验化路径

今天我们来讲这个主义。三杠一杠三杠一，代表人物是哈贝马斯。他这个主义叫……它是一种普遍主义，但是是一种 intersubjective universalism，即主体间的普遍主义。

哈贝马斯的哲学也借鉴了胡塞尔，而且他的理论精神与胡塞尔相当一致：都追求某种普遍性，即公共话语的普遍性。但他用的方法不太是现象学的方法，主要是米德、塞尔，还有理查德·罗蒂，以及《认识与兴趣》《后形而上学思想》等。我研究生时期写过一篇论文，发在我的知乎里，研究他的生活世界概念。他也是去先验化的，用主体间性进行去先验化，所以我把他放在三杠一杠三里面。

他的整体理论旨趣，可以看成是想建构一个修补性的方案，修补现代性下激烈冲突的不同话语范式。他认为这是话语范式的问题，没有意识到背后有一个背景性的终极矛盾。那么哈贝马斯是如何使用生活世界概念的呢？

生活世界这个概念，life world，或者叫 Lebenswelt。他用它来突破先验幻象，方法也差不多，和许茨的方法差不多。

他不认为先验主体性是认识的起点；先验主体性不是认识的起点，那肯定是主体间性是认识的起点。主体间性一开始并不是一种内在的东西。它有两个特征：一是人称化，二是视域被结构起来。另外，视域具有交换性，可以交织。视域不是从一个点出发敞开的；你要具有一个视域，它必须具有可置换性，这是无条件的。没有这种可置换性，就不会有主体化的机制，也不会有人称化的机制。这种可置换性可以简单说就是弗洛伊德所说的幻想化三阶段。

比如，我看到一个孩子在被打，看见一个孩子在被打，这是被打的终极幻想。实际上，它实现了一种 introjection，或者说一种注入：能够把自己的形象注入到一个情境里面。一个小朋友看到一幅画面，在他很小的时候，看到一个创伤性的东西。比如一个小朋友看见另一个小朋友被一个大人在打，他会看到这个画面当中的裂痕、创伤裂痕。这个裂痕本身没有办法被客体化，他没有办法仅仅把这个当成一个画面来看待。那这种情况怎么办？这种创伤怎么办？因为这种创伤实际上就是激起他的主体性；主体性就是：这太痛苦了，里面的孩子被打得尖叫或者怎么样。那么孩子不会把它推开，儿童会把它当成一个……这个画面本身会二重化：一方面作为一个外在的画面，他看见一个孩子 sees someone beaten；另一方面会内在化。这个画面本身没有任何变化，只是其中的裂缝激起的主体性，或者这个裂缝本身就是主体性。就是说，孩子在这个画面里面看到某种断裂性的、某种他不能理解的、不能领会的一种爱欲的僵局：这个成年人在反复地打这个孩子，或者说这个孩子在反复地哭泣或者怎么样。他会被这个循环的爱欲俘获，然后他会把这个画面内在化，他就会觉得这画面不仅仅是一个外部的画面，这个画面是他自己的内在视域，this image 就变成他的内在视域。他会把这个被打的孩子看成是他自己，seeing himself beaten；他把看到外面另外的孩子在被打，想象成看见他自己在被打，但是是同一幅画面，the same image。

这个原初画面是被压抑的。什么叫原初画面被压抑？这个外在画面本身不再能够被把握到、被领会到，因为你的主体性置入并接管了：这不是现实画面，这是我的爱欲结构，是我自我把握、自我人称化的一个基础。所以这种视域的可置换性——这个小朋友，真正那个小朋友，他是个他者吗？真正被打的那个小孩不是我呀。这个小朋友会幻想，他也会幻想这个成年人在打他的时候，他自己被他者怎么看。然后，本来真正是自我的旁观者反而变成他者，他反而把自己带入到这个本来被旁观的小朋友的第一人称视域里面去了。所以这叫作视域的可置换性。但视域的可置换性和人称化其实也是紧密相关的。

当然，视域的结构可以通过一些现象学的方法去把握。所有这些主体间性的东西都需要通过话语。你光有体验是没用的，你要把握到其中的裂隙，这个裂隙能够以主体化的方式转起来，然后把孩子的第一人称视域注入到这个画面当中——实际上就是使得这个画面本身变成一个主体性的视域。这叫内向化，或者叫 introjection，而不仅仅是一个我记不清的德文术语；我不知道那个德文术语叫什么，不想去查书了。这种裂隙的出现不是……这个孩子如果是猴子或者猩猩、高级灵长类就行了？不行，孩子一定要掌握语言。他一定要有语言的裂缝，否则他看这个画面是看不到裂缝的。也就是说，符号系统要优先来组织这个画面。这个画面不是原初画面，这个画面一开始就已经被符号系统所组织了。然后这里面又有裂缝：符号系统自己组织画面的过程当中有裂缝，裂缝自己把自己主体化，主体化的机制自己投射出一个自我作为主体，它实际上是原初他者的一个想象性的自我。

这个过程一定需要话语，或者用语用学、语用学的实践。discourse，或者说——这是学派问题：discourse 一般是法国人会用；语用学实践则是西方或盎格鲁\-撒克逊的 pragmatic 实用主义、语用主义那些人会用。父母一定要跟小孩说话，小孩会说话，一定要到两三岁讲话了，会咿呀学语，他有那个 language 机制。让他把握到里面的这些……这个时候没有主体，严格的主体还没有产生。

因为主体间性是这样一种前反思的原初机制，所以主体间性是先于主体性的。我们上一讲可能还没有比较细致地讲这个机制；它的方式都差不多，都有这么一个幻想化机制。但哈贝马斯本人在《后形而上学思想》这本书里没有特别用弗洛伊德精神分析的方法，也没有用内省分析的方式；他主要用的是语用学，还有一个人称化的机制。这本书我已经很久没看了，多少年前的了，已经四五年前、五六年前了。那个时候我在华东师大读硕士——哦，我在上海社科院读硕士，然后华师大是那边在借读，因为第一年研究院宿舍不够，就住在华师大。后来选了华师大老师的课，那个老师是个西马老师，为我们介绍西方马克思主义的很多大人物。最后我选了哈贝马斯，结合自己比较熟悉的现象学写了这篇文章。现在回过头去看这篇文章，学术上肯定有很多硬伤，我承认。

那么，从这种主体间性是可以产生主体性，没错；但你的先验反思姿态又是怎么产生的？很简单，就是因为掉链子。先验反思之所以会出现，或者说在生活世界当中能够产生一种先验现象学姿态，原因在于生活世界一向有一种新的旨趣、一种新的哲学旨趣，哲学 interest 产生了。这种先验反思的兴趣产生的原因，甚至可以说是其他范式都出问题了，整体性地出问题了。你所熟悉的那个模式、分类学或语用学模式出问题了。所以在哈贝马斯看来，胡塞尔这种思想产生有其时代原因，非常重要的时代原因，意味着知识旨趣本身出现了内在的不一致性。当然，哈贝马斯应该没有特别……他喜欢选择回到康德，back to Kant，甚至说回到某些人——我这个文章也会讨论；他比较喜欢嘲讽海德格尔，也喜欢嘲讽康德。胡塞尔在他看来，是因为先验哲学太过于主体主义、主观主义。哈贝马斯不会止步于他的理论域。也就是说，你要进入先验反思，原因在于整体的 problematic，problematicizable：你把那些普通人 take for granted 的东西，在你的私人话语或公共话语的交锋当中出现了重大问题，发现它们都是可问题化的时候，你才能进入先验反思的阶段。你说你要进入三字头的话，你没有发现这些东西有问题，那你是进入不了三字头的。你强行把它们说成是有问题，靠一些问题引出你这种问题意识，是做不到的。一定要你的话语实践、你的语用学实践本身察觉到一些不一致性，这很重要，很重要。

你察觉到之后，就会发现，原来先验反思当中的那种透明性，用哈贝马斯自己的话，会立刻变成杂芜的草丛，变得非常成问题，像灌木丛一样。你在专题化把握了这种内在视域之后，它并不会凭空给你一些现成的知识。你要靠一种先验现象学姿态直接成为胡塞尔，拥有胡塞尔那些问题域、问题意识或那种判明的能力，是做不到的。胡塞尔在这里就相当于说：我行，所以所有人都可以做梦了。先验主体间性，或者说一种先验现象学家的姿态，不是白嫖，不能白嫖。因为你之所以能够通过先验直观去把握或把一些东西悬置起来，我早就讲过了，是因为你在你的语用学实践当中不停地把这些东西问题化，觉得这些东西是可问的；系统地可问了之后，就会把它专题化。专题化之后，在杂芜的草丛当中能够看到一条现成路径的是少数人，是专门经过一些反思实践的人才能把握的。除非你在具体困境中遭遇问题，除非你像胡塞尔一样作为一个逻辑学家、数学家，或者作为一个心理实证科学的热情研究者投入其中，发现其中有各式各样的问题，否则你不能白嫖一种先验还原的现成性，you can't get that，是不可能的。

生活背景当中的知识，其结构方式通通都是语境主义的，基本上是语境主义。你们如果想要详细了解，可以去看我那篇文章。那篇文章我写了好多年，我自己也没有办法很熟练地再把它重新启用起来。我觉得那篇文章其实也挺天真的。

场域论上，有形而下的世界和形而上的世界。形而下的世界代表一些非专题化的、没有知识性、没有认知性的东西，不是专门专题化认识那种旨趣、那种 interest。比如，有些审美可能只需要一种权力旨趣，通通取决于特定的旨趣。生活当中大部分情况，我们对于事物的把握方式也会有一些好奇，但那种东西不能说是纯粹的知识旨趣，不能说是专题化的知识旨趣。也不是孩子喜欢说哪个奥特曼厉害、哪个奥特曼不行、哪个怪兽团灭了哪些奥特曼——这些也可以看成一种认知性旨趣，但它不是知识旨趣。形而上的维度则是由特定的、专题化的知识旨趣所结构出来的一个维度。

这些维度某种意义上讲，你必须依赖这种东西来结构一个普遍主义的维度，也就是一个普遍的话语空间。形而上的维度……我觉得哈贝马斯归根结底还是偏实在论的，因为他拒斥先验还原的路径。

在形而上的维度，他会专题化，或者说专家所领会、把握的那些维度更具有有效性、更具有可靠性。比如实证科学，乃至于哲学活动本身——现象学、哲学、语言哲学这些活动本身——可以看成是知识建制的这一侧。另一边则是日常语用学实践的这一侧，日常话语的生活世界这一侧。调和这两者的是公共理性，public reason，或者说是一种公共话语空间。它是一种客观中立的，但它的客观性不是超验意义上的客观性，而是主体间的一种客观性。

主体间这个维度的生成，也是因为它是调和性的。问题性的调整要靠右边，发生学的机制靠左边；或者说发生学的机制某种意义上也靠问题化，因为这里面有辩证法，一定意义上是有辩证法的。客观中立的话语空间，就成为一个共同体承认的来源，共同体之间相互认同、承认的来源。公共话语的维系靠右边，靠形而上这边，靠哲学家，靠知识分子。它需要知识分子站出来，需要哲学家站出来，由哲学家来诊断、判断公共理性、公共话语的客观中立这个话语空间有没有受到歪曲、有没有遭受威胁，出现问题怎么去修复。

哲学能够把握生活世界，把握生活世界的一般结构。那么如何去把握生活世界的一般结构呢？作为一个古典、经典的做法，它其实还是要借助一些先验的方法、现象学的方法。当然，哲学把握生活世界一般结构，你得用本质还原的方法，也得一起用一些辩证法：只要能用得上、能够有用，在一定的知识旨趣、一定的理论范式、一定的问题范式之下能够起到效果。所以在这个意义上讲，哈贝马斯虽然结构了这个场，但他的方法本身是一种实用主义方法，因为他受米德和罗蒂的影响还是蛮大。本体论上是一。

本体论上是一，是连续的。也就是说，他们在本体论上的姿态是：所谓本体性，就是不同的知识、不同的认识旨趣——interest，甚至可以说是利益——可以搞出不同的本体论，但这些不同的认识旨趣本身可以得到一个连续的社会学研究，连续的社会学分析，甚至是一种解构。米德可以算是结构主义的。但是这种连续的社会学分析、连续的社会学解构本身，最终是要维系一个共同价值、最低限度的共同价值、最低限度的公共话语。还是这样的：我们这个主体间的、客观的话语空间本身具有客观性、有效性，是最大的本体论。当然，每一种我们叫本体世界统握、世界统筹的方式本身都是一种本体论；他对海德格尔的吸收也在于，他觉得本体论可以有一系列历史性的变迁，但它们都出于不同的旨趣，然后这些东西可以串成一个连续的序列，在公共话语当中得到安顿，被哲学进行把握。它没有高低贵贱之分，但有的东西是极端的，要被排除掉，因为它会危害公共话语：它过于强调私人性，过于强调超越性，或者它短路——把它所设立的一个本体论意义上的维度直接短路到现实历史，认为它就得这样运行，然后欲求一种强力、欲求一种暴力，那它就不行。所以在这个意义上讲，这种连续性背后是一种自由主义姿态。这种自由主义姿态不至于堕入一种相对主义，它不会像许茨那样。

他不会像许茨那样。本体论上是连续的，也就是说，他这种自由主义是一种有点折中的自由主义：自由而不独立。他不认为每一种意志性都有能力架设自己的公共场域；他得有一个公共场域，然后通过一定的审查。所以你才能理解，哈贝马斯的哲学为什么能够成为欧盟的一个官方哲学。某种意义上，它代表德国那一侧的金融资产阶级、商业资产阶级、文化资产阶级的利益，而德国最强的主要是工业资产阶级。他的理论，《认识与兴趣》——有的翻译成《认识与旨趣》——这本书基本上可以看成是德国共同体内部主要力量的一个协约。

它里面主要分哪些旨趣？哪些认识旨趣？哪些兴趣？哪些生活话语背后的一些驱动性力量？所以看上去这个东西有点……但我认为，它的边边角角是用辩证法来围、来圆的。它主要的方法其实还是胡塞尔或康德那种先验哲学的方法，在方法论上还是那种；然后认识论上是三。

认识论上的三，我老是记不得是哪两个东西在对立。左边应该是非反思的、前反思的、情感性的；右边则是反思性的、认识性的认识，就是专题化认识。在认识上调和两者的，还是公共话语。也就是说，我们要把握这两个东西，得有一些语用库：我得怎么来说它们？以哪种方式去说？哪种实践是合法的、有价值的、会被别人承认的？所以无论是前反思的情感，还是反思性的专题化认识，都需要公共话语来调和。

也就是说，我们所有的认识都是一种社会化认识。不存在某种绝对的、纯粹的、内在的、私人的、先验的原子化主体的认识。这个东西也不是完全内在性的，它们都要通过主体化的、主体间的机制，同时就是一个交互主体化的机制。它是交互主体化，也就是主体间性化，intersubjectivization，交互主体化的机制。只有这样，你才能把什么东西把握成反思，反思就是这种问题化的意识、问题性的意识；你才能把什么东西叫作前反思。前反思 take for granted，why？为什么你会 take for granted？为什么你会觉得这样去描述、这样说、这样用一种语用学机制是合法的？It's all because 因为有公共话语，有社会化的认识，有承认，有一种话语的规范性，discursive regularity。我们最后来说目的论上，目的论上是一。

公共理性——他要追求一种公共理性，也就是说，他最终也是亲建制的。它是维护性的、修复性的，维护公共理性，维护某种意义上主流话语建制。但他希望这个主流话语建制本身有最小的本体论假设，甚至说不设立本体论假设，只设立否定性的本体论假设；除非那个本体论假设本身是那种比较极端的、冲突性的本体论假设。在目的论上就是一。

最后一点，他维持公共理性，或者说维持这个社会化的公共话语空间，怎么做到？就是不停地解先验化，或者不停去先验化，把去先验化本身当成一种实践方式。在这一点上，你可以看到这里和胡塞尔的悬置是一种吊诡的东西。就是社会学家，或者说那种社会学的哲学家——哈贝马斯认为他的同道中人有一种义务：要使知识体系、知识本身的生产和知识规范的设立，不再依赖于某种先验的自我同一，费希特式的、胡塞尔式的，乃至于海德格尔那种总体化的、历史性的、目的论性的东西。他把它进行去先验化，不停去先验化。作为一种实践，通过一种哲学家的社会学实践，他就能够维护这个公共理性、公共话语空间的一种——你可以说是健康状况。通过实践，这被看成是他们这些人的一种实践：新古典主义者、新的理性主义者、新的自由主义者。他这种意义上的普遍自由主义，就是去先验化，通过把所有的理论进行社会化、社会学化的把握，把它们消解、还原。所以在这个意义上，我说它既不是一种先验还原，也不是一种本质还原，而是一种社会学还原，社会化的还原，社会还原。

但这个社会还原本身不具有先验性，它本身不是一个……它是一种实践，是一种论战，或者说是你可以说的一种高级版的“说别人屁股歪”。高级版地说：你胡塞尔屁股歪，其实你代表德国大工业资产阶级、军事工业共同体的某种统摄性、总体主义（totalitarianism）的东西，类似的这种方法。我觉得这是某种泛社会学化。但它的方法旨趣上和现象学还是一脉相承的，它的整个结构我认为也具有一定的辩证性。

它的理路，你读它的整个思考过程，比如看它那本《后形而上学思想》——那本书又叫啥？我又忘了——《后形而上学思想》那本书，你们可以去看一看，是有点意思的。它对于如何从语义分析转向语言学、语用学，如何从先验哲学转向一种实用主义或者转向一种社会学的路径，可以在这里面好好去……这个东西可以看成是一个 ABC，基本的 ABC。但是这也是一种想要超越这个的尝试，它在哲学上是失败的，这个体系在哲学上是失败的，不可能的。因为你不可能建构；一个主体都没办法建构起所谓的公共话语空间，一堆主体也是没办法。所谓公共话语客观中立、主体间意义上的客观中立，这东西本身也是一种意识形态幻觉。但是它有它的功能，它有它的实际意义，它也是现在欧盟非常占主导的一种思想观念。

那么我们就需要严肃对待它。哈贝马斯将来会是我们的一个主要论敌，所以加一。国内译本是比较糟糕的，有点问题，你可以去看英文版。今天就讲到这里。
