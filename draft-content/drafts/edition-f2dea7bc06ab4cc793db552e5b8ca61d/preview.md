# 【哲学与现实】人在少年，感觉时间过得慢，人到中年，感觉时间过得快，这是怎么一回事？

人到三十岁，感觉时间过得快，时间过得很快。

如果你想知道最根本的原因，请在我的投稿里搜“时间”，你会搜到一系列关于时间是什么、为什么会有时间之类的内容，你去看。如果你不想对哲学有什么深刻的了解，那就听我胡扯。

人到三十岁觉得时间过得很快，主要原因是你的时间用来做事情的时候，做事往往是按部就班的；要么就是按部就班，要么就是摸不到头脑。按部就班地做事情，时间过得很快。

我可能写“小自然哲学”“小布尔乔亚”那个“布”写得太顺手了，念语音时念了出来。我举个例子让你理解：比如你开车，开车等红灯。

这个红灯，如果你是直愣愣地在这儿等，没事可做地等，就感觉这红灯好长、好漫长。因为你在等红灯的时候，就是数数、数秒数，或者数那个数字，看它颜色，或者观察周围的情况。但你等红灯的时候，如果掏出个手机，打开，比如我是 B 站 UP 主，打开 B 站去看我的消息；就是你打开手机，打开一个 APP，然后按部就班地去做一件事情，你发现这个红灯——你刚开过去，你要直行嘛，它是左转绿灯，它是一整个红灯——可能就两分钟，这两分钟一瞬间就没了。

一瞬间就没了，因为成年人特别会进行一种行为，我们把它叫做一种工具化的、流水式的沉浸，是很快的、流水性的那种沉浸。这件事对你来说就是见缝插针。

插在这里面，但它又展开了。这个展开的环节，比如你打开 APP，APP 那个页面几秒钟，里面那些工具性的、预备性的环节，就等于说是没有时间体验的；预备性环节对个体来说就是无时间体验的。

你回忆一下自己做这件事：等红灯时看手机，看到一个留言或一个微信，微信打开的过程、翻 APP 的过程，这些过程都是零，它的时间残余是零。你的时间体验对它完全没有灌注焦点，它完全是工具化的、完全浅薄的，直接给你那一点点片段的关键信息。

你可能等一个两分钟的红灯，就看到谁谁谁发来的一条消息，那一条里面也就几句话，让你感觉还没来得及看仔细。这几句话的字眼比较刺痛你，或者那个消息比较钓到你，你脑子里刚开始围绕这个东西想一点，绿灯就来了，起步。

这个时候你给自己下了一个判断：微信里有一个联系人给我发了一段话，这话里有猫腻，或者有学问、有意思，我得回去再复核一遍、复查一遍。在这种情况下，时间有两分钟，但实际上对你来说，这两分钟里体验到的时间可能就三五秒。那些准备性的、工具性的、浅薄的最后影像，你去沉浸一下，就像你打发时间吃糖：剥糖纸要剥半天，吃糖一开始也是淡薄无味的，到最后寡淡磨淡，最后有一点点刺激，里面是酸的，外面是甜的，最后那点酸会凸显出来。

这种情况只有三十岁的人才会做，你明白吗？就我的经验，只有三十岁的人会这样，因为三十岁开始……三十岁之前，比如我，在等红灯的时候，我不会打发时间。我面对红灯就感觉自己是不幸运的，有一种逆反：我靠，又没赶上，好烦，我要快点起步。等红灯的时候我在想，妈的，我为什么又停到一个红灯前面？这些车什么的，然后快亮灯的时候，就开始催前面的车：你快点起步，你快点起步。这就是三十岁之前对于世界的一些例行之事的感觉。

中间的这种阻碍，就是有这样一种觉得自己不幸运、自以为轻微地不那么幸运、没那么好的运气的逆反。这个东西是很有时间感的。我们说时间感是什么？就是让你觉得漫长，让你觉得难受，让你觉得“我操”。这是我的感觉。它让你觉得这是抽丝剥茧的事，你不愿意做，好烦，有一种拒绝之意。

你开车子，像我以前四十公里、四十分钟的车程，我开得心里一百个不痛快，不停地生气，骂这个傻逼起步这么慢，浪费老子两秒钟。你不停地算账，这个时间感其实也是虚假的：你不停针对时间本身算账，而没有针对事情算账。三十岁之前，你是在用时间、花时间，并且花心情算时间账，甚至也算心情账——我今天过得不开心，而“我今天过得不开心”更令我不开心。

它就有一种重叠，是二阶的：用时间算时间账。我花点时间想想，今天浪费了好多时间，好烦。这个时间感就像你在 B 站看视频，下面有个进度条，有时会隆起，有时会变和缓，有时又隆起——这好像是监测网速，我不知道是什么。

相当于你感觉时间过得好慢、时间比较漫长，就好像进度条隆起了。或者不说隆起，说它卡住了：你在花时间嫌弃，你在花时间反思，你空耗时间，或者别人耽误了你的时间；你在花心情厌恶别人影响了你的心情，浪费心情，针对那些让你浪费心情的人。这个时候，实际上这里面都是自我意识。在这个意义上，这种自我意识还作为一种二阶的、否定性的时间意识呈现。

这是否定性的时间意识，甚至可以说是二阶的、否定性的时间意志。你在浪费时间去嫌弃那个让你浪费时间的人，这个人不就是你自己吗？归根结底是你自己，但你会甩锅到别人身上：我操，这个傻逼车开这么慢、启动这么慢，那个家伙又花我两分钟问我问题，好烦。

比如你读研的时候，室友学不懂，你要花大半夜时间给他讲，你讲得好漫长，心想你怎么还不懂。这个过程里，你嫌弃时间漫长，或者嫌弃这个时间账浪费、不合算，其实是自己在做这个时间账。所以实际上是嫌弃自己。我说它是一个否定性的时间意志，而且是自我否定性的。

它实际上朝向自己，谴责你为什么不把生活过得顺利一点、为什么不把心情过得流畅一点、为什么要卡在上面。“我为什么又他妈等红灯了？烦死了，我的时间为什么都浪费在等红灯上？”这种感觉能让你觉得时间过得更长，谴责时间不够用，这就是让你觉得时间变长的秘诀。

一直在被打断，it is always interrupted。而且他否认这是自己的原因，说这是别人的原因、世界的原因，朝向那边左车道、右车道的车偏要到左边去，卡住我，让我多等一个红灯。

心里一直愤愤不平，一直在想：如果不是他……这就是我说的二阶否定，是 what if not。最近有个电影，不是 what if，而是 what if not。这是个秘诀：如果不是这个逼非要到左边去，我靠，我这个红灯就不用等那么久，现在就不会这么烦。我的时间一秒钟这样过，哇，好烦，就是这个家伙害的我。

而且这是投射性的，投射到他人身上，并且去幻想 what if not：如果不是这样会怎么样？他的时间体验好像就是二阶的，或者说是叠床架屋、拱上去的，有几层。

但到了三十岁，或者说到了某个年龄点之后，要逐步适应一种新的时间意志。就像那首《金线菊》里面，齐秦的姐姐唱的，叫啥？是耐于等待的、善于等待的。当你善于等待，就像我说的善于打发时间，你的时间意志就开始没有二阶化，不烦了，不去做这种 what if not 的、投射性、归咎性的归咎。这种归咎性实际上是自我否认：他首先自我否认，因为归根结底是自己在烦。

你谴责那个让你烦的人，但这个让你烦的人就是你自己，你不承认这一点，认为让你烦的是别人；而且你认为，如果那个别人不这样做，你就不用这样烦，时间体验就会更流畅。现在你不停试图归咎，不停幻想：如果不是这个死逼，如果不是这个家伙，如果不是这个世道，不是这个规则，不是我运气这么差、遭遇这个东西，那会怎样？这种自我否认的、归咎性的时间意志，会被另一种时间意志代替。另一种时间意志就是说……

做什么都要花时间。成熟的人不是一种局部耐心，他的心态不是“稍安勿躁”，不是一个临时的耐心。就好像生活中，我们不需要等排队时有点耐心、等电梯时看着数字滚下来才有临时耐心，或者牙疼了开始吃药才有临时耐心。对他们来说，不需要临时耐心，而是有一个耐于等待的、常设的、常有的耐心。

也就是说，无论遭遇什么——比如我这辈子发过几十次炎，局部疼痛不知道多少次，等红灯等了上千上万个，听别人慢慢把脾气发完不知道多久——在这个意义上，对于那些阻挠你时间流畅体验的东西，本来应当让你产生二阶的、自我否认、把根本原因归咎给别人的、投射性的、否定性的“如果不是这样”。这一层东西你就不需要了，至少不太需要了，因为对一个比较成熟的人来说，他一眼就知道。

你开始变成一种自我肯定性的反思。它也是一种自我反思，但这种肯定性是一眼就知道：我抱怨没有用，抱怨的用处就在于让我意识到这是一种抱怨。或者说，时间已经被浪费了，但我为了让自己好像要挽回这个时间，脑子里瞎想了那么多种多余的可能性。但对一个成熟的人来说，他放弃挽回了，不挽回了。

他开始把时间当作开销去花，很熟练地开销时间。而且他知道，把时间浪费在挽回时间上，只能造成一个好像时间流逝得比较慢的假象。三十岁之前、二十岁十几岁时觉得时间过得很慢，这是个假象。你跟时间赌气生气，或者跟生活中种种逆向的要素、情形赌气生气，把气归咎，然后幻想“如果不是这样会怎么样”，这是个假象；它产生一个假象，让你觉得时间还没有过，因为毕竟你对它进行了反思。

但当这种反思的训练，或者说当反思本身证明它在现实当中没啥用，很多反思都是多余的。“哎呀，如果不是这样多好。”你想穿越回去改变过去嘛。有人开这种玩笑，我以前在 QQ 群里说，我学哲学就这样穿越回去，把一个自杀的朋友救回来。这种超本体论的可能性在哲学上当然有讨论空间，那怎么实现它呢？这个世界的本体论架构有非常强的共同体伦理意涵，如果你打破这些基本框架，共同体伦理就无法组织了。

我要讲的是，你不再这样对时间进行操作，你真的会觉得时间过得很快，一年一年就是按部就班。我甚至可以说，十七岁之前的十七年，和后面到五十岁之前的岁月，或者十七岁到五十岁中间这三十三年，真的相当于十七岁，或者十六岁到四十八岁，差不多长，是两倍关系。就是因为很流畅了，或者说你不刻意去制造不流畅。

这意味着你的生命体验被现实夺走了，可以说你的生命被现实的事物夺走、缩短了。当然可以这样说。但你不缩短，生命也是内耗，而且是自我折磨。现在很多人到了三十岁、四十岁还是那种……我不叫内耗吧，不用这个词了，什么精神内耗、治好了精神内耗，觉得度日如年，他就是不停地发生一件事情。

总要想：如果不是这样，让他十全十美；如果不是这样，让这个人不横插一杠子，不作为一个阻碍的力量，他会怎么发生？要沉浸在这种幻想当中。这个时间固然过得慢一些，但生命的价值也就丧失了。生命要有一个实现过程，内在本质要实现出来。

你的种种社会化的展现自己，或者去交往、去创造、去定下规则、去实践、去践行、去验证、去否定、去拒斥、去打败别人，或者把你一个不成熟的意见摔碎在地，等等。这些过程都要花时间，你要意识到这都要花时间，或者说都要经过历史的中介。所以有点以逸待劳的感觉，稍微有点，但不是以逸待劳。这个“逸”其实就是你的“劳”，是以劳代劳；但当你以劳代劳的时候，这个“劳”就变成一种“逸”，就变成感觉时间过得很快的那种感觉。You understand？

你要经过历史的中介。你的生命不是靠内在体验获得现实性；成熟起来你会意识到，生命获得现实性不是靠内在体验，而是靠内在体验所激发的行动、创造的实践过程，然后在历史当中事件化，对历史事态产生影响。也就是说，它需要现实的中介、历史的中介，再把它像读条一样读一遍，它才有现实性。生命的现实性在于此。

比如我等红灯的时候，就会掏出手机打开拼多多，选一个比如“牙套戴着疼有什么办法缓解”，然后去搜索一下，我会做这个事。我不会在乎前面那个家伙起步慢一点还是快一点，也不会生气说之前有个逼超了我的车导致我红灯没赶上。对我来说，这个红灯两分钟一下子就过了，但我觉得花得值。这确实是在消耗、消费你的生命，与其说不是在使用你的生命。当你的生命被这样使用时，它确实过得很快，但它比你生命纯粹在那边空转好。虽然空转会让你觉得生命变长了，但这个生命没有质量，就是在那边负情绪爆表。但这些都是小自然哲学话语。

它是一种自我否定式的、二阶的时间意志，是一种意志。更确切地说，是一种虚无主义的意志，it is will。但这个 will 来自世界的一种回到内在的否定性力量，不愿意展开，并且对过去所幻想的理想图景耿耿于怀。

我本来打算二十五分钟就能开到目的地，你他妈让我开了四十分钟，好恶心、好烦。实际上这种空转之所以觉得时间过得久，是因为他花了更多时间制造一个时间过得慢的幻觉，来欺骗自己，让自己觉得自己没白活。

他实际上是这么一个套路：欺骗自己，让自己觉得自己没白活。这个套路恰恰就是所谓生命质量、时间质量的套路。生命质量、时间质量、时间过得很有质量，这是个意识形态；这个意识形态恰恰会让人们花很多时间去制造“我这个日子没白过”。

他花时间在那边拧巴，想“如果不是这样我就更好了”；或者你刻意追求时间的质量、生命的质量，往往就会变成一种怨怼性的——怨怼怎么写？——怨怼性的，不停抱怨或幻想：如果时间不是这样、现实不是这样、如果没有它……这也要花时间，这本身也要花时间，这也是直接在花时间。所以我说这种方式不合算，人在幼稚的时候这样去做是不合算的。

然后你大胆地去，真正沉浸在劳动创造和安排、布置你的生活内容当中，大胆去融入生活的内容，不要害怕浪费时间。不要怕这些时间好像被消费——它不是浪费，是使用。不要怕使用时间、使用生命。因为你不去融入生活，你就是孤独的个体，你的生命就是一个无穷、无限、无意义的空转。

你在共同体当中，是要为共同体的利益，或者为众人更合理的共同生存方式去探索、去追求。说难听点、鸡汤点，你处在关系之中，有朋友、亲人、同伴。说得严肃点，你的内在性、你的自我意志、自我意识，无非是绝对者试错的一个试错点，他还有其他无数试错点；而且你克服了……

绝对者的唯我论，克服绝对者内在封闭，或者说绝对者自己克服自身内在封闭的方式，就是尊重他人——或者不叫尊重他人，而是承认这种多样性、平等主义的多样性、多重性（multiplicity）。这是从哲学上讲。他不是争分秒，而是意志所在，事就应当去做，就应该去做事。

做事要花时间，那就大大方方地花时间做事。只要这个事情确实是在一个序列上面的，甚至不仅是时间，还有金钱，当然不仅是金钱，还有情感投入，甚至你的人生安全、安危，都要大大方方去面对你必须要做的事情。你不这样做，活着就没有意义。

你要看到你身后的、你过去的自己设立的那一系列都朝向这个方向，你就要去做这个事，这个时间花定了。这个时间他妈花定了，你必须要花，现在花和待会花一模一样。它已经露出端倪、露出苗头，显现出必要性，有内在体验了，那你就应该现在做。你为什么还要等、还要再想一想别的？

就是说，你不要做，就不要做。比如好多信没回，不回就不要回；有的信也没有意义。比如我要拍视频，要拍就拍。这当然有代价，代价就是时间过得很快。

但你得到的是：你的内时间体验会觉得时间过得好快，觉得生命好像在变短，但不再有一种时间过得慢的幻觉了。你获得的那个成就、那个收获是什么？你的内在本质被历史中介了，你成为一个历史当中的现实的人。

你在时间性上，你的存在、你在本体论意义上的存在、你的自我意识存在，在时间性上是有根的。你不再是那种无根的状态，你克服了你的无根性；或者说，在这个意义上，你促成了一个运动。

促成了一个运动，什么运动呢？就是历史所催生的：本来作为虚无的、内在虚空的自我意识，向着他本身返回了。历史把精神、把自我意识生产出来。

他通过你这种愿意去花时间、愿意耐一下性子——实际上已经习惯性耐着性子——其实代表历史向自身的返回。历史通过什么？通过精神形态的演化，产生了一个作为内在虚空的自我意识，但这个自我意识也就在你这样做。所以我说这是一种时间意志，是一种时间意志，意志啊，this is will。

这个意志是绝对者的意志，是绝对者在时间性上的意志。而且这个意志被第一人称中介，这个第一人称中介体现的就是时间转瞬即逝。这个意志的内在体验，如果被你的内在体验第一人称中介，你就觉得人生转瞬即逝、人间如梦，或者那种“哇操，一眨眼一年就过去了”。

这是一个意志，这种意志是轻松、欢快的，然后是一种自我肯定的意志。这种自我肯定的意志在时间性上，我们把它叫做一种轻快的永恒，this is light and swift eternity。它这种轻快的永恒，是快乐的舒展，因此我把它看成是具有历史自我肯定性的时间意志。历史自我肯定性，明白吗？
