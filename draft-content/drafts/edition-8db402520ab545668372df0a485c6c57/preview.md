# 【经典译读】康德《纯粹理性批判》（连载中）

对《纯粹理性批判》B版导言第二部分的讨论。我们拥有某些先天认识，甚至普通知性也从来离不开它们。这里要讨论的是，通过一个标记，我们可以安全地区分出纯粹的过程、纯粹的认知过程。于是我们可以把经验性认知和纯粹认知区分开来，用这样一个标记标出它们的差别，看看它们有什么差别。经验会教导我们，某物是这样或那样被建构的，但不能教导我们它不能是别的。经验只教导我们关于事物存在的可能性，却不教导我们它的必然性，也就是说，它并不告诉我们 it could not be otherwise，不告诉我们这个东西没法变成其他样子。

如果一个命题依循着它的必然性而被思考，那么它就是先天判断，即 a priori judgment。因为它具有必然性，不受经验扰动；无论经验怎样天翻地覆地变，它总是如此，那么它就是必然的。进一步，如果它是必然的、是先天判断，而且不是从任何命题中导出，而只是从一个作为必然命题而有效的命题中导出，那么它就是绝对先天的。换句话说，它只能从一个必然命题、从一个作为必然命题而有效的命题中导出。经验永远不会以真的或严格的方式给出它的判断，它只给出假定性的、比较性的普遍性。

经验永远不会以真或严格的方式给出判断，它只能给出假定的、比较的普遍性。通过归纳法可以得到一些相对比较普遍的结论，但它不是严格意义上、真正意义上普遍的东西。所以恰当的说法是：只要我们还未能感知到例外，这个或那个规则就没有例外。如果一个判断以严格的普遍性被思考，也就是以没有例外被允许作为可能的方式被思考，那么它就不是从经验中引出的，而是绝对先天的。

严格普遍性意味着绝对先天。经验性的普遍性因此只是一种武断的增长，即在有效性上从大多数情况下有效，增长到所有情况下有效。这里的 validity 不是 effective 意义上的有效，而是有效力，是正当、正确、对的，是符合整个体系对它的预估。相对于绝对先天所具有的必然性和绝对普遍性来说，经验性的普遍性只是在有效性上的一种比较任意的、专断的增长。这种增长是从在大多数情况下 holds、站得住脚，变成在所有情况下 holds。

举例来说，在“所有物体都是重的”这个命题中，严格普遍性本质上属于一个判断。它指向一个特殊的认识来源，即一种先天认识能力。换句话说，经验性的普遍性只是把大多数情况下起作用的东西的有效性增长为在所有情况下都有效，这是一种武断、专断的有效性增长。“所有物体都是重的”中的严格普遍性不可避免地属于这个判断，它指向一种特殊的知识来源，也就是先天认识。因此这个判断需要先天认识参与，它是一个先天综合判断。

必然性和严格的普遍性因此是先天认识的安全标志或指示。只要一个东西包含必然性，或预设了某种必然性，或自居为普遍有效，那么它就只能来自先天知识。康德在这里说的是，只有与经验无关的先天认识才能给你必然性和严格普遍性。反过来，只要能看到哪里有必然性、哪里有严格普遍性，就可以说这个认识是先天认识。必然性和严格普遍性属于一起，二者不可分离、同有同无。

你是必然的，就意味着在所有情况下都有效，也就是普遍的；你在所有情况下都有效、都是普遍的，那你也就是必然的。但在使用这两个标准时，有时更容易展示判断中的经验性限制，而不是展示其中的偶然性。因此，人们往往更容易、更貌似合理地去显示我们归于一个判断的无限制普遍性，而不是它的必然性。也就是说，要弄出一个判断的经验性限度比较容易，要证明它是偶然的则比较难。你只要发现一个例外，或者穷尽既有情况后发现没有例外，就可以说它没有经验性限制，于是容易说它是普遍的。说一个东西是普遍的，比说一个东西是必然的更容易。

在这里你们会发现，康德说 necessity 和 universality 的时候，necessity 前面没有加 strict，而 universality 前面加了 strict。因为 universality 是比较容易、可以逐渐得出的东西；而 necessity 是一有就有、一无就无的东西，是很硬的。普遍性本身则有点软。比如我手头有一百个例子都符合，我就可以用比较轻微的方式说它是普遍的，但它不是严格普遍。严格普遍要求穷尽所有例子。所以康德在这里告诉我们，我们想要展示判断中的经验性界限或限制；如果发现它没有限制，就会说它具有不加限制的普遍性。但要证明它是偶然的，就得穷尽所有例子，或者需要很多很多例子，所以不太能够去证明它的必然性。因此，明智的做法是把普遍和必然这两个标准分开来使用。我们在判断一个判断时，往往会分开来用它们。但康德告诉你，这两个其实是同一个东西，只不过后一个是在统计学、渐次统计学或经验性统计学意义上的，前一个则要求整体都加以统计，或者说它的结构本身就带有一种概率性。这个东西比较定性，那个东西比较定量；一个从质的角度说，一个从量的角度说。但实际上它们都是统计学，只不过一个要全部统计完毕才行，另一个统计一部分之后就有迹象觉得它好像是普遍的。所以通常我们会把这两个标准分开来使用。

但每个标准本身都是绝对可靠的、不会出错的。很容易证明，在人类认知中，事实上存在这样一种必然的、在最严格意义上普遍的、纯粹先天的判断。如果想从科学中举例，只需看看所有数学命题。康德认为，所有数学命题都是纯粹先天的判断，都是绝对必然的、严格意义上普遍的。

但我们昨天看到的，无论是石里克还是提出约定主义的那个人，他们都认为数学的公理本身不是纯粹先天判断；它也不是来自物质现实或直观，而是来自人的语用学习惯，来自人类所采用的符号学传承的习惯，是约定。如果想从知性最普遍、最通常的使用中举一个例子，“一切变化必然有一个原因”这个命题就可以。它满足标准，是纯粹的先天判断。

这里牵涉到休谟对因果性的怀疑论以及康德对它的评价。事实上，在后一种情况里，原因概念本身就明显包含一种必然联系，即原因与结果的连接；原因概念也包含规则的严格普遍性。如果像休谟那样，想从频繁联想、从事物的渐次发生中推出原因与结果联系的必然性以及因果律的严格普遍性，那么它就会完全失去，你根本找不到它。这里不是连续序列，而是 frequent，即不停频繁发生的联系。休谟对因果性的怀疑论是这样的：鸡每天早上都被喂食，重复了几千次，最后那天早上它早早起来，却被投喂多了——那天是感恩节。也就是说，你怎么证明我们不是火鸡呢？但康德说，如果你要从事物不断频繁发生的联系中，比如太阳升起、吃谷子，太阳升起、吃谷子，从这种频繁发生在一起的关联中推导出因果性的必然性，是推导不出来的。因为这里已经包含 of that which happens with that which precedes，即一个事情发生，和先行于它的东西发生，它们之间具有频繁联系，同时你有一种习惯，把从这种联系中发生的表征连接起来。你把太阳升起和吃谷子这两个 representation 连接起来。如果你这样做，这不过是一种纯粹主观的必然性。要从其中推出原因概念所包含的、能够带出结果的必然性以及因果律的严格普遍性，是不可能的。

甚至不需要这样的例子来证明纯粹先天原则在我们的认识中的现实性，我们还可以建立它们对于经验本身可能性的不可或缺性。也就是说，这些纯粹先天原则对经验本身是不可或缺的，因此它们是先天的。因为你要有经验，就必须先有这些纯粹先天原则；没有它们去组织经验，经验本身也不可能。康德在这里就是要证明纯粹先天原则或这些认知是存在的。那么，如果所有经验所依循的规则本身反过来总是经验性的，经验本身又从哪里获得它的确定性呢？如果这些规则本身总是经验性的，经验就无法获得确定性。因此，人们几乎不能允许把这些东西当作第一原理。

在这里，我们可以满足于把认知能力的纯粹使用展示为一个事实，连同它的标志，即必然性和严格普遍性。这不仅在判断中，而且在概念中也是如此：某些概念的起源是先天地揭示出来的。例如，从对一个物体的经验性概念中逐步移除一切经验性内容——颜色、硬度或软度、重量，甚至不可入性——仍然会留下这个物体所占据的空间。空间不是被给予的，而物体本身已经完全消失，因为它的可感属性、经验性属性都被去掉了。所以你不能忽略空间，不能忽略这一点。

同样，如果从每一个物体的经验性概念中，把经验教导给你的那些属性都移除，无论是有形的还是无形的，你仍然可以从中取得某种东西，使你把它思考为 substance 实体，或思考为依赖于一个实体的东西，也就是对实体的依赖这种规定性。即便这个概念比一般意义上的 object 包含更多规定性，它仍然是一个本体论预设：它是有实体的，是在实践中持存的实体，有机制；或者说物体依赖于一个实体性的机制、材料。这比 object 这个一般概念要更多。

因此，被这种必然性所说服——这个概念以必然性把自己压在你身上——康德把这种过程看成不言自明的。他好像认为，你不理解就说明你愚钝；他就是说这是必然的。我看的时候也觉得，object 里面就是有 substance，substance 超出 object，这就是先天综合判断。或者说，这种依赖关系比 object in general 要多。康德认为这不是明摆着的吗？所以他不去证明。比如你问他：你告诉我，object 里面为什么一定有 substance？他会用异样的眼光看着你，鄙视你。但实际上他没有证明，这没有证明。这是当时哲学传统中一些不言自明的东西，背后靠某种直观。当然，他也会搞一些逻辑证明，一些很粗陋的逻辑证明；那些粗陋的形式化证明实际上也是在同义反复，没有意义。因为 object 和 substance 的关系，后面整个辩证法会把它颠覆掉。

因此，被这种必然性所说服——这个概念以必然性把自己压在你身上——你必须承认，它在你的先天认识能力中拥有一席之地。

但我们必须补充一点：为什么你在思考 body 这个概念时，一定会感受到它有实体性、有机制，或者物体一定依赖于这个机制、这个实体？康德说，这是纯粹先天认识机能必然带出的东西。其实不是，这出于我们的语用学习惯、符号学习惯。你得出这样的判断，说了这样的话，然后反思它，觉得不怪，关键就在于此：你感觉它不怪，其实是语用学习惯。你觉得这两个符号在符号学空间里具有很接近的相似性，或者它们占据的几个关键点很类似，于是就说它们具有必然性，一个必然牵引另一个。从结构主义角度看，无论是 substance 实体还是 body 物体，它们在符号学里的定义都是通过与其他概念或符号的差异来维持的。当你思考 body 这个概念时，你必然会觉得里面有 substance，原因在于这两个东西在符号系统中运用时，其同一性是由与其他东西的差异所维持的。body 这个语词和其他语词在概念用法上的差异是 a，实体这个词和其他词在用法上的差异是 a'。当 a 和 a' 的差别很接近，或者它们的拓扑学结构非常类似时，你的符号学机制就会倾向于告诉你 they are the same thing，或者它们一个接着一个，是必然关系。这在康德看来不言自明，但在我们看来，你依赖了一个非常重要的经验：语用学经验、符号学经验。这个经验是习得的，不是天生就会说话。每个民族都有语用学习惯。为什么中国人的语用学习惯里不太容易把握这种东西？因为我们说话时，这些词没有在我们的语词体系、符号学体系里获得如此类似的差异配置。物体这个词我们常用，但实体这个词、substance 和 body 的关系不常这样用。而在西方那种语用学环境里，在工程学、现代科技和资本主义发展到一定程度的背景下，抽象思维使得每个人的符号学体系都那样建构，符号之间的差异都按文化共同体共同的方式建构。于是就会觉得人同此心、心同此理，怎么想都觉得这两个东西是必然的、连接在一起的。

这个过程当中都有沉默的暴力。它其实是直观的。康德说得好像是先天综合，或者 body 里面有分析性，但分析性本身也是偷跑的，法学上都不合法。康德反思不到这些东西，因为他处在前语言学转向，他完成的是认识论转向，可能刚把球踢到门线附近，还没进去。苛求他已经是语言学转向，就太苛求他了。今天第二节就讲完了。
