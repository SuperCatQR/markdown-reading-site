# 【二十分钟哲学】两种主体之哲学的主体（以及何为先验主体性）

接下来要讲的是第二种真正意义上的主体，也就是哲学意义上的主体，即所谓的 subject。subject 这个词，我词源学学得不太好，可能在亚里士多德那里，它指一个学科中主题性的、主要的知识，就是主题的意思。它还有一个意思是“在什么什么下面”，sub 表示在下面，subject 指在什么什么下面的东西。其实这个词本来就有实体的意思，后来实体用 substance 这个词来替代了。这里要讲的是，对主体性的把握，抽象地去把握它是没有意义的，我们一定要在它与实体、客体的关系中来把握它。主体一定要在两种关系中来把握：一是与客体（object）或对象的关系，二是与实体（substance，也有人翻译成基质、基底）的关系。先看第一部分，主体和客体、对象的关系。你必须承认，主体是把客体客体化出来的，通过 objectify，通过 objectification 这个过程，才搞出了客体。如果你学康德，必须承认一点——我们以现代哲学入门的康德、Kantian subjectivity 为前提来讨论问题。如果不是以这个为前提来讨论问题，我觉得我们没有共同话语的基础。你学分析哲学也要学康德吧？要骂我们学大陆哲学、欧陆哲学，你也得先了解我们在说的是什么，对不对？

我们要说的东西很简单：主体的内在核心，我们把它叫做内在的本质，也就是主体性，主体的主体性。这个玩意儿叫主体性。主体性相当于什么呢？因为我们讨论主体性的时候，前面都要加一个定语叫 transcendental，叫先验主体性。所以主体这个概念严格一点讲，当我们在西方传统语境里面讨论的时候，特别是从古典哲学、经典哲学，一直到结构主义、现象学、诠释学，还包括后面早期分析哲学，我们讨论主体性的时候，都是在 transcendental philosophy（先验哲学）的框架里面讨论的。那么我们要弄清楚什么叫主体性，什么叫主体，主体和客体的关系，什么叫客体化，我们现在得了解什么叫先验。

这个问题很简单，只要你有台电脑，就可以理解什么叫先验了。我把屏幕清空一下。什么叫先验？先验简单来说就是 Windows，就等于 Windows；或者你也可以说它等于苹果操作系统。苹果操作系统怎么写的我不知道，是 MOS 还是什么 M，反正我们用个大家都用过的 Windows 好吧？先验就是 Windows，就是操作系统，Windows 操作系统。

先验哲学有两个基本立场。第一，所有对象都是在这个操作系统里面按照它的规则生成出来的，所有东西都是在操作系统内部向你呈现出来的。简单来说，这个世界是模拟出来的，所谓现象性的世界，是操作系统模拟出来的。第二，主体本身是无法被模拟的，主体本身无法被模拟。也就是说，如果这是世界的话，先验哲学认为这个世界就是 Windows 操作系统生成出来的一个视窗，所以它会叫 transcendental horizon，叫做先验视域。

比如这个世界里面会有一个物，比如有一台车——这不是象棋，当然我可以把它画得像象棋，或者画得不太像。里面有一台车，那么这台车要在这个窗口里面显现、呈现出来，必须通过操作系统的一些源代码或者基本的操作指令、显示指令，把它建构、生成出来。比如一个杯子，它必然要有我们通常所说的关于一个杯子的概念，那就是先验的概念；或者高级一点说，它里面得有各式各样的范畴：量的规定性、质的规定性、模态的规定性——它确实是存在的，也是实实在在在那边的，当然将来有可能不存在，所以还有时间上的各种规定性。总之，这个东西得有各种属性拼凑起来。就相当于程序员要把这辆车写出来，你得写一个 object，写一个对象，然后把这个对象用 attribute 一、二、三、四、五等属性规定在那边，还有 quantity（量多少）、quality（质怎么样）等等，把这些乱七八糟的属性都加到这个 object 上面。所以，你理解了什么叫先验、先验性，什么叫先验的视域，就知道这个世界本身是通过一个操作系统生成出来的。这个操作系统有它自己的分类学，有它自己的分析，把一个东西拆分出来，把这个东西整合起来，它有自己一套机能在那边运作。这叫做一个先验。

那么这个操作系统具体来说，Windows 我们要说 Windows 10、Windows 7，对不对？Windows 98、Windows 2000、Windows XP，这是相关的版本号。我们会把它定义为某种先验主体性。主体性有很多种样态，有黑格尔式的主体性、Hegelian 的主体性，有 Kantian 的主体性，有 Descartes、Cartesian 的主体性，还有谢林、费希特的主体性。他们不同的主体性，就相当于 Windows 版本不一样。黑格尔的 Windows 版本是 Win7，康德的 Windows 版本是 Windows XP，笛卡尔的 Windows 版本是 Windows 95，费希特的 Windows 版本是 Windows ME，类似，差不多这个意思。不同的主体性，就是你这个操作系统具体的范式、操作系统里面的一些设定不太一样。那本来可能是一个动图 GIF，会动的，在黑格尔的操作系统 Win7 里面，黑格尔式的主体性让它动了，GIF 图动起来了。那么在康德那边，Windows XP 里这个 GIF 图可能也动了；但是到了 Cartesian 的、笛卡尔的 Windows 95 里面，这个 GIF 图就动不起来了。如果这个 GIF 图是某种历史性的、某种历史辩证法的话，它动不起来了，因为主体性版本太低了，不行，了解吗？

所以这个世界是由一套先验视域给它敞开来，然后在里面建构出各式各样的对象。这些对象要进入这个视域，要进入这个先验视域，要成为经验的对象，可被感知、可被把握、可以被理智去读取——简单来说，被操作系统读取的话，它就要经过一个对象化的过程。这个对象化的过程当中，对象本身有各式各样的东西就被阉割了。比如现在量子力学跟你讲，很多东西就是波函数，但在以前牛顿时代、康德时代或黑格尔时代，它把握这些东西还是把握成粒子，是一些 rigid、一些 body，一些硬的东西、硬的物体，还是把它理解成硬壳固体。所以操作系统在读取这些事物的时候，就把它们原本的那些东西篡改了，或者用别的东西替代了，让它可以在先验视域里面呈现出来。不同的先验视域能呈现出来的东西都不一样。

比如有人说爱斯基摩人一天到晚面对冰天雪地的白色，能分辨好几十种、上百种白色；我们普通人可能只有一种白色。这是感性层面、感性色彩层面的。再比如一些很聪明的人，对他来说一些概念体系就是起作用的，it works，他能感受里面的差别。比如一些理工科高级知识分子，就能感受到不同样式的超弦理论和量子场论之间一些细微的差别，他能在概念上感受到，还能在现实的实验现象里面发掘这种差异。但是普通人根本一窍不通，“我哪管啊，我不懂这东西”，我顶多知道什么原子核，这种东西就已经很了不起了，这个在人口里面占的比例就不高。就差不多是这个意思。先验视域决定了在你这个敞开的系统里面，开机之后，哪些东西能够作为一个文件夹被它读取。那么你们了解什么叫先验了吗？

先验哲学有两个基本原则：世界是操作系统模拟出来的，这个操作系统就是先验主体性。这个操作系统可能是 Windows XP、Windows 7；如果是马克思主义的话，我认为它可能是 Win10，是 Win10 操作系统模拟出来的。那么主体本身没有办法被模拟，主体性本身没办法，主体本身没办法被模拟。因为这个操作系统的模拟者就叫做 subject，这个先验主体、先验主体性就是这个操作系统。先验主体性把它作为一个对象来表达，那么一个主动去——也不叫主动，其实我们没办法拒绝的。你说我可以啊，现在停，把这操作系统关掉，我不要这操作系统——不可能的。你不可能让你眼前的世界消失于无，无没办法存在，我们之前讲过。所以主体不得不让自己的先验主体性去把整个世界作为一个对象化的把握、语言化的对象化的把握。你可以语言化地把握它，也就是用代码、用表征符号来把握它；你也可以叫对象化地把握它，它一个个东西都作为一个文件、文件夹放好了在那边。没办法，你没有办法，这个东西你没法拒绝。你说我要拒绝这种先验主体性，我拒绝它，不好意思，它是先验的，人家牛着呢，是超越性的。你通过有限的指令很难去拒绝它；它这个词 transcendental 也可以翻译成超越的。超越数，数学里面超越的就是不能用有限的代数关系表示。你是拒绝不了它的。这个操作系统开下来，电脑开下来，你要么做梦、睡觉的时候它会紊乱。我举个例子，你做梦的时候——我举个非常直观的例子——这个东西什么时候会紊乱？做梦的时候就会紊乱。做梦的时候，比如梦境本身的开始，dream，梦等于这个操作系统紊乱，Windows 宕机、Windows 出 bug，也可以看成它自己修复这个 bug，自己在修复这个 bug。梦境的第一个瞬间，每个梦境的第一个瞬间，实际上就是出 bug 了，因为你沉浸在梦里面。比如一下子我做梦，梦到我是一只小乌龟。你如果是正常人，醒着的时候，那你就会去反思：哇，为什么我是小乌龟？就是在醒的时候，你有 reflectivity，你有反思能力。大部分人——我靠，我突然在现实当中把你变成小乌龟，你肯定就哇，我为什么变成小乌龟了？但是你如果做梦梦到自己是小乌龟，你是不会反思的。这是第一个瞬间。这就是梦境，是直接的符号性认同，直接的 symbolic identification，直接的符号学认同。这是梦的第一个反常的地方。

梦的第二个反常地方是，梦境有时会让你体验到第三人称视角，或者叫上帝视角。我们日常生活中感受的视角都是我眼睛，我有一个主体，主体在这里，然后看到外面、看到这个世界，这个世界还三百六十度包围着我，这是第一人称视角。我这个主体自己看不到我自己，第一人称视角就是这样；如果在后背，就第三人称视角。但在梦里面，你有时会化身为上帝视角，你会发现你就是空白，那个视域里有各式各样的人，有这个人、有这个人、有这个人。你会在梦里面产生这种状态：你是一个纯观察者，纯观察者，你是不知道从哪个视点出发的，没有这个视点，而是整个视域向你呈现。这个就是梦境对于操作系统本身的一个例外状况，梦能够让它出现一种例外状况。包括有的创伤性体验也会有这种梦，也会对这个操作系统——这个 Windows、Windows 系统——产生一些影响。

比如有的神经症、精神病、分裂症，它的视域就直接裂成两个了。一般人的第一人称视域至少身体是完整的，但有的精神病比较严重，身体会裂开、断开，他只能看到上面，视域只有上半部分，下半部分看不到。精神分析为什么天然地和哲学联系得很紧密？因为精神分析就是研究这些反常状况，通过研究这些反常状况，我可以反向破译这个先验主体性是怎么运作的。否则你怎么去判断？你只能在这个 Windows 系统出 bug 的时候，看看它源代码是怎么跑的，否则你研究不了，了解吗？所以精神分析之所以和哲学这么紧密，拉康为什么也是哲学家，就是这个原因。我扯远了。

那么我们在这个过程中大致理解了主体和客体之间的关系。用很简单的话说，就是它是投射出来的，project 出来的。包括主体本身也会投射一个身体出来，客体里面包含自己的身体，也包含一个中心化的自我，都包含在这里面，叫 objectify，都包含在这个里面。

我们统一把这些东西都叫对象。所以不要说这个客体，客体里面包含自我，你知道这个 self（自我），它一般都是客体化的，预先被客体化好了放在这里面的。但是主体本身是没有办法被客体化的，subject 本身你想把它客体化成什么，不可能的。

这是不可能的，主体本身是没有办法把自己客体化的。有一个隐喻是说眼睛看不到眼睛、眼睛看不到自己。我觉得这个隐喻不太恰当，因为眼睛照镜子看到的当然是镜像，那个镜像也不是眼睛本身。观察者看不到他自身，也就是弄出整个视域的那个视点。外面这个视点没有办法在视域里面成为一个东西，它没办法进去，它进不去。但我觉得有个更好的方式来做比喻：当你跑操作系统的时候，你看不到源代码，看不到底层代码，不能监控底层代码，它不会实时给你把底层代码生成出来；你看不到底层运算的那些二进制代码，你看不到的。你能看到的话，这本身就代表无限倒退，本身就有问题。你是看不到的。主体是看不到他自己的，主体是看不到他自己的。这是先验哲学、先验 transcendental 的一个基本预设之一。
