# 【阶级阶级】预备部分——该体系的阶次关系；阶级物（1）——客体化的象征秩序

今天讲阶级。这几讲都是预备性的。一个预备性的问题是，它的“格”或“阶”的计数问题。但这里面的数不是数学意义上的数，而是符号学结构，都是阶次问题。阶级讨论的是阶次问题。

主义主义里面是一、二、三、四。这四个数字不是说一就是一阶的、没有反思的，二就是形而上与形而下的对立，三就是有一个主体性做中介；四则不仅有主体性做中介，还必须去主体化。四其实等于零，它是去主体化的；或者我们说它等于负一，它应该是负一，是一种反主体。也就是说，它必须等于三加一，这个“一”就是必须要有实践单元、行动单元、实践团体。说穿了，你得有你的小组或者团队，有你现实地介入世界的一个团体，一群人。

主义主义是这么一个关系。在阶级学里面，我们对应的数字关系可以明确告诉你们：一对应物，也就是 class age 阶级物；二对应小资产阶级，就是 petty bourgeoisie；三对应大资产阶级；四对应普罗大众。

四对应普罗大众，也就是说无产阶级。无产阶级是一个现代阶级，我甚至可以说它是最后诞生的，是现代人类解放性的力量，是现代人类的一个解放性阶级。它是小资产阶级和资产阶级被甩出来的那一部分，是他们最后甩出的剩余。无产阶级作为最后诞生的解放性力量，也是最受挫的：它在挫折中产生，在痛苦和挫折中产生，最后产生，经受最大的痛苦和挫折，才能迸发它的阶级意识。阶级意识是在痛苦和挫折中产生的。

人可以天然地是小资产阶级，甚至经过一定的教育就成为资产阶级。也就是说，人最天然的会是小资产阶级。我们来解释一下为什么。首先，物是一，物的阶次就是一。

物的阶次就是一。所以这里的“一”作为一个单元，实际上是客体性单元。客体性就是物本身的秩序，是简单的、单一的、重复的、单调的。物是一，那么小资产阶级是什么呢？

小资产阶级，小布尔乔亚，是二。这个二是什么意思？二就是要利用一，exploit one，要利用这个一，利用物。小资产阶级永远觉得自己没有在剥削人：他天然地觉得我没有剥削人，我只是利用了这个物，得到了更大的、更多的好处。小资产阶级是一个没有意识到自己在剥削人的人，他觉得自己是在利用物。

比如一个面店老板赚了更多的钱，他说这个店是我的，我就应该赚更多的钱，但实际上他拿到的是他伙计的剩余价值。小资产阶级在观念上觉得，我作为人驾驭了物。

所以他是个二阶。资产阶级则不一样，资产阶级已经明确意识到三了，也就是说，他明确意识到自己是个资产阶级，就是要剥削人、压迫人。小资产阶级那边还残留着温情，而且是一种真诚的温情，他真的相信。而大资产阶级、资产阶级如果有温情，就一定是伪装出来的；他知道自己所有财富的来源就是剩余价值，必须通过剥削人，而且在这个过程中也要利用小资产阶级。

他把小资产阶级这群人当成他的生产资料，然后去剥削无产阶级。所以最后的无产阶级是四。无产阶级是四，意味着他没有办法，他只能剥削自己。他也只能利用自己——都是同一个词，exploit，发挥最大功能。他只能剥削自己、利用自己，只能把自己作为一个物来利用，也只能把自己作为一个敌人来利用。所以，无产阶级身上兼具小资产阶级性和资产阶级性。一定要清楚这一点：无非是现实无法让他实现他的小资产阶级性，也无法让他实现他的资产阶级性。

我认为，无产阶级反而是克服了资产阶级性，克服了小资产阶级性，才成为的一种阶级意志。这里的“意志”我用的是 will，class will。我说的是阶级意志，不是说阶级意识；阶级意识是不能被第一人称中介的。

无产阶级欲成小资而不得，欲成资产阶级而不得。他靠物来剥削人实现不了，靠权力统治关系、逼税、靠钱或者什么乱七八糟的东西，想实现直接的人上人、不劳而获，都是欲求而不得。客观上讲，不是所有无产阶级都如此，也没有人天生就是道德圣人。他肯定是占便宜占不来，然后也在痛苦中意识到，占别人便宜是注定失败的，是错的、不对的、有问题的。他只能剥削自己，只能利用自己。

无产阶级是四，意味着上述三种，或者说他要直接存在也不行，他想要直接存在也不得。物是直接存在的，不需要反思；他做不到直接存在。那有没有可能无产阶级再堕落回物的状况？有可能，比如完全被洗脑，堕落回前现代的奴隶。但我说了，现代无产阶级不可能这样，只有偶然、零星的个体，完全丧失人的现代性和主体性，完全堕落为奴隶，那绝对病理化，这种情况很少、极为少。所以对应关系是这样的：一、二、三、四。主义主义的四字头实践天然属于无产阶级，三字头哲学属于资产阶级，形而上学属于小资产阶级。或者换言之，我认为封建士大夫阶层其实依然是小资产阶级的范式、小资产阶级的范畴，代天牧民。

然后这个物，物则是在无产阶级群众、劳动群众当中，它就是形而下学，对应的是形而下学的秩序。这里有一个比较明确的对应关系。

我们首先会讲第一个问题，即阶级物的问题。我们会按次序来讲，这个次序是一、四；可能顺序是四一二三，或者说四二一三，无论如何，这个三要放到最后来讲。

简单的一个分类其实是有分类的。这个三，我大约可以给它分类：一是垄断资产阶级，即国际垄断资产阶级、垄断性的帝国主义力量；二是非垄断的资产阶级，这种无法宣称自己是帝国主义的“蛇皮资产阶级”，但也很厉害，掌握政权，也掌握巨大的军事力量，这两个都很厉害，能参加资产阶级国际盛会，比如达沃斯论坛；第三个是民间资产阶级，没有资格参加达沃斯。

第四个就是各式各样的反资产阶级。如果我要说的话，各式各样的反资产阶级，但实际上依然是资产阶级；或者我们第四个就写前现代资产阶级，也可以明确地说，或者换句话就是贵族阶级。贵族是第四个的补充，比如那些贵族、前现代贵族、君主、僧侣、宗教领袖这些货色，还有大科学家、艺术家这些货色。或者我叫他们非资产阶级，不承认自己是资产阶级，但实际上他的存在就是个资产阶级，没有差别，也是真正实质意义上统治集团的一部分。

二里面的小资产阶级，我也基本上给你们分了，勉强就是上层、中层和底层。如果我要再精确一点讲，其实上层不好讲，我们就直接说：上层是裙带小资产阶级。中层可以说民间小资产阶级，或者说它是一个常态的小资产阶级，或者换句话叫市场小资产阶级。

中层是活在市场当中的民间力量。底层小资产阶级基本上就是瞎玩玩的，随时可能会倾没，所以干脆就叫底层小资产阶级，具有草根性、民间性。然后它还有一个剩余，这个剩余我们叫半无产阶级。底层小资产阶级当中有半无产阶级，整个小资产阶级会有一个剩余，叫半无产阶级。

半无产阶级是小资产阶级，不能归在无产阶级当中。无产阶级的无产阶级性是不得不、注定面临失败，而且是直接、现成地面临失败。半无产阶级就是处于滑落过程中的底层小资产阶级，正在滑落、正在危机化，或者叫危机中，基本上失能的、危机中失能的小资产阶级。这是第四个。无产阶级的一二三四我上次已经给你们分掉了，我们今天要讲的主要是阶级物这个东西。

阶级物，阶级物的主要分类。阶级物是一，那么就是一杠一、一杠二、一杠三、一杠四。

它是怎么一个对应关系？来想一想，think about it。一杠四已经是例外了，它已经不是物，而是非物。一杠三是一些观念物——这个说法可能不是特别精准。我们来想一想，这是一个非常复杂的东西。四肯定是非物，也就是一杠四这里已经是生命，而且是具体的、活的生命。因为在阶级物这个体系里，相当于我要给出一个我的自然哲学体系，但这个自然体系又得是阶级物：时间、空间的东西，你说它具有阶级性吗？寿命有阶级性，医疗待遇有阶级性，你家的住所有阶级性，对不对？所以一杠一这里，我们可以说某种意义上甚至是自然，自然物。自然物它又有一、二、三、四，这边又有一、二、三、四，我们这个分类不会少。

一杠二这里是一些社会物，或者叫伦理物，就是观念性的制度、观念性制度化的一些东西，比如民族、国家、家庭、婚姻这些东西。你看，一杠二里面就可以放一整个法学原理了。一杠三呢？

一杠三里面的东西依然是物。我们把一杠三里面的东西叫主体物、主观物、主体物。一杠三这里物的核心是享乐，是享乐对象。

我们现在就可以告诉你是什么关系。一杠二这里这些伦理物，包括财产，比如店面、地、租赁关系、门面这些东西，看上去是物没错，但它已经算社会物了。我不是说那个门板、楼板，我说的是租赁关系、许可准入。所以这些伦理社会物，其实也有它客观的、自然的物质载体，但同时有伦理性、社会性和法律性。

这个东西是小资产阶级生产资料。小资产阶级就是靠这个东西成为小资产阶级的。比如小资产阶级靠学历、靠文凭可以得到比较多的东西，相当于分点赃。我举个例子：比如他是一个工厂里的文书，她是个女的，利用自己的审美、人设来笼络一批工人，或者笼络一批中介，whatever；利用自己的文化、文凭这种抽象资本、资产，多领两百块、五百块钱一天；或者利用她形成的景观、美学景观，让老板、人上人好像更屌，whatever。小资产阶级是靠这些物的，但这些物并不直接是享乐对象。比如你的文凭，大专文凭或本科文凭、学历这些东西，小资产阶级凭借这样的东西……这种物我们叫文明物，人类所特有的文明物，但它的“文明”要加引号。

加引号的文明，因为在一杠一里面也有文明物，比如直接的劳动工具，铲子、锄头，当然也是文明。但它的文明不是那种可以让你形成奴役压迫关系的文明，不直接让你形成奴役压迫关系，或者让你可以多拿一份、造成不平等的文明。除非他把那个工具举起来当成权杖。你那根棍子用来捅马蜂窝、吃蜂蜜，那是根棍子，是一杠一的；但你那根棍子拿起来当权杖、装逼，那你就是一杠二，就成为一个伦理物、社会物。

你那根棍子如果再进一步拿来享乐，把它美学化、审美化，再复杂地变成一个享乐攀援、围绕它转的东西，那就变成一个主体物，或者换句话叫异化物，它具有异化力。举个例子，这个权杖不仅举起来让众人臣服，而且成为你和死士之间的中介：权杖指向谁，你的一群死士就冲出来把谁剁为肉泥。那这个权杖就是一个异化的物，因为权杖背后产生了一个享乐循环，死士看到权杖指向谁，就冲出来把他剁死。就像冒顿单于射箭，射谁就把谁……他射向自己的妃子，最后射向他爹，其他射手就把爹给射死了。背后就是说，它凝结了人的享乐模式，控制了人。这个物作为一个道具控制了人，直接控制了人，而且不仅仅通过物化的方式控制人，还通过内在化的方式控制人。

如果你仅仅把这个物上升到一个抽象的社会建制层面，那么大家服从这个社会建制，这是不走爱欲通路的，不走直接的爱欲通路，你明白吗？不是内在的、直接的爱欲通路。比如我们大家都知道，店面关系：这个房子是你租的，我租你的房子，我要给你付一千块钱租金，举个例子，这个就是小资产阶级关系、小资产阶级统治。

但如果是资产阶级统治呢？它背后的实质就是：我租你这个房子，为了租你这房子，我心里面高潮了，很爽，或者很痛苦、很拧巴、很激烈、很急迫。它内在化，变成一个享乐对象，或者变成一种异化力，把人卷入。

举个例子，美国的资产阶级把在纽约租上一套公寓看成是独立艺术家的第一步。这个艺术家为了租这个公寓付出了很大代价，然后租了一个公寓就爽得不得了。这样一套公寓就是一个三字头、一杠三的物，是个异化物。法拉盛租一套房子，对于想要移民、非法移民躲在那边的，那也是个异化物；但对于一般的美国老百姓，那就是个一杠二的物，不足以形成直接的对人的精神上的奴役。那么三呢？它作为享乐物就可以有这样的效果。

那么四的话，它就是非物。它不是物，本身不是物，而是被异化成物的东西，是被异化成物的非物。它不是物，但被异化成了物。这是一杠四。一杠四里面包含一些东西，比如爱情被异化成了物：它不是物，但被异化成了物。这个异化物可以讨价还价，可以买来买去。

比如智慧的高低，它不是物，但被资本主义学术、学术资本主义异化成物：买卖论文版面，我发过一千篇论文，每一个论文版面多少钱？这个版面给你，你帮我写文章，我写都不用写了，我掏钱就可以了。它被异化成了物，也是阶级物。它是非物，但被异化成了物，本来可以不是物。这就是一杠四。尤其是无产阶级的生命，无产阶级生命本身不是物……

他的生命、生活、幸福这些东西不是物，他的尊严不是物，但被异化成物。举个例子，一个底层被压迫女性，她的尊严不是物，但通过侵凌她的肉体、逼迫她出卖肉体，或者引诱、诱导、蛊惑、欺骗她去出卖自己肉体，把她的尊严变成了一个物，变成可交易物，六百块钱、一千块钱。这种被异化成物的非物放在四，所以被异化成物的非物在这里叫无产阶级：它属于四杠一，属于四字头，也属于一杠四；作为物，作为被异化成物的非物，它也是。

它属于一杠四。很多无产阶级没办法，在生产过程中，他的劳动本身就被异化成物，凝结在商品当中；商品本身要被定价，他的劳动本身也被定价，反过来牵引他的劳动被定价。那么这个一杠四就是非物，非物也是物，也是阶级物，也是 class age 的一部分。class age 一定要看到：阶级物不是 class thing，也不是 class item，它是指 class age。class age 是一个象征秩序，整个物的秩序是一个物化的象征秩序。所以一字头里面是一整个物化的象征秩序。

一杠四里面尤其是精神创伤，它是非物，但也被异化成物了，很多都被异化成物，这会引起很多病理化、很多变态，这在一杠四也很正常，生命的创伤、痛苦。这个一杠四里面也有非物，比如宠物。宠物是个生命，也不是物。我们划的这条线是：只要你是动物，可以和人进行一定活动性交流的动物，宠物也被异化成非物。那么宠物就介于一杠三和一杠四这个节点上。你看，一杠三是个享乐物，是能够具有异化力的物；宠物介于一杠三、一杠四之间，我们会找一个点位。

所以我们今天讲的就是这个一阶级物。这个一就是 class age，它其实代表象征秩序，物的象征秩序，一整个物化的象征秩序。这个物化的象征秩序让你幻想这个东西是稳固的、可交易的、可以自动移动的，好移动的，移来移去的。那么要说的话，一杠一很简单：如果从产品来讲，一杠一是产品，一杠二、一杠三……

非要说一杠一，就把它说成商品；一杠三这里可以是资本，资本实现在一杠三这边，它是 alienating，我们用这个词 alienating thing，一个正在进行异化的东西。一杠四就是 an alienated thing，但它是一个 nothing，不是一个东西，是 an alienated nothing。它被异化成了一个东西，其实它不是东西，它拒绝承认自己是物。

一杠二就是……一杠一的话，它是个理想，一杠一其实也是个理想状态，某些直接物、某些自然物。而在一杠二里面，自然物已经开始有了法权，我们要法权性的物。我不认为只是法权物，这两个东西都已经开始有物化。比如你把抽离的一个关系把握成一个稳固的东西。但凡在一里面就已经有异化了，最低限度的异化普遍都有。

普遍都有。这里面所有东西都可以说它是 alien 的，所有这些东西都是 alien 的，as one, it's an alien one。它和人的存在是异在的，所以整个是个 objectivity，整个是个对象性；整个这个位面都是对象性的位面，它总归是一个 alien one。但它起到 alienating 的作用，内在让主体臣服，让个体臣服、征召成主体。要到一杠三才可以，现代主体要被征召为现代主体，要到一杠三。一杠二还是前现代；一杠一则是动物时期或原始部落时期。但并不是说你进入现代就只有一杠三了，一杠二和一杠一同时还有。你要克服一杠三的很多矛盾，你要返回。比如我们评价内燃机，内燃机、你车上的发动机，一般都属一杠一，还是属于一杠一，明白吗？
