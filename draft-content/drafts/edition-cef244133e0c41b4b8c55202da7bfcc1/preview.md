# 【主义主义】分类性的叙事主义（3\-4\-1\-3）——过分精致的文青哲学：从写作的零度走向本体论的丧失，罗兰·巴特的泛叙事学策略

我们今天要来讲主义主义的三杠四杠一杠三，代表人物是罗兰·巴特。他的体系，我把它叫做 taxonomic narrativism，也就是分类性的叙事学。

罗兰·巴特在哲学上不严格，这个人很不严格，实际上是一个文人；也就是说，在哲学上他不太配被称为哲学家。可以说，列维\-斯特劳斯拎了他一把。

我们知道，结构主义运动始终有一个问题：它少两个东西，一个是时间，还有一个是主体。结构主义的重大问题就在于这两个它都没有。

它可以完全悬空，能指链完全悬空，整个世界就是符号，全是符号，但你总得有主体，总得有时间，总得有共时性原则。所以它如何从共时性走向历史性？我要强调，从哲学上讲，像皮亚杰的体系、皮亚杰的发生学体系，即心理发生学……

那个所谓结构主义的心理发生学体系中的一切历史性、一切发生性都是虚假的。为什么？因为它预设了实证主义主体，预设了科学主义、经验科学报告、实证主义的主体视角，也就是主体的大他者视角。

所以我不认为皮亚杰是真正够格的结构主义者，乔姆斯基也是，他们都不是够格的结构主义者。如果我们把结构主义看成一场哲学运动，就应当把它看成类似费希特知识学：费希特知识学从纯粹主体性走向客体性；结构主义运动则反过来，要从绝对的他者性——同质化的、匿名的、非人称的他者性——走向意识化的、有主体的、有我他二元对立的、可以中心化的、人称化的方向，从无我走向有我，就这么简单。

结构主义运动只有这样，所以它一定会走向精神分析。你了解吗？结构主义运动最后一定会走向精神分析，它会和精神分析汇合，就会变成拉康。

如果结构主义运动仅仅停留在政治批判、意识形态批判、文化批判，这都不够，一定要走向主体性，重新为主体性奠基。这才能恢复哲学的普遍性，结构主义才不会是一种荒诞的无我论——那里的人都带有自杀性，比如阿尔都塞、罗兰·巴特、福柯，他们就是无我论的病症。你理解吗？结构主义是有毒的，我再强调一遍。

按照我的书写，所有结构主义运动在这里还是分类性的叙事学；到了福柯那里，就不是分类性的，而是谱系学。谱系学要搞出主体和时间，也就是要让这个作为绝对平面、共时性平面的结构主义获得纵深，获得历史性、时间性，甚至能跟现实世界中实实在在事物的发生接轨。

这是结构主义运动的绝望所在：由于它是共时性原则、差异性原则，又是匿名性原则、非人称化原则、无主体性原则，所以它要真正变成一个活生生的哲学，就一定要把头长出来，长出主体性，要有头，要有脸，要有面孔，要有列维纳斯式的面孔学，要有一个绝对的大他者。这个运动在罗兰·巴特这里是失败的。他做出一个尝试，即叙事学的尝试，使符号学进一步变成叙事学。

罗兰·巴特后来走向解构主义，他没有走向后结构主义——后结构主义没有罗兰·巴特的位置。他走向解构主义，所谓互文性，或叫文本间性。所以他的体系前期靠分类学，different kinds of coding，各式各样的分类。

罗兰·巴特自己还没有很清楚意识到，所指是一个神话，所指这个神话不能正儿八经地对待。比如他写服装、广告这类东西时，还傻乎乎地把所指看成具有神话学地位，或把所指看成具有文本学地位，这都是错的地方。他再进一步用能指和所指的关系区分了几种符码（codes），这很糟糕。作为哲学家看，这很糟糕。你可以说列维\-斯特劳斯身上有实证主义残余，罗兰·巴特身上也有实证主义残余；这别怪他，因为他那些东西写得太早了。他是依靠符码的分类学，比如他还有另外一本书，两个字母中间加个横杠，那本书叫什么我记不得了，里面区分了好几种符码。

这些符码分类眼花缭乱，但都是虚的。他自己在炮制这些符码分类时，把巴尔扎克的小说分成多少个叙事单元、多少事件或语言单元，比如哪些是主题性的，哪些是什么。他把一本小说里的文本拆成几百种，但总共好像是五大类符码，有什么 image code 等等，我记不得了，反正有好几种 code。我不想跟你扯这东西，因为在我这个哲学家看来，这个分类学屁用没有，它是用来制造虚假纵深的，因为他自己对结构主义领会得不够彻底。但他设置的叙事学在某种意义上要求我们区分两种东西：作为文论、作为文学批评文论的蛇皮结构主义——那种结构主义竟然还让所指具有某种俨然可用的地位；而在哲学里，结构主义意味着只有能指链，只有能指或一些特殊能指，比如悬浮能指、中心化能指、主人能指，只有这些东西才具有结构主义地位。

如果你还认为所指可以作为某种分类学依据，认为不同的能指和所指有不同关系——有的是直接关系，有的要转一转，有的是反向关系——如果你还用这种能指和所指之间的关系去设立文本分类学或文本单元分类学，这已经是蛇皮了，这不够结构主义。我再强调，这已经不够结构主义了。

罗兰·巴特因此通过符码分类，把语汇赋予形式，不同的形式和内容，内容填充在基本分类学里，于是你对文本就可以有横向阅读和纵向阅读两种阅读：把同类的归并到一起，在形式上把它看成纵向阅读；把它铺展开、切割开，一环套一环地线性阅读，就是横向阅读。罗兰·巴特用这种蛇皮分类学使文本具有某种纵深性。但我要说，这个东西只在作为垃圾蛇皮语言学或蛇皮文论的蛇皮结构主义里有纵深性。真正使结构主义模型具有一定纵深性、符号学拟制的纵深性的，是他的叙事学，而且是他的广谱叙事学。广谱叙事学就是一个广义符号学。

广义符号学、叙事学的哲学贡献在于，它使生活当中一切东西都变成叙事，都具有某种发生性机制；但这个发生学机制可以存而不论。所有文本、所有体验、所有社会意识形态、所有感知、所有具体现实、所有社会秩序、社会规则、人际关系，都可以看成文本，都可以作为叙事系统、符号系统。这个姿态是罗兰·巴特通过写专栏对社会现象进行嬉笑怒骂。

也就在这个意义上，罗兰·巴特所追求的零度写作，所谓 zero level、零度文学、零度写作，最终使一切都变成写作，使一切都变成文本，everything is 文本。

但很明显，文学作品有自己内在的结构主义规则，有它内在的结构性秩序，或者说临时设立起来的一些结构性关联、一些内在张力，即文本内张力。通过写作和阅读——阅读本身也是写作——当然，罗兰·巴特后来会说，阅读本身就是写作，没什么差别。有的文本稍微难写一点，有的文本缝隙太严肃，写实主义那种比较只能用来读；有的文本缝隙比较大，比如法国后来那些神神鬼鬼的意识流小说，那是可以写的。但实际上它们都代表一种开放性，只有一个相对界限，没有绝对界限了。作者已经死掉了，叙事者只是一个符号学拟制。

但无论如何，叙事学使一种分类变得可能：人称化叙事和非人称化叙事。人称化叙事就是叙事中的人称化叙事。我们具体来看他的叙事学，即分类性的叙事学。具体来说，这个分类学在叙事学本身的架构里是分层性的叙事学，分层也是一种分类。所以它的场域论上对应叙事学的三层：一层叫做 function，功能层，或者叫函数层、函项层、功能层。

功能层是底层，是非人称化的底层，里面就是那些乱七八糟的符码。通过符码，功能层里有叙事单元，单元相互之间有关联、有关系。这种关系可以是逻辑关系，可以逻辑化，可以有因果关系，或者时间关系、发生学关系，也就是可以专题化把握的关系。这些关系就是所谓的功能。这些功能把整个文本——简单说，这一整个文本，或者它是个结构、是个符号系统——作为对象，这就是功能层，即它的最底层，是非人称化的。

另外一层是人称化的，叫做行动层还是什么？行动层吧，我记不得，可能弄错，你不管。反正另外一层是人称化的，里面的行动层有一些单元，由于它们有人的名字，或者具有某种身份地位，那些能指在更大的叙事层面、更大的语境中可以人称化、人格化，所以就会人称化，变成一个行动层。这时阅读的张力、阅读的趋向性就开始出现，也就是主体在阅读。这边对应拉康的想象界。这里面有镜像误认，就这么简单。它人称化，但这个人称化是虚假人称化；这里把一个人物看成一个人，都是虚假的，都是镜像化，都是虚假的人称化。

功能层对应语言，对应语言底层机制，即底层的结构主义机制。它们的相互关系就是各单元之间逻辑化的关系；逻辑化关系归根结底是差异性、共时性的关系，即共时性的差异性关系。那么这两层由谁来协调？由叙事层来协调。

叙事层能够产生一个效果，就好像让你觉得——当然叙事层为什么能起作用？因为这里面有博弈，有读者的意识、读者的能指链，也有写作者。它代表叙事者，不叫写作者，叙事者；写作者已经死掉了。它代表的是叙事层，代表文本的开放性。我再强调一遍，因为在罗兰·巴特体系里，叙事层是个兜底的东西，什么东西都在里面。这两层很好分辨，但叙事层使文本产生一种叙事效果，好像在讲一个流动的、具有时间性的东西。这个机制是怎么出来的？

这一层比较含混。叙事层里没有动力学机制，我再强调一遍，这里的动力学机制是假的。比如一个人物被别人骂了一句，他生气了，又怎么怎么样，这个行动层只是行动层，它不是真正的叙事层。否则文学就不称其为文学。文学不是一个个事件人称化，然后动起来就是文学；文学要让你感觉到它在讲述一个世界。能够让你感觉到讲述、编织起一个世界的，要靠叙事层。叙事层里有叙事者，也就是作者。作者在里面施加的一些结构、一些关联，还有读者，读者与现实意识形态之间、与其他社会意识形态之间的纠葛、羁绊，包括读者自己可能就是一通一通意识形态。它能够产生这种效果，让你感觉到文本是活的，是一个世界，是一个有世界的故事。它不是噼里啪啦地讲故事，而是会有一个世界出来。这个时候才会有所谓的叙事层。整个这三层构成一个叙事，或者构成一个叙事体系。

但在罗兰·巴特那里更进一步，本体论上是四，这个四意味着不仅仅是这个。当然，这是文学，文学本身是零度写作，对不对？罗兰·巴特认为，只有零度写作的文学作品，只有让文本内在的符号学机制、符号学张力自如地生成自己，按照文学本身的规则去生成自己。这个零度就跟精神分析里要求患者自由联想一样——怎么可能零度呢？做不到。但罗兰·巴特就是说，我先占一个制高点，我是绝对独立的，不受所有其他意识形态影响；文学就是自由创作，在绝对自由的结构拼排组合里都有解放性、突破性的东西。然后他就可以去骂其他意识形态。但他自己的叙事学走到后面会承认：不仅仅文学作品处在零度、零阶维度，而是一切都是共时性、差异性的能指系统、符号系统在进行无限的排列组合游戏，而且其他所有政治、经济、文化、艺术，具体生活、第一人称体验、感知、思维、反思、哲学、精神分析，所有这些东西都同样处在符号系统的零度层。

所以在本体论上，它使叙事广义化，叙事体系广义化，整个世界就是一个叙事。你写的一篇小说和你自己亲身经历的体验，如果可以全都消解成叙事单元，就是一样的。你小说里写的是这些能指、这些符号，你生活中体验到的是另外一些能指；那些东西不能叫所指。比如我这里手指头的颜色，也不能叫所指，它也是悬空的能指——有什么光亮、什么颜色、弧度，就是你看到的这些 image、这些图像，这些东西也可以拆分成能指。这就是一个广义叙事学，一切社会性——因为我对手指的把握也会不可避免地把它能指化：它是个手指，它是个直的东西，或者带点弧度，你看都是能指。包括这些色块、纵深感、三维感、生理学功能、社会意涵等等，通通都是能指，通通都是一个广义符号系统。所以这个分类性的叙事学，在这个意义上，我说它抵达了哲学的结构主义水准。了解吗？

然后在认识论上是一，就是零度写作。坚持零度写作，表现在他作为一个社评家嬉笑怒骂；他把嬉笑怒骂的东西好像还编了个集子，你可以去看看，可能比较有意思。如果你要在报社任职，或者写自媒体，可以平时读读罗兰·巴特，他就是拆解那些结构分析。他就是这样，用一个结构、弄一些类似结构去套世间万象，用结构主义分析、用结构分析去套一切社会现象、一切意识形态，好像都被他拆解了。但问题是他这样很容易转向解构主义。他会告诉你最后转向解构主义，告诉你没有什么结构，结构本身是个效果；你没有这个共时性的面，这也是符号学拟制，说有一个共时性层面，本体论上这个四甚至也是拟制。

你要意识到，结构主义预设的——特别是广义符号化或广义叙事学化了的结构主义——认为一切都是符号，一切都是叙事，这就设定了一种在场形而上学。整个世界符号学里的单元要素全都在一个共时性体系里面。但这个共时性机制没有办法维持住，会有结构主义者回去重新思考时间问题，提出演绎，重新思考这个符号场的发生学机制。

然后在目的论上是三。我们讲，在列维纳斯那边一直做一个神话，即那个能指的一零震荡、两极震荡、一零震荡的循环；而在拉康那边它要纵深化。拉康那边一零震荡也会有镜像，然后要有符号系统，要有象征界来实现纵深化，也就是自我的指涉需要纵深化，不能短路和镜像短路。它需要一个最低限度的不在场的自我，自我要感受到自己的不在场性。早期拉康一个很重要的一点，就是把黑格尔辩证法的否定性原则引入结构主义运动，使不在场本身变成一个很积极的、哲学上本体性的力量。不在场、缺失不是缺如的无，不是什么都没有，而是一个很强的力量，它代表着符号系统没办法俘获、没有办法把握的那个力量。这样才有纵深化。这样我们才可以回到观念论语境里去探讨前本体论。

然后在罗兰·巴特这里，协调两者的，我认为就是所谓整体主义、整体化。或者就是他把符号学原则，或者叫结构主义的原理、结构主义的差异性原则，往外推广。他在局部就是局部整体化。可以这样说，局部整体化。这就是在他走向互文性之前，在他走向文本间性之前，他的所谓局部整体化策略。这是他的结构主义策略，是罗兰·巴特的结构主义策略。我可以看局部，但可以理智地把这个局部当成整体，以偏概全，实现一个局部整体震荡，局部和整体的一个震荡。

我可以先分析这个结构。它是一个符号学上拟制的、有优先性的文本结构，来把握到一些结构，把握到一些文本的内在结构，比如俄狄浦斯情节；然后再用这个结构把它套到其他结构、其他文本上。原则上一切都是结构，一切都是文本结构，一切都是符号系统。这个符号系统内部的结构能够被这样把握出来、显现出来，是因为外部符号系统的张力。但我可以先指认，可以先无视外面其他符号系统对我的差异性张力——那叫法西斯的棍棒，那个差异数——我可以先无视它们，先从我的局部得到一些结构，然后再由这些结构出发，扩展到外部的。它是单向的，有点单向：先从局部走向整体，再去批判各式各样的意识形态。这个局部首先就是文学。文学实现了一零震荡，文学本身实现了对于世界的文学化，对于整个世界全体的文学化。

它一零震荡嘛：要么文学是一个零，是一个零阶自由写作，里面没有任何意识形态预设，没有任何偏见，没有假设，全是文学的自由创作，是所有人类文本的自由组合；但另一方面，文学又使整个世界文学化。所有意识形态、所有现象，这个世界当中的广告、服装、消费品、生活体验、精神状态、心理状态，政治、经济，所有现实都可以被文本化地把握，叫文本化，整个世界的文本化把握，通过叙事学、通过叙事学机制。因为世界好歹肯定是发生性的，肯定有发生学机制，那么叙事学就可以架构到——就把你的世界历史这种善变过程都看成是可以平铺到一个共时性的、把你的叙事结构平铺到、把你的发生学历史性的结构平铺到一个共时性维度里面去探索，平铺到一个叙事学框架里面去探索，进行结构主义分析、结构化分析。
