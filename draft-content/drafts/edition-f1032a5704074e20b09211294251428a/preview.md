# 【一刻钟哲学】两种主体之庸俗的主体

我们要讲的是两种主体，不是两种主体性。我们日常生活中或一般语境里所把握到的主体，实际上不满足于传统观念论，也不满足于西方哲学传统、笛卡尔所开创的现代哲学传统。现在哲学里流行的主体有两种。第一种是我所说的、普通人理解的主体，或者说一般人类学研究或比较主流的认知主义研究中的主体；他们已经不再研究传统笛卡尔意义上的主体了。不是有一个叫“笛卡尔的谬误”吗？

有一本书，它现在开始研究的主体叫 agent。我个人比较把它翻译成“能动者”，或者叫……它其实还有特工、代理人、代理商的意思，比如特工 007 就是 agent zero zero seven；动因也是这个词。为什么提出这样一种主体呢？

它实际上也是一种主体样态，但已经不再把它叫主体了，因为传统笛卡尔意义上的主体就是专门的那个主体。提出这个主体的目的，是为了抗衡、或者说掀翻笛卡尔式那种原子化的、或康德式那种纯粹理性式的主体，取而代之的是一个参与到和不同客体之间互动的主体，或者说在一个相互交互的 interactive 网络里面，它是一个比较具有能动性的主体。我认为这是一个失败的范式，因为它实际上很庸俗，和普通人心里面、或者科学共同体和理工科知识分子、科学实在论者头脑中想象出来的那种比较迂腐、庸俗的主体是对上号的。所以它是一种不太具有反思力的主体范式。

还有一个主体就是 subject。这个就是近代笛卡尔意义上的主体，实际上就叫主体。subject 这个词和两个东西相对应：一个是 object，即客体或对象；还有一个是 substance，即实体。主体处在和 object 以及 substance、和对象和实体的这种关系里面，它是一个三元关系。

那我们接下来一个个细讲。先把画布清一下，等一会儿。我们先来讲 agent 这种主体，第一种主体 agent。

它带有一种平等主义的观点。我用一张图来显示：用一个圆表示这是整个世界——我画的圆不圆，不好意思，重新画一下，太丑了，画一个稍微椭圆一点的形状。如果这是一个世界，这就是整个 world，或者整个场域 field。那么 agent，一般人脑子里面理解的主体，就是能动者、主动者，或者叫主动的个体：主动认识、主动改变、主动去实践、主动去解释、把握其他对象。这种 agent 像什么？它好像游戏里面的一个角色、一个英雄一样，他是英雄，he is a hero。然后其他客体、其他 object 就是小兵，比他小，其他就是小兵。

在 hero 和这些小兵之间会互相发生关系、互相发生关联。这种关联就会形成 phenomenon，它们之间的意向性就会变成现象。现在的认知主义或者一些具身化的哲学就认为，由这些现象，他们套用量子力学里面的一种观点，把这种过程叫做 diffraction，叫做衍射。就好像你学了量子力学，就知道现实的那些物质本身，是一个波函数衍生、衍射出来的产物；它并不是有一个实体化的东西在里面。

所以他们认为，笛卡尔式的主体 subject 是一种现象。它是更原初、更原本的 agent 介入到关联、相互关系当中去。介入到这种相互关系当中的 agent 发生了关系、发生了关联之后，产生的一种抽象出来的、比较普遍的现象，这个现象就会被把握成抽象的笛卡尔式主体性。这种主体性会错误地把一种相互关系把握成单向关系，于是就变成一个原子化的主体。这个原子化主体也是悬空于整个 world 之上的。subject 可以悬空于整个场域之上，对它发生一种认识，即认知主体，一种纯粹孤胆英雄式的、上帝视角式的，可以认识整个世界。subject 可以把这整个东西、把它自己的 agent 当成一个对象来加以认识。这是当前哲学里面比较流行的一种主体范式，叫做 embodied agent。

embodied agent，具身化的主体。有的人不会把 agent 翻成主体，或者叫具身化的能动者；他们喜欢说主动的个体，具身化的能动体、能动者，像特工一样。这个玩意儿兼有一种化身的意味在里面：代理，它是一个代理，或者是一个代理平台那种感觉。所有各式各样的这种他者，这种意志性的他者，它发生一种关系、一种建构性的关系，或者叫衍射，衍射出了那么一种实体化的中心。所以这种新的主体范式是去中心化的，是在这种相互关系当中去把握整个世界的。它是以现象取代了所谓的实体，取代了所谓的本质性的东西，取代了本质。这是一些当前的哲学家喜欢搞的，特别法国人喜欢这样搞；我看英美分析哲学里面也有好多人接受了这个范式，这个 embodied agent 范式。

齐泽克，或者说拉康、黑格尔——在我看来是观念论哲学家——或者一些辩证唯物主义者，德里达、德勒兹，还有包括海德格尔，他们都不同意这个范式。这个范式是资本主义学术异化下面产生出来的、对哲学本身的革命性进行阉割的一个范式。这不是一个非常好的范式，因为它非常明显地和我们日常生活中对于主体的想象是重叠的。

因为我们日常生活中就是把主体设想成我们日常的、矮化的主体。它是一个矮化的主体，重点落在“体”上。其实 subject 不是一个体，it's not a body，它不是一个 body，它没有 embodied。subject 是没有 embodied 的。但是我们中国人就会把它翻译成 body。其实我们中国的官方哲学，或者说我们教科书里面教的那个主体，就是主观能动体，实际上就是 agent。我甚至说，我们大天朝的哲学教育领先国际，不知道领先多少年。因为统治阶级最敏锐了，他知道如何把哲学割一刀，让它变得庸俗一点、钝一点，可以让下面聪明人陷于一种自我蒙蔽，或者不能够去把握一些真正关键的一些矛盾。

这个东西和日常生活当中的想象图式是非常紧密贴合的。我们日常生活中就把世界想象成一个轴是空间，一个轴是时间。然后一个 agent、一个主体就在这里面运动，从这个空间——它是中心嘛——从这个中心出发，它把握了各种万事万物，把它们把握成所谓的世界、事物，包括宇宙、自然、他人。这些东西都是在这个矩阵里面，都是在这个场域里面的。然后这个主体一般会身体化，它会有身体；其次，它是中心化的，它坍缩成一个中心。这是中国人。其实中国人对于自我的把握就是非常非常 agent 的，it's very traditional Chinese thinking style，这是非常非常中国式的一种思维方式。我觉得这是中国传统哲学的一种，它把自我看成是一个自身；也有人把 agent 什么的翻译成自身。

自身性，一个中心化的受体。实际上，这玩意儿与其说是主体，不如说是受体。它当然也是一个能动者，可以和其他东西发生关系。我们大部分人的自我意识的觉知就是这种，就是这种自身化，或者叫具身化。它是具身化的，然后是一个中心化的，和其他东西同时在场的，在同一个场域里面，在同一个当下时间性和空间性的场域里面共在的，也就是在世存在。海德格尔看来，这种存在很容易陷入一种常人状态，就是把自己当成各种物件当中的一个物件，把自我当成一个东西摆在这个空间场域里面，当然就变成所谓的自私：自私以自我为中心，所有的利益好处都要往这个中心去靠，他人都要为这个中心的第一人称体验、好恶、感性上的一些喜怒哀乐负责。这就是所谓的自私，所谓的中心化。

那么中国人呢，就是要你跳出这个中心化的、具身化的我身，跳出自己身体的局限。老子说“及吾无身，吾有何患”，差不多是这个意思。人嘛，就是要跳出这个，让镜像神经元发达一点，去感受别人的另外一个神，感受到另外一个神，感受一下，这就是所谓的人。那么就这样建构起一个社会化的、人情关系的一个网络。中国哲学基本上就告诉你怎么在这个人情关系网络里面去把握一个尺寸，把握一种规则和潜规则，怎么去玩这个游戏。

那么这个游戏大概来说就是一个模板游戏。这种主体性 agent 就是你里面模板可以操控的单位，可操控的英雄单位，可操控的单位。所以这个主体是游戏里面的一个你控制的角色，所以它叫 agent。其实如果你玩过一些做游戏的软件——哪个游戏软件我花了几百块钱买的——它里面那些动的单元就叫 agent、能动者。那一个个小的、游戏里面控制的小对象，它就叫一个 agent。那个游戏软件很明显把握住了这种哲学，体现出了这种哲学。

这种对于主体的理解，不是笛卡尔，不是康德，不是黑格尔，不是马克思，也不是什么一系列的德里达、海德格尔、萨特，他们理解的 subject 主体不是这个东西。比如费希特、谢林，他们把握的主体不是这个 agent，不是这个玩意儿。这个玩意儿是一个很不哲学的概念。它是一锅端的那种：你是一个东西，你是这个相互关系里面的一个临时的东西。那些哲学家讨论主体的时候，就不是讨论 agent 了。
