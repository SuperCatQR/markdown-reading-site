# 【经典译读】康德《纯粹理性批判》（连载中）

这是先验要素论中关于范畴的先验推理的过渡。康德说，只有两种情况能使综合性的表征与其对象必然关联、相互符合：一种情况是对象使表征成为可能，另一种情况是表征使对象成为可能。前者是对象激起表征，后者是表征激起并产生其对象。

第一种情况是经验性的关系。在这里，表征永远不是先天的表征；它涉及表象，尤其是感性表象，其中属于感觉的部分。这个句子很绕：就表象中属于感觉的东西而言，情况就是这样。

第二种情况是，表征本身并不产生对象。如果只考虑它的存在，它不能产生对象，因此它只是对先验对象的规定。若对象是可能的，它仅通过表征才成为可能。我们想要把任何东西体验为对象，并不是说表征创造了对象，而是说它给先验对象加上了某种规定。它可以唤起一个对象，但那个对象是先天对象，object a priori；这个对象不是由表征产生的，而是被规定的，例如被规定为空间性的、时间性的。这里 a priori 是副词，修饰“规定”，即“先天地规定对象”。如果说有先天对象，那就像齐泽克或拉康讲的 a priori object：它本身就能把某个东西当作对象来思考。实际上它仍然只是对先天对象的一种规定。

但对象认识只有两个条件：第一是直观，通过直观对象被给予，但仅仅作为表象被给予；第二是概念，通过概念对象被思考，并且以对应于该直观的方式被思考。从上面这些话可以清楚得出……

无论如何，在第一种情况中，即在对象被直观的经验性关联中，心智中事实上先天地存在着某种东西，作为对象形式的基础。这里 does lie 的用法有语法问题：作者可能因为插入的复数 objects 而把单数前项误写成复数。原文这里是单数，lie 应跟前面的 under which objects can be intuited 相应，即对象的形式基础先天地存在于心智中。也就是说，要把握直观对象，对象的形式、框架、用来盛放它的“篓子”，其基础先天地在我们的心智之中。因此，一切表象都必然符合感性的形式条件，即先天直观形式；只有通过它，表象才能显现，才能被经验性地直观并被给予。现在的问题是：先天概念是否也不会先行？也就是说，它们作为条件，是否也预先存在？只有在这些条件下，某个东西、对象、表象或心智中建构的对象才能显现。如果不是被直观，而只是在一般意义上被当作对象来思考，是否也先得有先天概念先行？因为只有这样，所有对象的经验性认知才会必然与这些概念相符合。

如果没有预设这些概念，就没有东西会成为经验的对象。除了时空直观形式之外，康德还要问：是不是还得有一些先天概念先行，使我们对对象的经验性把握成为可能？然而，一切经验除了包含来自感官的直观之外，还包含一个在直观中被给予的对象的概念，以及一些落实到具体环节的概念。光有时空这两个直观形式还不够，还得有概念。这里所说的 concept of an object 是在直观中被给予的对象的概念；或者说是显现出来的对象的概念。一般意义上的对象概念，各式各样的 in general 的概念，不是特指哪一个，而是普遍而言，它们都在一切经验认识的最底层，并作为经验的先天条件。这一点可以承认，但不能因此把认识分成一层框架，再乱七八糟地填满。

范畴的客观有效性，作为先天概念，取决于这样一个事实：只有通过这些先天概念，经验才是可能的。就思想的形式而言，这些概念必然地、先天地与经验对象结合、连接。现在他把它们叫作先天概念，apparently concepts，即先天概念。

也就是说，齐泽克把 object a priori 这个说法拿出来做文章。apparently 本来可以放在后面当副词用，如果写成 apparently object，也可以说它是先天对象；但他把它放在后面。康德其实是把这种东西拆成一些具体范畴，并不真的有一个 object 本身，有一个 object a priori。齐泽克这样做有点故意做文章。我们搜一下有没有 apparently object。这是第224节。搜不到 apparently object，只搜到 apparently objective，先天客观的；没有先天对象。后来居然又搜到了。文本里可能只出现一次先天对象。这个老哥看得真细。我印象中好像没有，但他在《言辞的否定》里好多地方讲到，说这个东西对应拉康的客体小 a。居然还真的有。好吧，回去看，第224页。他拿一个单词做文章，但确实有一个段落在讨论，也引用了那个段落。我那时想，康德是用先验范畴来架构客体性的，不需要一个影子式的先验对象，没想到真的有。先天对象，可以，厉害。

我们读到这里。结果是，这些范畴具有客观有效性，只要你考虑它们的思考形式。因为它们必然地、先天地和经验对象连接起来。只有通过它们，所有经验对象才可以被思考。但康德只说 be thought；我认为这里不够彻底：it's not only be thought，it's be。没有范畴的话，it can't be intuited，它根本无法被直观。光有时空，我很疑惑。哪个孩子没有沉浸在语言之中呢？这种概念化的努力是超空间性的。时空直观形式和先验范畴之间并不是可以明确分开的；这种区分只是为了康德拯救所谓先天综合学科的一种做法，不应该这样分。当然里面有界限、有边界，但机制比这复杂得多，不是直接两分就行。对于所有先天概念的先验演绎，因此有一个原则：整个研究必须朝向并依据这个原则。这个原则就是，它们必须被视作一切经验可能性的先天条件。这里其实很模糊，但他后面说了，无论是直观还是思考，也就是说，如果你……

没有范畴的话，it can't be intuited，它没有办法被直观。你光有时空，我很疑惑。没有哪个孩子不沉浸在语言之中；这种概念化努力是超空间性的。时空直观形式和先验范畴之间不能明确分开。这种区分只是康德为了挽救先天综合学科的一种做法，不应该这样分。我们继续往下看。里面当然有界限、有边界，但机制复杂得多，不是直接两分就行。对于所有先天概念的先验演绎，有一个原则：整个研究必须朝向并依据这个原则。这个原则就是，它们必须被视作一切经验可能性的先天条件。这里很模糊，但他后面说了，无论是直观还是思考。也就是说，如果你不懂概念，没有先天概念、先验概念，那你就会熟视无睹，两眼睁着也是盲的。你的直观也是空的直观、空洞的直观，像一张皮一样的直观。我的意思是，那种直观连时间和空间都没有办法组织。它不叫时空没办法组织，而是说一旦这种空泛的、没有概念的直观，它根本不存在，这是个理想情况。我们有时候一敞开，它立刻就会概念化，conceptualization，立刻会有构想，会有内在的软件系统，就像硬件自己组织成一套软件。你们听懂听不懂？这些东西都是硬件；说穿了，这些概念体系、这些先天概念好像是装在脑子里的软件，但实际上它也是硬件，只不过这些硬件把自己的粗重部分阉割、缝合起来，你体验不到它。它不会作为表象，不会作为颜色、色彩之类现成的东西被体验到，它是被缝合起来的。

这些概念提供了经验可能发生的客观基础，因此它们是必然的；没有它们就不会有后者，所以只要有后者，它们就是必然的。经验的 unfolding、展开、显现，并不是这些概念的 deduction，而只是 illustration，一个事例。比如我拿一个果子，可以说这个经验里有圆形。圆形某种意义上可以说是先天概念，但它仍依赖于经验。一个点、周围一圈距离相等的点，这些东西需要广延性、绵延，属于数学组成部分，是先天的。你也可以把它看成“它是圆的”这个概念。什么叫 unfolding of the experience？就是我把这个经验展开：它是一，是好多种不同东西组成的一个 totality，它是一个现实存在，actuality，等等。反正十二个范畴每一个都可以取一个，至少可以用四个范畴来描述它；unity 和 totality 肯定是用 totality 来描述。把经验展开，说它符合哪些概念，这种方式不是先验演绎，不是为范畴表中的范畴或先天概念的必然性做辩护，而只是举事例，告诉你我们在经验里一定要通过概念才能把经验组织起来。你看，从这里面我能把这些概念说出来，条分缕析地展开，发现它确实包含一些概念，确实有什么并列、一起占据一个空间等等。

如果这能算演绎，那么这些概念就会变成偶然概念：这个果子恰巧有，另一个果子没有；就算所有果子都有 totality，这种证明也不足以构成证明，不足以表明必然性，不足以说它是 deduction 或分析性的，因为你总有可能有一个果子不是这样。你要说一个果子，说“一个什么什么”的时候，就已经是一种先验演绎了，已经依赖于经验了。如果没有这种原初关系，没有与可能经验的原始关系，那么在经验中所有认识对象都会被发现，它们和任何对象的关系就完全不能理解、不能把握。它一定要有一种 original relation，这种原始关系指的就是先验 deduction。只有在先验演绎层面去证明这些概念是必然的，并且和这个 original relation——也就是上面说的 original relation——相关，才行。

要把握一个经验，我必须靠先天概念作为它的直观和思考的基础。不过有三种原初来源或能力，它们包含一切经验可能性的条件，并且不能彼此推导，而是并列、不能互相重叠。这三种能力是 sense、imagination、apperception。下面这些东西奠基在它们之上：感官提供杂多的 synopsis；想象力把杂多综合起来、拼起来；先验统觉或原初统觉把它变成 unity，比如把果子变成一个果子，把响指变成一个响指。感官把东西连接起来，但还没有装配成一个东西。这三个阶段有点像倒置的：感性给的是框架、梗概；想象力给的是 senses；最后原初统觉给的是 unity。想象力把东西综合、连接起来，最后靠统觉来分。统觉的 unity 看上去是整合性的，实际上也是划分性的。不管怎样，它叫 unity，就是独一性、单元性。unit, unit one, unit ready，打过红警就知道，unit 不是 union，不是牢不可破的 union。

除了它们的经验性使用之外，这三种能力都有一个先验的副本。除了经验性的 sense、imagination、apperception 之外，还有先验的 sense、先验的 imagination 和先验的 perception。它们只关涉形式，并且是先天的，即先天地可能。我很感兴趣，但这里有点怪。比如 empirical sense 如果给的是 synopsis of the manifold，那它只是给了一个大概，只是最低限度的组织度。我很想知道这里用的词到底是什么意思。关于感官，我们在第一部分已经讨论过了。

康德说，关于感官我已经讲过了。经验性的使用和这个……其实有点怪。empirical sense 说是通过感官先天地给了 synopsis，然后它又和 sensation 结合。这里面有主客二分，让人感觉思维怪怪的。Empirical sense 只产生那个 synopsis。那你的 manifold 从哪来？Where can I go to the manifold？这就像台上吹得震天响，下面人说“那我们呢？”manifold，这个杂多、多样性，感官本身的多样性从哪来？那我们呢？了解吗？这真的怪怪的。这个相当于……哎呀，我不能说不举例子，烦死了。

我们已经讨论过先验感性论，在第一部分已经讨论过了。但现在我们要尝试理解另外两种能力的性质。什么叫先验想象力？什么叫先验统觉？他说得非常……继续看吧。

有名的洛克忽视了这一点。因为他在经验中遭遇知性的纯粹概念，所以他也把这些纯粹概念从经验中推导出来，于是他的讨论前后不一致、矛盾。也正因为这样，他胆敢去尝试获得一些知识，这些知识远远超出一切经验的边界。因为那些概念其实来源是先天的、先验演绎出来的，他却说它们从经验中产生。如果我们老实巴交地思考一下，它确实从经验中产生，只不过这个经验本身不是一个僵死的、傻白甜的、naive 的、innocent 的经验。

康德在这里认为，经验本身没有神秘意义，没有神秘力量；经验中不存在超越性的力量。他把经验阉割了，或者说把表象阉割了。表象是蛇皮表象，只要它是表象，就不是永恒的，都是垃圾，不行，没用。但在洛克那里，经验中是有派生力的，经验是活的。这个“活”不是说它自己可以自治，而是说它当中可以产生知性范畴，经验有自组织能力。举个例子，就像东印度公司统治印度，觉得印度没有自我管理能力；过了几十年，印度派年轻人去牛津大学学习。牛津大学是不是英国的？我操，没文化，牛津大学好像是美国的？哦，是英国的，真没文化。差不多这个意思。你懂吗？其实它就是这种僵死的东西，被你看成完全静态、被动的东西，但它有自组织力。你的意识结构本身，被你忽视、忽略、贬低、贬斥、阉割成僵死的一潭死水，它其实是自己生成的，它的内在不一致性自己生成，你只不过是它的内在不一致性的一个体现，不是一个超越的主人。那个纯粹先验范畴是什么蛇皮玩意？它是这个世界本体性的一种僵局。它是世界通过意识这个中介显现成一些新概念形式时的概念本身。

它是世界显现的形式、装配形式。各种本体论环节、装配形式就是概念。康德不玩辩证法；康德的辩证法相当于一个小学数学老师用加减乘除去批改微积分作业，或者用加减乘除去批群论，因为符号长得有点像。这不是一个意思，什么妖缘啊之类，不是一个意思。

大卫·休谟承认，为了做后面这件事，这些概念必须有自己的 origin。休谟的叉子分为分析和综合，或 matter of fact 与 relation of ideas；matter of fact 是一切经验的来源，此外还有先验和综合的二分。但他不能解释知性如何能够思考概念，这些概念本身 not combined understanding，不是知性中装配起来的，却又必然和对象结合。他无法思考这些概念。因果、原因和结果 combine，休谟不能理解这种结合不是只在知性中被 combine 的；如果只在知性中结合，就只有概率学的、regularity 的、习惯性的东西，没有必然性。康德认为，原因和结果这两个概念是在对象中结合的，combine in the object；但它是在对象的表象中结合。原因性概念在对象的表象中结合，不是在物自体里结合。这里有分层：休谟是在心智中结合；普通人在物自体里结合；康德说是在物自体的表象、在 object as appearances 中结合。

物自体把自身的因果关系、内在关联表象化，呈现给意识主体、认识主体。这种因果性在康德看来具有合法性，也是必然结合在一起的。康德很大胆地写了 in the object，但后面没有写 in the object in itself，所以这里的 in the object 指的是在表象中、作为表象的对象中。

休谟这个低智商的人永远没有想到，也许知性本身通过这些概念就能成为经验的发起者，be the originator of experience；在经验中，它才会遭遇到自己的对象。所以康德这里是主动认识论：知性是主动的官能，主动牵引你通过概念去认识。但概念本身到底是经验论还是形而上学，是先验主义者还是实在论者，这有一万种解读。康德有四副脸孔：为了满足不同需求，逢人说人话，逢鬼说鬼话。他既要保住学术共同体，又要搞伦理热忱，还要让晚年过得有滋有味。人是多变的，他炮制形而上学框架、认识论结构，哲学家把它当成“你要吃啥菜我给你炒”。你不能说这口铁锅只能做川菜；那他如果得痔疮吃不了辣呢？所以不要吵康德到底是什么，不重要。康德那小脑瓜下棋，五子棋下八卦阵，他就会下八卦阵，那就觉得八卦阵无敌吗？不是的。你不要以为八卦阵很屌，有些小朋友学了康德，就觉得全天下下五子棋八卦阵稳赢。

休谟出于某种必然性，把概念从经验中派生出来，即从 frequent association 所产生的主观必然性中派生。A 和 B 不断联系出现一万次，就产生主观必然性。这种必然性是主观的、蛇皮的、一厢情愿的必然性。就像火鸡每天早上起来都有人喂它，到了复活节那天，没人喂它，而是一刀剁下去，血流到它自己嘴里。康德认为休谟把这种主观必然性错误地当成了客观必然性，也就是把习俗、习惯当成了因果性。但休谟接下来又很一致地推进，宣称不可能超出经验边界，因果性概念不能超出经验。那些由 custom 和经验性反复连接得到的概率性原理、科学原理，也不能超出经验范围。康德在这里夸他：你至少坚持了认识有限性的原则，把这些概念的使用限定在经验维度。至少休谟不像普通傻逼，普通人真觉得因果关系是物自体的、属于事物本身的；休谟说不是，它属于我们的主观必然性，是我们设立、瞎想、猜测、赌的。我们都是火鸡，起床叫两声有东西吃，没办法，最后看会怎样。

康德则折中一下——也不叫折中，他比休谟更休谟，比普通人更普通人，既赖皮又贪心，还显得很聪明。他说：我们一天到晚体验到一种概念性的必然关联，这说明什么？说明这是它向我显现的。它向我显现，它就这样装配起来。就像养鸡场主人用一种只有火鸡能领会的语言对火鸡说话，指向火鸡所显现的经验；就像人类表象指向人类显现。对于上帝或天使那种高级理智，不需要表象。所以我体验到的表象里有因果性，那就是最屌的。因为这是主人用只有我听得懂的话语亲口跟我说的：有因果性。那它就有因果性，这概念的连接是在对象中装配起来的。但这个对象不是物自体，不是天经地义，而是主人用只有我能听懂的话跟我说的，是只有人类能体验的表象向我显现的因果性。
