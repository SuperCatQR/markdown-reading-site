# 【四十分钟哲学】如何进行真正的哲学反思，如何破除庸俗的人文主义

四元矩阵里面，人类的本性（human nature）、自然的自然性（natural nature）、自然的本性，还有人类的人性（human humanity），以及自然的人性（natural humanity）。这四个东西的对立，其实分别就是语言、存在（大写 Being）、死亡，以及最后这个生命。人类内在最人性的东西就是生命。

庸俗的人道主义是怎样的呢？它只能把握这两个东西相互之间的关系，只能把握这两个格。庸俗人道主义蠢就蠢在只能把握 human nature，也就是 language、语言的维度，以及 natural humanity，也就是生命的维度。什么意思呢？它只能把握人当中那种有秩序、井井有条、美好的维度，也就是语言的维度，人内在有序、安宁、宁静、平和的维度。安宁的语言就是人文主义。我就说人文主义吧，因为一般的人文主义者都是庸俗人文主义者，百分之九十九点九的人文主义者是庸俗的人文主义者，是傻逼人文主义者。好吧？他们只能把握两个维度：一个是 human，只能把握 H 和 N 的交叉，要么把握 HN，要么把握 NH，只能把握人性和自然性这两种东西的交叉。它只能把握这两个东西交叉的一面，就是 human nature，人内在的有序、安宁的维度，那个本质。所以它会把自然想象成一种安宁的东西，或者说人内在的自然像一种安宁的语言，就是“有话好说，别动手”。另一方面，它只能把握自然所具有的那种有序、安宁的人性维度；不过这时候侧重的不再是有序，而是自然所具有的自由萌发、活力的维度，那就是生命、创生的维度。它只能把握这两个维度，只看见了这些东西。

他们只懂得用一阶的方式、一层的方式、first class 的方式去把握人性，还有自然人性和自然。他们不知道这两个东西可以加倍：humanity 可以加倍，自然也可以加倍。这两个东西一加倍，加倍出来的东西就是他们受不了的东西。
