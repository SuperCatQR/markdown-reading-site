# 【三节哲学课】终极形而上学：柏拉图一生最伟大的失败

我们现在梳理这八条命题的两两组合。它首先有对称组合。对称组合我之前讲过：左边都是一样的，一共有四种。抄作业：左边一和四都是“if there is one”，那么结果是什么？“the one is not all and the others are not all”，把 not all 写到最后，就是 the one is not all，the others are not all，结果都是 not all，非全。这对应的是在场形而上学。或者也可以看成 proto\-fascism，一种男权主义，是男性动物里特有的东西，意思你们自己去找。第二种对称组合是两个命题组合到一起：if one is。如果这个太一可以具体存在、可以显现，那么我们可以说：the one is and the others are all，the others are all，它们就是整全的。这是什么情况？这是犹太主义，也就是恐犹主义。说的就是把这个“you”当作一种恐惧。

有了这种恐惧，它可以解释一切。而且它是作为一个鬼魅般的太一存在在那里。这种东西看上去好像是什么纳粹主义，很粗陋，其实它是一种神秘主义，一种非常强的神秘主义。这种神秘主义可以理解成一种彻底去性化了的男性主义。我当年思考时把它思考成斯宾诺莎主义。所以我觉得，斯宾诺莎的理论里包含了恐犹主义的内核，因为斯宾诺莎本人是犹太人。他这种神秘主义也会导致一种……实际上你可以把它理解成一种上帝的自我凝视，在斯宾诺莎那里就是上帝的自我意识，是一种鬼魅般的存在，是上帝的永恒自我意识。这个东西你可以理解成一种彻底去性化了的男性主义。

彻底去性化，以至于他认为所追求的伦理目标本身就代替了女性性。这里的上帝不是一个蹩脚上帝；如果它是上帝，它就是一个全能、同时又极度可怕、极度可怖的上帝。而它的极度可怖也就是极度宁静，是斯宾诺莎那边极度宁静的上帝。这个上帝为了安抚他，会变成 the others，就变成自然神论。所以我认为，神秘主义发展到自然神论，实际上是发展到了高峰、到了极致，发展到斯宾诺莎这种静谧主义的自我直观，也就是上帝的自我直观。

不要说多了，我们再看下面一个：if one is not。如果我们拒绝斯宾诺莎这种诱惑，说太一不存在，并没有一个具体的存在，它只是太一的对应物，我们就会得到 the one is all / is and the others are all。我们拒绝太一的存在，不让它主宰一切，或者认为太一是否定性的存在，是一种生发性的力量，becoming。这时这个一就是全部，他者也是全部。这可以看成克尔凯郭尔主义。the one is all, the others are all，它们形成一种短路，对应着信仰与质疑、怀疑、独神怀疑同时存在，并且都达到极致；这时才是所谓的宗教阶段。懂一点克尔凯郭尔的人自然就懂这里说的是什么意思。这时太一是一种生发性的力量，一种否定性的力量，是在事物的边缘往外生长、展开、张开的那种力量，但它自己不具有自信，不具有自我同一性。所以它构造了一切，但反过来说，它构造了一切，却只能让不是它的那些东西占据整个场域。虽然这是 the one，你没发现前后逻辑矛盾吗？if one is not，太一是生发性的力量，但不能直接在场；后面又说 the one is all。如果我们用逻辑学而不是形而上学去理解，这他妈就是放屁：the one is not，the one is all。你不觉得互相矛盾吗？is not 了，怎么 is all 呢？所以这时你要看到这种短路：这个 all 等于这个 not，也就等于 becoming，等于生发的那种力量。这个全部是一种动态的全部，一种否定性的、不停超越性的全部，是超越性的力量，所以它不停地生成，从 being 上面、从存在当中不停生成出一种力量，从 is 上面不停生成出一个 not，一个 not is 的东西。它是这样一种力量。所以你可以理解：the one is all，它存在为 all、存在为一切，这个 one 本身不存在，但它能够存在为一切，它可以 become everything；它可以存在为一切，但它自己不存在，它生发出这一切，这是存在论上的生发。然后 the others are，其他东西存在，所有他者存在。这个 one 本身是掩藏起来的，没办法被直接把握。这种存在主义就是克尔凯郭尔的存在主义，是原汁原味的存在主义，不是海德格尔后来把主体性维度塞进去的那种，不是一种形而上学的、很标准的存在主义。这种立场可以看成……我现在想，之前我说斯宾诺莎是彻底去性化的，它到底是去性化还是超性化呢？斯宾诺莎那种应该是去性化的；而克尔凯郭尔主义，看上去又像男权主义，其实它应该是一种女性主义立场。克尔凯郭尔主义应该是一种女性主义立场：becoming 要高于 being，就是 not being，或者说 be not be，not 是非，以一种不存在为目的来存在，大于存在本身，优先于存在本身。在本体论上，太一是没有办法现身的，它永远掩藏在那边，永远使得别的东西能够借助它的力量生长出来。这也就是存在者存在。存在者存在就是这个意思：the others are all，它是通过借由这个 one，借由这个不存在的 one 的力量，一种无的力量生发出来的。那他是男的还是女的呢？应该是一种女性主义，因为虽然没有直接说，但它是一种前反思的女性主义，我感觉是比较少女的女性主义，还尚未进入菲勒斯性化秩序的无知女性状态，还天真地认为有一种生命力在那边涌现、生成。
