# 【主义主义】顺从主义（1\-4\-4\-1）——“小人”的哲学，随大流、随波逐流、占小便宜、沾沾自喜、“人家都这样”背后的隐秘机制

我们要讲主义主义中一杠四杠四的第一个，也就是一杠四杠四杠一，即庸俗主义。庸俗主义下面的第一个，理所当然、也比较容易想到，就是顺从主义。

顺从主义叫 conformism，conform 就是顺从的意思。它一般表现为随波逐流、随大流、从众。“从众”这个词很有意思——从众的人，你做什么人都可以，但不要做一个从众的人。你看“人”字，撇来撇去，一点横竖都没有，一点骨气都没有。随波逐流、从众、随大流，这个东西在场域论上是一。这个场域其实并不结构场域，它不叫场域，而叫“大家”——everyone、everybody 或者 people，这种大家。本体论上是四，就是完全不懂、完全不反思。这里的四意味着它会恐惧。这些人看恐怖片就特别怕。可以把它描述为匪夷所思、细思极恐。认识论上也是四，这里可以用 unheimlich（heimlich 加 un）或者 unkind 来表达，英语翻译就是：我稍微想一想，就让我害怕得不得了。所以他们不反思，在本体论上不反思。比如他们本体论上最常有的就是死亡问题，死亡驱使他们随波逐流、随大流。他们在思考死亡时就会觉得好害怕，然后就转回来，看到现实世界的一些秩序，默认了现实的本体论秩序，默认这些东西是真的：钱是真的，今天吃了一顿好的，都实实在在。

认识论上它是四。他在认识论上要区分所体验到的现象是真的还是假的，但他也不反思，根本不思考。这些人就是莫名其妙。遇到理解不了的东西发生，他就直接归类为“莫名其妙”，说这个东西我不懂。他不会有问题意识，会很快缝合起来，但里面没有一致性，也不追求维持认识论上的一致性。他既没有对抗，也没有要求自己所认识、体验到的一切必须有一个合理、完整的解释；他不这样，就是莫名其妙，我也不知道啥。会有这种状态的人，普遍受教育水平比较低。莫名其妙，it works 就行：这有用，起作用就行，能行就可以了。

目的论上是一，那就是随波逐流、随大流。这个一就是大家的规矩，或者就叫规矩、讲规矩，也可以叫从众。无论怎么表述，实际上就是大家都说好的东西，很容易从众。

他的思考很容易被影响。我描述一个现象：那边送鸡蛋，送几十个鸡蛋，大家都说好，然后一窝蜂跑过去拿鸡蛋。拿完鸡蛋之后，就听那边胡吹，开始吹什么养生锅特别好，或者养生茶杯特别好。这个时候，那些大爷大妈——我不搞性别，也有年轻人，不搞年龄歧视——甚至也有受教育的高级知识分子，我不搞学历歧视。反正这些人里面有一两个可能提前收了好处，我买我买，可能就是托。托一喊“我买我买”，其他人一看，哎，还有这个便宜好占，我不仅有了鸡蛋这个便宜，还可以占另外一个便宜，于是也去占便宜。所以目的论上就是这个一，我甚至可以就是占便宜，take advantage，占便宜。有便宜不占？就占便宜。就是随波逐流、顺从。他为什么会顺从？归根结底是因为他认为顺从是什么？是占大家的便宜，他认为顺从就是搭便车，占大家的便宜。

所以我跟你讲，顺从主义里面包含着一个东西。它看上去完全令人绝望，其实不是。顺从主义里面包含了一个最低限度的反抗——the minimal，有一个最低限度的东西。这个顺从里面的最低限度就是它的内核机制。顺从主义骨子里是什么？我跟你讲什么叫顺从主义。

举个例子，玩斗地主的时候，大家都下顺子，这边下个小顺子，那边又下个顺子，三个人轮流下顺子，连续下了好几把顺子。顺从主义者是什么样的人？他觉得我可以占大家的便宜。比如他下顺子时，自己那张牌里可能是六七八九十、J、K，对不对？他占了一个便宜，就把什么东西塞进去，把九用一张八偷偷塞进去。你也在下顺子，牌一把甩出来，他也下顺子，偷偷塞一张，把对八甩掉；又偷偷甩一张，然后下顺子又甩进去。顺从主义者就是在随大流当中偷偷塞一点点东西让自己获利的那种人。所以在这里，占便宜，一定要占便宜，了解吗？顺从主义者的核心并不是为了维持秩序，他有一个最小最小的差异、一个反抗，或者一个赖皮，或者某种 make some difference 的小姿态。这个最小差异本身使得他顺从了。也就是说，顺从本身永远是通过 a minimal rebel、一个最小的反抗、最小的 reaction——我最小的拉开的最小距离——这个东西就能满足他了。

在大家都随大流的情况下，我能够用最小的技巧隐秘地骗到他，deceive the big Other。大家就是 big Other，这个“大他者”；我忽悠他，那你就是顺从主义者，了解吗？顺从主义者。因为这两个词很有意思。

你看“顺”这个字，一撇当头，一竖短一点，三笔都不一样，看上去大家都聚在一块，其实都有差异。我在这里用这种方式，是想说服一些人：如果你把“顺”写成那样，就不好看了；人家反而觉得你这个人太古板、死硬，严格遵循规则。严格遵循规则的人反而有反思，不是随大流。严格遵循规则，他知道为什么要遵循规则吗？有两种情况。一种是他知道遵循规则总体利益对我有好处，能提升自我利益，这很清楚，总体利益提高，也是一种睿智。比如通过排队这种方式，大家都排队，很严格地排队；随大流的人反而没什么规则意识，他要占小便宜，占大家的便宜，所以他随大流、随份子，看着人家都去炒这个股，他也去，了解吗？另一种情况是，他把遵守规则本身当成目的，有点变态；循规蹈矩本身让他爽，遵守规则本身那种刻板、死板，有点禁欲主义，克制自己的欲望，拼命把自己缩成一个正方形——本来是个圆形，拼命把自己缩成正方形。他跟自己周旋，能体验到一种异样的、病态的快乐，一种强迫症式的快乐。这两种情况都不是随大流，严格意义上讲，他们的主体性都很强烈。

但是随大流的主体性也强烈。主体性这个维度永远没有办法通过服从于哪个秩序被压抑掉，它不会被压抑。一杠四杠四中间这两个四就代表一种主体性的混乱。为什么会混乱？因为主流的意识形态或秩序，没有在主体的本体论维度和认识论维度架设相应内容，所以留下很多乱七八糟的余地。这里面完全没有被规训。这个四不能看成是无，它可以是某种无，但这种无是一种主体性的无。

它是一种未规训的、什么都可以又什么都不可以的混乱状态，了解吗？所以这种随大流、随波逐流的人，如果情境使然，比如高速路上大卡车翻车了，他就要占便宜，就会变得很邪恶。或者比如吃人血馒头——鲁迅同志写的那种——他会做出很邪恶的事情。因为在他的主体性维度，群魔乱舞，什么都可以，everything is possible。所以他们并不是看上去那样服从秩序，他的主体性并没有被很好地规训成那个样子；反而在这个意义上，我觉得他们很野蛮。随大流的人其实很野，你们要深入去了解他们，随大流的人很野。

我举个例子，比如军训的时候——或者不说军训，某些训练的时候——站队列，大家都整整齐齐站好了。那么随大流的人是哪种人？他也很主动地站得整整齐齐，两条腿也往那儿站，但他会不停去找那种小的空档和缝隙：脚要稍微挪一挪，假装挪一挪；帽子稍微抖一抖；他会不停做小动作。随大流就是认为，只要我刻板地遵循了大家的规则，总体上、大体上遵循了这种规则之后，就像下顺子一样，大家都下顺子，我就偷偷塞一张，了解吗？

随大流也是这样：大家都站在一排了，我偷偷把脚挪一挪。他把这种 meaningless、没有被整合到符号系统里，或者在他看来尚未被整合到符号系统里的姿态，看成一种反抗，或者一种取悦自己的方式。而他取悦自己的方式就是不被看见——不被看见！

他如果能说，我这一个小的东西……我举个例子，比如有那种很勇敢的人。另外他的一个对立面是什么？比如峨眉弟子。我们都看过《倚天屠龙记》吧，里面的峨眉弟子——比如纪晓芙——偏要把杨逍送给她的什么东西戴在自己手上。其他所有东西都和别人一样，她也往那边一站——这是脚印啊，不要想歪，这是脚印——峨眉弟子都站在一起，但她偏要弄一个东西和别人不一样。其他所有东西都和别人一样，偏有一个东西不一样。这个东西在她的服从姿态之下，其他都服从，但偏有一个东西完全不一样，就会被凸显出来。比如杨逍送她的一根发钗，或者一枚戒指，戴在那边。然后灭绝师太一眼看见，啪一掌就把她打死。你看，这种随大流——这种反而是另外一种，不是随大流。

这种就不是随大流。这种反而很有目的性，他知道整体性的秩序；他要维系自己，并不是通过相同性，而是通过排斥他者、排斥异质性来维持自己。也就是说，我什么都跟别人一样，偏有一个东西是我自己的——这种姿态实际上就不是随大流。而随大流的人恰恰与这种比较解放性的姿态相反：他的那个最小差异，是不要让别人看见。他认为，只要我把这个东西瞒着、让别人看不见，我就是不随大流，我偏不让你看见。但在这个过程中，他这种不让人看见的方式，他以为自己是在反抗，对不对？

他弄了一个最小的、别人看不见的维度，其实预设了一个大他者：或者家长，或者教官，时刻准备看这些东西。其实他要意识到，那个教官根本不在乎你的小脚稍微动了动、那边摸了摸脸。虽然教官刚说过不准摸脸，但他站了半天，脸上流汗，还是要动不动摸一下，他觉得这很爽、很有意思。他还要假装教官看见，其实教官说不定根本不在乎这个东西。教官之前把一个人拉出来，因为他擦了汗，骂了一顿，原因在于这是凝结共同体的特殊方式：要批一个人、拉一个人出来。一个无意义的、非常无聊的共同体，就是要拉一个人出来说“你这里不行”，只是找一个由头，比如擦汗的由头把他拉出来而已。

这种随大流的人就误以为擦汗 it's regression，或者认为这是违背，是 transgression。擦汗就是 transgression，就是违背，所以他就擦汗了。他没有意识到，人家早就过了这个阶段，早就把你驯服了。擦汗其实并不是擦汗，反而是那个大流——那个教官，或者那个 order、那个秩序——偷偷许诺给这些随大流的人：我可以假装看不见你们在擦汗。通过这种方式，他把你们驯服了，了解吗？

我可以假装看不见你的脚稍微动一动、脖子前晃后晃。通过这种方式，你自以为不随大流，你自以为：他不是叫我不准擦汗、不准动吗？我偏偷偷动一动，偏擦擦汗。这个时候你的焦点不就只剩下这些小动作了吗？队列已经站得好好的，你的主体性就被限缩在一个很小、不起眼、根本无关紧要的维度。大他者、那个秩序知道那是无关紧要的，他故意留那个东西，故意把它设定成“这就是在违背我”——擦汗、稍微动一动就是在违背我，你也不准擦汗、不准动，然后站在那边稍微动一动、擦擦汗。其实他真正想说的是：你可以擦汗，你可以动，你可以把这个当成反抗或忤逆的姿态，但仅限于此。你只要这个东西就够满足你了，你就用这种方式偷偷地做，而我自己要合作地假装看不见。教官走来走去的时候，其实他都知道谁在动，他都知道一站站半天、站好几个小时很无聊。哎呀，this is this trick，就是这个技巧。所以这些家伙自以为在用一种 unseenable 的方式，自以为瞒过了，其实他恰恰进了那个圈套，进了那个圈套。

所以 conform 这个词很有意思。con 在英文里就是骗、诈骗、欺骗、骗局的意思，加上 form，这个形式本身其实是一个欺骗性的形式。form 就是形式；C\-U\-N 作为前缀有组成的意思，所以要组成一个形式、成型，就是随大流组成一个形式。conform、conformism 就是从众主义、顺从主义。另一方面，你可以把它理解成：你要骗过这个 form，你自以为骗过了形式，自以为稍微动了一动，自己是一个不合格的形式，偷偷假装自己有那么一点点不合格——这边擤擤鼻子，那边吐口痰，挤眉弄眼，汗流下来太干偷偷擦一下。你以为你骗过了它，实际上你恰恰是通过这种方式，把你的主体性的反抗限缩在这个维度，于是你就形成了这个形式，了解吗？

没有一个 perfect。形成形式，形式就是符号系统。背景性的符号性秩序会非常公开地告诉大家：在这个形式框架里面，这个位子本身肯定是将死的，或者是非常完美的 perfect；但并入这个位子的东西或多或少会有一些不完美。这种差异永远存在，它一定要拉开这个差异，也就是要拉开组成整体的那些部分和整体为这些部分所设定的那些位子之间的差异。如果没有差异，那这个整体——你走，我可以换另外一个；你走，我可以换另一个形状的——你了解吗？它要作为一个整体，要包含特殊性、包含一些局部的小东西，作为一个大的东西、大的框架，把里面这些东西装进去，就要求你不能严丝合缝，不能完满符合于这个东西。如果你完满符合于这个东西，某种意义上你反而 perfectly fits the……非常完满地适应于这个框架，反而会让大家都意识到：原来这个框架不存在，原来存在的只是这些个体的人，原来存在的只是这个基准点。它就会把具体的东西、把这个东西本身，而不是把这个东西所占的那个位子，看成基准点，了解吗？举个例子，比如海瑞这种非常好的人员；或者我觉得公司里面一个非常出色的设计师，或者一个人事，perfectly 出色的一个人事，他在那个位子上非常好地协调各种关系，让领导各方面都满意。他好到一定程度之后，其实他对这个管理结构是有问题的。为什么？因为他一旦走了，就会发现，再怎么来的人都不行，这个结构本身被他定义了。什么是人事就被他定义了；再怎么换其他人，都不如意，整个系统就没办法运行起来。所以这个系统一开始就一定要设定：我的这个位置和我坐这个位置的人一定要有差异，一定要有那么点不足或者有那么点过头。你做得太过了，或者有那么点差异，这样我才能够让大家相信有这么一个位置存在，了解吗？这个人事上任之后，老板说“你这个人是表现还好，但是哪些不行，太那个了”，这个时候大家才能支撑起一个幻想。因为背景性的符号秩序永远是一个幻想，它永远是想象性的，是想象出来的，它实实在在地不存在，对不对？它是大家幻想出来的。它怎么幻想呢？必须通过语言的方式，通过大家的言辞、语言和思考，说“哎他啊太那个了”，或者“他还有点不够”。它必须不停地再生产这种差异。这个差异是使得大家愿意进入这个框架的前提，是使得这个框架能够让大家汇集起来的前提。

比如新人就职，一定要让他说“我是个见习的，我不够格”。但干活干了好几年之后，他会发现，一开始那些还是老一套；其实其他人也不够格，不够格、不合格。这个最小差异是构成性的，它很重要，对于大家愿意到符号系统里去找个位置，并且通过这些位置想象出来的不同位置来定义你自己，是至关重要的。所以这些从众的人，他以为自己在那边占小便宜、玩小把戏，有那么一点出格，或者有那么一点点不够、缺斤少两，或者稍微有点过分，这种小的任性，他以为是在背叛这个体系或逆反；其实不是。这些小手段恰恰是在构建这个东西，恰恰是在让大家意识到：哦，原来这个东西是过分的，原来有一个恰恰好的东西。比如他是个农民——我这里没有歧视农民的意思——要么就是一个随大流的农民，太占小便宜；或者我说普通的工作人员，他一定是个老实巴交的工作人员，太本本分分，那还不让大家觉得他随大流；他一定要贪点小便宜，才能让大家觉得他是个随大流的，了解吗？或者他有某些很小、很古怪的小癖好，才能让其他所有人觉得他是个普通人，有那么一点点不一样的地方。这个不一样的地方，实际上是让大家了解什么东西才是普通的。那么一点点非常小的、不成体系的差异，让大家能够把握到 what is common——什么是普通的？什么是普通呢？就是大家也都那么一点点不一样，有那么一点点不一样。

每个人都有自己的那一点点不一样，那这个就是随大流，这就叫随大流。这种小的差异是构成性的。而一杠四杠四杠一的人，把这种构成性的小差异本身当成自我认同——不是完整的自我认同，而是零碎化的。他今天在那里占点小便宜，这是他；明天在那里占点小便宜，这又是他。他甚至会自相矛盾：这边占了点小便宜，那边其实让自己吃了大亏；那边又占了点小便宜，又让自己吃了大亏；那边自以为占小亏可以占大便宜，其实那个小亏就亏到底了。他们没有一以贯之的自我，是散开来的。所以在这个意义上讲，他的主体性被很成功地分散了，又非常成功地被聚焦在这些小的斗争、非常 mini 的、minimal 的 struggle，小的对规训的叛离，烈度非常小，方式非常分散。

但是，在最低层面，这些人的随大流主义、随大流占小便宜的主义，证明了有那么一种可能性：只要有新的符号秩序能够把他这种占小便宜的东西整合起来、整合到一起，让他体验到他的匮乏——他没办法，不得不占小便宜；当占小便宜变成不得不占小便宜，不占小便宜就无法维持另外大部分的生活，他就活不下来——如果他没有办法占得稳稳当当，他就能够把这些东西都贯穿起来。这个时候他就能觉醒，就能想清楚，他的主体性就能产生出来。但这个主体性需要引导，需要阐明，需要知识分子、聪明人，或者说需要那些已经吃过很多教训的人去帮助。所以我们对于他们的姿态应该是：不要鄙视，有什么好鄙视？其实很多人在很多情况下都是这种随大流的。比如我要吃什么东西，我在思考，我随大流，我也随大流；我为什么想这个东西？是他，是我。但我会在挑的时候稍微弄一下：这边我要微辣，那边我要中麻什么的，乱七八糟。我也会有一些小的余地来体现我内在的自由，了解吗？
