# 【一小时哲学】什么是小客体（petit\-objet a）？

今天算是答疑，但我们来讲这个。法语我不会念。它叫小客体，其实就是 little object，小 a。他们把这个玩意儿称为欲望的对象成因，也就是 object cause。它不是欲望的 object，而是欲望之所以能够获得 object 的原因。我们之前说过，欲望围绕着一个对象，它追求它的 object，但实际上它的目的是这个小客体。翻译起来好烦。

齐泽克在一个视频里——你们去 B 站就能看到——举了一个已经被举烂的例子：他有一个快四十岁的女性朋友告诉他，她的前任曾对她说，如果你身上肉再少几磅，你的身材就完美了。齐泽克说，千万不要去减肥，因为你减肥之后，这个欲望的对象成因，这个 object cause，这个小 a 就没了。

也就是说，它的作用是什么？这个小 a 本质上是一个 surplus，是一个剩余，是一个多余。这个多余的效果是什么？它会让你觉得，如果没有这个东西，如果把它去掉，就有 perfection。它是这样一种剩余：如果这个东西不挡在我们面前，把它去掉就完美了，了解吗？但问题是，这个完美，这个 perfection，是一个效果，是这个剩余制造出来的效果。

他还举了一个例子：法国当时做了两个美女超模让你选，其中一个脸上有一颗小痣，反而成了大众情人；另一个长得太完美，反而落选，没成为大众情人。有一颗痣的那位成为大众情人，因为她脸上有这么一个不完美的东西，这个不完美的东西起的效果就是做一个剩余，它会让别人去幻想。因为有这个剩余，才有这个幻想：幻想没了这个剩余的话，她的完美会多美丽、多漂亮。就好像玩过《三国无双》嘛，《三国无双》里面的甄宓，她脸上就有这么一颗痣；貂蝉是完美的，但普遍认为甄宓比貂蝉更性感，更有诱惑力。《三国无双》真是小时候玩的。他的人物设计就是，长了痣的那个更有致命诱惑，更觉得她是那种……啊，就是这个欲望的对象成因，就是小他者、小客体 A，它有这么一个效果：它能够让你觉得，把它去掉就可以获得完满，获得最美好的东西。

关键问题是，这个完满、这个美好，是它本身多出来的剩余制造出来的效果；你可以说它打乱了所谓的完美。完美从来都不存在。如果你把它去掉，如果那个快四十岁的女性朋友去减肥，那么 perfection 也会消失，她就会变成 plain，变成庸俗平凡，变成平凡，变成没有意思。

那么这个东西在本体论上是什么呢？拉康有一个幻象公式：左边是 Cartesian subject，笛卡尔式的主体，也就是所谓的“我思”；右边是小他者。在笛卡尔那里，右边就是“我思故我在”的“我在”，应该就是。那么在一般人那里，右边实际上是某种幻想，它是最原初的，实际上是关于身体轮廓的一个想象。你在镜子里看到的那个自我镜像是最先的。就像我现在播这个视频时，一直盯着那个摄像头……

我在图片采集软件里看自己的样子，因为它给我某种安定感：我不是在面對你，我是在面對我自己。我录像的时候和齐泽克不一样。齐泽克很讨厌看他自己的样子，很厌恶。有一个斯洛文尼亚老哥模仿他搞了一个模仿秀，就是那首 Cut the Ball；你们自己去搜一搜，B 站上说不定也有。但那个词太黄了，说不定审查通不过，是一支非常恶心的 obscene dance。后来他被采访，问他如何看待这支舞蹈，他说他根本没看这个视频，因为他不敢面对自己。我跟他相反，我拍完视频之后永远盯着自己看。

就是这个东西，首先它可以有各式各样的小他者，或者小的 object、小客体，有各式各样的。一开始是自我镜像，那么在哲学思考里面就是所谓的“我在”，“我思故我在”。还有一些，比如你爱慕的那个人，热恋当中的爱慕对象，你的爱人——不一定是你的爱人，就是你所爱的人——或者说在政治阴谋论里面，被你塑造成……如果你是保守主义者，你会把它想象成一种像幽灵一般的个体，比如犹太人，比如在纳粹、在极右翼保守势力眼中的犹太人，或者某些少数族裔。比如汉民族主义会排斥广州的什么什么，或者西安的什么什么，我就不说出来了，反正都是这个东西。其实就是少数族裔会被一个保守主义团体所排斥，他也会被塑造成一个小客体、小客体 A，一个排斥对象。

我们不仅排斥，比如纳粹，整个纳粹意识形态的自我构成就是通过排犹主义、反犹主义、反闪米特主义。因为他们施加、投射在犹太人身上的所有幻想，实际上都是在他自己统治集团内部实现的；他幻想的这些东西，其实就是他自己的内在统一性。所以拉康用这个公式——幻想公式——实际上要定义的是主体的自我认同：它必须通过一个异质性的他者，而这个他者其实是这个主体缝合之前的他自己。也就是说，在意识形态缝合或符号学缝合之前，所有主体都需要进入符号学秩序。在进入符号学秩序、被阉割的那一瞬间，他就丢失了自己存在的根基，丢失的那一块就是小客体。但主体会围绕这个小客体建构幻想。后面这三种呈现的东西，其实都是主体围绕着自己丢失的那一部分——他被符号系统阉割，进入符号系统、进入一个纯粹符号秩序的世界之后，他的存在根基。

你可以把它想象成灵魂出窍，想象成一个大仙出阳神：他的身体还停留在一个凡俗位面里，还在这边打坐；他的灵魂已经飞到一个什么时空里去了。他的这具身体就是所谓的小客体 A。然后他在那个符号学世界或者灵界里，有一个另外的凡俗身体。他要想办法出去，在这个梦里面想办法出去，对不对？他要找到他自己，找到回去的路径。这个路径在哪里？他会看到各式各样的东西：某个洞穴里面的法宝，是不是这个东西？他不确定。他可能有一种灵界——你可以说是他灵魂出窍之后，用自己的法力构建出来的，或者由他自己一部分法力和这个世界其他一些大修士、非常厉害的人的法力共同构建了一个灵界。他在里面遭遇到的一些东西，其实就是由他自己法力变化而成的东西。他就认为，接近那些东西就可以找回自己的真身，然后灵魂再回来，回到真身，脱离灵界的束缚。你大概可以想象成这么一个结构。在这个意义上讲，实际上哲学家们，特别是拉康那边认为，我们进入符号学秩序、进入符号系统，也就像一个大仙出阳神进入灵界一样。他真正的身体、他的肉身被排斥在这个世界之外；然后要在这个灵界里面，由各方势力、各方法力共同建构出这个灵异的、神圣的、各种法力魔法的世界。其实我们的世界就是这样一种世界：前面一个由各种肉体、混乱的力量构成的世界，它是前本体论 pre\-ontological；后面这个世界就是 ontological。西方哲学基本上是这样的：我们本身的自我同一性的根基是在一个前本体论的世界里面，那个时候本体论还来不及布置出来，还来不及布置出这么一个灵界、布置出一个世界出来。所谓的灵界就是世界，我们所身处的世界其实都是魔法开创的一个世界，创世性的力量达成协定、协约之后开创出来的这么一个世界，然后这是一个 ontological 的世界，就是无数股力量在那边互相调、调出来一个世界。

桥，就是这个字，桥事情的桥，或者搭桥，差不多，桥出来一个世界，互相博弈、妥协出来的一个世界。开创这么一个世界，它这个世界里面的秩序，大家订立下来的所有本体性力量订立下来的那个秩序，就是本体论。就是本体论：大家约法三章，说在这个世界里面人是可朽的，定期要死亡，记忆要给你删除，时间性体验是有终结的；空间是怎么样的，空间有大小、内外之分；空间的向度就是这个存在、生活在这个世界里面的主体只能体验到三个向度，但他只能现象学直观到两个维度，就是画面只能直观到 image，但通过纵深可以把握到三个维度，什么乱七八糟。所有这些设定，都是各方势力互相桥、桥出来的。然后这个里面思维要用听觉思维，要用线性的听觉做思维；客体的呈现方式要有明确轮廓，或怎么样。在梦境里面客体是没有明确轮廓的，而在醒来的世界里面客体是有明确轮廓的。就是这样的本体论决定了这个世界里面的游戏规则，还有它整个显现的基本模式。那么我们自己的那个本体论的前本体论根基，它是没进入到这里的。它就是缝的时候把这个东西缝到外面去，你可能就一根脐带连着进去了，把它缝住了。那么这个小客体就是就是这个东西，就是这根脐带吧，你可以说。一个人就会在这个世界里面找这个缝隙，找这个由本体论建构出来的世界的缝隙，要找到它，后来发现这个缝隙就是他自己，就是他自己内在的规定性，就是他自己的这根脐带可以通回去，了解吗？

因为这个整个世界的显现，你不要把它理解成……这个并不是变成了这里面的一个人，这具肉体它是变成了这整个世界的每一个版本，一个本地版本，了解吗？就是说，我这样说吧，一个这个玩意儿它变成了一个 world，或者它变成了一个中心化的 world。但这个 world 是一个中心化的 world，就是有一个主体做中心，有一个 subjective vice 的，它是一个 subjective vice 的 world，中心化的一个 world。比如大仙在这里盘腿打坐，他变化成了一整个世界。当然，这里面这个世界每个人都有一个世界，每个人都是个本体客户端，都是一个客户端在这个本体论结构里面。这有好几个，他可以和其他很厉害的人……也打坐，也变成了一个，然后互相之间构成一个大世界。简单可以这样理解，但不同的哲学家可能对这个描述的版本有不同的看法。你们都看过修仙小说，所以我觉得举这个例子应该可以帮你更好地理解。

然后这种笛卡尔式主体有一个特点：在哲学里面，这个主体，笛卡尔式的主体，拉康把它叫做 barred subject，我叫它 Cartesian，笛卡尔式的，或者康德式的，或者 Kantian。它的特点就是它是虚无。为什么用这个标志？那个标志跟美元的标志是一样的。拉康用这个标志，意思其实 it's money, it's capital，就是钱，就是 capital，就是 money。这种 money、这种抽象，就是笛卡尔式主体性，它实际上和现代资本主义的 constellation 是一致的，和它的铺展是一致的。然后我们要说的是，笛卡尔式的主体性为什么叫虚无？为什么它是个虚无呢？

因为它是一个纯观察者，pure observer。r 还是 or 我不知道，or 啊，它是个纯观察者。对于整个世界来说，它就是一个不存在的阿基米德点。它可以从这个阿基米德点出发去观察一切，观察一切。但有个问题：它没办法观察到它自己，所以它必然要假设一个“我在”，这是我思的这么一个极限的点。所以在笛卡尔那边，自我并没有身体化，笛卡尔式的主体没有身体化，它是 unembodied，um 开头吧，这个我思是未身体化的。它的身体的建构围绕这个极点，然后他说这里面有一些轮廓，比较靠中心的地方有个头，有个身体，有两条腿、两只手。他说他需要通过认同才能建构出这里面的东西，了解吗？他需要认同，他需要 identification，需要这个 identification 才可以认同这里面的这个世界。外面这一圈就是所谓的 world，但是整个结构是一个 subjectivized world，是一个主体化的世界。然后这里面世界的中心部分，始终占据中心的就是一个身体。笛卡尔会认为，这个身体里面有一个更正确的对应物，就在身体的大脑中间有个东西，是这个点的真实对应物，它的名字就是松果腺。一个腺体。他们说这个腺体是人类的第三只眼睛退化而来的，上面还有点感光细胞。好多灵修学派都说，只要练这个玩意儿就能练出什么魔法能力，什么乱七八糟的，这都扯淡。实际上它是一种前现代的思想，就是笛卡尔思维。他的这个哲学虽然是现代思想的发端，但是这种认定——这个东西就是我思，就等于松果腺，就是我在的核心——它的一个生理学、物理学基础就是松果腺，这是一种前现代的思维，也叫拟物主义。他一定要找个东西去做比喻，那种感觉，拟人主义或者不知道，反正很蠢的，这种思维是很愚蠢的思维。

到了康德那里，就是说我们要知道观念论哲学，idealist，观念论哲学里面的这种虚无的、作为虚无的主体性，作为虚无的阿基米德点的主体，它像一个阿基米德点。阿基米德说，给我一个支点，我能撬起地球；笛卡尔说，给我一个支点，我可以投射整个宇宙。这个宇宙是从这个支点投射出来的，这样你懂了吗？就像这个世界本身就是一个虚无的幕布，所以它倒转了洛克的白板说。白板说认为心灵是一个白板，然后这个世界投射在上面，投射在上面，然后获得了……其实在笛卡尔那边，世界是一个巨大的虚无的白板，然后从我思这边他投射了整个具体的、时代性的一个世界在里边。那么谁来保证这个投射是正确的呢？它背后站了一个更大的他者，大他者就是上帝。有个上帝在和这边单线联系，然后投射出了整个这个世界。上帝，你们可以把它理解成：这个自我就是下面一个灯泡，然后上帝是手电筒后面的电池，再后面的一个图像，然后投影仪把整个世界给投影出来，把整个世界、山川河流，先中间是个人的形象，然后有房子什么的，乱七八糟的，灵魂画着不画。所以观念论里面的主体 subject 就是一个作为虚无的阿基米德点。

从这个阿基米德点是可以获取，或者说可以感受到、可以 identify 所有万事万物的存在。那么它其实并不是纯无，它有一个剩余，总有一个剩余。在笛卡尔那边，那个剩余就叫做松果腺。他直接找了一个生理学、解剖学意义上的器官作为这个剩余，因为笛卡尔那边就是“我思故我在”，“我在”一定要找到一个客体的对应物才行。然后到康德那边，他发现问题不对了。在康德那边，这个阿基米德点被叫做先验统觉。他发现问题不对了：后面有一个剩余。这个剩余呢，是在康德的一本书里面——那本书叫什么我记不得了，还有什么伦理和宗教啊什么的那本书里面——他发现了主体有一种……
