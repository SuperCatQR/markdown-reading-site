# 【主义主义】陈述性的话语主义（3\-4\-1\-4）——福柯的谱系学、考古学和微观网络幻视下错误的去中心化路径

今天要讲“主义主义”的结构主义最后一个：三杠四杠一杠四，代表人物是福柯。我把他的体系命名为 state mental discourseism。这个术语是多义性的，也可以翻译成“陈述的话语主义”。

三杠四的四个东西，我都用一个形容词加一个“什么什么ism”。第一个是列维斯特劳斯，我称之为“结构的（structural）人本主义”，因为他在结构学、结构主义上真的有突破，提出了悬浮能指。第二个是“隐喻的象征主义”。在列维斯特劳斯那边，结构主义的基本单元是神话。当然不能说“神话主义”不对，它归根结底是破解神话的，所以叫人类学主义、人本主义。

第二个是拉康，我称之为“隐喻的象征主义”。他的突破在于让一种张力显现出来，也就是纵深性。结构主义要获得纵深性，先不谈时间性，先要谈纵深性，也就是要有真正的主体出来：一个镜像的自我与符号秩序中的主体之间形成纵深，形成隐喻关系。镜像实际上是用来隐喻那个东西的。早期拉康那里，隐喻是更重要的问题意识；到晚期，转喻占据优先性，因为隐喻的问题已经解决，他自己有了底层符号学的辩证机制，所以隐喻和纵深性的问题已经解决。因此我把它叫做“象征主义”，即 symbol，目的是走向象征界，象征才有纵深。

接着是第三个，昨天讲过的罗兰·巴特，我称之为“叙事主义”。他的结构主义符号学分析的基本单元是叙事、叙事活动。说到“隐喻性的象征主义”，大家会想到那个家伙——那个喜欢用几个字母给人格做分类的蛇皮，名字我都不屑于记住。他完全没有抵达哲学意义上的结构主义阶段，所以我觉得他不配，没什么好讨论的。罗兰·巴特这里是一种分类学。他做不出真正的纵深怎么办？他就搞出部分和整体关系，搞出很多模棱两可的分类学，在文论里弄一堆模棱两可的形式分类，分好几类，那本书里又分好几类。这些东西都是炫技，没有意义，里面没有真正直面问题，也没有严肃的哲学意识。但他的“泛叙事化”把整个世界所有文本、现象、体验、意识形态、政治现象、经济现实都泛叙事学化，这在哲学上是有贡献的，所以我要把罗兰·巴特提出来。

今天讲福柯，我称之为 state mental discursivism。他的结构主义、符号学的基本单元是话语，只有在话语那里才能进行结构分析。更进一步是 statement。statement 是陈述，但福柯在这里玩了双关，甚至三关：state 与政治权利有关，与城邦、共同体有关。state 当然有陈述、设立、说出来、表达出来的意思，也有状态的意思，代表一种稳定状态、共识性的局势，即符号系统结构中的一个局势、一个状态。这其实就是福柯所设想的政治性关联体的基本态势，也是权力网络的基本态势。state 也可以指国家。后面加上 mental，把 statement 变成 state mental，就是双关。

mental 在这里有两层意思：一是心智正常、心智健全；二是发疯的，即 mentally sick，精神有问题。所以 state mental 一方面指 state 认为自己肯定是心智健全的——“爱欲与文明”，我是文明，我肯定是正常的；另一方面，mental 又代表它为什么如此关心 mental，为什么 state 要专门给那些 mentally sick 的人设置一个位置。

特别是在福柯那里，十九世纪之后的现代文明、现代工业文明，尤其是二战之后，大家认识到社会是个有机体。法国社会学传统尤其如此，前面讲过孔德、斯宾塞这些人，他们从实证主义运动开始，在十九世纪就意识到社会是个有机体。这个有机体会产生剩余，也就是它的排泄物；当时知识界和统治者已经意识到，它的剩余就是 mentally sick 的人、精神失常者。于是社会不再把他们看成普通病人或普通罪犯，不把他们和这些人放在一起，而是专门隔离出来，并免除他们的刑事责任和民事义务。他们成了现代法治体系和现代权利义务关系网络的一个剩余，而这个剩余支撑着有机体。所以 state mental 表示 state 和 mental 之间有非常紧密的关系，这也是福柯分析出来的。

我明确告诉你，这是福柯对于知识型（episteme）的分析。我可能拼错了，记忆力很差；应该是 episteme，知识型。

福柯对知识型以及知识考古学做了很多了不起的工作。知识考古学（archaeology）与 archive（馆藏、记载）有关：它是在 archive 这个术语之上形成 archaeology。考古学更确切地说不是考“古”，而是把知识型考古考出来，通过发掘学术史——因为留存下来的材料往往只有学术史材料。人类从中世纪开始，普遍来说是从文艺复兴开始，学术活动和学术史留下大量文本材料，这时就可以进行知识考古学；中世纪之前的残篇手稿文本量不够，无法支撑一个符号学体系。知识考古学在福柯那里就是成熟的话语主义，其实现方式就是通过知识考古学，一直考到最底层的东西——statement，即陈述，也就是不同学科的、学科性的 theoretical statement，理论性的陈述。这些从文艺复兴开始，后面启蒙运动，大量学术内容都保存在欧洲老图书馆里。

美国没有，可能英国有，所以能干这事的就是老欧洲。福柯这套知识考古学为什么能有一席之地？因为他在战后代表了法国世界的尊严。美国人干不了这事，二手书摊上买不到十七世纪出版的书，十八世纪的书也买不到几本。十八世纪时美国有啥？啥都没有。那种用罗马字母印刷、特别漂亮、用拉丁文写的书，老实说我都看不懂；也可能是罗马化字母写的德文或法语书，字母特别漂亮。每本都是金边，或者红边——红边是宗教性的，金边。整本书特别漂亮，我见过，差点买，一看超贵，几十欧、几百欧、上千欧一本。这种活可以看成老欧洲的行活。所以福柯在学界的面目并不是你们想的那么激进，他没那么激进。他在法国哲学圈里是很正的一种研究，可以叫学术史梳理，或者科学史、文化史梳理。这活很正统，迪尔泰这种人可能会做。他很年轻，但干的活像五六十岁的人干的。

但福柯只分析了一小部分。知识考古学里只分析了文艺复兴到十七、十八、十九世纪，可能还有十五世纪，十五、十六、十八、十九、二十世纪这些东西；后面天下大乱，走向战后秩序。知识考古学也有断代，它对知识史、话语史进行断代，分三个阶段：文艺复兴时期、十七到十八世纪启蒙运动时期、十九世纪以后——后者才是我们所谓的现代哲学。简单讲，文艺复兴时期是相似性思维，就是“瞎说瞎讲”，那时人没那么聪明，逻辑思维能力没那么强，笛卡尔还没出世，笛卡尔那种对世界的符指化、坐标系化把握还没有成为时代精神。它的知识型通过相似性原则（resemblance）维持，即在能指与所指之间、词与物之间，是一个三元知识关系：词、物、相似性。这个相似性很含混、说不清，但它也是一种知识型，是在结构中起作用的规律性、规则性、一种张力。

到十七、十八世纪，也就是启蒙运动时期，更强调机械性、机械性的原则。这里起主导的知识型，episteme，相当于范式，相当于科学范式；但它的知识型比库恩的科学范式、范式革命要彻底、究竟得多，因为这个知识型是结构主义的，由底层符号学支撑，是由 statement（陈述）构成的，statement 是它的基本单元。

statement 其实就是状态。比如经济学陈述，一则经济学陈述：“联准会降准会使得全球经济有过热的风险。”这是一个经济学陈述。这一则陈述由许多同样的陈述支撑，但陈述之间也会有冲突。有冲突的地方，就能让结构主义分析师从话语中看出：应该是由陈述构成话语，由陈述构成某种学科话语，然后再由话语进入所有话语之间。怎么看话语的形式？通过陈述之间的相互矛盾、冲突和相互支撑。在学科史中，同一时期，比如经济学，这些陈述肯定相互支撑、相互关联，但也会有矛盾点、冲突点、症状。这些症状暴露出隐藏的形式；把隐藏形式抽象、把握出来，它就变成一种话语。于是有各式各样的话语，比如经济学话语、精神分析话语、心理学话语、政治话语、性的话语、粗俗的性的话语、艺术话语等等，有各式各样的话语。

这些话语之间又会有冲突，也会有相似性，比如结构的共通点，但也会有冲突。通过结构主义分析，可以把握到它们共同都有的一种结构，从而把握到一个时代的知识型。与其说是一个时代的知识型，不如反过来说，是知识型塑造出一个时代；知识型更源初。知识型是所有社会话语底层结构的一种共性，或者说一种张力、一种态势、一种基本运动方式，甚至是它的发生学和本体论，即话语本身的本体论方式。所以是知识型反过来决定一个时代，这个时代里所有人的思想、心灵、精神等等，都由知识型决定，由话语以及不同话语相互关联形成的知识型决定。

所以在福柯那里，首先神 goodbye 了——结构主义嘛，不可能有大他者；其次人也 goodbye 了，没有人，不存在主体，不存在一个时代里主体性的迸发或精神，一切由知识型本身决定。一个时代对应一个知识型，是知识型决定时代。

这只是从“知”的层面说；反过来，我不太能说，包括我自己言论的尺度。回到十七、十八世纪，那里是机械性原则占主导，特别讲究逻辑，还有线性序列。逻辑性和线性序列构成树状网格，构成机械性的网格，也就是矩阵，或者叫坐标系网格。这种坐标系网格、线性序列主宰了十七、十八世纪绝大部分思维。但福柯这里分析错了：观念论运动并不服从这一套，当然我们在康德身上看到很大影子，但那已经是十九世纪、一八几几年了。德国在十八世纪一七几几年还没什么文化，所以这些运动被忽视了。不管了，反正他说的是对的，因为十七、十八世纪是笛卡尔、英法经验主义和某种理性主义占主导，逻辑机械性原则占主导。

在十九世纪，则是有机体原则，这就是福柯蛇皮的地方。他没看到观念论运动、后观念论不是搞有机体的。不管了，反正这里看到的是：福柯科班好像是学精神病理学出身，学的东西蛮多，什么都要学一学。他对哲学史上的精华领会不深刻，就认为十九世纪的时代精神，或者说他所谓知识型，是有机体原则。有机原则就是追求事物的本质性关联、彼此支撑，但会有短路，会有系统、体系化，会有一个至高原则或原初的辩证法机制作为动力学机制，让这个东西不停自我更新、活着，让知识结构、知识框架不停活着、自我更新。它是个有机体原则。

福柯对十九世纪时代精神的领会不深刻，他没有看到观念论里蕴藏着一个颠覆性力量。这样分阶段是有问题的，因为十九世纪最重要的思想运动就是观念论运动；后面由存在学运动、存在论运动、现象学运动片面地继承，而结构主义运动也继承自它，也靠科耶夫——老实说真的是靠科耶夫。有机体原则下，一切事物不再是逻辑性、线性的排列组合关系，而是差异性的、他者性的、彼此支撑的，并且不停自我更新；会有矛盾、僵局，通过辩证法克服，从一个较低形式到更高形式。这种理解有点斯宾塞的感觉，不管了。

知识考古学对应这三个时期。反过来看疯癫：在文艺复兴时期，疯子被看成非正常人，但代表某种神秘甚至神圣的维度。比如那个画家疯掉——具体年份不管——在文艺复兴时期，疯人还是可以说圣语的。到了启蒙运动、理性主义、经验主义时期，疯子被看成非理性；社会把犯罪、过度激情、性倒错、疯子都看成非理性，关到一起，扣帽子，把疯子看成一般的非理性。到了十九世纪以后，特别是出现了精神分析和心理学运动，大家意识到，原来疯癫是有机体的剩余，是它的构成性例外，是它的丑闻。所以不再把精神失常者和罪犯、其他边缘人士关在一起，而是单独关起来，想要治疗他们；通过治疗他们来安慰自己：我的体系是对的，我的有机体没问题。特别是知识分子和社会权力、整个社会治理体系，都拼命想安抚、治疗好这些失常者，单独关起来、单独治疗，以证明自己具有时代前瞻性，能治疗时代病症。这样，疯子被看成最特殊的剩余；而这个最特殊的剩余在精神观念上支撑起最一般的、最普遍的秩序，因为它是有机体的剩余。

再往后，到后现代。二十世纪，明确说是一九……你们看我鼠标轨迹，那一年之后进入后现代：法国知识分子弃守现代性阵地，放弃了，因为他们看到一次虚假事件——由布尔乔亚扮演小布尔乔亚学生演出来的虚假事件，不算事件，只是一次拙劣的丑闻。这些知识分子借坡下驴，弃守现代性阵地。所以从二十世纪七十年代开始进入所谓后现代。在我看来，后现代实际上是一种现代性的倒退，又回到前现代，可能回到十七、十八世纪，甚至观念上回到十六世纪文艺复兴那个蛇皮状态。不管了。

现在我们看福柯的场域论。看最后，其实也讲得差不多了；另一个东西不知道能不能讲，就是他的 micro power。我试着写：左边写微观，右边写宏观。左边是微观网络，右边是宏观结构。宏观结构可以叫谱系学（genealogy），即宗谱、谱系的意思；微观网络的探查则通过话语分析（discursive）或陈述分析。微观网络结构里会有冲突和失衡，通过冲突——它的发生学机制是考古学在协调两者。通过考古学协调两者，把微观话语中的冲突失衡，发现它们隐藏的、埋在深处的规律或结构，然后慢慢导向一个宏观。

主体就是考古。在福柯那里，如果主体性还有残余，主体就是一个考古学机制，我们把它叫做话语考古学的机制。主体意味着能够穿透：考古学机制从具体、最浅层、最表层的陈述和话语中的不一致性出发，通过这种不一致性和里面的冲突，抵达某种普遍形式；把普遍形式连缀起来，主体就获得所谓的知识。众所周知，在福柯那里知识等于权力。知识就是权力，就意味着主体只是记载；主体的唯一活动就是 archive。如果说福柯有某种主体性，他其实没有主体性，他不承认有主体这种东西。他只承认只有话语，或者只有符号在运动。无我论嘛，大哥还不了解吗？设立任何主体，在福柯那里都被看成一种权力，即发展某一种权力。这种姿态不是解构主义的，它就是结构主义的。我再强调一遍，福柯这个姿态不能说成解构主义；解构主义不是这样的，解构主义连结构都不要了。

这种姿态其实是很正统的结构主义姿态。我不知道为什么有人把福柯叫解构主义，或者叫后结构主义者；福柯就是个结构主义者。结构主义本身并不是什么温文的东西，它本身就很具颠覆性，只是很多人不懂。我认为福柯把结构主义精神继承到底了，尤其是他最后导向知识等于权力：知识就是对普遍形式的一种记载。它比较有穿透力，结构更有压倒性优势，或更有穿透力，因为它是普遍形式，更冠冕堂皇，或者更有效——我不知道怎么描述。如果说有一种主体性，那在场域论上协调两侧，协调微观结构、微观权力网络和宏观结构；宏观的甚至可以说是 state 结构，即所有 statement 都服从的那些结构。这就是考古学机制，就是主体 archive 的活动。archive 吧，我不知道怎么念，不管了。
