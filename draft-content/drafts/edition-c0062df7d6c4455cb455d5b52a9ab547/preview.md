# 【主义主义】批判哲学（3\-2\-1）——以“判断”为枢纽的康德先验哲学计划

来补充一下。在康德那边，我好像说过了，但记不得有没有说过；我可能有点暂忘症，不知道叫什么症。不管了，就是说 representation，也就是表象。你要获得表象，表象是结果；你要获得一些表象，要通过判断。判断活动可以产生表象。

判断活动相当于连接那些先天概念，也就是先于经验、独立于经验的先天概念。把纯粹先天概念当作范畴，然后怎么把它们用到这些表象里呢？

就靠判断，靠判断力，把它揉到表象里面去。我们的官能怎么把它组织起来？怎么把那些感觉要素组织起来，赋予形式？靠先天统觉。它靠几层：想象力、先天统觉，还有它的知性；用先天概念即范畴，然后通过判断。但它也是通过综合——判断分为综合和分析，主要是一些综合性，把它连到一块去。分析是把这个属性就认定为这个属性，圆就是这个圆，方就是这个方，黑就是这个黑；但综合把它们综合到一块去，变成一个时空当中的复多体，变成一个有时延、有空间广延的复多体。

然后可以把不同属性装载在一个实体上，其中就有那十二个先天范畴。所以，表象要表象化那些感性的、前表象的、尚未被表象的感性材料，也就是感觉材料——那些资料本身什么都不是，那些复多体，即 manifold。那些复多体还是前表象化的。在康德那边，如果你不用知性、统觉、想象力对它加以整理，你就会视而不见。前表象的复多体要加以判断和整理，依据知性的规则和知性当中的概念加以整理之后，才生成表象，生成有意义的、可理解的、可思的、可认识的表象；否则之前那些东西不叫认识。视而不见就是盲的：东西摆到你脸上，你就像睡着了一个人。有的时候人就是睁着眼睡觉，或者他睡着，你把他的眼皮翻开，然后在他前面放个东西，他也看不到。

那个人也看不到，因为你整个系统没有开始运行。怎么判断系统没运行？就是没有生成一些既定的、绝对真实的结论在你的符号系统里运行。

你一旦跑了这些判断的结论，一个表象在你的符号系统里就可以说对应 n 个判断叠加组合起来的一个终极判断，一个很长的复合句。所以他喜欢写复合句。表象在你的意识空间里、在符号学空间里就是一个超长复合句；然后一念，“哎，我懂了”，你就把握到、看到这个表象了，表象就生成了。

所以判断是表象化的关键枢纽。因为判断使抽象概念、先天概念和本质性的东西与这些材料发生关联；这些材料激活并一定程度上限制、征用、调用、援引本质性的东西，也一定程度上屏蔽其他东西。这些材料的功能就是刺激我们调用这些本质，刺激这些范畴，从而给它一个判断。

这些前表象的复合体本身什么都不是，甚至没有空间化、时间化，不占据意识视域中的任何位置。所以在这里，表象和判断的二分是他的认识论的一个基本套路：表象是被动的，是作为结果的、静态僵死的东西；判断是主动的，是活的东西，是知性、思，甚至最后回到“我思”的维度。好了，我不跟你扯了，我就补充这些。
