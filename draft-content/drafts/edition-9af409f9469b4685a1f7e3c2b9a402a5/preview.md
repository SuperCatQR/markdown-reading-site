# 【四十分钟哲学】哲学的二阶论域（3）：何为主体性

我们在形而上学已经讲到二杠三，也就是我思形而上学，所以今天要讲“何为主体性”。我思形而上学二杠三的核心，就是在这里做中介的主体性。

本体论上有三个东西，或者说还有另外两个存在：一个是空间性的存在，它仍受限于存在与非存在的二分；另一个是时间性的存在。

存在物或本体分三类，有三种本体。第一种是空间性的本体，也就是可以摆出来的、现成的东西，它会变成二分：一个是存在的，一个是不存在的。这里的存在都可以写成 exist。第二种是时间性的本体，它的存在方式是 persist。这比较好理解：它的存在等于不存在，它超越于存在与不存在的二分。它是时间性的存在，是一种动力学、动态的存在；而空间性的存在可以理解为静态的存在。静态的存在有一个 yes or no 的真值表，可以指派它到底存在还是不存在。比如空间性的存在，像我这张桌子，我有一个形而上学空间的清单，清单告诉我桌子存在还是不存在；另一边，公园里那只猴子存在还是不存在。

当然那个动物园或公园里不太有猴子，公园里只有人。还有第三种存在，即时间性的存在，它是 persist。它的存在方式就是存在等于不存在，是一种动态存在。它的存在就是对形而上学空间真值表的篡改。可以说空间性的存在就是形而下的存在，它会空间化，进入空间场域；时间性的存在是形而上的存在，它在历史缥缈的维度中存在。那么本体论上第三种存在就是主体性。

讨论主体性的存在时，一般只能用 being，或者 becoming，也就是生存意义上的 becoming；也会用 existentialism，即生存意义上的 live 或 living，a living being，活生生的、一直存在的存在。

主体性在本体论上一开始出现时，是作为一个被动观察者，也就是笛卡尔式的我思，cogito，笛卡尔式的我思存在。

今天要讲主体性这个词怎么来的。在我的一个最简单范畴表里，它是两个场域的交点：宇宙论加上认识论，或者场域论加上认识论，epistemology，这就变成主体性。

要把握主体性，只要思考两个问题。第一个问题是：为什么整个场域要从认识发生的机制来把握？也就是为什么整个场域是认识论化的？什么叫场域是认识论化的？或者说，为什么我们说场域是先验化的？

也就是说，为什么我们把握到的空间、时空或这个世界里的一切，都必须通过一个认识的中介、认识主体性的中介才能把握？为什么这个场域渗透着、被装了软件？你把握这个世界时，它像装了一个软件飘在那边。这个场域是认识论化的，这个宇宙是认识论化的，是被一个软件所渗透的。简单说，你所把握的一切都被软件渗透，都被认识的维度、主体性的维度所中介。

你没有看到世界上任何一个东西是没有形状的吧？只要它有形状，这个形状就意味着被你的某种形状范畴、知性范畴所中介。只要能被你体验到，它就已经是范畴化的，或者叫图示化的，schematize。被你体验到的一切，甚至你体验到的整个场域本身，一般会被把握成一个时空场域；也有人会把握成时空。

再加上另一个形而上的、超时间的维度。一般而言，时空场域和宇宙这个场域是形而下这一边；形而上学还有另一个场域，即超时间的场域。实际上，真正的时间性藏在这边。下面时空宇宙中的时间性已经是空间化的时间，是二手时间、二流时间，也就是你已经把时间当成一个空间向度，把握成一条线，不再把时间真的当成原初时间。原初时间就是形而上学的超时间，a temporal。超时间的维度里面有真正的时间性维度，它里面调一个东西，对整个全域都是决定性的调整。

我们去把握时空、把握世界这个场域，无非是这两种场域：形而上学家无非把握这两种场域。这两种场域都被软件渗透，都被某种图示化思维、范畴化思维、知性范畴所渗透。那么这种渗透是为什么？为什么会有这种渗透？这种渗透为什么不可避免？这种渗透就是为什么世界是主体化的。这不是黑格尔意义上的主体化，而是问：实体为什么不可避免是主体化的？

也可以理解为：为什么实体不可避免是主体化的？或者至少，为什么整个场域——不说实体——我们体验到的真正场域里，只要被我们体验到的一切东西，都是主体化的？这个场域为什么是认识论化的？它被精神、思维、认知范畴这些东西预先渗透，弥漫在其中。这是第一个方向：为什么外部世界已经预先被一些内在的范畴体系所渗透？它看上去是硬件、是环境，但这些硬件已经预先被图示、被范畴所渗透。你看不到任何东西是不可以被图示化、不可以被范畴化的。

最激进地不能被图示化、不能被范畴化的是什么？混沌系统？描述混沌系统的大量统计数学范畴，也是被符号化、被图示化、被范畴化的。比如量子力学中的量子波函数，波函数还不够图示化、不够范畴化、不够符号化吗？波函数，你要学多少前置学科才能理解？所以，去想象一个绝对前符号化的外部世界是不可能的。你必须借助某种符号性的中介、一个棱镜，这个棱镜是摆脱不了的。这是把握主体性的一个维度，代表这个场域本身是主体化的，或者说实体不可避免是主体化的。这是第一个维度。

第二个维度反过来：我们还要看到主体内在的认识论世界。主体内部，不是指你身体里面或精神里面，而是指主体内部那些范畴结构，也就是意识结构。为什么这些意识结构俨然像个宇宙一样？主体内在的范畴体系就像装了一个软件，像装了一个操作系统。你的意识结构，你的认知范畴体系——认知、回忆、反思、欲望等整个意识结构——为什么如此？为什么它好像是个场域？为什么它是场域化的？structure like language，它是个场域性的结构，里面既有共时性维度，也有历史性维度；既有静态结构，也有动态运行模式，就像个小宇宙。说小宇宙，不是说里面真的都是，而是说它的结构体系像网状、网络状。归根结底，它是个能指链。但作为能指链，它有自身的动力学机制，也有拓扑学机制。它里面的框架结构俨然好像有一个空间、一个力学体系在里面。

所以第二个方向就是：为什么主体内在是场域化的？为什么内在世界像一个场一样？而且这个意识结构是相对稳固的。

这种稳固性特别体现在你的身体意向性上，关于身体的意向性上。举个例子，你让你的右脚第二个脚趾动一下，它就动一下。但你要依靠你的范畴体系，不能不依赖语言来达到它。你当然要语言中介：你要想“我的右脚二拇指动一下”，你要跟自己说这句话，要经由符号学中介。否则，你都不知道我叫你动哪一个，对吧？

否则你没有办法定位到那个东西，没有办法定位到那个使它动起来的符号学机制。你的身体内在的意向性俨然形成了一个符号定位网络，一个符号性的空间网络、空间定位网络：一个是定位，还有一个是自发、spontaneity 的网络。如果你练健身，就能感受到。比如举重时，你慢慢能形成“我的腰腹部、腰背上第几块肌肉要动一下”的空间性网络，然后符号化地加以定位，再发动它、控制它。一般人控制不了，比如一般人没办法让耳朵动；但如果你多练习，慢慢就能形成这样一个 cognitive、认知性的映射，一个 mapping，一个映射，一个图，一个像地图一样的东西。这就是第二个问题。

这个只是帮你理解，因为空间化在身体上确实已经空间化了，比如哪边是哪边。我要说的是，意识结构的空间化、场域化，指的是它里面的这些关系之间有一个比较稳固的体系。比如记忆的结构和时间体验的结构之间，有一个比较稳固的现象学关系，意识结构的关系；性别的结构和你的爱欲机制之间，也有一个比较稳固的关系。这个内在意识结构如何像搭房子一样搭起来，我们居住在其中。归根结底，用海德格尔的话说就是语言，语言之家；归根结底，它是用语言、用 language 搭起来的。要说你内在意识结构是用什么搭起来的，它就是用语言。拉康也说，无意识是像语言一样被结构的，像幻想小说 fiction 一样被结构起来的。它的结构就是 language 的结构。我们前几天直播时讲过，language 还具有优先性，语言比言语具有优先性。

这就是两个方向：一个是从场域论看内在的认识论化，或者说外部空间一定要经由内在范畴体系的中介，这是第一个方向；第二个方向是内在范畴体系自己会俨然具有某种外部性。我内在的意识结构就好像一个外部世界，我的主体性就好像住在里面。在这个意识结构里，主体性变成飘萍无依的东西。所有这些意识结构都不能等同于主体性本身。意识结构不等于主体性，意识结构是意识结构，主体性是主体性，你了解吗？

主体性是一个虚空，它是空的，没有规定性。它飘在意识结构这个宇宙当中，飘在里面。不能说哪个意识结构就是主体性，不能说你的记忆功能就是你的主体性，你的内听觉就是你的主体性，你的身体轮廓感就是你的主体性。这些东西不是你的主体性。主体性游荡在意识结构构成的外部世界里。所以这里有一个外部世界，它是被意识结构所建构的。那到底意识结构是在这个外部世界外面，还是意识结构在外部世界里面呢？

这个问题必须放在主体性的问题域里才能思考。如果我们认为意识结构或先验范畴体系、知性范畴网络是无条件的、不可逾越的、不可突破的，是闭合的，那么这就是先验主义，康德式的先验主义：我们没有办法跳出先验知性范畴体系去思考，这是非法的。你的电脑只有在开机、操作系统运行的状态下才能操作；你把操作系统关掉，硬件没有指令，它不跑，硬件不会空转。先验框架就相当于电脑的操作系统，operating system。没有操作系统，你跑个屁？你还能跳到显卡里面，让显卡给你变一个美女出来吗？断了电的显卡、没有跑驱动的显卡，输入输出没有接到操作系统里，直接让显卡给你投影投个大美女出来，怎么可能？不可能，对不对？先验主义啊。

如果你非常仔细地研究意识结构，一般要通过现象学的方式去研究、探究，或者用精神分析的方式去研究、探究。主要只有两条路径：现象学和精神分析。其他的解释学、人类学、分析哲学、认知主义都不太够；认知主义可能还能帮点忙，其他不行。

主体这个词 subject，我前面已经讲过。它原来有成臣民的意思，subject 臣民，有臣民的意思，也有成熟、被支配的意思，所以它带有被动性。在黑格尔和拉康哲学那边，主体性是被动的，是纯被动的，passive。笛卡尔那边也是，作为我思、纯我思 cogito，它是空无的，没有规定性，自己是很空的。

主体性代表一个裂缝、裂隙，代表实体本身的不一致性、不完备性。实体没有办法完全成为它自己，那怎么办？只能通过主体来中介，只能裂开一个口子。这个裂开的口子，或者说实体的自我分裂、自我裂开、自我裂解，就叫裂开。这是比喻。什么叫裂开？就是本体论上为符号化敞开，为符号化的中介活动让步。我只是用比喻，一般说裂开说顺嘴了；其实就是实体没有办法用一个本体论把自己完全整合起来，空转。空转也是比喻，你只能去领会，这个东西没办法跟你说清楚。

它在本体论上要向符号性的中介活动让步。符号性的中介活动是什么？就是意识。什么叫符号学的中介活动？它能居间中介、调配实体的运动，居间调配实体的运行，那不就是意识吗？意识就是这种自主性：承受实体之前的暴力，但能够缓和这个暴力，让它迟滞一下，然后去调整它。这就是意识。

实体不完备，所以敞开了裂隙。这个裂隙使得符号学中介、符号学的一个视域，一个感受性的视域成为可能。感受性的视域不就是你的意识吗？意识不就是个感受性的视域吗？那么，感受性本来应该是本体性，对不对？如果它本来是本体性的，就意味着它在本体论上要闭合了；如果它本来就是本体性的运动，本体论上就闭合了。所以这时就有本体性和感受性的二分：一个是 nominal 的，一个是 perceptual 的。Nominal 的是本体性的，不需要感知，不需要额外的意识维度去感受它，它就在那边空转。感受性的维度则需要意识作为一个维度。比如这样拍一下，有点疼、有点凉，感受性就出来了，你有一个维度。

力剩余出来了。如果完全是本体空转，比如空气分子撞我的脸，我是感觉不到的。这些东西太不必要去给它符号化，太有限了，没必要。实体在这里没有裂开口子。什么时候实体裂开、打一下，产生“这个感觉”，可以说到达一定阈限，或者具有一定事件性，能够撕开本体论的空转，那我就能感受到这个东西，它就会有一个意识的维度，在这么一瞬间敞开。空气打我脸，我肯定感受不到，没必要。

所以主体，一般拉康会加一个斜杠，这个斜杠代表它是完全被动的，它本身不会实体化，它本身是无根基的、无根的。你找不到它，它是一个裂开的口子；这口子里面的所有东西都不是那个口子本身。它是一个纯 void，pure void。我的文章里还讲了几种不同的方式，但我觉得没必要讲。比如主体是纯粹虚无；作为纯粹虚无，有几种方法可以把它纯粹虚无。一个是用本质主义的方式，但我们现在讲三种错误的方式：本质主义的方式、表象主义或现象主义的方式、结构主义的方式。这三种方式都会错误地把主体理解成某种虚无，等同于一种虚无。主体不是等同于虚无，它不是主体和虚无的关系；主体的那种无不是直接的无，主体不是直接的一个本体性的无。这三种错误中，第一个就是萨特。萨特直接把主体等同于某种本质主义的虚无。我的文章里写的是有问题的：他把主体和虚无的关系看成直接等同。这个虚无是不是萨特《存在与虚无》里的那种虚无？

在《存在与虚无》这本书里，主体在本体论上就是无，这是很错误的，极为错误的，是错的。因为在拉康看来，主体并不是一个本体性的无，主体不是本体性的无，不等于本体性的无。什么叫本体性的无？就是纯无，就是一种肯定性的虚无，然后就是一种荒谬深渊的意思。

在拉康看来，主体一定会有个对子，主体是有对应物的。主体是虚无没错，但这种虚无有一个对应物，这个对应物就是剩余，即 objet petit a。这个 objet petit a 出现在这个世界的符号学中，它是整个非无的、那一切符号体系的一个剩余。主体通过朝向 objet petit a，可以结构出一个 fantasy。这个 fantasy 一般而言就是镜像阶段的东西，是一个自我自恋的外壳。自恋的外壳把主体裹起来、包起来，主体就具有了它的自身轮廓、想象性的图像，也就是自我的一个想象性图像。而不是说主体直接就是一个虚无。

在萨特那里，主体直接是一种虚无。主体直接是虚无，就导致目的论体系比较难以建构；主体和世界相接洽时，你就忽视了这个世界本身具有一种不一致性。主体是虚无没错，虚无在萨特那里也被把握成一种不一致性，荒谬深渊性的不一致性。但萨特忽略了一点：这种不一致性，这个主体作为虚无，它的本体性不来自它自己，他是本质主义的。所以在这个意义上讲，你看我这里既然把萨特写成本质主义，虽然他自称存在主义——存在主义好像是本质主义的死敌——但萨特在起点上做得不够存在主义。他不能直接把主体看成这种虚无，而要把主体作为虚无：主体是个无头的主体，而不是它自己就是无。

简单来说，这个主体可以理解成有很多本体性机制在里面空转。那么主体是什么？主体恰恰是能够作为一个无头的主体，纵容这些本体性机制在它自己这里、在主体性内部空转。这些本体性机制在拉康那里叫作死亡驱力，death drive，或者就是无意识，或者就是那些能指链。在拉康那里，主体是一个能指的主体，一个无意识的主体。这个无意识的主体，说它是虚无，其实它是敞开性的。它通过什么敞开？通过主体的后撤，通过主体性的一种绝对否定性的后撤姿态，敞开一个空间，使得死亡驱力、无意识里面包含的一些能指链在主体性内部空转起来。每一个能指链实际上都没有办法填补这个主体后撤。主体后撤了个什么？没有主体后撤，主体就是这个后撤运动本身，纯粹地让开这个位置。那是谁让开的位置？没有人让开位置，就这个位置自己敞开了。只不过它会回溯性地被把握成：原来之前有一个东西让了这个位置，才会让这些东西能够进来。其实什么东西让了这个位置？没有东西让出这个位置，这个位置平白无故敞开了。那么主体是什么？主体就是这种平白无故：它想要追寻“是什么东西让我敞开了？是什么东西让出这个位置？”没有东西让出这个位置，你就是这个让出位置的运动本身。所有的能指空转的能指链、所有这些死亡驱力，都是用来填补让出来的这个空虚。所以主体是个无头的主体，像无头苍蝇一样到处乱转，它不知道哪一个是他自己，哪一个都不是。所以拉康的主体在最低限度上是个异证化的主体，是一个比较积极的主体，是一个 active 的主体。虽然这个主体的积极性完全来自它的被动性——主体是一个绝对被动的主体——但它能够通过它绝对被动的后撤姿态，向它所有的积极性提供位置、提供空间。在萨特那边，虽然它叫存在主义，实际上是一种本质主义。我这里包含一个反讽：萨特理解的那个直接作为虚无的主体，不具有这样一个比较辩证的结构，它直接就是一个荒谬深渊的不一致性的主体，一个虚无的主体性。

那么这个主体性就直接在本体论上作为一级力量，然后开始实现本体论意义上的东西。不过在这里运行的还不是本体论的，而是符号学的机制。当然这也不遑多让，都差不多，没有太大差别。只能说，萨特的主体性是一个 psychotic 的、被害妄想症的主体性；拉康的主体性则是一个歇斯底里的主体性。他们的主体性的秉性不太一样。

恰恰在这个意义上，萨特不够存在主义，拉康反而更存在主义一点。第二个主体性是表象主义的主体性。表象主义认为，主体在表象主义层面是虚无的：这个世界上根本不存在某种本质、本体性的维度，背后的本体性维度是不存在的，是假的、不存在的。那么主体性是什么？主体性是一种用户幻觉。认知主义、神经生理学家，比如梅钦格的无我论，或者丹尼尔·丹尼特那种类似的观点，还有达马西奥，他们会认为主体是一种用户幻觉。就像我现在在放大缩小这个东西，其实根本没有一幅画面在放大缩小，只有一些像素点，几十万、上百万、上千万个像素点自己在变白变黑、切换颜色而已，并没有一幅画在那边动。所以他们认为主体在这个意义上是一种虚无的主体。他们认为主体本身是虚无的、主体是不存在的，就会走向无我论，而且会激进地走向无我论。因为他不相信有本体性的维度，也不相信本体性的维度符合某种符号学的辩证法，所以他思考不了这些东西，就会陷入一种无我论，很无脑的无我论。

最后一个是结构主义的无我论。比如列维纳斯，他反笛卡尔式主体；还有阿尔都塞，他小时候、始终伴有一种妄想，这个妄想就是“我不存在”“自我不存在”。阿尔都塞一直受这个妄想折磨，晚年精神病发作也是因为这个妄想，他一直觉得自己不存在。结构主义通过他者的优先性，以及结构当中能指之间差异的优先性——差异的优先性和他者的优先性——来消解同一性。差异优先于同一性，他者优先于自我、优先于主体、优先于中心，这样就把主体性瓦解了。主体性变成虚无，变成一种机制。

结构主义的暴力使得一个共时性结构大于历时性体验。尤其就主体性而言，就是历时性体验。为什么共时性结构大于历时性体验？什么叫结构主义？举个例子。在文化批评和神话学、神话起源学里面，比如某个女神造人，还有一个男神开天辟地，他会把这四个东西搞成一个矩阵、弄个结构，然后去套很多民族史。汉民族有什么，其他民族有什么，巴比伦、埃及都有这个东西。然后他发现这里面是一个能指结构，是一个能指链的结构、符号学的结构。这个结构是一个共时性结构。这些符号之间，尽管我不可能找到百分百对应的，但我能看见：比如女神和造出来的人、泥人之间的差异，这个差异有；男神和女神之间的差异有；开天辟地和造人、灾难、大洪水这样的事件之间的差异也有。可能在另一些民族里不是洪水，而是干旱或火山爆发；开天可能不是开天，而是把地凿开、把山劈开；男神可能不一定是男神，而是某种雄性的力量。但这个结构当中的差异是有的，都是有的。然后这个共时性结构或同时性结构，会把所有历史当中历时性的演化、演化出来的不同版本，都收进来。怎么样？就好像鲜艳一样，都可以相应地放在这个共时性框架里面。比如某 A、B、C、D，对不对？把它排列组合：A B C D、A C B D、B A D C、D C B C A D，把所有可能性都列出来。
