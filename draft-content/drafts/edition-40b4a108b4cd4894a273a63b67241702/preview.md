# 【主义主义】逻辑行为主义（2\-4\-3\-3）——日常语言学派是如何继续逻辑实证主义的勾当的

现在要讲主义主义的2\-4\-3\-3。代表人物是赖尔，牛津学派的日常语言学派代表人物Ryle。这个主义叫逻辑行为主义。因为它太烂了，我不想多说。

这东西太丑了，我不想多说。逻辑行为主义叫 logical behaviorism。英语怎么拼？前面是 logical，后面是 behaviorism，logical behaviorism。我担心把 logical 和 behaviorism 连起来会出问题。

赖尔受晚期维特根斯坦的影响。他就是要处理一个内部性问题，也就是语言的内部性问题，于是导向一种伪行为主义。这就像之前说的卡尔纳普，那是一种伪还原主义：还原论还原到哪个阶段，由谁说了算，这里也一样。所谓行为主义，就是把人的内在心灵消解成还原性的东西。

为什么需要这种调和呢？因为它要处理 convention 和 criterion 之间的对立。convention 意味着它是由学术界、学术共同体内部的秩序预先规定好的，因为按道理这是逻辑实证主义的计划。逻辑实证主义面临的最大问题，其实是规范性的来源问题。

我甚至可以说，这是规定性的来源，不只是 normality，我可以说这是 determined，determination，规定的来源。这意味着，你要把那些实证的原材料加以符号化、加工。加工时，规定性从哪里来？你总要有规定性，要把它进行关联性的连接。光有逻辑体系不行，光有分析性的逻辑体系不能得到关联性的连接，连数学性的连接都没有。所以一开始，我们是通过学术共同体的共识来实现这种关联性的连接。后来发现，我靠，这样搞的话，学术共同体共识——那我们这批人算什么？

那我哲学家还是没饭吃，你了解吗？那就让科学共同体自己说了算呗，我哲学家没饭吃。卡尔纳普说不，我为了让哲学家有饭吃，要提出一个评判标准，不是你们说了算，我要有我的评判标准。我预设哪些东西是有意义的，我有我的句法学；我的句法学告诉你哪些句子、哪些说法是有意义的，哪些东西是无意义的。所以你们一定要让哲学家吃饭。你让我吃饭，我就帮你炮制相应的逻辑还原主义，还原出来的那个东西就是你的一阶研究对象。你让我吃饭，我就承认你的一阶对象是客观的，可以进入我的逻辑句法学，在句法结构里作为合法的项。如果你不让我吃饭，不承认我的学术地位，我就干死你，把你的研究对象消解掉，这叫逻辑还原主义，你了解吗？

这可以看成是卡尔纳普那批人从欧洲逃到美国。他一看，原来美国人文研究这么糟、这么没有反思性、这么自然主义、这么笨，顶多这么实用主义、这么粗糙。他立刻发现这里有他用武之地，他有饭吃了。

我觉得卡尔纳普就是 criterion。说得很庸俗：你们学逻辑的人难道不要吃饭吗？你一天到晚干的事情，不就是提出 criterion，去批评、批判哪些东西合法、哪些东西不合法吗？

那么这两种东西是有冲突的。为什么？左边是理工科，是学术共同体，寄存在那里的学术共同体，大家都跑到美国去；右边是新入局的其他共同体的大牛，其实都是德国人，他们冲上来就跟你冲突。这时候怎么调和？还是靠英国人，靠维特根斯坦来调和。晚期维特根斯坦其实无心调和，他把这些都推翻掉了：什么语言游戏，全都在胡搞。他使得日常语言和学术语言之间不再有明确界限。

赖尔则比晚期维特根斯坦好得多，或者说赖尔还很天真，认为我们可以搞出一个逻辑地图。他还是一个相信逻辑地图存在的人，所以仍然是逻辑实证主义者，只不过他认为调和这两种方式要通过行为，通过行为来调和，也就是通过一种倾向性、心灵的倾向性。其实就是通过行为主义来调和。

行为主义使得当时美国学界越来越如火如荼地追求所谓客观性、外在性。美国学术共识的取向就是行为主义，拒斥一切内省分析，拒斥一切内在观察报告，连自己内在的第一人称观察报告都不行了。另一方面，这种对卡尔纳普 criterion 的批评，使他的评价体系、评价标准变得有意义：只要你能够被行为主义描述，被一种行为主义方式描述，你就符合他的句法学评价标准。赖尔比较有名，他批判笛卡尔，批判笛卡尔的二元论，认为笛卡尔的问题在于错误运用、混淆了两种范畴——心理范畴和物理范畴。

他认为心理范畴、心灵性的范畴，不能用来描述那些心理性的东西、心灵性的现象，不能说它存在，说它是怎么样的。我记不得具体说法了，但大意是：这些第一人称报告里说的东西，你不能预设心理具有某种实体性。你可以把整个内在自我作为一种感受性、感受器官，这是可以的；这个感性可以给你提供物理报告，可以言说物理范畴。但你对你自己内在心灵结构的所有感受，最终都不能说它成为结构，它不能结构起来，不会是 constitution，不可能有结构。你只能把它把握成一些倾向、一些趋势、一些习性，把你的内在心灵转化成感觉和行动的倾向、趋势、习性。说一个人性格偏激，你不能这样说，因为性格在他看来是心理范畴、心灵范畴，不能用一个质性的东西去描述它，不能说它好像是个对象、是个实体，然后具有某种属性。你只能说什么叫心理偏激？这只是一种说法，一种含混的说法。实际上就是他在遇到某些行动时会行动得怎样，他的感觉会怎样，也就是说他有某种习性、某种倾向、某种趋势。

这样一来，所有内在心灵的建构都变成行为主义上的倾向。当然，这种消解、这种还原的可靠性很有限，它的调和能力也很有限，因为在这里 convention 里面大量包含一些先天的假设，与经验无关、超越经验的假设，物理学假设。比如通过这种方式，它也可以为行为主义心理学做支撑。逻辑行为主义为行为主义心理学本身撑腰，让它堂而皇之地宣称自己是科学，而且是人类的科学。

无意识就变成伪概念。在他们看来，没有无意识，不存在无意识这种东西；它只是行动的一种证明——你身体不受控制嘛——行动的一种倾向、感觉的一种趋势。梦境也是这些。我一直在想他们怎么消解梦境，我不知道他们怎么消解梦境。哎呀我靠，我都不想说了，我感觉恶心、头疼。

但是这种行为主义还原的方法，在你面对比如波阵面、波群这种概念时——我举个例子——这种假设性的、很抽象的、超越经验的学术假设，它就有了普遍公民权，被当成物理性的、物理范畴，不管它是不是某种心理性的建构。当然，它也会被说成一些更基本的倾向，可以消解成一种倾向，只不过更复杂，是一种行为倾向，也就是我们的经验体验的一种概率、一种概率倾向、概率学倾向。因为赖尔本身认为，所有这些假设都是概率性的，所有结构都是概率性的。比如波阵面到底存不存在？它存在的概率，就是关于波阵面的一系列经验观察报告，这些报告支撑了它为真的概率。如果里面有一个错，那它就是错。所以他会说，为了使得这个假设继续成立，我把不符合的那个去掉。对于某个经验反馈，如果它预测失败，或者与它不相符，我就把这个预测能力去掉。这样波阵面的概念还能继续用，但它排除了这么一种情况，解释力就变得有限了。

然后你可以看成，赖尔这个东西、赖尔这个哲学，其实是把龙种变成了跳蚤。龙种就是晚期维特根斯坦的那些思想；在赖尔这里，龙种变跳蚤。本来那个东西是很有张力的，我认为是三字头的一个东西，到了赖尔这边，就基本上变成一种非常流俗的东西，就是这种行为主义。它是未加反思的，因为他没有意识到：逻辑实证主义和行为主义这两个是不兼容的。

它们是不兼容的。你为了调和 convention 和 criterion——convention 可以看成主体间的，criterion 看成主体的、比较内在的——就用一个客观的东西来调和，用客观行为主义。客观行为主义具有客观性：行为是内在的，我可以体验到这种倾向、趋向，也可以写第一人称报告；另一方面，它的主体间性可以见证你的行为。于是通通把所有这些东西都变成行为报告，变成行为主义的倾向性报告，也就是感觉发生的概率学报告。行为这个东西其实也被消解了，变成一种感觉、一种感觉发生的特定模式、获取一种感觉的特定模式。它本来也是概率性的，行为本身也是概率性的，因为在这里你连主体性都消解掉了，那请问何为行为？行为主义本身是一字头的，因为它是实在论。逻辑实证主义，我靠，老实说，它是一种很内在性的东西，是一种很内在性的哲学、一种形而上学，因为它只依赖第一人称报告。

他们只依赖第一人称报告，假设这个世界背后有一种逻辑性结构，可以使得第一人称报告具有跨主体间性、为真、概率性；它也预设一种逻辑体系，思维的逻辑体系，观念连接的逻辑体系，有跨主体间的有效性，可以保证它为真。你一个逻辑实证主义，怎么就上了行为主义这条船呢？

我是很醉的。赖尔在消解笛卡尔二元论的时候，我觉得这相当于是很谄媚那些实在论者，那些不是科学实在论，而是天真的实在论者，或者就是行为主义那种最矬的科学实在论。他谄媚这些最矬的科学实在论。这个我觉得真的是……我是很受不了这个东西，我长这么大，我受不了这个东西。

因为你逻辑实证主义的视域，你的视域不是一个实在论的视域，而是一个第一人称的、体验的视域。你的这个视域从内在性出发：我不能确定它到底是真的，所以我要建构逻辑实证主义；我只能确定我的这个感觉是真的，我第一人称报告我感觉到这个东西，然后对它进行描述。只是在描述的时候，我要尽可能服从逻辑，服从被逻辑检验过的语法；我说的时候尽可能用大家说的公共语言，说一种超出我第一人称体验范围的语言，这样才能形成知识。还要用一种最低限度的、观念性的、理性化的结构把它结构起来，我才能形成知识。

你最后他妈的变成行为主义，我请问你：你观察这个行为，你把这些东西都消解成行为倾向性，那你这个视域本身怎么消解成行为？你在胡搞啊，视域本身没办法。而且你把你的心灵过程、心理结构降解成行为，这种行为是更难被观察的，更难被第一人称直接体验到的。你说性格是一种行为倾向、一种趋势，你的第一人称体验真的能够体验到这种倾向、这种趋势吗？难道你的第一人称体验更能够把心理把握成一种行为吗？你是很难直接体验到的，直接体验到的就是心理内容，你何以说把这种心理内容变成一种倾向或趋势呢？你第一人称报告是体验不到这种趋势的。我们都能坐火车，你只能感受到速度，很难感受到加速度，或者很难感受到加速度的加速度；这种趋势是体验不到的，而你的心理过程、心理内容你能体验到。

我说，现在我不能够以一种描述物理范畴的方式去描述心理，不能把物理范畴用到心理对象上面去。那我的第一人称经验报告所用的那些行为主义范畴，难道就更高、更干净吗？当你说趋势、说这是一种行为的时候，这个东西不是更虚吗？更虚啊！因为当我们说到行为趋势，不就是两者的关系、一种变动、一个变化的过程吗？这个时候就有无尽的扯皮了：运动优先还是实体优先？

这个就是我真的是服了。这些东西更难被体验到，它形成的第一人称报告更是有问题。一种倾向性、一种偏好，哪有人可以预先在心理事件发生之前就描述自己的偏好？发生了之后，你如何把你——哦，你吃个冰淇淋感觉很开心，这个开心你就说我有一种偏好，将来会吃更多的冰淇淋，把它描述成这种东西？我很开心，这个开心不等于就是我要将来吃更多的冰淇淋。但你偏要这样说，我好像也觉得是这个意思。那你岂不是预先知道答案，然后投射到这个心理状态上面去？你这是回溯性地去把它刻画了。所以在这里，我觉得他在目的论调和的那种方式，我把它叫做刻画，characterization，回溯性的刻画。

他把它刻画成一种行为，刻画成某种看上去客观的东西、客观中立的东西。他调和就是这样调和的：把两者争执的、共识和标准之间争执的那些部分搂出来，我就把它刻画成某种客观中立的东西。这也可以看成是逻辑实证主义——一个逻辑实证主义穷途末路、没办法了，为了自己在学术界里面找一席之地，他妈的又开始有新招了。我真的服。维特根斯坦已经让你们没饭吃了，那么这些人为了继续有饭吃，哎呦，我这新出一个产品：我可以帮你处理——你的学术内部肯定也是有争论的吧，你有一些既定的共识，然后这个时候有个大牛提出一个标准，相互冲突了之后怎么办？

没事，你们冲突的那个点拿过来，我给你刻画一下，让它具有客观性。这样一搞，当时美国学界大量的内在性的东西，大量存在论地位可疑、他们不承认存在的东西，还有认识论地位可疑的东西，通通就被这样刻画、批量生产，刻画成是行为。行为又是个啥东西？行为又被默认看成是 behavior，肢体的移动吗？行为仅是肢体移动吗？不行啊。他说行为的时候，肯定包含心理行为、倾向、偏好，一种概率性的东西，这些都是抽象结构，非要把它说成是行为。那为什么他非要把它说成行为？他占了那个位置，他占了逻辑实证主义的位置，占了整个学术共同体至高话语权的位置：我是逻辑的，我是客观的，我是必然的，我是明证的。所以他可以这样派发，派发这种——你们在吵一种内在报告有没有合法性？那我帮你搞一下。比如经济学上的投资意愿，或者信用，这些东西，他通通把它逻辑实证主义地刻画为一种行为、行为的概率、行为的倾向。

赖尔可以是个代表人物，我觉得他是逻辑行为主义代表人物。真的是，这些人是恰饭恰开了，吃饭吃开了。你一天到晚说我录个视频就恰饭了，这些老哥恰饭恰的什么终身教职、各种徒子徒孙，然后各种名誉都吃到了，这些人都吃到了。

那么他在场域论上是二：一个是形而上学的一个世界，一个是逻辑地图——它叫逻辑地图。在逻辑地图里面，一切知识、一切命题都有它自己的界限，都有预先确定好的界限：这些话怎么说是合法的，怎么说是不合法的；超出这个界限，荒谬、不合法。另外一个场域就是我们的感觉，感觉所把握的那些要素、那些场域，也就是第一人称视域。逻辑地图和第一人称视域，然后在本体论上是四，不用说了就是四；在认识论上是三，是调和的。

这种调和就是这个经验性的、直接的——我说穿了，直接性的体验 versus 一些间接的体验，间接的体验，观念性的一些关联、观念性的连接，比如一些抽象概念、抽象概念的图示，还有一些物理学模型、科学模型。这种东西：左边就是纯现象、第一人称现象，右边就是经由理智加工的。那么它们的关系就被调和了。

第一个调和它的是石里克，语法调和；第二个调和它的是卡尔纳普，也是逻辑调和，或者句法学调和。最后一个在这里，就是由他的这个——叫词项，越来越清晰：一开始是整个逻辑语法，然后是句法，到赖尔这里就开始对词项进行区分。因为赖尔是后维特根斯坦的，是晚期维特根斯坦之后的，所以在维特根斯坦那边，句法的那种严苛性就没了。那么赖尔这个时候只能玩词项，词项的一些规则、词项的分类学。词项的分类学就是要做到这一点：他说有的词是直接的经验，可以这样用；有的词是间接的，只能用一些词而不能用那些词来描述它。所以赖尔在这里——你们会看到，在石里克那边，他调和的是整个 grammar，语法调和；在卡尔纳普那边，进一步变成句法，英语怎么拼？syntax。syntax，那么最后到了这里，单元越来越小。

一开始是一整个句法，一整个语言里面的那些所有规则；然后到卡尔纳普那边就蛇一点、矬一点，只涉及句法了。因为卡尔纳普面临一个基本要素的问题：哪种要素合法，哪种要素不合法，他自己是颤抖的，不敢再细化下去。然后到了赖尔这边，他直接就是词项，词项的一个分类学，直接就 terms，直接就是词项的分类。因为晚期维特根斯坦说了，句法主义是错的，不行，所有语言都是游戏语言、游戏规则。但赖尔说，词可以，句子不能够死板地去划分哪些是原初的句子、原语言，哪些是日常语言、游戏语言；句子不能分，但是词可以。他说的词这种论域，不是很明确吗？

词的哪些是属于心灵的、内在的，哪些是属于这个世界的外在的、物理世界的，这种二分不是很明确吗？所以在这里，这个第一人称就是一种内在的；这个逻辑地图其实也被看成是某种外在的、白嫖的。就是这种内外二分，你可以看成是第一人称体验的自己的一个二分：内外二分。这个老哥还学过现象学，我觉得赖尔也算是个现象学家，但是现象学成就很有限。所以他最后就搞个词项分类学来调和这两个东西：他把词分成几类，有些词可以这样用，有些词不能这样用。他不需要去建构一种严苛的句法规则，规定哪些句子可以说、哪一类句子没有意义；也不需要去搞一整个语法，因为那个时候已经有晚期维特根斯坦。
