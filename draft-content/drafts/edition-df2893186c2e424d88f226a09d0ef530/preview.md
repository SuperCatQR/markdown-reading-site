# 【二十五分钟哲学】主体和实体的关系（从康德到黑格尔）

最后我们要讲主体和实体之间的关系。上一讲已经讲过主体和客体之间的关系，这样我们可以更进一步了解哲学上的主体是什么，也就是 subject 和 substance。

我们直接快进到康德。康德版本的主体（subject）就是所谓的先验统觉。先验统觉可以理解成 Windows 窗口，窗口化的 Windows 显示屏，一个空的、非常空旷的、虚无的框架，什么东西都从里面走个过场。康德的实体就是所谓的物自体，thing itself。物自体可以理解成什么？我用个简单的比喻：你把它理解成显卡，物自体就是显卡。这个显卡通过 Windows 窗口能显示出很多对象出来，但你没有办法通过电脑窗口显示屏看到显卡。看不到的呀，大哥，你不可能看到显卡。你如果在窗口里面能看到显卡，除非弄个摄像头对准你的机箱，把机箱拆开了。我这是一个比喻。当然，通过这种方式你也可以说看到所谓的物自体，但那个你要看到的不是真正意义上作为一个东西的那个显卡，而是那个底层的运算单元、底层的信息，把那个信息涌现给先验统觉的那个东西。

substance，所以在康德那边，这个物自体是看不到的，没有办法通过 Windows 窗口看到你自己的显卡。你只能通过 Windows 窗口看到这些显卡生成出来的乱七八糟的东西。它可能连显卡都不算，可能是硬盘里面的数据，或者硬盘里面的磁盘、磁片。如果你不是 SSD，而是机械硬盘，这个物自体就相当于是硬盘里面的那些光盘，一片一片的小光盘。你不可能通过你的 Windows 窗口看到它们。而且你有且只有 Windows 窗口，你没有其他摄像头，你只有这个机器给你显现出来的东西，你没有摄像头，你没有摄像头可以拍这些东西。你有且只有这个先验视域（horizon），这个先验的视域给你涌现出来这么一个视窗。

我们举目四望，万事万物无一不是这个操作系统生成的。你眼前的手机、手表——虽然大部分人没手表——你嘴巴里面的湿润感觉，耳朵听到的声音，各式各样的感觉，所有这些东西都是通过先验范畴组装、搭配、综合、演化出来的。先验统觉是它的一个窗口，统一到先验统觉里面去，让它在一个所谓的视域里面、一个世界里面一起涌现出来。

那么在康德那边，这两个东西是什么？是割裂的，是 separate、separated，是分离的、割裂的，老死不相往来，你碰不到它。这个主体只能把握到、只能吃现成的，只能看到它的先验主体性、先验统觉，还有那些先验范畴，以及各种分析判断能力，和它所综合显示出来的图像。它只能把握到这些东西，所以会把这些东西背后的东西叫做先验图式。

他甚至不好意思说显卡了，我不好意思说显卡，你可以说它是程序，是显卡的驱动程序。这样就好说了：物自体是显卡，它的驱动程序就是这些先验图式。先验图式把图像、image、pictures 显现出来。但主体本身被它的先验主体性、先验统觉强行限制，是没有办法接触到这个显卡的，因为康德在《纯粹理性批判》里面说得很清楚：如果你的主体通过直观（intuition）能够去把握到、看到这个显卡，你怎么跟它说？你篡改源代码了。你明明被人打了一顿，却说我改我的源代码，把它变成被人按摩了一顿，好舒服；甚至我加个钟。人家用刀把你胳膊砍下来，你把它变成人家给你做了一道很好吃的菜。源代码可以瞎改，这个图示都给它改掉，那你这个生活就没有意义了，生存就没有目的性了。在康德那边，这是伦理上不可接受的。这个也是只有上帝、只有神能够这样改，叫做理智直观。这种直观叫理智直观，自己能看到自己，自己能够把握到自己内在的这些原初代码，能够改它、能够调配它。

我们直接快进到黑格尔。在黑格尔那里，他的主体就叫主体，实体还叫实体，他这个词儿都没变过。但是实体里面另外一个词叫 Geist，精神、spirit，或者叫精神。这个精神是要动的，是要运动的。那么主体的话，如果它是一个主体，也是要运动的。这两个玩意儿在黑格尔里面是同一个东西。我就不……他写了一本书叫《精神现象学》，phenomenology，他其实就告诉你：这个实体 Geist 是怎么通过主体这个中介，然后去把整个我之前所说的世界、这个现象世界、这个视域给它涌现出来，各式各样的东西给它涌现、生成出来；这个 Geist 是怎么催动这个主体、催动这个主体性、催动这个操作系统，来把这个世界给它涌现出来。

所以在这个意义上，黑格尔有一个很著名的论点，就是黑格尔的 A、B、C：substance is always subjectified，实体总是主体化的。

因为我们之前讲过什么叫 objectify，objectify 就是客体化。我们之前讲过何为客体化或者对象化。这边我们在黑格尔这边又掌握了一个机制，叫主体化。对象化之前已经懂了，就是这个操作系统怎么把它生成出来。主体性、先验主体性会把所谓的实体或者叫物自体那些原初的数据、一些粗糙的原初数据对象化，变成一个在现象世界当中显现出来的物，显现出来一个物，这叫对象化。外面是 Windows 操作系统，外面是一个 Windows。然后这个对象化的机制就叫做主体性，先验主体性，先验主体性。

那么在黑格尔那边，他会说这个 substance、这个实体，就是你一开始所用的所谓的原初材料。在康德那边，实体是物自体，是原初材料、原材料，而且是你看不见的原材料，是那种相当于贵妇人看不到厨房里面那些宰杀、那些惨叫、那些血腥的东西；贵妇人看不到血腥的东西。但是黑格尔要说，你遮掩的那些看不到的实体，它本来就已经是主体化了的。也就是说，这个 substance、实体的内核就是主体性。实体——我换张图吧——就是这个东西：这个桌布，把它理解成现象层面，也就是所谓的世界，打引号的世界。所以我们日常体验到的整个世界，就是这个，什么东西都在里面。然后下面这个东西把这个东西给撑起来，撑出它的形状轮廓；下面这个东西是一坨黑箱，叫做实体，叫实体，实体把它撑出来。那么它中间有个东西，观察者后撤，中间有个观察者就叫做主体，中间康德意义上的。就是说，我主体是这个实体涌现成这个现象当中的一个像滤镜一样的东西，或者说是中间的一个中介、中转商、中间的一个程序。我下面这个是 raw material，下面这些是 raw material，是一些原初的数据，这些最矬的原初数据；中间这一层是主体。这是康德的一种说法，中间这一层是主体。

这些实体经由主体这个中介，主体里面有好多函数，有好多图式，然后这些无序的东西就被整合，然后变成一个清晰的现象世界，里面就有一个东西、一个物、一个物、一个物。这是康德主义的说法。所以在这个意义上，这个东西就被隔开了，这个实体你永远感受不到它，主体只能面朝现象世界。但是他屁股后面呢？因为主体对于自身的把握，也只能通过一个现象世界来把握他自己。主体要问：我主体背后的实体在哪里？背后的物自体、主体背后的物自体是啥？在哪里？所有现象世界里面这些东西，背后都有一个老大跟它对应在那边，有一个实体对应在那边。那么这个作为中介的主体也就问了：那我自个儿呢？我自个儿在哪里？实体永远找不着，你找不到你自己存在的根基。在康德那个意义上的那个主体，其实是一个阿基米德点，是悬在空中的，悬在太空当中的。

那么到了黑格尔那边，他就认为这个实体本身，它的内核就是主体化的，就是 subjectified。也就是说，这整个东西加起来叫做主体，叫做实体；在黑格尔那里，这整个结构叫实体，而不是它下面这个机制叫做实体，不是下面这个 substance 这个机制叫做实体。因为在黑格尔看，这整个实体创造一个主体性的中介，然后再显现出一个现象世界，这个运动、这整个运动，甚至实体通过这种方式让这个主体没有办法把握它自己，这种主体的无能——康德是主体是个无能的主体，他没办法把握到物自体，也没有办法把握到他自己的存在的根基——这种主体的无能本身，inability，这种无能为力，它具有一种实体性。反过来说，主体在作为一个中介去认知实体的过程，把它现象化为一个世界的过程，是这个实体在迂回地认识他自己。所以所谓的主体就是实体的自我认识，实体的自我把握就是主体。
