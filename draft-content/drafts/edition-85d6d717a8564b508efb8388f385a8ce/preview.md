# 【主义主义】针对资本主义的精神分析（3\-4\-4\-4）——无意识何以生产出主客体？理论家为编织体系，走向注定失败的大学话语

今天要讲的是主义主义的三杠四杠四杠四。它的代表人物其实很多，大致从马克思到阿尔都塞，再到晚期拉康。晚期马克思的《资本论》，到阿尔都塞结构主义的马克思主义，再到晚期拉康，也就是他所谓的第二次回到弗洛伊德。

拉康有两次回到弗洛伊德。第一次口号喊得震天响，却被国际精神分析协会里那些弗洛伊德主义者踹了出去。第二次回到弗洛伊德时，拉康的主导问题意识是 Raison，我不确定这个词，也就是里比多（libido）。

里比多为什么变得关键？简单说，通过阿尔都塞对《资本论》的结构主义把握，问题浮现出来：一个结构或曰无意识，或者《资本论》所把握的那个社会生产活动，是符号化的。问题在于：无意识何以具有生产性？它为什么具有生产性？这里的生产性不是指生产物质财富、精神财富，而是指无意识为什么能生产出主体性，另一方面又为什么能生产出客观性。它一方面生产出 subjectivity，某种否定性的东西；另一方面生产出客观性，也就是 objectivity，能生产出对象，并生产出表象世界的一致性。晚期拉康的主要问题域，就是要思考这两个问题。

这里思考的是主体和物。二者之间会有一种异化关系：主体的否定性始终呈现为不愿自己变成物，不愿自己成为世界表象中那个融贯一致的本体论网络里的一个现成东西。这种东西反映在社会意识里，就是普罗大众（proletariat）。普罗大众不愿意什么？不愿意自己在这个致密的本体论网络里，也就是不愿意自己在市场中被定价，不愿意自己在市场中变成劳动力，成为劳动力也就异化了，成为劳动力并被定价，成为一种商品。它不愿意自己变成商品。这里的异化，其实就是商品拜物教。

中间有一个机制，就是资本主义的活力论（capitalism vitality），而这个机制就是 life without negativity：没有否定性的生命，毫无否定性的生命。资本主义就是一个无脑增值的纯生命，这种生命没有任何断裂。它就是无意识。但问题在于，这个无意识为什么还具有生产性？

它为什么还有劳动力？在这种无意识当中，有一种 labor。无意识是一个生产者的无意识，是劳动者的无意识；这个无意识的主体是有的，这个主体就是普罗大众。这个普罗大众，在拉康的体系里，现在不是作为一个经验上的、实证上的具体现实的阶级。那么现在的普罗大众指的是什么？在拉康的体系里，普罗大众指的就是无意识的主体，subject of unconscious，也就是社会无意识的主体。

这个无意识不同于荣格的地方在于，荣格的无意识是 collective unconscious，它是 collective 的，机制也比较挫。在弗洛伊德那里，无意识的机制则是一个深如海的里比多仓库。但在拉康这里，无意识是一个生产机制，它能生产出两个产品：一个是主体，另一个是客体、客体性，或者说客观性。它生产出客观性，或者说客体性，更重要的是把世界那层光滑的表象生产出来。

这门学问，我把它叫做 cycle analysis of capitalism，即对资本主义本身的精神分析，代表人物就是晚期拉康。如果你想很好地理解它，齐泽克当然是必读的；此外还有一个较年轻的托姆希奇（Tomšič），他的书也值得读。你可以把他看成年轻的齐泽克。他的代表作有 The Capitalist Unconscious，还有一本叫《元乐的劳动》（The Labour of Enjoyment，也译作享乐的劳动）。如果你想具体了解这个流派，又没有时间读晚期拉康，或者没有时间把拉康那些研讨班、十七、二十那些研讨班拎出来看，那我建议你直接看这两本书。

它是对资本主义本身进行精神分析，但我要告诉你，它最后产生的并不是一个分析话语。我觉得与其说它是精神分析，不如说它最后产生的是实证话语，是大学话语。这是我个人的观点：它最后生产出来的是大学话语，而不是分析师话语；它最后生产出来的是一套大学话语，和马克思的《资本论》一样，是一套大学话语。

对于新的共同体、新的社会可能性，我们再看它的场域论。场域论上做协调的，就是这个 proletarian。它是一个主体性，但是社会的、universal 的、普遍的主体性（subjectivity）。也就是说，它是一种无意识主体性，是 subject of unconscious，是无意识的主体。无产阶级的主体，就是政治主体；政治主体就是纯粹否定性（pure negativity）。所以这个结构实际上最像观念论。

在场域论上，左边站着的是生命，但这里的生命就是 capital，也就是 life without negativity：它是一个生命，但没有否定性，毫无否定性。它会不停地生出两种东西：一种是它的增值，它会不停自我增值，但这种增值会甩出剩余；另一方面，它又能够使主体性闭合，能够产生 fantasy。也就是说，一方面它增值，不停创造出一个创伤的、被剥削的主体；另一方面它又能够不停闭合，通过幻想机制，通过中间这个菱形，把两边闭合起来，并在这里产生剩余快感。剩余快感和剩余价值一样。在拉康那里，这个结构就是无产阶级和它的剩余价值，中间这个幻想让你看不见它，或者让你觉得世界是平滑的，没有剥削关系，没有创伤断裂，这个世界是由一种意识形态所主导、所弥合的。

所以这个主体一方面处在一种不断日复一日、年复一年的生命当中，另一方面它又在理论当中生存。这个理论代表的就是 abstraction，即抽象。这个抽象就是各种社会话语：政治的、法律的、经济的、心理学的、文化的、哲学的、观念论的、现象学的等等。这些社会话语进行理论抽象，而这些理论抽象在每一个理论里面都是一个整全的。这样一来，理论和现实之间就有张力。我认为这两者之间有张力。理论和现实之间的张力是被什么调和的？或者说它是被什么再生产的？又或者，是由于什么原因让你看不见它？是由于无意识（unconscious）。也就是说，一个政治主体一定是无意识的。

一个政治主体一定是无意识的，他不能反思，无法反思。比如一个具体现实劳作、不在这个链条里面工作的人，他无法反思。他无法反思的原因，不是因为有一个理论给他画了一些图或什么，而是因为这个体系使他的反思都是无效的，因为他的反思是犬儒化的。他恰恰有反思，而且恰恰反思到这些不同理论圆谎的方式不一样，所以他会觉得自己反思得足够充分，因此他是不能反思的。我们处在一个反思过剩的时代，或者说反思有好多好多种，到底哪个才对？哪个都不对。于是可能产生一个幻觉，觉得这说明社会本身还是像康德主义一样，是融贯一体的，背后那个本体本身肯定是一致的。但问题就在于此：政治主体无法抵达他的意识，他无法获得意识。政治意义上的这个主体，只能否定；但这种否定性又反过来为他注入了生命力，因为它缺 negativity，这种否定性让它危机化，然后又为它注入生命力，使这个能指链转起来。

所以晚期拉康就是在思考一个无意识的结构：它如何能够……索绪尔式的、传统结构主义失败了，就在这里失败了。我们讲三杠四讲到这里，就很明确地说明，传统结构主义所把握的那种结构失败了，因为那种结构没办法解释清楚：它如何产生出否定性；另一方面，它如何会有否定性作为它的动力学机制；另外，它如何有一种表象化、具象化的机制；最后，它如何产生出那一层客体性，也就是 objectivity、客观性。它让你觉得背后没有一个结构，事情本来就是这样的，让你忘掉那一层，或者怎么样，whatever。

在本体论上是四，也就是不存在历史。不存在一个融贯的一致的历史；没有的。你不能去幻想有一个作为场的历史。这相当于《共产党宣言》里面那句话，严格意义上讲，就是：迄今为止的一切历史都是 class struggle 的历史。由于迄今为止的一切历史都是 class struggle 的历史，所以在 class struggle 里面，它一定会导致历史、历史的那个视角。何为历史是没有答案的，这是一个分裂的；历史之势，历史要势，它是注定失败的。

如果这是马克思在《资本论》里的一个洞见，那么《资本论》的核心洞见就是：不存在社会关系，但是存在社会，因为社会就是 class struggle 所不停派生的一个场。会有一个共识性的场一直存在，但如果你说它的历史性，你就不能幻想有一个历史作为社会的根据律。你没有办法设想社会有一个时间上的因果链条，不能设想社会有一个时间上的因果链条，也就是它的历史在决定着社会往下面怎么走。这是非法的。为什么？因为历史当中没有历史，因为一切历史都只是 class struggle 的历史，the history of class struggle。所以在这个意义上讲，它是不存在的，它不能够抵达一致，在本体论上。

那么从它的一个切面上看，就是不存在社会关系。在一个当下的社会、一个历史之切面上，不存在社会关系。你不能说这有这个关系、这有这个关系，不是的。应该说，从他的视角他有这个关系，但从他的视角这个关系没有；他是和他，然后这边有这个关系。社会关系本身是不存在的，因为你没有一个上帝视角可以去评判社会关系，没有上帝视角可以评判有什么社会关系存在。但是社会本身存在，因为 class struggle 是现实发生的，它是无意识。社会本身是有的，因为它是无意识的生产场、生产场所。它生产的不是无意识，而是无意识生产主体性和客体性的一个场所；它不停地生产这两个东西，生产否定性和生产实证性，或者叫 objectivity。

我再强调一遍：这是我们达成的共识，斯洛文尼亚学派达成的共识——社会关系是不存在的，但是社会是存在的。因为社会作为一个由 class struggle 构成的博弈场，它本身是一个 empty signifier，一个空能指。社会本身是什么？这是空的，需要由 class struggle 的博弈去定义它，但是社会关系不存在。那些自由主义左派则认为社会不存在，比如福柯、德勒兹这些人，社会不存在，是游牧的；但是社会关系存在。自由主义左派反过来认为社会关系存在，而社会不存在。美国那些白左就是如此：社会关系是本真的，而社会则是不存在的，不能预设一个场，却可以预设本真的社会关联，whatever。这种观点反而是糟糕的，因为它完全忽视了社会。他们想要很多局部的、细的、一簇一簇的东西，由这些细的一簇簇的东西不停涌动起来，就制造出一个社会的假象。这是自由主义 leftists 扯的一个臭谎。真正的答案应该是：社会是存在的，但是社会关系永远无法结构起来。社会没有一个公开的、中立的、平等的视角，永远没有一个绝对视角可以描述有什么样的社会关系。但是我们必须说，每一种力量都在不停挣扎着，想要把它的社会关系固着为社会本身，或者把它的社会关系隐藏、压抑下去。比如布尔乔亚，他就拼命把他和普罗大众的那种 exploitative 的社会关系压抑下去，然后把压抑下去的资本、资本主义雇佣制直接说成社会的本质，那就是普遍的商品化。雇佣制被掩盖成一种商品化，他会说社会就是资源的有效分配，等等，就是各种力量场，或者财富积累、聚集、交往的一个公共场所。

用这种方式，他就把他视角下的社会关系堂而皇之作为社会本身那个隐藏的本质属性，让大家忽视这一层，然后去承认其他衍生出来的社会关系。社会关系是不可能的，因为从他的角度，他会以他所理想的社会关系，把它变成社会的根本规则，压抑下去，让你看不到这个社会关系。所以从他视角里面看到的社会关系，他会努力让它变成社会的普遍法则，伪装成社会的普遍法则，然后让大家看不到它。岂止如此，这个社会关系本身，而且是一个 partial、局部片面的、他所愿意去设定的一种社会关系，一种政治意图，想要把它埋设到社会本身的底层，作为社会的底层机制。所以它不能成为一个关系，不能拿到台面上让大家去认同它。一旦它拿到台面上让大家认同它，它就失败了。

另一方面，比如被他压抑的那一部分人，也就是普罗大众，他也会有自己脑子里设想的一种社会关系，然后希望把这种真正平等的、按劳分配的社会关系，把多劳多得、不能不劳而获，作为社会的底层规则。社会关系总是 partial 的。就像男女关系：男人眼里的女人和他的关系应当怎么样，女人眼里那个男人和他的关系又怎么样，这两个关系不一样，不对等，对不上。但是在过程当中，由于不能摆到台面上，男人要让女人和他成为某种关系，就必须把这种关系压抑下去，作为他和女人交往时的一个底层规则，想要以这种方式引导他和那个女性的关系。所以台面上的关系就是绅士，或者是一种男权；但骨子里的关系不能拿到台面上，不能让对面认同或者直接看到，是见光死的。所以在这个意义上，社会关系是不能存在的。就是《资本论》里面以结构主义的方式表达这个社会关系不存在，存在的只有局部的意识形态化，还有侧向的、从一个角度出发，他想要去奠定一种光滑的社会机理。但是社会是存在的，社会作为这么一个空的能指的博弈场，它是存在的。

这个场之所以存在，是因为大家都把它的根本的社会关系、那个理想社会关系都承认，但这个东西不能放到台面上，我们要压抑一个东西，把它放到下面去，好让它变成这个擂台的基础。大家都愿意把一部分想法、点子拿出来，与虎谋皮，都视对方为虎，要与他谋皮。那么既然如此，就要把一堆鬼主意埋在下面，好像当面要握手，要公平竞争、公平竞赛。所以大家的最小公约数就是：大家都认为有一个场、有一个规则，但是这个规则不能言明，要压到下面去。我的规则是我的这样，你的规则是你的这样，它们可能有一个同样的名字，这个名字就是社会。或者说，我普罗大众有我的平等，你布尔乔亚有你的平等，但是大家都认有一个平等，都追求平等，而且他们在台面上都说我们追求的是同一个平等，说不定都认；但是下面压在下面，他们博弈的时候，真正用的规则、那个平等，是完全不一样的。所以大家达成的最低共识是：可以有一个场，要有一个场。这个共识也是无意识，是无意识生产出来的客观性。就是这么一个社会作为一个场，它是要有的，但是这个场是个空无的场，各方压抑下去的东西是不一样的。

所以在认识论上，这个四就是无意识（unconscious）。但这个无意识，认识论上四甚至……我是不是更确切一点？在这里，认识论上的四更多指的就是所有的抽象活动，也就是 abstraction。我就这样写，不说无意识吧，我就说认识论上四意味着所有的 abstraction，所有的布尔乔亚理论化活动，都是不可信的。它都是不可信的，或者说它都是一种异化（alienation）。所有 abstraction 都会带来 alienation，或者都会带来症状：都会有那个剩余的东西做症状，都会有它的症状。认识论上是四，我甚至可以写，就是普遍的意识形态；但是意识形态缝合一定会有剩余，一定会有这个症状（symptom）。abstraction 意味着理想化，比如显艳化、超艳化，各式各样的 abstraction：政治的、经济的、心理学的、文学的、哲学的。整个布尔乔亚的学术体系和意识形态体系都是四。晚期拉康的理论姿态就是这样的：这些 abstraction 都是……那么他要用的就是 separation，要用这个 separation 来代替 abstraction，要体验到那个主体性的匮乏，要去主体化。

在所有的资产阶级、布尔乔亚话语里面，这个 abstraction 都会给你一个主体性，要么给你一个主体性，要么给你一种生命活力。这个主体性就代表生命、活力。所以在这个意义上讲，无论是德勒兹、瓜塔利，还是马尔库塞、阿多诺这些搞爱欲批判的人，觉得资本主义是压抑的，压抑了生命力，压抑了主体的生命力，压抑了那种涌动的活力——这些东西通通都是 abstraction，通通都是不可信，通通都是意识形态，通通都没有用，屁用没有。这些东西都构不成否定。真正的否定要靠 separation，要去主体化。这个主体是一个被动的主体，是一个消极的主体；或者也不叫消极吧，他就是说他不会把自己卷入欲望辩证法的回旋里面，他会自激发。

然后在目的论上，目的论上的四，同样，我在这里再强调一遍：这个目的论上的四就意味着那个调和失败了。主人话语和癔症话语，你想用分析性的分析话语去调和它们，这是没用的，注定失败的。这是注定失败的。目的论上，分析性的话语是注定失败的，it must fail。那么拉康，我的观点是，拉康在这里等于说是半个实践者的姿态。他踏上了一个注定失败的冒险，就是要重新获得一套……所以我认为这个体系是一个三字头，他要重新获得一个大学话语、普遍话语，或者说 discourse of universal universe，就是要获得一个 S2。这是失败的。他的目的论上就是说要做那种无力的理论化，是一个无力的理论化，是一个注定失败的理论化。目的论上的四，意思就是，你们要明白，那种理论家的姿态最终是绝望的，是绝望的。

结构主义，而且是马克思主义的结构主义，不是索绪尔主义那种结构主义，而是《资本论》里面那种结构主义。它的方法是个绝望的方法，也是一个解释学方法；我甚至可以说它是一个解释学方法。我要重复一句话：就好像你是一个历史当中的人，是大海当中的一个舵手，你手上没有地图，也没有什么无人机给你开上帝视角，你只能凭借海平面、风浪，还有天上的星图，还有云朵的状况这些东西来判断。你只能有很小的东西、很少的东西来判断。这是一种诠释学方法。

理论家在进行这种结构主义言说的时候，你要把你自己考虑在内。我只能这样说：你要把你自己考虑在内，就是要把自己作为一个理论者考虑进去。你的著作不一定要完成，比如拉康，比如马克思，到死都没有结束这些问题。但是，他就是那种绝望的，但又不放弃、绝不放弃的理论化。它虽然是无力的，是不注定成功、注定失败的，是一个无力的理论化，但一定要去构造一个大学话语，也就是说一定要 positivization，一定要把这个世界的运行方式肯定地道出。关键问题就在于，他的方法是结构主义的，他不设定任何本体论根基。

但马克思主义的结构主义要求从一个无意识的符号系统出发，你要去描述它如何自己生发出主客体，自己生发出一整个本体论化的力量。比如马克思对商品、对价值理论的研究，在阿尔都塞的解读里，这里面就有一个认识论的断裂，或者说有一种全新思维方式的产生。这种全新的思维方式，不是根据背后有一个历史、有一个因果链、有根据链条、有理由链条往这里牵引；它这里的历史完全是断裂的。它的文本话语，就是你可以自己捉自己的错。如果说有一种辩证法的话，这种辩证法我勉强可以说是唯物主义辩证法或者结构主义辩证法：它就是自己捉自己的错，自己和自己在对抗、在博弈。因为这个符号系统里面本体论化的那些机制，会有一个主体或者一个客体生成出来。比如《资本论》里面告诉你，资本主义的运动如何把主体性不停再生产，让它有剩余价值、有否定性，然后又不停地把客体性、把这个世界抹平，弄成一个没有裂痕、没有沟壑的东西；它的生产机制是怎么弄的？那么你这个大学话语在描述过程当中，凭你这个理论家咋说咋地，但是你要使得你这些话语具有解释性，甚至具有预言性，那么在目的论上，它必须持这个四的姿态。必须持一个四的姿态，必须持的是一个假模假样的——不叫假模假样，是真诚的、自信的姿态，而不是主人话语那种 pretend to know。positivization 是真诚的、自信的、相信的。

那么对于拉康来说，他的自信、相信的那个主人话语，其实是不说话了的；这个主人话语就是这个无意识的主体，就是无产阶级、普罗大众。但这个无产阶级、普罗大众又是一个比较抽象化的东西，它不是具体化、现实的谁是谁、哪些人、哪几个人、哪个人，不是哪种收入或者工作、身份背景的人，不是这样的。他得是真诚、自信的，没有怀疑的，无疑的。无疑就是他不怀疑自己的根据。也就是说，他在场域论上设了这三个场，然后由这个调和，由这三个道场做游戏就做下去了。但他有一个姿态，知道自己这个东西有可能是错的，有可能是冒险的。他领会场域之中的一个分裂，然后用他的主体性，纯粹的主体性，作为时代的一个共性。我们每个人其实都是 proletariat，都是普罗大众，因为我们的主体性样态、基本样态，在资本主义这个时代，在这个 global capitalism——我指的是国外，或者说全球除了少数几个国家、我们这些国家之外的那些资本主义现实当中——这种主体性的基本样态、底层样态就是无头的主体性，或者叫无意识的主体性。由这些前提出发，由这些符号学的基本格局出发，你必须冒险，理论上就只能冒险到底。

我再强调一遍：理论家最激进的姿态，不是主人话语，也不是癔症话语，也不是分析师话语。我觉得他最激进的姿态，冒险到底的话，就是普遍话语，就是 discourse of universe，大学话语 S2 串在后面。因为你们最后要意识到，S1 是被回溯性地建构的。什么是主人话语？这是回溯性建构，理论工作先行。我这里觉得，这就是这些大人物的最后的生命寿命、最后的理论工作，但也是理论工作先行。但是这个理论要坚持马克思主义的结构主义原则：一个无意识的符号系统，本身具有生产性，具有生产力。它会劳动，它会再劳动。这就是信仰，这就是核心信仰：世界是活的。但这个活不是像资本体系那种无脑增值意义上的活，不是符号系统的无脑自我循环；这个活意味着它能甩出否定性，它会有一些丑闻，或者一些致命的断裂。这致命的断裂要靠体验主体性中介才能不停地划过去，或者 whatever。无意识，就是无意识符号系统，再说一遍，这就是物质。物质具有……我不太想说得太清楚。它具有生产力，它具有劳动力，但是这个劳动更多的是在它的褶皱上，在它的符号系统的不一致性上面涌现出来。这种不一致性、这种褶皱，也往往就会被叫做 enjoyment，元乐，或者就叫里比多。
