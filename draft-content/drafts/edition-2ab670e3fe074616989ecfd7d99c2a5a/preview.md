# 【主义主义】相对语法主义（2\-4\-3\-1）——维也纳学派创始人&amp;逻辑实证主义运动发起人之一，石里克用逻辑语法建造的乖宝宝形而上学

今天要讲的是“主义主义”的二杠三、二杠四杠三杠一。它的代表人物又是哲学型的，是史里克。这个主义可以叫 grammaticism，或者可以叫 relative grammaticism，也就是相对语法主义。

但史里克晚期在目的论上是一，因为他也可以看成是一个开明的人，是一个平等主义者。他晚年时——其实没活到晚年就被学生杀了——可以看成是乖宝宝那种类型。他的伦理学没有创伤性，认为所有语法在某种意义上都具有平等关系，都是相对的。所有行动都想获得自己的幸福；他的伦理学很简单，也专门有一本书讨论伦理学。里面的伦理学基本上就是傻白甜：不同的行动、不同的行动种类，都可以平等地追求、设定自己的幸福，就好像这些东西相互之间没有冲突一样。

他认为伦理和共同体的目的就是幸福的最大化。但另一方面，他又认为我们的行动可以通过一套特有的语法来规定它所追求的幸福是什么。那是不是我只要说出我的幸福是什么，就实现了幸福？不是，相互之间有冲突。所以他背景性地预设了：看上去是平等主义的，其实不是，实际上是个保守主义。也就是说，实际上是那些已经把位子占住的人，他们追求幸福的方式已经结构在共同体里面了。你如果是被压迫的人，想要获得你的幸福、定义你自己的幸福，就一定会和别人的幸福相冲突。在这种情况下，他就认为不行，因为你违背了幸福最大化；大家都平等，你怎么可以和别人冲突呢？

你如果是群体的行动，在他那里就不能……你可以自己设立你的幸福，但你的幸福就是鸡同鸭讲。比如底层泥腿子说：我不承认，我追求的幸福就是要让你们付出代价，要让你们受到伤害。但在史里克那里，他就认为他们说的不是同一种话，其实认为他们的语言不是同一种语言，不服从同一种语法。看上去像相对主义、平等主义，其实这里面是一种保守主义。当然你可以说他说他的、我说我的，但如果他以我的痛苦为乐呢？这个时候我只能……我不能再用语言、用语法的相对性或平等关系去抗争，不能这样搞。所以史里克这个“一”可以看成保守主义的“一”。看上去是大家都追求幸福最大化，我就觉得有点怪怪的。

史里克的体系里，相对性是非常明晰的。因为在语法上，比如说在“概念”上，conceptual，概念本身其实是——那个叫什么名字？——庞加莱的约定主义，有一定的约定主义色彩，有很强的约定主义色彩。史里克有很强的约定主义色彩。他最核心的 implicit definition，这个观点后来被逻辑实证主义——其实是那些外人用逻辑实证主义的时候——说成什么隐意阅读也好、隐意写作也好，其实早就有了，就是“不清晰的定义”，即隐性定义。史里克那里就已经有了隐性定义。他认为，一个……

一个命题系统、一个语言体系或理论体系，它的 axiom、它的公理本身不能被显性地定义。公理本身是怎么样？公理肯定也有一些组成部分、一些概念。公理一是这样，公理二是这样，比如有三个，或这里有两个。隐性定义有两层含义。一层含义是，它可能援引一个什么——如果把史里克看成早期实证主义、纯粹实证主义、很死硬的实证主义，那么这个隐性定义可以把握成：公理一和公理二的隐性定义意思是什么？就是早期实证主义版本、死硬实证主义。你可以把它理解成，公理一和公理二只是纯操作规则。到底什么是公理一、什么是公理二，只是比如四个概念 a、b、c、d 之间的相互关系：在公理一里面它们有个逻辑结构关系，公理二涉及 c、d、e、f，再来个公理三又涉及 a、b、c、d。这样在三条公理里面，a、b、c、d、e、f 都各出现两次。它告诉你公理一、公理二、公理三的关系，它们之间你说它定义的其实不是一个定义，只是组成部分之间的相互差异。那实际上是一种结构主义，是一种比较结构主义的实证主义，直接导向比较死硬的结构主义。我说什么是公理一、怎么定义公理一，只能看公理一和公理二、公理三的差异在哪里。

差异就是公理一里涉及 a、b、c、d，其中 c、d 是公理二也有的，但 e、f 没涉及；公理三涉及 a、b，它们互相都差两个。这种差异、重叠关系，以及概念之间的逻辑关系——逻辑关系本身完了。这个东西实际上虽然看上去是结构主义，但是一种逻辑结构主义。这个结构主义不是真的结构主义，不是符号结构主义，它是逻辑结构主义，是蛇皮，不是符号学意义上的结构主义。它有一个形式逻辑前提，有形式逻辑、形式语言前提。比如这里面有一些逻辑关系，有一些词、量词，这些操作符，史里克他们会默认这些东西本身不需要定义，在他们看来就是纯操作、纯心智操作。比如否定、取合集这些操作——取合集可能还需要定义一下——但基本的逻辑连词，他会认为是白嫖的。它是个逻辑结构主义，它的结构主义建立在一个逻辑形式框架最深处的框架前提之上。他不会怀疑这种东西，他把这种东西看成是严明的。

这里实际上就有等级制。你凭什么这东西不可以？你凭什么这些东西不被看成和 A、B、C、D 这些东西一样？比如推导性的符号代表一种分析性，你凭什么这种东西……然后他就不管，他就认为这些东西是比较原初的结构。如果它是死硬的实证主义，那它的隐性定义就是结构主义色彩的。那么如果他到了晚年——也不叫晚年吧，比较缓和了——他的约定主义或相对主义色彩更强，或者向意志性稍微敞开的时候，他就不是结构主义了。

可以看成，这个时候的隐性定义已经包含了一定的语言之外的东西，有那种构成性例外的感觉，即语言之外的一些要素。就是说 A、B、C、D 可以有一个 G。举个例子，它不是靠公理之间的相互差异关系来使每个公理都得到隐性定义，而是总会有一些例外性的东西来补充，或者直接弄一个公理四，为这些例外性的东西开后门。它会有这种。所以这个我不知道叫什么，不太清楚给它取个什么名字。它有点像自然语言敞开了。它会倾向于认为，一种语言里面没有很明确的公理体系，没有专门的公理集，也没有很明确的句法——不像卡尔纳普搞句法主义，没有很明确的一堆句法告诉你哪些句子合法。我操，那我们怎么构成所有的句子？

不这样做也可以让一些语言有意义，也可以让一些语言有……但他们只处理一些非常形式化的语言，比如史里克只处理唯我论语言，以及包括其他一些形而上学语言。他晚年的时候也会比较没那么激进，会认为这些语言其实也有它自己的意义，只不过它想要设定自己的 grammar、自己的语法，只要它服从自己的语法。但关键问题是，这中间有一个点：什么叫服从？什么叫服从语法？

服从性与语法一致，与语法相一致，这个一致性其实就是史里克思维的一个命根子，叫做 point coincidence，重合点。point 就是点的重合，coincidence 怎么拼？coincidence。这是个数学方法，简单得不能再简单：比如 f\(x\) 和 g\(x\) 联列，取两个函数，一个函数一条线，另一个函数另一条线，把两个函数表达式联列，就可以得到交点，这个交点就是 point coincidence。这个其实没什么技术含量。爱因斯坦在广义相对论的证明上好像用到了 point coincidence，我不是很懂，就是利用有那么一个点。那么史里克为什么会用到这个概念呢？

他是为了使得在广义相对论，或者说相对论、相对性为认识论本身——你可以看成史里克其实是一个认识论家。他为认识论提出了一些难题。比如，首先相对论会告诉你，一个稳固的公共图景是不存在的，因为时间和空间这两个坐标都取决于你的私人参考系。时空关系的变动，一个对象在时间空间关系中的变动，它遵循的 law、它的模式、函数关系，对于每个私人参考系，都有平等的惯性系，都有它自己的合法性，都会说“我描述的就是对的”。所以，在不存在公共图景的情况下，你如何能够重新拼凑出一个公共图景？

他就用 point coincidence 的方式。他举了一个例子：比如教室上有个黑板，下面坐了好几排小朋友，两排小朋友吧。然后一个小朋友指了一下手指，指了黑板上的一个点，他的指尖和这个点，在这个小朋友的观察里面，就是 point coincidence。我们就设定这个东西是在语言当中不言自明的东西。然后其他人讨论：旁边这个小朋友看他的手指和这个点肯定不是重合的，但他为什么能够知道这个小朋友手指指的就是那个点呢？因为他的语言当中会领会有一种约定，有这种 point coincidence。因为这个家伙公开声明了他这两个点的重合关系，所以旁边小朋友想：你既然公开声明了，我就把它当成一种 grammar。这个时候就使得不同 grammar 之间可以有跨主体间性。你可能用的是一套 grammar，我用的是另外一套 grammar。也就是说，在这个意义上，我们才能获得真正的 grammar。一个语法如果没有办法交流，那算什么私人语言？所以说，史里克就是要通过这种重合点的方式，使这个语法具有跨主体间性，让大家能够建构一个公共图景，可以指称同一物，或者说可以表达同一种逻辑关系、同一个命题，把握同一个概念，去转述同一个直观，等等。

史里克在场域论上，场域论上的“二”字头很明确。其实他们的场域论和认识论都是重叠的，就是直观 versus 概念。上面这里是直观性的第一人称体验，就是这个小朋友第一人称的内在体验。这个内在体验其实也是不同的感觉，不同的感觉样态，sense modality，比如触觉、嗅觉，不同的感觉样态，其实就是不同种类的感官，different kinds of senses。它也是经过类似语法性的拼合，这里叫 coordination，就是把它统一在一个坐标之下。比如你耳朵听见一个东西，同时眼睛看到一个东西，这两个东西在时间性上可能有差别，比如听到雷声，但你会把它命名为同一物：先看到闪电，再听见雷声。时间上有差别，但你还是可以出于一些习惯，或者出于对科学解释的信仰，把它看成同一个东西。然后你就会有一个 coordination，把你对同一个东西的不同感官弄在同一个参考系里面，合成同一个对象。这就是我说的左边这个场域是尚未被 coordination 的，也就是说左边这个场域可以说是离散的直观，离散的感官。

史里克没有去设想：你告诉我，比如你听一段声音，你怎么把握这个声音本身的连续性呢？他当然可以说，我们把握的不是这些东西；在最一开始的直观里，不存在离散的直观，你去设想一种离散直观本身就是有问题的。我们当然可以回溯性地回过头去分，比如我看到这个东西，是看到它的图像还是听到它的声音？但我能够分，其实已经是一种符号学操作，是一种例外的符号学操作。而不是说它一下子——比如一个美女趴到你身上来，又有香气，又有她的体温，又有她呼出来的湿漉漉的感觉，又有你自己各种荷尔蒙分泌的反应，这些东西混杂在一块不能分。你分的时候就已经说你没戏了；如果你这个时候很冷静地分这些东西，那你就没戏了，说明你对她没感觉。那我建议你不要逢场作戏了。我倾向于，而且在这个过程中，如果我们是个拉康主义者，我们更能够意识到，在这种情况下大量的画面是想象性的，大量画面是 fantasy。对于这种离散直观本身才是个 fantasy。根本不存在离散的直观，直观一开始就是各式各样的东西，都已经是被组织起来的。你后面分的时候，这个东西已经死了，然后再分，已经是在你的语法框架之下对它进行再分。但史里克默认有一种离散的直观。

在感官种类上它是离散的，甚至在它那个本身这个时空连续性上它都是离散的。本身在时空连续性上都离散——我们会默认这个时间不一定，它可能在时空连续性上还没有想得那么彻底，还没认为它是离散的。这个东西它就是一笔带过了。他只是觉得这些东西可以拼合到一块去，然后变成我们这个时候语言就可以比较合法地去描述一些直观性的东西了。但从直观走向知识，他严格区分直观和知识，知识当中就包含一些约定性的东西。

约定性的东西背后是什么？是科学共同体的权威。举个例子，比如说知识：同样的直观，你既可以说是洛伦兹的尺缩定律是对的，你们自己去搜索洛伦兹的尺缩、空间收缩、长度收缩，length contraction；也可以说是爱因斯坦狭义相对论的一个解释，就是测地线，光跑测地线。相对运动起来，按照那个速度有尺缩效应。尺缩效应其实根本尺没有缩，实际上没缩，是因为光线会沿着空间的曲率、按照测地线跑得最快，沿着测地线按照曲率。尺缩效应我不是很懂，我漏洞百出，别管那物理系的人随便喷我，我在这里只是要讲明一个道理。比如史里克就会认为，你对于一个直观想要变成知识，其实这个时候有好多种解释。这个时候有两个东西，一个叫表征框架。在一种表征框架之下，比如洛伦兹的电磁学——我不知道电磁什么学——洛伦兹电磁学是一种表征框架，然后爱因斯坦的相对论是另外一种表征框架，它各是一种表征框架。这些表征框架背后都是一种揣测，其实这两个东西都是 hypothetical 的，都是猜测性的。洛伦兹的长度收缩也可以解释水星进动还是什么，我不知道，反正后来证明爱因斯坦相对论是正确的那个实验，洛伦兹玩也行，就很烦。它们有不同的表征框架，但洛伦兹的表征框架简单，对现实的描述就很复杂，要长度收缩，按照它那个复杂的方程式收缩；而爱因斯坦的表征框架复杂，空间曲率，它有个爱因斯坦的度规方程，我操，一堆什么十几元的函数，我靠，我他妈服了。

哦，那个叫张量，有十个分张量，那个叫张量。它的表征框架比较复杂。爱因斯坦对于空间的 geometrical behavior，它演 confirmation 吧，还是那个词怎么说的，就是空间本身背后的几何学构造，它对它描述很复杂，表征框架很复杂。但是爱因斯坦对这个直观的描述很简单，他用很简单的一点：光线沿测地线跑。比如看到光线从太阳那边过去的时候弯曲了，那么爱因斯坦对它的解释很简单，对它的描述很简单，描述这个现实的方式很简单，very simple。但它的表征框架很复杂。而洛伦兹的长度收缩是在经典牛顿力学绝对空间和时间的体系之下搞的，所以它的表征框架很简单，就是牛顿力学的一个表征框架，但它对于比如光线弯曲，对于这个事实的描述就很复杂。你选哪一个？
