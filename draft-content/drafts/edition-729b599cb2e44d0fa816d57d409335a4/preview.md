# 【主义主义】体系化的理论探索（4\-1\-3\-3）——总要有人探索野路子

我们今天要讲四杠一杠三杠三。代表人物其实很多，这也是一项实践工作。代表人物包括奥地利马克思主义学派，以及 Hilberg——他当然是奥地利马克思主义之父——还有格律贝格。格律贝格开创的早期一直延续到霍克海默早期，当然其中很多人是反霍克海默的，也就是早期法兰克福学派。

他们的立场都比较中派，包括法兰克福学派也是中派，超资产阶级，也超意识形态对立。

这个体系，我一般把它叫做社会主义理论探索。准确说，应叫体系化、系统化的理论探索，尤其是对社会主义本身进行系统化的理论探索。这是以奥地利马克思主义学派尤为突出的中派特点，早期法兰克福学派也如此；但后面就不行了，法兰克福学派到阿多诺之后就开反极权主义之类的东西。

这种理论探索包括帝国主义论。帝国主义论的理论探索，是奥地利学派为列宁、也为布哈林做的准备，还包括 national capitalism，或者叫 state capitalism，也就是国家资本主义。这是 Hilberg 的助手——叫什么名字？——波洛克率先去研究的，这些都启发了 L。虽然我们要说，奥地利马克思主义学派在思维上有点新康德主义、neo\-Kantian，也有点马赫主义，但马克思主义被列宁狠批，新康德主义的认识论范式也被列宁狠批，因为它削弱了二元对立，也削弱了阶级性，削弱了革命性。

但是，奥地利，也就是格律贝格这一系，包括奥地利马克思主义学派，他们对社会主义本身的新的探索、新的研究，极大促进了当时的实践，包括列宁本人的实践：一国可以先建成社会主义，在落后的民族国家可以先反帝国主义的最新形态，然后可以搞 state capitalism；先锋队可以驾驭 state capitalism，把它作为工具、作为环节加以操作。这些研究都极具开创性，对社会主义如何实现、如何达成极具开创性。

我们要讲的就是这个。奥地利马克思主义学派后来肯定被干掉了，失败了。作为一个实践，它没有什么成果，因为四杠一杠一本身是理论活动；实践上，由于当时纳粹来势汹汹，奥地利很快被合并、吞并就没了，随后是搜捕，人都跑了。但当时奥地利马克思主义学派与第二国际——也就是讲德语的马克思主义，与考茨基主编的《新时代》——是两大理论中心，两个都很厉害；只是这个东西偏偏偏理论。

在奥地利马克思主义时期，比如在阿德勒这些人手里，马克思主义并不是首先被看成一种社会学，因为当时已经涌现出很多新的社会学范式；而这个社会学是以社会存在，或者叫社会的人、社会联系、社会连接作为单元来分析马克思主义。在认识论上，由于吸收了新康德主义的一些认识论，他们已经认识到不存在绝对的经济物质，不存在绝对和人没关系的经济物质。

经济物质这种看上去所谓物质性、客体性的东西，在最低限度上也包含意识的维度、精神的维度，或者说具有精神性、意识性。所以在这里他会告诉你，你所谓的经济物质也是社会化的一种存在，但它不是一个主体化的、第一人称内在的体验，因为它是一种社会存在，是社会中人与人之间的关系，产生了异化。比如你和母亲的母子关系或母女关系，这种母女关系、母子情、母女情超越你和妈妈两个人，超越个体，超越实体化的节点，是一种精神性外化；精神可以外化，而这种外化嵌入经济活动、物质生产活动当中。所以在这个意义上，奥地利马克思主义学派一开始把马克思主义看成一种社会学革命，看成以社会性的方式、以社会关系作为基本理论对象和现实单元来解释整个现实。

从理论产物上讲，它实际上相当于后面二杠三里面的二杠四杠三那种社会学实证主义，有点像二杠四杠三；但就这个活动本身而言，它是一种体系化的理论探索，可以为具体实践献策。这非常重要。这种理论努力，你想列宁哪有时间？他没有时间。他的理论思考当然有天才的，比如像 T 有天才的洞见、历史的远见，但同时他要吸收这些理论思想家在头脑风暴中所进行的探索，吸收他们的新想法。

我甚至还要说到后面，包括早期法兰克福学派、三大助手，还开始讨论东方专制主义，讨论东方专制主义下的社会主义实践形态，然后开始用这种方式来抨击 L 和后面的 M。他们会玩这种东西。

这个论域可以反思现实，具有对现实的反思力。它必须不在俄国或另外一些地方，不能在政治的漩涡、风暴中心当中，得稍微离远一点。所以四杠一杠三是必要的；最冲突的地方是暴风的最核心，四杠一杠三杠二是外围安宁的地方——科尔施被开除出去——而暴风的最核心是 S 本人，S 本人有教科书化、体系化的活动。那么在暴风外围，还必须要有对这种种现象加以批判、加以反思的理论实践活动。这是必要的，这种探索是必要的。

我快速把长于论过一下。长于论上这个“四”是实践单元。这个单元，比如早期法兰克福学派，当时以高级知识分子读书会的形式，叫马克思主义工作周，Marxist 的工作周，有高级知识分子参与；这些高级知识分子都是西欧一些著名的 Marxist，就那几个：卢卡奇、波洛克、科尔施这些人。他们在德国定期会聚。

他们好像就聚了一次，讨论了三个主题，主题就是怎么研究马克思主义。马克思死了，总不能拿考茨基这种废物搞出来的东西，不顶用；或者列宁搞的那一套也很粗糙。那我总要在思辨上、思维上进一步探索。以这种工作周的方式，形成一个学术共同体；可以说，这不是布尔乔亚知识分子，而是这些内部的我们自己人组成的学术共同体。但要在比较外围的风暴之外，政治性不能太浓，宗派性也不能太浓，这些活动不是宗派性的。

不是要抢山头，不是“我代表我赢了”。当然具体个人会有这种想法，但结成这个学术共同体就不太会有。具体个人当然会有。早期法兰克福学派后来还会编 MEGA——MEGA 是马克思恩格斯全集的考证版、历史考证版——还要做文库，比如社会主义和工人运动史文库。他们会搞这些东西，这是一个系统的理论探索、系统的理论整理，重新整理和探索 MEGA。

现在是 MEGA2，是吧，又搞了一次。我都不知道；我记得以前上课时就有一个搞这种文献性、思想史梳理性的“历史人民理论家”。在他们一般看来，他们还是认为，这里所谓“人民”可以看成是……你大概能够明白：历史必须通过社会关系——社会关系的动荡、变动、快速变动，社会模式的快速变动——来理解。这个历史是什么？是革命史，是运动史，社会主义运动史、工人运动史。在大量社会关系剧烈变动之下，理论家可以进行社会学考察、经济学考察、政治学考察，这是跨学科的。这些学者用的学问范式很多，有统计学、新康德主义，还包括格式塔心理学。这些理论家会大胆运用大量布尔乔亚共同体里面的学术范式来考察；大家认为学者就该大胆一点、开创兼容并蓄一点，可以用这些东西，然后反过来观察运动当中社会关系的变动——人的实实在在的活动所导致的社会关系的变动。社会关系变动不就是人吗？人不就是社会关系总和吗？然后通过这种方式来搭建新的理论体系。

奥地利马克思主义，我们的 official 对它评价颇高；它是中派路线，所以评价颇高。我们的 official 评价颇高，像贴金。

本体论上还是一，一般可以把它说成社会存在，一种比较温和的社会存在。这种社会存在用相对科学的社会学方式去研究它内在的社会存在和社会学；或者他们认为马克思主义是超意识形态的。但问题来了：那认识论上的对立怎么说呢？

左边是科学，右边是哲学；左边是纯应用性、布尔乔亚性的，右边是哲学的、总体批判性的，局部运用性的就是分科运用性的。我们会想起恩格斯在《社会主义从空想到科学的发展》第二章所说的：哲学和具体的、在近代被形而上学化并分割开来的科学之间的对立。这边是形而上学，那边是辩证法，是一种总体性、批判性的辩证法哲学。那么这种认识论上的对立，这边是布尔乔亚、是普罗，由什么来协调呢？由什么？其实是由跨学科——我们老师说跨学科的——但同时又是一种社会学性的研究，社会研究。

跨学科的社会研究，其实是一种社会学；但由于它的跨学科性，以及它马克思主义范式的哲学批判总体性，所以它具有跨学科性。法兰克福学派就是法兰克福社会研究所。他们也研究马克思主义的研究方法本身。他们说，在认识论上，这种跨学科社会研究的最终目的，就是要弄清楚马克思主义的研究方法本身到底是什么，研究方法本身应该是什么样的研究方法。这个研究方法本身就是一个开放的理论探索活动。

所以，他们有一种总体化的精神，依然有一种总体化的精神。这里的本体论依然是一种总体化，这个社会存在依然是一个总体化的。你不要以为自己就有资格去喷斯大林，对吧？总体主义者也是总体化的、总体性的。社会存在、社会生活的所有领域都要被思考，所以它并不是一般意义上后来布尔乔亚学术分科化之后的特异化，不是和经济学、历史学、政治学并列的社会学。这个社会学是无所不包的、包括一切的社会学，是总体性的社会学。
