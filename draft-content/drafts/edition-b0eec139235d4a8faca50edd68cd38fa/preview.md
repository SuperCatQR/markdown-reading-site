# 【主义主义】宇宙悲观主义（1\-1\-1\-4）——科幻小说家的虚无主义自恋范本和假冒伪劣宏大叙事

我们今天要讲的是主义主义的 1\-1\-1\-4。它的代表人物很多，往往是小说家，尤其是科幻小说家。我们先讲它的名字：cosmism。cosmism 是 Lovecraft，也就是写克苏鲁的那位小说家提出来的。他叫它宇宙主义，我把它翻译成宇宙悲观主义；翻译成宇宙主义不足以表达它的底蕴。宇宙悲观主义是指，人类面对的这个宇宙是冷冰冰的宇宙，目的论上没有以人类为中心，也没有像 1113 那样把人类幸福的增值、积累当作整个体系的目的。它的“四”就是：它是冷冰冰的，没有目的可言。科幻小说家，比如刘慈欣，也基本上是这样一个宇宙悲观主义的调调。这个就是吓人的，是用来吓人、用来进行去目的论化的，把世界的存在去目的论化，变成一种宇宙悲观主义、虚无主义，或者一种生存的失败主义、悲观主义。这是悲观主义、失败主义、虚无主义的状态。这个东西其实很好理解。

代表人物、代表物品就是二向箔。二向箔就是很标准的东西，什么降维打击、高等智能降维打击。这个很无聊，It's very boring。因为无非是文明分几类，这种意识形态是近代以来比较矬、无脑的科幻小说喜欢搞的；无脑的、矬的、蛇皮科幻小说最喜欢搞这个，骗人的，文明分几类，然后越来越屌、越来越厉害。怎么可以用一个行星的能量、一个恒星系的能量、一个大型星系（不是银河系）的能量、整个银河系的能量，文明又分成几类？我靠。

这个游戏骨子里就像小朋友刚学会数学、刚会数数的时候，互相攀比谁能数的数更大。比如我说我有一亿块钱，另一个说我有一亿再加一块钱。这种无聊游戏背后隐含了一个意识形态：人类文明就是一种文明，无论发展得多厉害，面对一个能级比它再加一，或者加零点零一，或者数字后面再加一个数字的文明——十的二十次方再加个数字变成十的二十一次方——就不行了。我记得当年 Flash 上有个网页小游戏叫《爬虫》，就是宇宙文明不停发展，什么十的多少次方，次方越多越屌。这种就是小孩比拼：“我有一亿，我有一亿，我有什么什么”，很无聊。

这是由于科学独断论或科学实在论，它最后面是数学精神。用康德的话说，这叫数学上的崇高，或者量上的 mathematical sublime，或者说数学上的无限、数学上的极致、数学上的二律背反。数学上的崇高、数学上的无限，通过量的堆叠，不停超出外部边缘、超出界限，就会走向宇宙悲观主义。宇宙悲观主义意味着：无论人类文明在 1113 里面多幸福，人类总的幸福多厉害，人类文明多强大，可以支配十的一千多多少次方的能量，宇宙根本不管你；宇宙在后面再弄一个比你多一个的能量，就把你干掉、干崩。很荒谬、很蠢。无论你发展到多大的文明度，后面搞一个比你更大的，就干死你。

这背后有受害妄想症、受迫害妄想症的宇宙悲观主义。他感受到物理秩序的自行歧视，感受到这个秩序自行歧视、不顾中心化利益，不顾人类世界自我中心化的利益。人类世界会自我中心化，而物理秩序不顾它的利益，“关我屁事儿”。这里又是结构主义：符号系统具有自主性，能指的自主性，autonomy of 符号系统，自主性或自治性，被以反人类中心主义的方式感受出来。但他没有意识到……

他们幻想：比如人类世界的系统复杂度是十的一千次方，他们幻想十的一千后面加一个一万零一次方、一万次方复杂度的系统，会以莫名其妙的、像二向箔一样残暴狂野、道德上的恶、邪恶，或者冷冰冰、残酷无情、荒谬、没有任何目的性的方式，把它干掉或侵吞。就好像人无意中捏死一两个细菌、踩死蚂蚁。地外文明搞实验时也一样，比如人类在太平洋做核弹、氢弹实验，搞死很多鱼类、珊瑚礁；高级星际文明拿银河系某个悬臂做实验，就会毁灭无数个星系。他们就这样像斗兽棋一样思考——他妈的斗兽棋，而且是一个不会回头的斗兽棋。你比我大，我比他更大，比他更大，很无聊。

这好蠢，我真觉得这是小孩思维。因为他没有意识到一点：有限性。存在的意义在于有限性，有限性就是窗口期。

这个窗口期不仅仅像刘慈欣在《三体》最后写了一个小宇宙漂浮在纯空间里，里面有一条鱼在飘——不是这个意思。窗口期指的是主体化的生存，有第一人称意识的主体化的生存。它的发生学、整个历史要有意义，而意义本身需要在差异性的符号系统里，在系统差异性的系统里。这个差异性系统要能够相对稳定地维持它的差异，所以它一定会设立自己的边界；它有一种本体论力量会设立边界，比如设立认识论边界：我的符号系统就不表达你了，你有什么比我更屌的，我当你不存在，我不表达你了。你要明白一点。我举个例子，我举个例子。

比如有一个超强的核子风暴或太阳风暴，一瞬间把人类文明都毁灭掉——我假设，举个例子。一瞬间把人类文明都毁灭了，整个人类体验、人类叙事全都消解掉了。这个时候符号系统就不再符号化了，it no longer symbolizes it。一个差异性的系统、一个稳定差异系统被摧毁了。在这种条件下，后面那个悲凉凄惨的结局不被符号化，它没有任何意义，没有符号系统注册它，没有一个叙事学框架，没有一个一字头的场域让悲剧发生，没有谁在见证悲剧。悲剧是无人见证的，悲剧的悲剧性就在于悲剧是无人见证的。在这种情况下，你说这里有痛苦或者有什么希望，没有任何意义。你明白吗？

所以场域论上，我要给你写一个“一”。场域论上的“一”意味着这些宇宙悲观主义者、这些蠢人、笨蛋，他们会觉得宇宙是一个能级比拼场。能级越大，高能级就干死低能级；高能级干死低能级就有悲剧，低能级扰乱高能级也会出问题。你懂吗？能级的一个比拼场。为什么他会认为是能级比拼场？

因为它是在 1112 里面体现出来那种上升性：纯空间、纯时间没什么能量，然后有了物质、有了原子，能量、能级就高了；然后有序度高了，变成细胞生命，有序度越来越高，又变成动物，自我系统的复杂度越来越高，功能性越来越强，whatever。能级比拼场就是有序度高的维度。比如细胞状态的生命只能控制地底熔岩、太阳光照这些能级，蛇皮能级，几百焦、上千焦、几焦耳、零点零几焦耳；但如果生物很屌，可以造核电站，它控制的能级就很强，可以控制零点零几个行星那么大的能级。有序度越强，控制的能级就越强；智慧性越强、越复杂、越高级，能控制的能级就越强。能级比拼场是一个文明斗兽场，可以看成文明斗兽场。文明之间的斗兽场本身不文明，很不文明。

但问题是你要明白：宇宙本身这个场是怎么来的？宇宙这个场本身是怎么来的？你不去思考吗？You want to think about it? 这个斗兽场他妈的怎么来的？这个斗兽场的符号化、它的涌现，不需要本体论支撑吗？它背后有本体论在支撑这个宇宙的涌现，就是这么一个能级比拼场、大战场。而且更进一步，这个场的显现要经由主体中介。我们就是看到所谓的弱人择原理：因为我已经体验到这个世界存在了，所以它已经是；弱人择原理是个幸存原则。我的存在可以回过头去把这个宇宙当成一个有能级、有比拼梯度的场所。

但无论如何，1114 认为宇宙是一个能级比拼场，而能级是无限扩张的，至少对人类来说，或者对于我们的智慧维度水准来说。我们这些主体性都是第一人称化的，有生老病死、爱恨情仇，智慧复杂度没那么高，能控制的能级就那么点：发个电、烧个煤、烧个火，能让我们吃穿不愁、玩玩电子游戏，就这能级了，再高没有了；顶多搞个核弹，风暴来了，核弹的能级不如气旋风暴的千分之一。我们很无力。可是他觉得，宇宙法则当中没有一个法则为我们这些渺小的、有限的主体撑腰，没有一个法则为有限的人类主体撑腰，没有一个法则为在中介整个世界、用意识体验让叙事让场上演一幕幕历史的有限人类主体撑腰。我们作为他的中介、作为他的观众或体验者，是他实现自己的中介。你学哲学的不懂中介这个术语，太笨了，我受不了。

我要说的是，1114 觉得这个场是先有的，后来在场里慢慢通过进化过程派生出一个意识。我们只是他当中的一些小观众，或者小小道具组的成员，或者剧场里的一些小人物。当剧场上演更高级、更厉害、更屌的东西时，我们就被无情抛弃、被干死；然后更高级的东西又会有更高级的上演，又再把它干死，又更高级又把它干死。没有一个力量束缚它的能级无限往上拉，没有一个力量在宇宙量的增长上、毁灭力上限制它，它的量的增长是无限制的，没有力量在限制它，就会让它毁灭、让它干死。其实没有力量在约束它，no power is restricting this destructive 毁灭性力量。

没有另外一个力量在约束这种毁灭性力量。因为在他看来，能够约束这种毁灭性力量的不就是更屌的一个力量？既然可以约束它，那它也可以毁灭它。这个力量可以约束它、让它稳，就像一个温情的动物园饲养员，或者一个温情的培养皿、细菌培养皿的教授：“我可以让细菌多繁殖几代，现在不干死你，但总有一天要把你干掉。”他再有更高级的，又看这些教授、这些人类群体，又是一个培养皿里的细菌：“我现在不管你们，你们快速繁殖繁衍，但我总有一天会把你们干掉。”可以约束它、维持它，但是也可以毁灭它。在这里他就不停设定有一种任意，或者有一种无限增长的东西。

这个无限增长来自 1113。1113 本来应该是幸福的增长、快乐的增长，现在到 1114 变成什么增长？恐惧的无限增长、被害妄想症、绝望的无限增长。你总是好像抓到一个东西：人类掌控了什么反物质，还有更屌的；人家直接把空间维度又怎么样；还有更厉害的，人家直接把宇宙叙事学维度怎么样，whatever。他们没有意识到，这些力量不是同质的。他们的问题是，他们设想这些互相制约的力量是同质的，只不过一些东西更屌、一些东西更弱。所以他在本体论上的“一”就是：这些力量本质上都是能量、能级下面的量，是让场域里东西的性状发生变化的力量，是让场域里寄存之物的描述状态发生变化的力量，就是话语权。说穿了就是话语权。

因为如果我们把这个场看成一个符号系统，那么在这个局部空间里有没有一颗原子？有的能量说有，有个能级；有没有更强的能级？有更强的能级；没有，就是话语权的争夺。作为符号系统的一个宇宙，你们意识到，在物理主义框架之下，宇宙变成一个符号系统。那么谁的智慧更屌，或者谁的能级更厉害，驾驭的能级更厉害。一种秩序，比如弱相互作用力，对于某个尺度里的一些空间褶皱，它的定义权就很弱；强相互作用力较强一点；电磁就更强；有的地方强，有的地方弱，它就变成斗兽棋。我觉得这东西真的很恶心，我要呕。你知道吗？因为这个很蠢。

你没有意识到，这些东西不仅不是同质的，而且它们之间在形式结构上是互相制约的。但这些笨人以为，决定这些性状的——决定这个光是红色、那个光是蓝色，决定这种能量现象是声音而不是光，决定这种能量现象是这个空间而不是粒子，决定这种能量现象是什么什么——通通只是他们那个秩序强弱与否，或者它在数学参数上是多一个零还是少一个零的问题，就是一个加减法问题。说穿了就是一、二、三、四、五、六、七、八、九、十，无限延续下去。这个是两百七十九的算法配置，所以它能一般般；另外一个是一亿六千七百九十六万什么乱七八糟的力高级配置，所以它又把整个空间场重新定义了，强定义。

这个本体论说穿了，就是物理主义者、科学实在论者幻想不同的物理秩序或不同的科学秩序之间有一个话语权强弱问题。所以驾驭话语权更强的秩序，比如反物质、暗物质，就更屌，能级更强。我们人类只能驾驭裂变、聚变这种话语、这种秩序，所以能级一般般，搞不定，是吧？写小说都写成这东西：谁大谁小，谁家的爸爸强，谁家的妈妈弱，这种小孩在地上打滚的玩意儿。你真觉得这种科幻小说有什么技术含量吗？

这都是毫无政治经验、毫无反思性、对符号学结构、意识结构、精神性结构、精神性要素之间的张力都没有反思性的人才会搞出来的东西。他会把现实现象通通同质化成能量所导致的。在认识论上，能量导致出来的什么呢？就是主观主体的那种感觉，能量导致出来的感觉体验。认识论上就是主体性、人主体性的维度；主体就是一个感觉体验的维度。能量决定你的感觉，决定你的体验：能级高就可以把你的感觉弄成痛苦，或者把你干掉，让你没有感觉，剥夺你的体验；能级低一点，你的体验、你的感觉就受制于那个更高能级。

然后一切感觉、一切体验都是能量，都是一些物理秩序在它的场里发生作用，驾驭、统御这些能量，让这些能量具有某种性质，比如光的能量。在局部的时空场里，我要组织起光的能量，就是有什么玻色子产生什么光子，乱七八糟的；这边我要搞出一个失衡的、不对称的规范场，就搞出另外一些能量，让里面产生一些效应。你的所有一切效应，归根结底都是一些秩序，就是不同能级的、有的屌有的矬的秩序，在同样的时空框架之下。甚至说这比时空框架还要厉害：有的能级强，就可以搞 n 个时、n 维时空、n 维时间、n 维空间，开始玩这种花活。你只有两维空间一维时间，太弱了；我有一千维空间一千维时间，把你拉满、把你干死。我操，whatever。I feel this stupid。

我觉得这种东西背后有一种很顽固的愚蠢性。当然，时间不能有多个维度；时间性如果搞一千个维度，整个叙事结构就崩解了。时间维度顶多有一个。在他们这个将死的数理化框架里，由于它是数学化的，由于它的本体论过于数学化，所以导致它没有本体论了，它不理解本体论为何物。They no longer understand what is ontology。他们不再知道本体论为什么了。

他们尤其不知道本体论里面的一些环节，比如定在（Dasein）这个环节，即事物较为稳固的一种存在，或者一种规定性。或者在这个场域里面——这个时候还不能讨论场域。比如在黑格尔逻辑学里，在存在论走向定在的时候，你不能讨论场域，不能讨论有个时空场；这个时空还是量化的，是定维的，维度是确定的。时空场这个玩意在哲学上太靠后了。这玩意是你白嫖的吗？神经病啊！你凭什么直接就有这个东西？

你要说它有，你就要有认识论发生学机制；你要为你的认识论、为你对它的那种凭空的符号化描述做辩护，这些都是需要建基的。你不能直接白嫖，说我的第一人称体验告诉我有时空场、有空间场。大哥，这个符号学秩序是通过符号系统的流动意义链、意识的体验感受、第一人称体验来不断支撑它、不断充实它，让你觉得有个时空场在那边；它要不断维持，要通过生命活动、思维活动、认识活动、认知活动不停去设定，它不是白嫖的。我一刀把你砍了，你晕过去了，你告诉我这个时候对你来说有没有时空场，有意义吗？
