# 【道家哲学】庄子·大宗师\-第一步：外天下；从墨子、宋荣子、慎到，到老子、关尹子、庄子；从心怀天下的伦理热忱，到神游物外的形而上学

庄子本人对于这种外天下、涵养天下、涵摄天下的状态，并不是特别喜欢。他对天下并不是一种包容的姿态，而是虚涵天下的姿态。那么，庄子对天下究竟采取什么姿态呢？

是一种讽刺的姿态。他称之为“以天下为沉浊，不可与庄语”。他认为天下沉浊、太混乱、太混浊，不能用大话去描述、夸赞或夸耀它；而应该通过讲寓言、通过讽刺，用寓言故事来对世事进行批判。看上去这叫作“不谴是非，以与世俗处”。

表面上“不谴是非，以与世俗处”，但实际上，庄子并不想跟世俗玩同一套东西。他追求某种超越世俗之外的生活姿态，即“上与造物者游，而下与外死生、无终始者为友”。

所谓“外死生、无终始者”，其实都是哲学研究的对象，是哲学的内容，是本体论架构、本体论结构，也就是研究哲学命题。说穿了，所谓“外死生、无终始者”是什么东西呢？不就是空间、时间，还有某种生命、原初力量、起源性力量等等吗？以这些东西为友，他看上去“不谴是非，以与世俗处”，但实际上已经在谴是非了。他认为世俗天下沉浊，不可与庄语，没必要跟他们把严肃的东西说清楚，所以他就讲一些寓言讽刺故事。

这也是一种外天下的姿态。他完全不服从天下当中的符号学秩序，而是自己设立一套自己的寓言体系，也就是他自己的符号学体系。通过这套符号学体系，他获得与形而上学层面的事物交流的方法，获得某种超越凡俗世界的生存状态或生存方式。外天下，这是一种哲学路径。

还有最后一个路径是惠施的。惠施通过什么？通过他的聪明智慧，即“惠施多方”，通过辩论，提出很多矛盾性的论题，比如“无厚不可积也”。

什么叫“无厚不可积”？厚和积是彼此相互依赖的概念。有厚的东西，一定需要东西来积；但你必须先有东西积累起来，才会有厚这种东西出现。所以这两个东西谁先谁后呢？到惠施那里，就是“无厚不可积也”：世界上不存在厚的东西，所以不能积，因此不存在广延。厚就是广，积就是延，厚积可以翻译成广延。这两个东西在概念上、逻辑学上相互依赖：你要有厚，前提是先积累起来；但没有厚，你又怎么积呢？反过来，要有厚一定要有积，要有积一定要有厚，于是又回到先有厚还是先有积的问题。

所以惠施说“无厚不可积”，他就是通过这类逻辑学游戏，把世俗当中的符号学体系全部颠覆掉。

庄子把这一路径叫作“遍为万物说”的姿态。他说了很多话，自己建构了很多归谬，归结出世俗天下那种符号学当中的矛盾，然后“遍为万物说”，把天下万物都说尽了，把它们的矛盾性都归于其中。在这个意义上，他也实现了一种外天下。

庄子对他的评价是“散于万物而不厌”：他的智慧分散在一切事物当中，却还不满足。又说“卒以善辩为名”。“善辩为名”一方面有出名的意思，另一方面，他提出的一些逻辑命题也可以叫“名”。

“惜乎惠施之才，骀荡而不得，逐万物而不反。”最重要的评价是“逐万物而不反”：他的主体智慧、知性或知性能力一味追逐万物，不懂得自我返回，不懂得返回到自身当中去。这种姿态虽然看上去外天下了，但在庄子看来，这是没有办法返回的。

你虽然外于天下，但就像打怪、丧尸围城一样，不停地打来打去，来一个打一个，四面八方来就四面八方打。惠施的做法就像禅宗机锋：东边来东边打，西边来西边打，旋风来旋风打，来什么打什么。他用自己的智慧、辩论和诡辩式的逻辑学，把所有名相都打掉。但在庄子看来，这种努力是令人绝望的。

庄子说惠施“逐万物而不反”。因为对天下来说，对天下那么多东西来说，惠施又算得了什么呢？庄子说：“由天地之道观惠施之能，其犹一蚊一虻之劳者也。”他就像蚊虻一样，太小了。所以庄子认为，这种知性者路径、聪明的路径，想靠它来外天下是很难的。

想用逻辑归谬法把天下的一切论断都归出问题，然后排斥、拒斥掉，这太累、太难了。庄子形容惠施是“穷响以声，形与影竞走”：就好像用声音想让响声静止，用自己的声音让外面的声音全停住；又像身体和影子相互竞走。这种劳作是无穷的，没办法彻底实现，只能不停对每一个名相做辩论，做诡辩式的驳斥。他的努力其实也是外天下，外天下的俗见，或者说外天下背后那些背景性的秩序、符号学秩序；他就是通过不停设立悖论来做到这一点。惠施有那么多悖论，你们可以自己去看，我在这里就不细讲了。

前面那些步骤都是导引性的，最后三个步骤才是庄子、惠施和老子这三种模式。要成为老子那种外天下的模式，你的社会地位要比较高，不容易受伤害，同时在精神上也可以抵达。但我觉得更重要的是，前面三种伦理姿态你都要体验过。这样，最后那种虚涵天下、虚怀若谷的虚怀，才不会有任何个人前反思的伦理执着，才能真正做到“空虚不毁于物”。

外天下这个过程，我认为不是很有必要，但你们可以借此反思一下。大部分人并没有真正动手做过。“道术为天下裂”，裂开来才叫作“术”。很多人没有真正实践过，没有在行动中坚持过自己的伦理姿态，更遑论反思了。在这个意义上，我觉得外天下这个过程有必要：你要和天下拉开一点距离，而这里每一个姿态都是和天下拉开距离的。

第一个是墨子，天下人都不喜欢他，都承受不了他，但也会喜欢他、受不了他。然后宋荣子太圣母了，其他所有人都觉得他讨厌，觉得这种圣母烦死了，但他还是要坚持，他是不近人情的。所有这些姿态都不太近人情。近人情的可能只有那个……对于他个人体验来说是不近人情的，这个人肯定是个怪人；但他和别人相处的时候，当然是体贴别人的人情的，我是这个意思。他自己的行动是异类的，这些人的行动都是异类，都是“古之纯人”，是很纯粹的行动者。

老聃的那种姿态是一种理想，但也可以去尝试，就是完全不持伦理姿态，任万物而自化。那么如何抵达那一步？前面三步你必须都去尝试，发现都行不通，才能破掉自己最后一点点幻想，才能使自己不具有一种伦理姿态，“建之以常无有”。不常坚持自己的伦理姿态，不去干涉，不去毁伤万物，不去妄加评断其他事物。这种状态需要锻炼才能锻炼出来。

光像田骈、慎到那样去搞齐物论，还是不算的。你仍然有隐藏的相对主义，它隐藏了一种标准，隐藏了被排除在这个列表之外的东西。它有所“魍断”，不免于“魍断”。所谓“常反人，不见观，而不免于魍断”。我认为“魍断”的意思是：这种平等主义实际上有很多东西是不近人情的，它没有把那一部分考虑在内，这就叫“魍断”。就像杀鱼时把鱼头鱼尾砍掉不要了，差不多就是这个“剜”的意思；不是成玄英说的那种“魍断”是无头无脑、没有棱角的意思，那种理解太过了。还有“其所言之事不免于非”：他所坚持的那些好的东西不免于非，其实还是包含着对其他事物的否定。我觉得表面上看，他“公而不党，易而无私”，是田骈、慎到、彭蒙的那种平等主义，以及“决然无主”的状态，实际上是有隐藏的私货的。

你只要克服这种虚伪的、比较虚伪的平等主义和相对主义立场，下一步就能体验老子、老聃和关尹子他们那种真正不去设立，或者说是没有能力设立的状态。其实那时周王室衰微，他们不是不去设立，而是没有能力设立，老实说只能放权。这些东西我们可以参考借鉴一下。因为他们都是前现代，不知道社会当中的天下之道，也就是外天下有外天下之道。这可以看成外天下之道、本体论，或者走向形而上学，或者走向一种智慧游戏，不停驳斥一切世俗见解。还有天下之道本身有它的符号学症结，也就是 class struggle、capitalism。这个症结是你一定要去应对、一定要去反思的，但这些前现代文本没有能力反思到。所以我们也不需要苛求他们。这个东西你可以看着玩。但第一步，这些步骤，具体讲究这些步骤，最后还有两个分支可以让你选。

你可以选择像庄子那样搞语言学游戏，也可以选择像惠施那样搞逻辑学游戏，不停驳斥世间之道，驳斥世间符号学结构中的不一致性，然后追求一个更高的形而上学维度，叫作“与外死生、无终始者为友”。这是你可以体验到的；如果你学哲学，确实有这个能力。但这种伦理姿态是不是值得追求？好，那么就讲到这里。外天下是第一步，是道家特别是庄子修行的第一步。
