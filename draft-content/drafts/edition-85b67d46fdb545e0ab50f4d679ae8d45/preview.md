# 【三分钟哲学】【辩证法】鸡生蛋？蛋生鸡？

我们今天来讲辩证法的第一个小专题，也就是非常有名的鸡生蛋、蛋生鸡问题。我直接说正题：鸡生蛋，是鸡把蛋生出来的。反题是蛋生鸡，是蛋把鸡生出来的。

那么，错误的合题，也就是庸俗辩证法的合题，既不是鸡生蛋，也不是蛋生鸡，而是把两者加起来，变成鸡生蛋、蛋生鸡、鸡生蛋、蛋生鸡……子子孙孙无穷匮也，互相循环。这是标准的整体主义理解方式，彻底错误。正确的合题很简单，就是鸡生蛋，合题还是鸡生蛋。

问题在于，我们所有的辩证法（dialectic）都包含一个重音的转换。第一句话，也就是正题，是鸡生蛋，重音在“鸡”上；第二个反题是蛋生鸡，重音在“蛋”上；错误的合题是鸡生蛋生鸡生蛋生，重音总在这两个所谓的主体上。辩证法的合题告诉你，这个否定是一个虚假的否定，因为正题本身就包含了对自身的否定。也就是说，所谓鸡生蛋，我们把重音从鸡或蛋挪到“生”上，就能看到这个辩题内在的问题。

如果我们把重音放到“生”上，你就会开始思考：什么叫鸡生蛋？你应该想想，实际上是鸡把蛋排出来、创造出来的。鸡生了蛋之后，鸡还是鸡，它自己没有本质性的变化。所以这个“生”是创造者和被创造者之间的关系，就是 create。

那么，把重音移到“生”上之后，你再看所谓的反题，也就是蛋生鸡里面的“蛋生鸡”，它不是蛋 create a chicken，不是蛋创造了一只鸡，而是 become——蛋变成了鸡。

所以，你把重音移到正题中间那个字“生”上，它在反题里也没有获得重音、没有被重视。正题和反题当中的差异，被这个虚假的合题掩盖了，变成“鸡生蛋生鸡生蛋生鸡生蛋生鸡”，“生”不停重复，我们误以为它是同一种“生”。这就是虚假的辩证法，它把差异抹掉了。

真正的辩证法要把这个差异凸显出来：鸡生蛋，这个“生”意味着，鸡把蛋生出来之后，就有了两个东西，一个鸡，一个蛋；但蛋生鸡时，蛋变成了鸡，之前的蛋就不存在了。或者说，所谓的蛋只是鸡的一个存在状态，是它一开始的存在状态。所以它的合题是这个鸡生蛋。
