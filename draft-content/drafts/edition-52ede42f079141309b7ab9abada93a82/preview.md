# 【现实观察】关于编制，我们应该拥有怎样的理想，如何逐步实现这些理想

我们要倡导一种关于编制的价值观：获得编制，类似获得铁饭碗，这没什么。当然，你更有安全保障，但本身从铁饭碗里吃饭，并不是值得荣耀的事。这不是荣耀。从铁饭碗里面吃到饭，这不是荣耀。说得简单一点，这不是荣耀。

那么，获得铁饭碗之后，什么是荣耀呢？生产优质的公共服务。你们编制实际上是机关事业单位人员，那就要生产优质的公共服务。生产公共服务是基本，生产优质公共服务才值得荣耀。这是零阶，这是一阶。那么，进一步值得称赞的是什么？

是带动那些仅仅想从铁饭碗里面吃到饭的人，一同生产优质的公共服务。我觉得这是关于铁饭碗的一个价值观。那么，这个优质怎么来评判呢？

评判优质，第一是有利于人民、一线劳工大众；第二是有利于食利者和一线劳工大众、人民之间关系的改善。这个改善不是缓和，而是使他们的关系转向对一线劳工大众有利，让关系得到改善，最终有利于一线劳工大众的收入、家庭、地位和话语。

这就是评判优质，归根结底就是为人民服务，这很值得称赞。第三点是带动一同生产优质的公共服务，我觉得更值得称道。但这个时候下面有一个歧路了。

你不仅自己有编，还能帮助别人，相当于开府释事、提拔愿力一样，你还可以提拔别人。这个字我读错了，不管它。这个时候有一种价值观：你是个大人物，不仅自己有编，还能让别人有编。这就叫提拔愿力、开府释事。

开府释事、提拔愿力，我认为这不是值得骄傲的，这不是值得骄傲的。哪怕你是一个身居高位的人，可以带一个班子，或者一人得道鸡犬升天，这也不值得骄傲。那么，值得骄傲的是什么？真正值得骄傲的、再进一步的是，使得无编胜有编。

如果这个编制成为某种既得利益，板结了，甚至说这个利益格局板结了，你如果能够通过努力，使得无编之人做同样的工作、进行同样的劳动、具有同样的社会贡献，但是能够使得无编和有编得到的效果、得到的反馈回馈，至少差距能够缩小。这样就是激发了社会的活力，让无编和有编在社会共建上是一样的。就相当于两个都是给别人做安保服务的，一个是无编的，一个是有编的，你可以等而视之，让同样的劳动有同样的价值，能够缩小差距，能够让这个差距缩小，能够让这个都体面、都得到尊重，不仅是利益，还有同等的尊重。

同等的尊重，然后克服这里面对编制的盲目崇拜，也就是说，我们可以清除官僚主义崇拜、官僚主义的毒素，让有编和无编的、生产公共服务的，或者说为市民群众、为老百姓提供保障的、制度性保障的，都能够得到同样的对待。

当然，无编和有编也涉及学术类人才。比如研究生写论文被导师窃取或占用，但你作为系主任，能够去调和他们的关系，让这个研究生做主要作者，让他做一作，差不多就是这个意思。

那么这是值得称赞的，这是了不起的，不仅是值得称赞，这是了不起的。如果他能够制度性、系统性地实现这一点，如果一个有权有势的人物能够制度性、系统性地实现这一点，那他是伟大的。这样的人物是伟大人物，他是伟大的。

所以在这个意义上讲，我认为，能够在改革时代让农民工进城发展。之前农民工都是不允许进城的，要开条子，进来之后你也没有活干；能够允许农民工进城打工，这在某种意义上就是使得无编和有编之间虽然同样都是工作，但差距被缩小。

当然，你要说，另外一些有编里面的劳苦大众和那些有编的身居高位的，他们的利益分配就不公平了。那我们考虑一个时代大潮里面的人数，如果我们实在要算利益总量，那么确实有伟大人物，在这个意义上是伟大，但只是从这个意义上来讲是伟大的。所以，这种伟大需要进一步继承。

我们拒绝，从原则上拒绝一些既得利益将自己和制度性的认定捆绑到一起。原则上不认同这一点。我们要明确说，原则上不认同既得利益，以及扩大既得利益的那条路径或者那个手段；这个手段不应当和一种制度性的任命或者制度性的身份固定捆绑到一块儿。

当然，这完全是理想主义的。那么我们这里当然要问，为什么今天讲这种理想主义？因为我们就是围绕着编制做一个理想主义价值的等级阶次认定。它越来越理想，按照这个方向是越来越理想。

所以我希望在这个时候叩问一下各位：你想要去获得编制、考编，那你到底是要追求什么呢？最起码的，你的目的是要生产优质的公共服务，而不是从铁饭碗里面吃到饭，然后过上安逸的日子。我希望你考到编制之后，更接近人民大众，为人民大众提供优质公共服务，而不是更远离他们。

这个需要弄清楚一点，也不要因为有一个铁饭碗，然后可以事少、钱也不算少，就过上安逸的生活，特别在一些县城、在一些小城市，朝九晚五，那生产的公共服务是极为有限的，或者说极为粗劣的。或者说，这个生产的公共服务并不是对外的，不是向下的、向民众的，而只是一些繁琐的、无聊的写文案，写重复的空话、形式主义空话，做材料，做这种事情。

我希望不应当过这样的日子。这是关于编制我的一贯立场。我们具体问题具体分析，不会一耙子全部否定，也不会说全部肯定，并不意味着有这么一个身份就代表符合我们追求社会主义、追求人民至上的立场和理念。但是，这是一条实践的路径，这个路径有它的方向性，无论如何有它的方向，这个方向性归根结底来自于它的人民性：为人民服务，保障人民群众的利益。

确保人民群众的权益得到实现。然后还要反过来，这个方向性还具有某种自反性。反过来，它最伟大的一点，就是要使得拥有这些行政性认可和制度化确证的编制或特许权的这些人，与同样生产公共服务的人——我举个例子，外包出去的服务人员——之间，有编服务人员和无编服务人员的待遇差距能够缩小。你不缩小这个待遇，不就是两伙人干同样的活，总产出一百万，但是一伙人拿走八十万，那这是某种可以说是具有剥削性的。我们要实事求是讲，这具有剥削性，要缩小这里面有可能存在的差距，至少从结果上来看。

我们对这个东西，最终要承认一点：在行政共同体里面的官僚主义色彩，以及这种有编无编的不平等关系，它是资本主义的残余，我们需要努力去克服、去肃清。这是我的一贯立场，我也大胆地敢把这个立场讲出来。我认为我们社会、我们共同体的最根本立场是认同我所说所讲的，但只是在立场上，在价值观上，在主流意识形态上、主导的意识形态上，我们必须说清楚这件事情。
