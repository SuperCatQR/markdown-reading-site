# 【主义主义】我思形而上学（2\-3）——笛卡尔的梦魇，斯宾诺莎的宁静，科学的摇篮，形而上学的坟墓

二杠二的辩证形而上学，都是通过在 metaphysics 的世界里、在形而上学空间中，产生出一些反现实的、与现实不一样的符号性机制。

这些反现实的符号性机制或规则，随后被叫做伪本体论化。伪本体论化之后就可以认识论化，认识论化之后还可以目的论化，目的论化就得到一些伦理学。

这个形而上学空间最终其实生产出伦理学调配的一些符号性指令。这些伦理学符号是用来干什么的？当然是用来缓和矛盾的，它的目的就是缓和矛盾。因为谁会最追求形而上学空间？苦难中的人，苦难中的人！苦难啊！为什么会敞开形而上学空间？苦难，甚至是仇恨，是这些东西在引导这个空间悬在上面。

这是知识阶层，是 upper class 的达摩克里斯之剑，是 upper class 的达摩克里斯之剑。

虽然他们受过教育，更有符号学优势，可以去调配苦难和仇恨中悬起来的形而上学空间，但他们并不能完全支配它。他们要驾驭它，就必须想尽办法让这个回路最后生产出一个目的论化的伦理学体系。这个体系能怎么样？一方面要缓和矛盾，另一方面还要对他自己有利，让他赚到，同时又能缓和矛盾。所以这整个努力、整个尝试都通通失败了。

他什么时候成功呢？那么我们要讲下面一个了：二杠三。二杠三这个题目叫做我思形而上学。

我思形而上学这个时候就把本体当中的一个东西抬到台面上来，就是意识、思维。它把心抬到台面上，让它成为一个本体。以前的本体是这几个维度：存在和不存在。这是一个受形而上学支配的维度。

还有一个是超越、超绝的存在。超绝的存在不受形而上学支配，或者它就是支撑起形而上学本身的那个力量，是一个本体性力量。那么最后这里必须要有一个意识和思维的维度，它作为一个纯粹的观看者，调和这两者的矛盾。

所以这个纯观看者实际上是认识论维度，后面就是认识论的维度。认识论维度介入到这里面，认识论的维度把自己本体化了。它的目的是什么呢？

它的目的是使这个本体论的框架更加闭合。你主体就会陷在这种第一人称观察里面，主体性就陷在第一人称中，而不会变成后面目的论当中的那些激烈的争端。主体不再去激烈地争执这个东西，而是陷入对本体性事件的观察当中。这时主体会说：我们现在就直接说，现在告诉你，认识的维度、观察者观看的维度，它也是个本体性的维度了；你现在只要直接去体验这个本体性的维度就行了。那么这个时候才会产生现代科学。我跟你讲，这东西产生现代科学。

这个纯观看者的维度代表一种什么立场？代表一种拉开距离。所以它的代表人物应该是笛卡尔，Descartes，一种拉开距离的主体性姿态。它为什么能拉开距离？因为在这个二杠三的本体论框架里面，主体已经注册进去了，它可以正当地拉开距离。现象学也是这样：我们可以拉开距离，拉开距离不限于泥淖之中，不限于泥潭之中，这是无条件的，是个本体论假设。

有人要说：哎，你凭什么和现实拉开距离？你不是现实的一部分吗？这是本体论假设。也就是说，我意识、认识者、我思这个东西，它什么也不是，它就是本体与其自身拉开的那个距离。你不是说这个距离不可能吗？我现在告诉你，这个距离就是可能的，因为我们的意识的存在、我思、我的精神就是这个距离。我就是这个距离，这个距离本身是本体性的。这个距离本身，作为符号学当中的一部分，定义了何为可能、何为不可能。

现在你们懂了吧？就是说认识论的维度把自己本体化了，成为规则制定者了。你不能再说：哎，凭什么解释学循环？哎，你的我思怎么可能和这个世界拉开距离？你把握自己，还不是依然在这个世界里面把握自己？你就算拉开距离，还不是依然在这个世界里面吗？不，二杠三的这个形而上学恰恰要告诉你：我意识、我思，它什么都不是。它不是一个无力的、孱弱的、悬空的东西，不是像一层膜一样的一个认识论维度。它不是一个认识论维度，它这个时候已经变成了主体性维度，一个本体性的维度了。它就是这个世界创造出来的、本真地创造出来的这个距离，就是它自己和自己创造出的这段距离，它自己和自己拉开的这段距离，它自己悬空的这段距离，悬在空中。

所以在这个意义上讲，这样一搞，你会觉得这个我思形而上学有一个很诡异的地方。就在二杠二里面，二杠二里面有一种存在和不存在的区分，或者叫有和无的区分。这里其实是凡俗的，或者说形而下的；那里是形而上的。那么这里面是什么？它是存在，就是一个有等于无的、不可思议的东西。它既是有，是至高至精纯的存在，又是无，是最虚无、最虚无缥缈的，也就是说它突破了有无的二分。形而上学当中的那个本体突破了有无二分，它使得有无两者结合到一块，同时是有，同时是无；它是最高级的无，也是最高级的有。这是在二杠二里面设立的，二杠二里面会这样设立。这个东西不是太一吗？太一生水，太一和水都算这种东西。它在有无的二分之前。
